字符串扩展

数值解析、替换、填充、分割——对标 C++ std::string 的解析能力。

导入写法CN

导入 字符串扩展::{字符串转整数, 替换, 分割};

数值解析

三个解析函数把字符串转为数值，失败（空串/非法字符）返回 错误(6)（无效参数）。解析按 UTF-8 字节进行。

解析.cnCN

导入 字符串扩展::{字符串转整数, 字符串转浮点, 字符串转布尔};

函数 主() -> 整32 {
    结果<整64, 整32> 整值 = 字符串转整数("12345");
    如果 (整值.正常) { 打印(整值.值); }        // 12345
    结果<浮64, 整32> 浮值 = 字符串转浮点("3.5");
    如果 (浮值.正常) { 打印(浮值.值); }        // 3.5
    结果<布尔, 整32> 布值 = 字符串转布尔("真");
    如果 (布值.正常) { 打印(布值.值); }        // 真
    结果<整64, 整32> 坏 = 字符串转整数("12甲");
    如果 (!坏.正常) { 打印("解析失败"); }
    返回 0;
}

输出：12345 3.500000 真 解析失败

替换与填充

返回值均为拥有型字符串（调用方 RAII 自动释放）。替换按字节偏移处理；目标为空串时原样返回。

替换

函数 替换(字符串 输入, 字符串 目标, 字符串 替换为) -> 字符串

把 输入 中所有出现的 目标 替换为 替换为，返回新串（输入不变）。内置安全计数器（上限 100 次）防自包含死循环；目标不存在时返回原样副本。

参数类型说明
输入字符串原始字符串
目标字符串被替换的子串（空串=原样返回）
替换为字符串替换成的子串

返回　替换后的新字符串。

替换.cnCN

字符串 新 = 替换("甲乙甲", "甲", "丙");
打印(新);

输出：丙乙丙

分割

C 风格输出参数边界：结果写入调用方准备的 字符串* 数组。数组长度须为编译期常量（数组声明限制），故以「数组+长度」传参。切分出的每个元素是动态分配串，用完须逐一 字符串释放。

分割 不安全

不安全 函数 分割(字符串 输入, 字符串 分隔符, 字符串* 结果数组, 整64 数组长度) -> 结果<整64, 整32>

按 分隔符 把 输入 切成若干段写入 结果数组，返回实际段数。数组装不下剩余内容 → 错误(6)（已填元素由调用方释放）；分隔符为空串 → 错误(6)。

参数类型说明
输入字符串原始字符串
分隔符字符串切分用分隔串（不可为空）
结果数组字符串*调用方准备的输出数组
数组长度整64输出数组容量

返回　正常(实际段数)；数组不足/分隔符空 → 错误(6)。

分割.cnCN

字符串[8] 段;
结果<整64, 整32> 数量 = 分割("甲,乙,丙", ",", 段, 8);
如果 (数量.正常) {
    整64 i = 0;
    当 (i < 数量.值) {
        打印行(段[i], "|");
        字符串释放(段[i]);      // 逐元素释放
        i++;
    }
    打印("");
}

输出：甲|乙|丙|
