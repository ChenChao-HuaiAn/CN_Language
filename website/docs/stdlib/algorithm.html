数组算法

全部作用于原生数组/指针（非容器）。排序为冒泡（升序）；二分查找前置条件=数组已升序。未找到返回 -1。泛型函数要求元素类型支持 == 或 </> 比较。

数组算法.cnCN

导入 算法::{排序整64, 二分查找整64, 线性查找, 逆序, 计数, 最大元素};

函数 主() -> 整32 {
    整64[6] 数据;
    数据[0] = 5;
    数据[1] = 2;
    数据[2] = 8;
    数据[3] = 2;
    数据[4] = 9;
    数据[5] = 1;
    排序整64(数据, 6);
    整64 i = 0;
    当 (i < 6) { 打印行(数据[i], " "); i++; }
    打印("");                     // 1 2 2 5 8 9
    打印(二分查找整64(数据, 6, 8));   // 4（升序前提下）
    打印(线性查找<整64>(数据, 6, 7));      // -1（未找到）
    打印(计数<整64>(数据, 6, 2));          // 2
    打印(最大元素<整64>(数据, 6));         // 9
    逆序<整64>(数据, 6);
    打印(数据[0]);                    // 9
    返回 0;
}

输出：1 2 2 5 8 9 4 -1 2 9 9

排序整32 不安全

不安全 函数 排序整32(整32* 数组, 整64 长度) -> 空类型

对 整32 数组原地冒泡排序（升序）。长度为 0/1 时不动。

参数类型说明
数组整32*数组首地址
长度整64元素个数

排序整32.cnCN

整32[4] 值;
值[0] = 3;
值[1] = 1;
值[2] = 4;
值[3] = 2;
排序整32(值, 4);
打印(值[0], " ", 值[3]);

输出：1 4

线性查找

泛型 <类型 T> 函数 线性查找(T* 数组, 整64 长度, T 目标) -> 整64

从头到尾逐元素 == 比较，返回首个命中下标；未找到 -1。任意可比较相等类型可用（泛型单态化）。

参数类型说明
数组T*数组首地址
长度整64元素个数
目标T要找的值

返回　首个命中下标；未找到 -1。

线性查找.cnCN

整32[4] 值;
值[0] = 10;
值[1] = 20;
值[2] = 30;
值[3] = 40;
打印(线性查找<整32>(值, 4, 30));
打印(线性查找<整32>(值, 4, 35));

输出：2 -1

二分查找整32 不安全

不安全 函数 二分查找整32(整32* 数组, 整64 长度, 整32 目标) -> 整64

前置条件：数组已升序。折半查找，O(log n)。

参数类型说明
数组整32*已升序数组
长度整64元素个数
目标整32要找的值

返回　命中下标；未找到 -1。

二分查找整32.cnCN

整32[5] 值;
值[0] = 1;
值[1] = 3;
值[2] = 5;
值[3] = 7;
值[4] = 9;
打印(二分查找整32(值, 5, 7));

输出：3

长度整64元素个数
目标T要统计的值

最大元素

泛型 <类型 T> 函数 最大元素(T* 数组, 整64 长度) -> T

返回数组中的最大值。空数组（长度 0）是未定义行为——调用方保证长度 ≥ 1。

参数类型说明
数组T*数组首地址
长度整64元素个数（≥1）

返回　最大元素。

最大元素.cnCN

值[0] = 3;
值[1] = 11;
值[2] = 7;
值[3] = 5;
打印(最大元素<整64>(值, 4));

输出：11
