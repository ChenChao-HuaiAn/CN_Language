数学

八个浮点数学函数——映射到硬件/运行时数学库。

导入写法CN

导入 数学::{平方根, 幂, 绝对值, 向上取整, 向下取整};

浮点函数

参数与返回值全部为 浮64。三角函数以弧度为单位。取整函数返回浮64（不是整数类型），需要整数值时显式转换。

浮点函数.cnCN

导入 数学::{平方根, 幂, 绝对值, 向上取整, 向下取整, 正弦};

函数 主() -> 整32 {
    打印(平方根(2.0));          // 1.41421…
    打印(幂(2.0, 10.0));        // 1024
    打印(绝对值(-3.5));         // 3.5
    打印(向上取整(1.2));        // 2
    打印(向下取整(1.8));        // 1
    打印(正弦(0.0));            // 0
    返回 0;
}

输出：1.414214 1024.000000 3.500000 2.000000 1.000000 0.000000

平方根

函数 平方根(浮64 值) -> 浮64

算术平方根；负值返回 NaN（硬件语义）。

参数类型说明
值浮64非负实数

返回　√值。

平方根.cnCN

打印(平方根(16.0));

输出：4.000000

幂

函数 幂(浮64 底数, 浮64 指数) -> 浮64

底数的指数次幂。

参数类型说明
底数浮64底数
指数浮64指数

返回　底数^指数。

幂.cnCN

打印(幂(2.0, 8.0));

输出：256.000000
