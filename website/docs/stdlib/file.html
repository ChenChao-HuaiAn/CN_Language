文件

文件读写七件套——对标 C++ fstream；中文路径开箱即用。

导入写法CN

导入 文件::{打开文件, 写入文件, 读取文件行, 关闭文件, 文件存在};

文件句柄

句柄类型为 空类型*（C 层 FILE*）。打开模式：1=读、2=写（截断）、3=追加。句柄用完须 关闭文件。中文路径在运行时内部按 UTF-8 转宽字符打开（win 实测支持）。

文件句柄.cnCN

导入 文件::{打开文件, 写入文件, 读取文件行, 关闭文件, 文件存在};

函数 主() -> 整32 {
    结果<空类型*, 整32> 写口 = 打开文件("笔记.txt", 2);
    如果 (写口.正常) {
        结果<整64, 整32> 数 = 写入文件(写口.值, "第一行\n第二行\n");
        关闭文件(写口.值);
    } 否则 { 返回 1; }

    结果<空类型*, 整32> 读口 = 打开文件("笔记.txt", 1);
    如果 (读口.正常) {
        结果<字符串, 整32> 行 = 读取文件行(读口.值);
        如果 (行.正常) {
            打印行(行.值);                 // 第一行（行串已含换行）
        } 否则 { 返回 2; }
        关闭文件(读口.值);
    }
    打印(文件存在("笔记.txt"));           // 真
    返回 0;
}

输出：第一行 真

打开文件

函数 打开文件(字符串 路径, 整32 模式) -> 结果<空类型*, 整32>

打开文件返回句柄。模式 1=读、2=写（截断）、3=追加。

参数类型说明
路径字符串文件路径（UTF-8，支持中文）
模式整321 读 / 2 写（截断）/ 3 追加

返回　正常(句柄)；打不开 → 错误(错误码.文件)。

输出：已打开

读取文件行

函数 读取文件行(空类型* 句柄) -> 结果<字符串, 整32>

读一行；文件尾返回错误。返回为拥有型字符串。注意：返回的行串保留行尾换行符——直接输出用 打印行(行.值)（不再追加换行）；拼接/比较前可先 字符串修剪。

参数类型说明
句柄空类型*文件句柄

返回　正常(一行文本)（含行尾换行）；文件尾 → 错误(错误码.文件)。

读取文件行.cnCN

结果<空类型*, 整32> 口 = 打开文件("日志.txt", 1);
如果 (口.正常) {
    结果<字符串, 整32> 行 = 读取文件行(口.值);
    如果 (行.正常) {
        打印行(行.值);
    } 否则 { 打印("(到文件尾)"); }
    关闭文件(口.值);

输出：你好
