线程

新线程/并入线程 + 类型化互斥锁<T>——默认安全，宁严勿松。

导入写法CN

导入 线程::{新线程, 并入线程};
导入 线程::互斥锁;

线程基础

入口为函数指针 整64(空类型*)；实参按值拷贝进新线程（安全默认，无别名）。未 并入线程 的线程在 主 返回时触发运行时错误（宁严勿松）——每个线程都必须被并入。linux 真实现（pthread）；win 后端为运行时错误桩（路线图波次内）。

线程基础.cnCN

导入 线程::{新线程, 并入线程};

不安全 函数 作业(空类型* 未用) -> 整64 {
    静态 整64 计数 = 0;
    循环 (整64 i = 0; i < 100000; i++) {
        计数 = 计数 + 1;
    }
    返回 计数;
}

不安全 函数 主() -> 整32 {
    结果<空类型*, 整32> 建 = 新线程(作业, 无);   // 实参=无（豁免窗口）
    如果 (建.正常) {
        打印(并入线程(建.值) > 0);       // 等待结束并取返回值
    } 否则 {
        返回 1;
    }
    返回 0;
}

输出：真

新线程 不安全

不安全 函数 新线程(整64(*入口)(空类型*), 空类型* 实参) -> 结果<空类型*, 整32>

启动新线程。入口=函数指针（返回 整64、收一个 空类型*）；实参按值拷贝语义传给新线程。返回线程句柄。

参数类型说明
入口整64(空类型*) 函数指针线程函数
实参空类型*传给线程的实参（按值拷贝）

返回　正常(线程句柄)；创建失败 → 错误(错误码.参数)。

并入线程 不安全

不安全 函数 并入线程(空类型* 句柄) -> 整64

等待线程结束并取回其返回值（同步点=顺序一致）。每个线程句柄必须恰好并入一次。

参数类型说明
句柄空类型*新线程 返回的句柄

返回　线程入口函数的返回值。

互斥锁<T>（类型化句柄）

锁与受护数据类型化绑定——拿 A 锁护 B 数据的「锁错对象」错误在类型检查下不可表达（Rust Mutex<T> 字段私有同位）。受护数据在公开字段 值 中；上锁/解锁 显式配对（RAII 锁守卫在路线图中）。实例为对象句柄语义：跨线程共享同一实例即共用同一把锁。

互斥锁类.cnCN

导入 线程::互斥锁;

不安全 函数 主() -> 整32 {
    互斥锁<整64> 计数器 = 互斥锁<整64>(0);
    计数器.上锁();
    计数器.值 = 计数器.值 + 1;      // 受护区间内访问 值
    计数器.解锁();
    打印(计数器.值);
    返回 0;
}

输出：1
