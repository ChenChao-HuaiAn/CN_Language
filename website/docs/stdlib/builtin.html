内置函数

随语言自带的内建函数——输出/输入/字符串/内存/驻留/类型工具，无需导入。

格式化输出

打印函数族只有 打印 / 打印行 两个变参函数（外加 格式化）。注意命名语义：打印 = 末尾自动换行；打印行 = 不换行（「行」表示逐行连续输出）。字符串 + 数值 自动拼接（“甲” + 1 → “甲1”）。

输出.cnCN

函数 主() -> 整32 {
    打印("总分：", 95, " 平均：", 95 / 3.0);
    打印行("这一行没有换行，");
    打印行("接着输出。");
    打印("");                        // 补一个换行
    字符串 报告 = 格式化("%s 得 %d 分", "张三", 95);
    打印(报告);
    返回 0;
}

输出：总分：95 平均：31.666667 这一行没有换行，接着输出。 张三 得 95 分

打印

函数 打印(任意值...) -> 空类型

变参打印，逐参输出，末尾自动换行。多参数间无分隔符（需要空格自己加：打印(甲, , 乙)）。整128/正128 打印完整 128 位。

打印.cnCN

打印("甲", 1, 2.5, 真);

输出：甲12.500000真

打印行

函数 打印行(任意值...) -> 空类型

同 打印 但末尾不换行——适合分段拼一行输出。（历史教训：旧版 打印行整数 语义恰好相反，已删除，勿混淆。）

打印行.cnCN

打印行("A");
打印行("B");
打印("");
打印("C");

输出：AB C

格式化

函数 格式化(字符串 格式串, 参数...) -> 字符串

sprintf 风格格式化，返回新字符串（拥有型）而不直接输出。占位符：%d 整、%u 无符号、%f 浮点、%s 字符串、%c 字符、%x/%X 十六进制、%o 八进制、%p 指针。

格式化.cnCN

字符串 文 = 格式化("%x %f", 255, 1.5);
打印(文);

输出：ff 1.500000

IO::读取行

内置 函数 IO::读取行() -> 字符串

标准输入内置（stdlib IO 模块 读取行() 的底层）。业务代码用 IO::读取行 包装版（返回 结果 以显式处理 EOF）。

字符串函数族

字符串为 UTF-8 字节序列（\0 结尾），全部按字节偏移工作。返回字符串的函数都返回拥有型新串。比较语义：内容相等用 字符串比较（或 ==），排序序用 字符串字典序（负/0/正）。

字符串内置.cnCN

函数 主() -> 整32 {
    字符串 文 = "你好, CN";
    打印(字符串长度(文));            // 10（UTF-8 字节数：你好=6）
    打印(字符串包含(文, "CN"));      // 真
    打印(字符串前缀(文, "你好"));    // 真
    打印(字符串子串(文, 0, 3));      // 你（按字节切，3=一个汉字）
    字符串 全大写 = 字符串大写("cn lang");
    打印(全大写);                    // CN LANG
    打印(字符串字典序("apple", "banana") < 0);   // 真（字节序）
    返回 0;
}

输出：10 真 真 你 CN LANG 真

字符串构建器

高频拼接的缓冲区句柄四件套（Rust String::push_str 同款）：反复 字符串连接 是 O(n²)，构建器摊销 O(n)。句柄为整数 ID，完成后 必须 字符串构建器::完成 收尾。

字符串构建器.cnCN

函数 主() -> 整32 {
    整64 建 = 字符串构建器::新建();
    整64 i = 0;
    当 (i < 3) {
        字符串构建器::追加(建, "第" + 整数转字符串(i) + "段;");
        i++;
    }
    字符串 文 = 字符串构建器::完成(建);
    打印(文);
    返回 0;
}

输出：第0段;第1段;第2段;

内存管理

手动内存四件套对标 C 的 malloc/free/realloc/memcpy；统计族用于泄漏观测；竞技场族是「进程级一次性分配」（bump 分配，重置一次全释放）。业务代码优先容器/拥有型字符串（RAII）；手动内存是不安全域的逃生门。注意 重新分配 对超过 2GiB 的请求拒绝并返回 无（可观测拒绝前置）。

内存.cnCN

不安全 函数 主() -> 整32 {
    整64* 表 = 分配(2 * 类型大小(整64));   // 两个整64 槽
    表[0] = 7;
    表[1] = 8;
    空类型* 更大 = 重新分配(表, 4 * 类型大小(整64));
    整64* 新表 = 更大;
    打印(新表[0], " ", 新表[1]);       // 扩容后旧值保留
    整64* 目标 = 分配(2 * 类型大小(整64));
    复制内存(目标, 新表, 2 * 类型大小(整64));
    打印(目标[1]);                     // 8
    置零内存(新表, 4 * 类型大小(整64));
    打印(新表[0]);                     // 0
    释放(新表);
    释放(目标);
    返回 0;
}

输出：7 8 8 0

类型工具与所有权

复制/转移 是显式的克隆/移动双内置（C++ copy/move 对照物）；类型大小 参数是类型名而非表达式；运行时错误 立即终止进程。

类型工具.cnCN

类 点 {
    整64 x;
}

函数 主() -> 整32 {
    打印(类型大小(整64));          // 8
    打印(类型大小(点));            // 8（单字段结构）
    字符串 甲 = "原文";
    字符串 乙 = 复制(甲);          // 深拷：两份独立
    乙 = 乙 + "!";
    打印(甲, " / ", 乙);
    字符串 丙 = 转移(甲);          // 移交：甲此后不可读
    打印(丙);
    返回 0;
}

输出：8 8 原文 / 原文! 原文

类型大小.cnCN

复制

泛型 函数 复制(表达式) -> 实参类型

泛型克隆：返回实参的独立副本。字符串=落堆拥有串；类实参要求该类型定义了拷贝构造（无则编译错误）；容器/结构体整体深拷。

转移

内置 函数 转移(变量) -> 实参的值

所有权移交（C++ std::move / Rust move 同构）：零拷贝交接，源变量自该点起任何读性使用均为编译错误（Rust E0382 同款）；对源变量纯赋值可复活（重新初始化）。标量（整数/浮点/布尔/字符）拒绝转移——复制语义无转移意义。

转移.cnCN

字符串 甲 = "贵重";
字符串 乙 = 转移(甲);      // 交接，甲不可再用
打印(乙);
甲 = "新值";               // 纯赋值=复活，合法
打印(甲);

输出：贵重 新值

运行时错误

函数 运行时错误(整64 错误码) -> 空类型

打印 运行时错误(错误码N) 并终止进程（退出码 1）。错误码语义见 核心.错误码。标准库容器的「直读越界即中止」就是它。

字符串驻留

字符串内容加入全局驻留表，返回唯一整数 ID（Symbol）：相同内容同 ID、内容只存一份、O(1) 相等比较。编译器符号表的实现机制，也开放给业务（海量重复串的键控场景）。驻留表进程级存活，不随 释放全部 释放。

驻留.cnCN

函数 主() -> 整32 {
    整64 甲 = 驻留("token");
    整64 乙 = 驻留("token");
    打印(甲 == 乙);                 // 同内容同 ID
    字符* 文 = 驻留文本(甲);        // ID 反查文本（借用视图）
    打印(字符串复制(文));
    打印(驻留计数() >= 1);
    返回 0;
}

输出：真 token 真
