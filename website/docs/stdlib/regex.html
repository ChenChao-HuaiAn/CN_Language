正则

递归回溯式正则引擎——Rob Pike TregEx 风格的实用子集。

导入写法CN

导入 正则::正则引擎;

支持的语法子集

语法含义
字面量逐字符匹配（UTF-8 字节级）
.任意单字节（不含 \0）
[abc] [a-z0-9] [^a]字符类：枚举/区间/取反
^ $行首/行尾锚定
* + ?量词（仅作用于单字符原子：字面量/. /字符类/转义；贪婪+回退）
( … )分组（组内可用 |；组不可接量词）
|或（顶层与组内）
\x转义 \ . [ ] ( ) * + ? | ^ $

语法子集.cnCN

导入 正则::正则引擎;

函数 主() -> 整32 {
    正则引擎 re = 正则引擎("^h[oai]+t$");
    打印(re.完全匹配("hoat"));       // 真（^ $ 锚定整串）
    打印(re.完全匹配("hot!"));       // 假
    正则引擎 查找 = 正则引擎("h[oai]+t");   // 无锚：可命中任意起点
    整64 起点 = 查找.搜索("shot boy");
    打印(起点);                      // 1
    返回 0;
}

输出：真 假 1

正则引擎(模式串)

函数 正则引擎(字符串 模式串)

以模式串构造引擎。模式在每次 搜索/完全匹配 时解释执行（无独立编译步骤）。

参数类型说明
模式串字符串正则模式（语法见上表）

正则引擎-构造.cnCN

正则引擎 数字 = 正则引擎("[0-9]+");
打印(数字.搜索("ab123") >= 0);

输出：真

搜索

函数 搜索(字符串 输入) -> 整64

在文本中寻找首个匹配，返回匹配起点下标；无匹配 -1。模式以 ^ 开头时只尝试起点 0。

参数类型说明
输入字符串被搜索的文本

返回　首个匹配起点；无匹配 -1。

正则引擎-搜索.cnCN

正则引擎 re = 正则引擎("o+");
打印(re.搜索("moon"));

输出：1

完全匹配

函数 完全匹配(字符串 输入) -> 布尔

整个文本须被模式完整覆盖（首尾隐式锚定，无需写 ^ $）。

参数类型说明
输入字符串被检验的文本

返回　完整覆盖为真，否则假。

正则引擎-完全匹配.cnCN

正则引擎 整数模式 = 正则引擎("[0-9]+");
打印(整数模式.完全匹配("2026"));
打印(整数模式.完全匹配("2026年"));

输出：真 假
