核心

错误码枚举与四个泛型工具函数——全部模块的地基。

导入写法CN

导入 核心::错误码;
导入 核心::{交换, 最小, 最大, 断言};

错误码（枚举）

全标准库统一的错误码枚举。所有 结果<T, 整32> 中的错误值都取自这里，不要写魔法数字。

错误码

枚举 错误码 { 除零=1, 越界=2, 空指针=3, 内存=4, 文件=5, 参数=6, 未初始化=7, 溢出=8 }

值域与《设计规格书》附录 B 一致。成员访问用点号：错误码.越界。与内置构造器 错误(...) 搭配使用：返回 错误(错误码.文件);

错误码-值域.cnCN

导入 核心::错误码;

函数 演示() -> 结果<整64, 整32> {
    返回 错误(错误码.越界);
}

函数 主() -> 整32 {
    结果<整64, 整32> 读 = 演示();
    如果 (!读.正常) {
        打印("失败，错误值：", 读.错误);
    }
    返回 0;
}

工具函数

三个泛型函数编译期单态化（T 替换为实参类型），要求类型支持对应的比较运算符。

工具函数.cnCN

导入 核心::{交换, 最小, 最大, 断言};

函数 主() -> 整32 {
    整32 甲 = 3;
    整32 乙 = 7;
    交换<整32>(&甲, &乙);            // 泛型调用须显式单态化
    打印(甲, " ", 乙);               // 7 3
    打印(最小<整32>(甲, 乙), " ", 最大<整32>(甲, 乙));   // 3 7
    断言(甲 > 乙, "甲应大于乙");     // 条件为假时终止进程
    返回 0;
}

输出：7 3 3 7

交换

泛型 <类型 T> 函数 交换(T* 左, T* 右) -> 空类型

交换两个变量的值。参数为指针（T*），调用时取地址：交换(&甲, &乙)。函数体内用下标写法 左[0] 读写（等价 *左；行首解引用赋值与乘法有词法歧义，标准库统一用下标）。

参数类型说明
左T*指向第一个变量的指针
右T*指向第二个变量的指针

返回　无。原地交换。

交换.cnCN

整64 甲 = 1;
整64 乙 = 99;
交换<整64>(&甲, &乙);
打印(甲, " ", 乙);

输出：99 1

最小

泛型 <类型 T> 函数 最小(T 左, T 右) -> T

返回两者中较小的一个。按值传参，支持所有实现了 < 比较的类型。

参数类型说明
左T候选值一
右T候选值二

返回　较小者（类型 T）。

最小.cnCN

打印(最小<整32>(3, 7), " ", 最小<浮64>(2.5, 1.8));

输出：3 1.800000

最大

泛型 <类型 T> 函数 最大(T 左, T 右) -> T

返回两者中较大的一个。要求类型支持 > 比较。

参数类型说明
左T候选值一
右T候选值二

返回　较大者（类型 T）。

最大.cnCN

打印(最大<整32>(3, 7), " ", 最大<浮64>(2.5, 1.8));

输出：7 2.500000

断言

函数 断言(布尔 条件, 字符串 消息) -> 空类型

条件为假时调用 运行时错误(错误码.参数) 终止进程，并在标准输出打印诊断行。用于开发期前置条件检查；发布构建不会自动移除断言（需手动裁剪）。

参数类型说明
条件布尔断言条件；假则终止
消息字符串失败时的诊断消息

返回　无。条件为真时什么也不做。

断言.cnCN

断言(1 + 1 == 2, "算术坏了");
打印("到这了");

输出：到这了
