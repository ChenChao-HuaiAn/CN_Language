系统

命令行参数——对标 C 的 argv。

导入写法CN

导入 系统::{参数个数, 参数};

命令行参数

程序经 cn run 程序.cn 参数… 或直接运行可执行文件时，命令行参数从这里读取。

命令行参数.cnCN

导入 系统::{参数个数, 参数};

函数 主() -> 整32 {
    整32 个数 = 参数个数();
    打印("至少 1 个参数：", 个数 >= 1);
    结果<字符串, 整32> 首 = 参数(0);
    如果 (首.正常) { 打印("程序名非空：", 字符串长度(首.值) > 0); }
    返回 0;
}

输出：至少 1 个参数：真 程序名非空：真

参数个数

函数 参数个数() -> 整32

命令行参数个数，含程序名本身（对标 argv[0]），至少为 1。

返回　参数个数（整32）。

主.cnCN

// 系统库 E2E（Task 6.5，规格书10.4 命令行参数；对标 C++ argv）
// 覆盖：参数个数（含可执行文件名本身）/ 参数按索引取 argv
// 调用方式：直接调用系统库内置函数（系统::参数个数/系统::参数，全局注册、无需导入），
//   由编译器 IR 层映射到运行时 __cn_argc/__cn_argv（system_api.cpp）
//   ——与 stdlib/系统.cn 模块封装同名（25_math 数学库同模式：E2E 直接验证内置）
// 命令行参数注入：run_e2e.py 检测同名 主.args 文件（每行一个参数，首行=argv[1]；
//   argv[0] 恒为可执行文件名本身）——本用例参数：
//     hello
//     CN语言
//   → argc=3（argv[0]=可执行文件名、argv[1]=hello、argv[2]=CN语言）
// 打印语义（用户裁决）：打印=println（自动换行）
// 注意：参数字符串由运行时（CRT）持有，不得 字符串释放

函数 主() -> 整32 {
    打印("===== 系统库（Task 6.5）=====");

    // ==================== 1. 参数个数（含可执行文件名本身） ====================
    整64 个数 = 系统::参数个数();
    打印("参数个数: ", 个数);             // 3（exe + hello + CN语言）

    // ==================== 2. 参数按索引取 argv ====================
    打印("参数个数>=1: ", 个数 >= 1);     // 1

    // argv[0]：可执行文件名本身（非空）
    字符* 程序名 = 系统::参数(0);
    如果 (程序名 != 无) {
        打印("argv[0]非空: ", 字符串长度(程序名) > 0);  // 1
    } 否则 {
        打印("argv[0]为空");
    }

    // argv[1]：hello
    字符* 参数一 = 系统::参数(1);
    如果 (参数一 != 无) {
        打印("argv[1]: ", 参数一);        // hello
    } 否则 {
        打印("argv[1]为空");
    }

    // argv[2]：CN语言（中文参数）
    字符* 参数二 = 系统::参数(2);
    如果 (参数二 != 无) {
        打印("argv[2]: ", 参数二);        // CN语言
    } 否则 {
        打印("argv[2]为空");
    }

    // 越界：超出 argc-1 → nullptr → 失败
    字符* 越界 = 系统::参数(99);
    如果 (越界 != 无) {
        打印("越界参数: ", 越界);
    } 否则 {
        打印("越界参数失败");             // 失败
    }

    打印("===== 系统库测试完成 =====");
    返回 0;
}

输出：===== 系统库（Task 6.5）===== 参数个数: 3 参数个数>=1: 真 argv[0]非空: 真 argv[1]: hello argv[2]: CN语言 越界参数失败 ===== 系统库测试完成 =====

参数

函数 参数(整32 索引) -> 结果<字符串, 整32>

按索引取参数字符串。参数(0) = 程序名。越界返回 错误(6)。返回的字符串为拥有型（内部已复制落堆，RAII 自动释放）。

参数类型说明
索引整32参数下标（0=程序名）

返回　正常(参数串)；越界 → 错误(6)。
