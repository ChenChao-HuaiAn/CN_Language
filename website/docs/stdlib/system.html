系统

命令行参数——对标 C 的 argv。

导入写法CN

导入 系统::{参数个数, 参数};

命令行参数

程序经 cn run 程序.cn 参数… 或直接运行可执行文件时，命令行参数从这里读取。

命令行参数.cnCN

导入 系统::{参数个数, 参数};

函数 主() -> 整32 {
    整32 个数 = 参数个数();
    打印("至少 1 个参数：", 个数 >= 1);
    结果<字符串, 整32> 首 = 参数(0);
    如果 (首.正常) { 打印("程序名非空：", 字符串长度(首.值) > 0); }
    返回 0;
}

输出：至少 1 个参数：真 程序名非空：真

参数个数

函数 参数个数() -> 整32

命令行参数个数，含程序名本身（对标 argv[0]），至少为 1。

返回　参数个数（整32）。

参数个数.cnCN

打印(参数个数());

输出：1

参数

函数 参数(整32 索引) -> 结果<字符串, 整32>

按索引取参数字符串。参数(0) = 程序名。越界返回 错误(6)。返回的字符串为拥有型（内部已复制落堆，RAII 自动释放）。

参数类型说明
索引整32参数下标（0=程序名）

返回　正常(参数串)；越界 → 错误(6)。

参数.cnCN

结果<字符串, 整32> 名 = 参数(0);
如果 (名.正常) { 打印("程序名拿到了"); }
结果<字符串, 整32> 越界 = 参数(99);
如果 (!越界.正常) { 打印("无此参数"); }

输出：程序名拿到了 无此参数
