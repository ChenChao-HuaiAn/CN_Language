映射集合

映射<K, V> 哈希表 / 字符串映射<V> / 集合<T>——键值与去重的三件套。

导入写法CN

导入 映射集合::映射;
导入 映射集合::{字符串映射, 集合};
导入 映射集合::{查找键位置, 查找值位置};

映射<K, V>（哈希表）

键值对哈希表：桶 + 链结构，负载因子 3/4 自动翻倍重哈希，设置/获取/包含/删除 期望 O(1)。小映射 8 桶起步按需倍增（Rust HashMap 同策略）。键类型须支持 == 与到整64 的位模式转换（数值/字符/枚举键）；字符串键用 字符串映射<V>。深拷语义 + RAII 自动释放。

映射.cnCN

导入 映射集合::映射;

函数 主() -> 整32 {
    映射<整64, 整64> 字典 = 映射<整64, 整64>();
    结果<空类型, 整32> 设 = 字典.设置(3, 300);
    设 = 字典.设置(4, 400);
    设 = 字典.设置(3, 999);          // 已有键=覆盖
    结果<整64, 整32> 取 = 字典.获取(3);
    如果 (取.正常) { 打印(取.值); }   // 999
    打印(字典.包含(4), " ", 字典.包含(99));
    打印(字典.删除(4));               // 真
    打印(字典.大小());                // 1
    返回 0;
}

输出：999 真 假 真 1

设置 不安全

不安全 函数 设置(K 键, V 值) -> 结果<空类型, 整32>

写入键值：键已存在→覆盖旧值（旧值字符串正确释放）；不存在→追加。负载因子 3/4 触发桶翻倍+全键重哈希。

参数类型说明
键K键（须支持 == 与位模式转换）
值V值

返回　正常()；扩容失败 → 错误(错误码.内存)。

释放内部数组 内部 不安全

不安全 函数 释放内部数组()

显式销毁内部数组（映射作为容器元素被弹出/清场时由容器调用）。释放后可安全复用。常规 RAII 路径用析构即可，勿手动调。

桶索引 内部

常量 函数 桶索引(K 键) -> 整64

内部散列辅助：键的 8 字节位模式 Knuth 乘法散列 & 桶掩码。

链查找 内部

常量 不安全 函数 链查找(K 键, 整64& 前驱) -> 整64

内部桶链查找：返回键位置（找不到 -1），前驱 经引用输出（-1=桶头）。含静态未构造防御（零初始化态视为空映射）。

析构键值 / 析构值 内部

函数 析构键值(整64 索引) / 析构值(整64 索引)

编译器注入挂点：K/V 为字符串时释放对应槽并清零（幂等）；非字符串实例零注入。删除/覆盖 内部使用。

字符串映射<V>

键类型固定为 字符串 的哈希表（FNV-1a 逐字节散列 + 字符串比较判等），行为与 映射<K, V> 同构。泛型 映射 的键消费链暂不支持字符串键，本类是官方通道（泛型键分派落地后回收为别名）。

导入 映射集合::字符串映射;

函数 主() -> 整32 {
    字符串映射<整64> 评分 = 字符串映射<整64>();
    结果<空类型, 整32> 设 = 评分.设置("张三", 95);
    设 = 评分.设置("李四", 88);
    结果<整64, 整32> 得分 = 评分.获取("张三");
    如果 (得分.正常) { 打印(得分.值); }
    打印(评分.包含("李四"), " ", 评分.包含("王五"));
    返回 0;
}

输出：95 真 假

清空 / 拷贝构造

集合<T>

值唯一的集合（对标 C++ std::set，当前为无序线性表实现）：添加幂等（重复添加是 no-op）、按值删除。深拷语义 + RAII。

集合.cnCN

导入 映射集合::集合;

函数 主() -> 整32 {
    集合<整64> 去重池 = 集合<整64>();
    结果<空类型, 整32> 加 = 去重池.添加(5);
    加 = 去重池.添加(5);            // 幂等：不重复
    加 = 去重池.添加(9);
    打印(去重池.大小());            // 2
    打印(去重池.包含(9));           // 真
    打印(去重池.删除(5));           // 真
    打印(去重池.包含(5));           // 假
    返回 0;
}

输出：2 真 真 假
