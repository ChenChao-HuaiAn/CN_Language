容器

向量 / 链表 / 栈 / 队列——RAII 自动释放，元素按真实类型大小紧凑存储。

导入写法CN

导入 容器::向量;
导入 容器::{链表, 栈, 队列};

使用总览

四个容器全部深拷语义 + RAII 自动释放：作用域结束自动释放底层内存，元素为字符串/类对象时自动逐元素析构。扩容策略统一为「0 → 4，之后每次翻倍」。返回 结果 的方法返回值不可丢弃（编译错误），须按本文示例接收检查。

总览.cnCN

导入 容器::向量;

函数 主() -> 整32 {
    向量<整64> 表 = 向量<整64>();
    结果<空类型, 整32> 加 = 表.追加(10);
    加 = 表.追加(32);
    整64 首 = 表.元素(0);        // 副本读取（快照语义）
    遍历 表 中 每个 x {           // 遍历循环逐元素只读访问
        打印行(x, " ");
    }
    打印("");
    打印(首 + 表.大小());        // 12
    返回 0;
}

输出：10 32 12

向量<T>（动态数组）

对标 C++ std::vector。底层一块连续内存，支持下标随机访问；元素按 类型大小(T) 字节紧凑存储（与数组 C 布局、指针步进统一）。拷贝构造为深拷贝（逐元素按 T 的拷贝语义）。

向量() 不安全

不安全 函数 向量()

构造空向量（容量 0，不分配内存）。首次 追加/插入 时分配。

函数 读面() -> 整32 {
    整64 大小值 = 全局向量.大小();
    整64 容量值 = 全局向量.容量();
    布尔 空值 = 全局向量.为空();
    整32 元素值 = 全局向量.元素(0);
    结果<整32, 整32> 读取值 = 全局向量.读取(0);
    结果<整64, 整32> 获取值 = 全局映射.获取(1);
    布尔 包含值 = 全局集合.包含(3);
    整32 累 = 整32(大小值) + 元素值;
    如果 (读取值.正常) { 累 = 累 + 读取值.值; }
    如果 (获取值.正常) { 累 = 累 + 整32(获取值.值); }
    如果 (包含值) { 累 = 累 + 1; }
    返回 累;
}

函数 主() -> 整32 {
    造数据();
    打印行("读面累加");
    打印行(读面());
    返回 读面();
}

输出：读面累加16
