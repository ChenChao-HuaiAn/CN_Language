随机数

xoshiro256++ 伪随机数发生器——快速、种子确定性、非加密。

导入写法CN

导入 随机数::随机数生成器;
导入 随机数::播种扩散;

随机数生成器

xoshiro256++（Vigna 2019）+ splitmix64 播种扩散。固定种子 = 确定性序列（可复现测试）；需要非确定性时用 播种扩散(时间戳) 做熵源混合。非加密用途（统计模拟/游戏/测试数据）；密码学用途不保证。

随机数生成器.cnCN

导入 随机数::随机数生成器;

函数 主() -> 整32 {
    随机数生成器 生成器 = 随机数生成器(42);   // 固定种子
    打印(生成器.下一个范围(100));    // 56（种子 42 的确定序列）
    打印(生成器.下一个范围(100));    // 95
    打印(生成器.下一个浮点() >= 0.0); // [0.0, 1.0)
    返回 0;
}

输出：56 95 真

随机数生成器(种子)

函数 随机数生成器(整64 种子)

以种子构造并完成 splitmix64 四轮扩散播种（近邻种子扩散远离，避免全零/近邻状态退化）。

参数类型说明
种子整64任意 64 位种子

随机数生成器-构造.cnCN

随机数生成器 甲 = 随机数生成器(7);
随机数生成器 乙 = 随机数生成器(7);
打印(甲.下一个() == 乙.下一个());   // 同种子同序列

输出：真

播种

函数 播种(整64 种子)

重置内部状态并按新种子重新扩散播种（复用同一生成器实例）。

参数类型说明
种子整64新种子

随机数生成器-播种.cnCN

随机数生成器 生 = 随机数生成器(1);
生.播种(2);
随机数生成器 对照 = 随机数生成器(2);
打印(生.下一个() == 对照.下一个());

输出：真

下一个

函数 下一个() -> 整64

输出 整64 全域随机值（含负值=两补码位模式）。

返回　64 位伪随机整数。

随机数生成器-下一个.cnCN

随机数生成器 生 = 随机数生成器(9);
整64 甲 = 生.下一个();
整64 乙 = 生.下一个();
打印(甲 != 乙);                     // 连续两值几乎必不同

输出：真

下一个范围

函数 下一个范围(整64 上限) -> 整64

输出 [0, 上限) 的非负随机整数。取模法，上限不整除 2^63 时有极轻低值偏差（非加密用途可接受）。

参数类型说明
上限整64排他上界（须 > 0）

返回　[0, 上限) 内整数。

随机数生成器-下一个范围.cnCN

随机数生成器 生 = 随机数生成器(3);
整64 骰子 = 生.下一个范围(6) + 1;   // 1~6
打印(骰子 >= 1 && 骰子 <= 6);

输出：真

下一个浮点

函数 下一个浮点() -> 浮64

输出 [0.0, 1.0) 均匀浮点（高 53 位构造，IEEE 754 精确）。

返回　[0.0, 1.0) 浮点。

随机数生成器-下一个浮点.cnCN

随机数生成器 生 = 随机数生成器(5);
浮64 概率 = 生.下一个浮点();
打印(概率 >= 0.0 && 概率 < 1.0);

输出：真

旋转左 / 扩散混合 内部

（内部方法 × 2）

播种扩散

播种扩散

函数 播种扩散(整64 熵源) -> 整64

熵源混合便捷函数（质数乘 + 黄金常数回绕扩散）。典型用法：生成器.播种(播种扩散(当前时间戳()))——时间戳近邻值经扩散后远离，Rust SeedableRng 同构。

参数类型说明
熵源整64原始熵（如时间戳×质数+计数器）

返回　扩散后的种子。

播种扩散-函数.cnCN

随机数生成器 生 = 随机数生成器(0);
生.播种(播种扩散(1700000000));
打印(生.下一个范围(10) >= 0);

输出：真
