随机数

xoshiro256++ 伪随机数发生器——快速、种子确定性、非加密。

导入写法CN

导入 随机数::随机数生成器;
导入 随机数::播种扩散;

随机数生成器

xoshiro256++（Vigna 2019）+ splitmix64 播种扩散。固定种子 = 确定性序列（可复现测试）；需要非确定性时用 播种扩散(时间戳) 做熵源混合。非加密用途（统计模拟/游戏/测试数据）；密码学用途不保证。

随机数生成器.cnCN

导入 随机数::随机数生成器;

函数 主() -> 整32 {
    随机数生成器 生成器 = 随机数生成器(42);   // 固定种子
    打印(生成器.下一个范围(100));    // 56（种子 42 的确定序列）
    打印(生成器.下一个范围(100));    // 95
    打印(生成器.下一个浮点() >= 0.0); // [0.0, 1.0)
    返回 0;
}

输出：56 95 真

随机数生成器(种子)

函数 随机数生成器(整64 种子)

以种子构造并完成 splitmix64 四轮扩散播种（近邻种子扩散远离，避免全零/近邻状态退化）。

参数类型说明
种子整64任意 64 位种子

主.cnCN

// E2E 379（250/251/252 系·F2-33 stdlib 随机数模块，2026-09-16）：
//   xoshiro256++ + splitmix64 播种——固定种子确定性序列（期望值=python 独立
//   参考实现预计算，非「跑出什么写什么」）+ 范围/浮点值域 + 双编译对照
//   （宿主 vs v2 位运算语义对齐的运行级验证）。
导入 随机数::{随机数生成器, 播种扩散};

函数 主() -> 整32 {
    // —— 段1：固定种子 42 的确定性序列（下一个 整64 全域）——
    随机数生成器 生成器 = 随机数生成器(42);
    整32 序号 = 0;
    当 (序号 < 5) {
        打印(生成器.下一个());
        序号 = 序号 + 1;
    }
    // —— 段2：范围 [0,10) ——
    序号 = 0;
    当 (序号 < 5) {
        打印(生成器.下一个范围(10));
        序号 = 序号 + 1;
    }
    // —— 段3：浮点 [0,1) ——
    序号 = 0;
    当 (序号 < 5) {
        打印(生成器.下一个浮点());
        序号 = 序号 + 1;
    }
    // —— 段4：种子 7 的 100 次范围(6) 加权校验和（分布面压缩锚定）——
    随机数生成器 生成器乙 = 随机数生成器(7);
    整64 校验和 = 0;
    序号 = 0;
    当 (序号 < 100) {
        校验和 = 校验和 + 生成器乙.下一个范围(6) * (序号 + 1);
        序号 = 序号 + 1;
    }
    打印(校验和);
    // —— 段5：种子 42 的 1000 次下一个 之和（低 16 位·全序列守恒锚定）——
    随机数生成器 生成器丙 = 随机数生成器(42);
    整64 总和 = 0;
    序号 = 0;
    当 (序号 < 1000) {
        总和 = 回绕加(总和, 生成器丙.下一个());    // #474 显式回绕（回绕语义值不变）
        序号 = 序号 + 1;
    }
    打印(总和 & 65535);
    // —— 段6：重播种确定性 + 熵源混合便捷（同种子重播种=序列可复现锚定）——
    生成器.播种(播种扩散(987654321));
    打印(生成器.下一个());
    打印(生成器.下一个范围(1000));
    生成器.播种(播种扩散(987654321));
    打印(生成器.下一个());
    返回 0;
}

播种

函数 播种(整64 种子)

重置内部状态并按新种子重新扩散播种（复用同一生成器实例）。

参数类型说明
种子整64新种子

主.cnCN

// E2E 380（252-a·算法面双编译对照）：随机数算法 stdlib 导入形态。
//   位运算旋转掩码/两补码回绕/移位取模语义的宿主 vs v2 运行级对齐——
//   算法实现以 stdlib/随机数.cn 为唯一来源（候选4 stdlib 兜底：D29①；
//   导入类构造初始化=D28·两缺陷根治后本用例由类内联形态升级，285-a）。

导入 随机数::随机数生成器;
导入 随机数::播种扩散;

函数 主() -> 整32 {
    // —— 段1：固定种子 42 确定性序列（首值锚定）——
    随机数生成器 生成器 = 随机数生成器(42);
    整64 首值 = 生成器.下一个();
    整64 第二值 = 生成器.下一个();
    // —— 段2：范围值五次之和（0+1+5+1+6）——
    整64 范围和 = 0;
    整32 序号 = 0;
    当 (序号 < 5) {
        范围和 = 范围和 + 生成器.下一个范围(10);
        序号 = 序号 + 1;
    }
    // —— 段4：种子 7 的 100 次范围(6) 加权校验和 ——
    随机数生成器 生成器乙 = 随机数生成器(7);
    整64 校验和 = 0;
    序号 = 0;
    当 (序号 < 100) {
        校验和 = 校验和 + 生成器乙.下一个范围(6) * (序号 + 1);
        序号 = 序号 + 1;
    }
    // —— 段5：种子 42 的 1000 次下一个 之和（低 16 位）——
    随机数生成器 生成器丙 = 随机数生成器(42);
    整64 总和 = 0;
    序号 = 0;
    当 (序号 < 1000) {
        总和 = 回绕加(总和, 生成器丙.下一个());    // 1000 次全域随机值累加·回绕语义（#474 显式回绕）
        序号 = 序号 + 1;
    }
    // —— 段6：重播种可复现（同种子两次序列首值一致）——
    生成器.播种(播种扩散(987654321));
    整64 复现甲 = 生成器.下一个();
    生成器.播种(播种扩散(987654321));
    整64 复现乙 = 生成器.下一个();
    // —— 断言位权合计 31=全过（两侧退出码一致判据·228 惯例）——
    整64 累 = 0;
    如果 (首值 == 5652830896459303956) { 累 = 累 + 1; }
    如果 (第二值 == 3546038017885523995 && 范围和 == 12) { 累 = 累 + 2; }
    如果 (校验和 == 14172) { 累 = 累 + 4; }
    如果 ((总和 & 65535) == 27469) { 累 = 累 + 8; }
    如果 (复现甲 == 复现乙 && 复现甲 != 0) { 累 = 累 + 16; }
    返回 整32(累);
}

下一个范围

函数 下一个范围(整64 上限) -> 整64

输出 [0, 上限) 的非负随机整数。取模法，上限不整除 2^63 时有极轻低值偏差（非加密用途可接受）。

参数类型说明
上限整64排他上界（须 > 0）

返回　[0, 上限) 内整数。

主.cnCN

// 394_双编译stdlib随机数兜底（276-a D29①验收）：
//   纯 stdlib 依赖形态——用例目录不含 随机数.cn，宿主/v2 两侧均须走
//   「stdlib 兜底」加载 stdlib/随机数.cn（宿主 driver 候选4 既有；
//   v2p 276-a 新增同款候选4）。断言面全为确定性（同种子序列一致+范围界内）。
导入 随机数::随机数生成器;
函数 主() -> 整32 {
    随机数生成器 甲 = 随机数生成器(42);
    随机数生成器 乙 = 随机数生成器(42);
    整64 a1 = 甲.下一个();
    整64 b1 = 乙.下一个();
    打印(a1 == b1);
    整64 c = 甲.下一个范围(100);
    打印(c < 100);
    打印(乙.下一个范围(50) < 50);

}
