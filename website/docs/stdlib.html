向量<T>：最常用的容器

向量.cnCN

导入 容器::向量;

函数 主() -> 整32 {
    向量<整64> 表 = 向量<整64>();
    表.追加(10);                 // 尾部追加（结果<空类型, 整32>）
    表.追加(32);
    整64 首 = 表.元素(0);        // 副本读取（快照语义）
    整64 n = 表.大小();

    // 引用写穿（Rust &v[i] 同款·不安全函数内）
    // 表.元素引用(0) = 99;

    遍历 表 中 每个 x { 打印(x); }
    返回 0;
}

容器访问三形态：元素(i) 副本读取、设置(i, v) 写回、 元素引用(i) 引用写穿（不安全）。扩容翻倍策略（0→4→×2），析构自动释放底层数组。

映射<K, V>

映射.cnCN

导入 映射集合::映射;

函数 主() -> 整32 {
    映射<整64, 整64> 字典 = 映射<整64, 整64>();
    字典.设置(3, 300);
    结果<整64, 整32> 取 = 字典.获取(3);
    如果 (取.正常) {
        打印("字典[3] = ", 取.值);    // 300
    }
    返回 0;
}
