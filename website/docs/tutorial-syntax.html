教程·语法基础

变量、类型、运算符、控制流、函数、数组、字符串、结构体、枚举——写过程式 CN 的全部基础。

程序骨架与语句

CN 源文件 UTF-8 编码、.cn 扩展名；顶层由函数/结构体/枚举/类/接口/导入/全局变量声明组成；入口=名为 主 的函数。

骨架.cnCN

// 单行注释
/* 块注释，支持嵌套 /* 像这样 */ */

静态 整32 全局计数 = 0;      // 全局静态变量（零初始化）

不安全 函数 主() -> 整32 {    // 静态变量写=不安全操作（进阶篇·安全区边界）
    全局计数 = 全局计数 + 1;
    打印("计数：", 全局计数);
    返回 0;                   // 0 = 成功
}

输出：计数：1

分号是语句边界的唯一标记与 C/Rust 同款：每条语句必须以分号 ; 结束。换行在词法层只是空白——表达式可以任意换行续写，但行尾漏分号不会被「自动补分号」救回来，而是直接报语法错误。这避免了行尾/行首词法拼接类的事故。

变量与常量

声明即初始化是 CN 的默认姿势——未初始化的局部值类型变量读取是编译错误（编译期数据流检查，零运行时成本）。

变量.cnCN

函数 主() -> 整32 {
    整32 甲 = 10;            // 显式类型
    变量 乙 = 20;            // 类型推断（= 整32）
    浮64 单价 = 9.5;
    布尔 通过 = 真;
    字符 等级 = '甲';        // Unicode 字符（4 字节码点）
    甲 = 甲 + 乙;            // 赋值
    打印(甲, " ", 单价, " ", 通过, " ", 整32(等级));  // 字符打印=码点
    返回 0;
}

输出：30 9.500000 真 30002

常量与静态CN

常量 尺寸 = 4;              // 编译期常量：引用处直接替换
静态 整32 访问次数 = 0;     // 全局/类内静态：零初始化，进程生存期

不安全 函数 主() -> 整32 {  // 静态写在不安全域（读取任意处安全）
    整32[尺寸] 表;           // 数组长度=编译期常量表达式
    访问次数 = 访问次数 + 1;
    打印(尺寸, " ", 访问次数);
    返回 0;
}

输出：4 1

  • 常量 值在编译期折叠进引用处，可为算术表达式（常量 尺寸2 = 尺寸 * 2;）。
  • 静态 变量有零初始化保证，生存期=整个进程；函数内声明同样合法。
  • 未初始化读取（整32 x; 打印(x);）是编译错误——不会读到垃圾值。

基本类型全景

整型 10 种（有符号/无符号 × 5 位宽）、浮点 2 种、布尔/字符/字符串，以及别名 整数=整32、小数=浮64。

类别类型大小范围/说明
默认别名整数 / 小数4B / 8B= 整32 / = 浮64（保留中文习惯的别名）
有符号整数整8 整16 整32 整64 整1281~16B整8：-128~127 …… 整128：±2^127
无符号整数正8 正16 正32 正64 正1281~16B正8：0~255 …… 正128：0~2^128-1
浮点浮32 浮644B / 8BIEEE 754 单/双精度
其他布尔 字符 字符串 空类型1B / 4B / - / -真/假；Unicode 码点；UTF-8 拥有串；void

字面量.cnCN

函数 主() -> 整32 {
    整32 十进制 = 42;
    整32 十六进制 = 0xFF;       // 255
    整32 二进制 = 0b1010;       // 10
    整32 八进制 = 0o777;        // 511
    整64 长值 = 100L;           // L 后缀 → 整64
    浮32 单精度 = 1.5f;         // f 后缀 → 浮32
    浮64 科学 = 1.5e10;
    打印(十进制, " ", 十六进制, " ", 二进制, " ", 八进制);
    打印(长值, " ", 单精度, " ", 科学);
    返回 0;
}

输出：42 255 10 511 100 1.500000 15000000000.000000

窄类型的算术语义（资深提示）同宽窄整数算术保持窄域（整8 + 整8 = 整8），溢出按两补码回绕（127+1≡-128）；字面量向窄类型赋值做编译期值域检查（整16 甲 = 40000; 拒绝）。混合符号（整N × 正M）变量运算编译期拒绝、字面量豁免——详见类型参考。

类型转换

宽化隐式进行；窄化/跨符号/浮整/指针↔整数一律显式 类型名(表达式)，语义=位模式变换（Rust as 同款）。

转换.cnCN

函数 主() -> 整32 {
    整32 小 = 7;
    整64 大 = 小;                // 宽化：隐式放行
    浮64 比例 = 浮64(小) / 4;    // 显式转浮点 → 1.75
    整32 截断 = 整32(3.99);      // 浮转整：截断 → 3
    正64 位模式 = 正64(整32(-1)); // 升宽：符号扩展 → 2^64-1
    打印(大, " ", 比例, " ", 截断, " ", 位模式 == 18446744073709551615);
    返回 0;
}

输出：7 1.750000 3 真

  • 升宽：有符号源符号扩展、无符号源零扩展。
  • 同宽跨符号：位模式重解释（整64(正64(2^63)) = -2^63）。
  • 降宽：低位截断。
  • 字符串拼接语境例外："编号-" + 7 自动把数值转字符串（布尔转「真/假」），见字符串节。

运算符与优先级

全套 C 风格运算符，13 级优先级；这里只讲 CN 有立法规矩的部分，完整优先级表见词法参考。

运算符.cnCN

函数 正数(整32 x) -> 布尔 { 返回 x > 0; }

函数 主() -> 整32 {
    整32 a = 7;
    整32 b = 2;
    打印(a + b, a - b, a * b, a / b, a % b);   // 9 5 14 3 1
    打印(a << 1, a >> 1, a & 3, a | 8, a ^ 1); // 14 3 3 15 6
    打印(a > b, a == 7, a != 7, !正数(-1));    // 布尔族
    整32 c = a > b ? a : b;                     // 三元（右结合）
    a += 10;                                    // 复合赋值族 += -= *= /= %=
    a++;                                        // 后缀自增：表达式值=原值
    打印(c, a);
    返回 0;
}
  • / 对整数=截断除；% 取余（除零=运行时错误码 1，常量除零=编译错误）。
  • 逻辑 && || 短路；位运算只适用整型（浮点位运算编译拒绝）；>> 有符号=算术右移（符号扩展），无符号=逻辑右移；移位量按位宽取模（x << 64 ≡ x）。
  • 后缀 ++/-- 表达式值=自增前原值；前缀=自增后新值。
  • 三元 条件 ? 真值 : 假值 右结合、惰性求值。

控制流：如果/当/循环/选择/遍历

条件括号可选（裸条件与带括号均合法）；中断 绑定最近的循环或选择；选择 默认贯穿（fall-through）、显式 中断 停住。

条件与循环.cnCN

函数 分级(整32 分) -> 字符串 {
    如果 分 >= 90 {
        返回 "优";
    } 否则 如果 分 >= 60 {
        返回 "及格";
    } 否则 {
        返回 "不及格";
    }
}

函数 主() -> 整32 {
    打印(分级(95), " ", 分级(70), " ", 分级(30));

    整32 i = 0;
    当 i < 3 {                 // 当循环（前测）
        打印行(i, " ");
        i++;
    }
    打印("");

    循环 (整32 j = 10; j >= 0; j -= 5) {   // for 风格
        打印行(j, " ");
    }
    打印("");
    返回 0;
}

输出：优 及格 不及格 0 1 2 10 5 0

选择.cnCN

枚举 命令 { 启动, 停止, 查询 }

函数 主() -> 整32 {
    整32 键 = 2;
    选择 (键) {
        情况 0:
            打印("零");
            中断;
        情况 1, 2:            // 多值分组
            打印("一或二");
            中断;
        默认:
            打印("其他");     // 不写 中断 会贯穿下一分支（C 语义）
    }

    字符串 指令 = "开始";
    选择 (指令) {             // 字符串选择
        情况 "开始", "继续":
            打印("执行");
            中断;
        默认:
            打印("未知");
    }

    命令 c = 命令.查询;
    选择 (c) {                // 裸枚举成员（按条件类型定向解析）
        情况 启动:
            打印("启动中");
            中断;
        情况 查询:
            打印("查询中");
            中断;
        默认:
            打印("…");
    }
    返回 0;
}

输出：一或二 执行 查询中

遍历与中断继续.cnCN

函数 主() -> 整32 {
    整32[5] 数据 = {10, 20, 30, 40, 50};
    遍历 数据 中 每个 x {        // 数组遍历：x=元素副本
        打印行(x, " ");
    }
    打印("");

    循环 (整32 k = 0; k < 100; k++) {
        如果 k % 2 == 0 { 继续; }   // 跳过偶数
        如果 k > 10 { 中断; }        // 终止循环
        打印行(k, " ");
    }
    打印("");
    返回 0;
}

输出：10 20 30 40 50 1 3 5 7 9

中断 的绑定规则中断 跳出最近进入的一层 选择 或 循环（谁近绑谁，与 C 的 break 一致）：循环内选择体写 中断 只跳出该选择，循环继续；从选择内直接跳出外层循环无直接语法。继续 仅对循环有意义。

函数：重载、默认参数、引用参数

函数是first-class公民：同名重载按参数类型区分、默认参数从右向左连续、T& 引用参数直写调用方、泛型函数编译期单态化。

函数.cnCN

// 重载：同名按参数类型与个数区分（仅返回类型不同不构成重载）
函数 最大(整32 a, 整32 b) -> 整32 { 如果 a > b { 返回 a; } 返回 b; }
函数 最大(浮64 a, 浮64 b) -> 浮64 { 如果 a > b { 返回 a; } 返回 b; }

// 默认参数：从右向左连续声明
函数 问候(字符串 名字 = "世界") -> 空类型 {
    打印("你好，" + 名字);
}

// 引用参数：直写调用方（左值地址传递）
函数 交换(整32& a, 整32& b) -> 空类型 {
    整32 临时 = a;
    a = b;
    b = 临时;
}

// 常量引用参数：只读借用（体内赋值=编译错误）
函数 求和(常量 整64& x, 常量 整64& y) -> 整64 { 返回 x + y; }

函数 主() -> 整32 {
    打印(最大(3, 9), " ", 最大(2.5, 1.8));
    问候();
    问候("张三");
    整32 p = 1;
    整32 q = 2;
    交换(p, q);            // 引用实参：直传左值（不加 &）
    打印(p, q);
    整64 x = 100;
    整64 y = 23;
    打印(求和(x, y));      // 常量引用实参须左值变量
    返回 0;
}

输出：9 2.500000 你好，世界 你好，张三 21 123

按值传参的两种语义（资深提示）标量/结构体按值形参=副本语义（体内写不影响实参）；类类型按值形参=引用语义（形参槽存对象句柄，体内经句柄写穿调用方同一堆对象——类变量即指针槽模型）。要与「副本语义」写类，传前显式 复制(对象)。详见函数参考。

泛型函数.cnCN

泛型 <类型 T>
函数 交换泛型(T& a, T& b) -> 空类型 {
    T 临时 = a;
    a = b;
    b = 临时;
}

函数 主() -> 整32 {
    整32 甲 = 1;
    整32 乙 = 2;
    交换泛型<整32>(甲, 乙);      // 显式单态化&lt;类型&gt;；引用实参直传
    打印(甲, 乙);
    返回 0;
}

输出：21

数组：定长、值语义、编译期长度

数组=类型[长度]，长度可为编译期常量表达式；整体赋值=整块值拷贝（两态独立）；越界=运行时错误（错误码 2）。

数组.cnCN

常量 行数 = 3;

函数 主() -> 整32 {
    整32[5] 表 = {10, 20, 30, 40, 50};   // 聚合初始化
    整32[行数] 零表;                      // 长度=常量表达式
    零表[0] = 7;
    打印(表[0], " ", 表[4], " ", 零表[0]);

    整32[3] 甲 = {1, 2, 3};
    整32[3] 乙 = 甲;                      // 整块值拷贝
    乙[0] = 99;
    打印(甲[0], " ", 乙[0]);              // 1 99（两态独立）

    整32 和 = 0;
    遍历 表 中 每个 x { 和 = 和 + x; }
    打印(和);
    返回 0;
}

输出：10 50 7 1 99 150

  • 下标从 0 起；越界读/写=运行时错误 错误码2 越界 终止。
  • 数组作为实参传给函数=按值整块拷贝（形参内改不影响实参）；要原地改用 T* 或 T& 形参。
  • 定长数组之外，动态容器用标准库 向量<T>。

字符串：拥有型 UTF-8

字符串变量=拥有型（堆上 UTF-8，作用域结束自动释放）；+ 拼接（右侧数值自动转字符串）；s[i] 按字节读（UTF-8）；写入不可（不可变类型）。

字符串.cnCN

函数 主() -> 整32 {
    字符串 名 = "CN 语言";
    打印(字符串长度(名));            // 9（UTF-8 字节：CN=2+空格1+语言=6）
    字符串 拼接 = "你好, " + 名 + "!" + 1;
    打印(拼接);                       // 你好, CN 语言!1
    打印(字符串包含(名, "语言"));     // 真
    打印(字符串子串(名, 3, 6));       // 语言（字节切片）
    打印(名[0]);                      // 67（'C' 的 UTF-8 首字节）
    打印(字符串大写("cn"));           // CN
    返回 0;
}

输出：9 你好, CN 语言!1 真 语言 67 CN

  • 长度/查找/子串/下标全部按 UTF-8 字节 口径（一个汉字 3 字节）——字符串长度("中") = 3。
  • s[i] 返回 整8（带符号字节）；字符串不可原地下标写（编译拒绝）——修改=用内置函数重建新串。
  • 完整的字符串函数族（20 个内置）见内置函数·字符串族。

结构体：值聚合与指定初始化器

结构体是纯值聚合（无方法）；用 类型{字段=值} 指定初始化器构造——穷举纪律：缺字段/未知字段/重复字段=编译错误。

结构体.cnCN

结构体 点 {
    浮64 x;
    浮64 y;
}

结构体 线段 {
    点 起;      // 嵌套结构体字段
    点 止;
}

函数 主() -> 整32 {
    点 a = 点{x = 1.0, y = 2.0};
    点 b = a;               // 整体值拷贝
    b.x = 9.0;
    打印(a.x, " ", b.x);    // 1 9（两态独立）

    线段 线 = 线段{起 = 点{x = 0.0, y = 0.0}, 止 = 点{x = 3.0, y = 4.0}};
    浮64 dx = 线.止.x - 线.起.x;
    浮64 dy = 线.止.y - 线.起.y;
    打印(dx * dx + dy * dy);   // 25（3-4-5 直角三角形）
    返回 0;
}

输出：1.000000 9.000000 25.000000

  • 成员访问统一 .；指针左侧自动解引用一级（p.x 等价 (*p).x）——-> 已废除。
  • 缺字段/多写字段/重复字段全部编译期拒绝（静默零填禁入安全域）。
  • 拥有型字段（字符串/容器）的释放随结构体变量作用域自动级联（RAII）。

枚举：命名常量族

枚举成员=命名整数常量，可显式赋值（含负数）；引用形态=枚举名.成员（点号）；选择 内可裸写成员名。

枚举.cnCN

枚举 颜色 { 红, 绿, 蓝, 自定义 = 100 }
枚举 方向 { 上 = -1, 中 = 0, 下 = 1 }

函数 主() -> 整32 {
    颜色 c = 颜色.蓝;
    方向 d = 方向.上;
    打印(c == 颜色.蓝, " ", 整32(d));   // 真 -1
    选择 (c) {
        情况 红: 打印("红"); 中断;
        情况 蓝: 打印("蓝"); 中断;   // 裸成员名
        默认: 打印("…");
    }
    返回 0;
}

输出：真 -1 蓝

枚举成员引用形态成员引用=枚举名.成员 或 选择条件位裸成员名；枚举名::成员 非法（:: 保留给模块路径限定）。
