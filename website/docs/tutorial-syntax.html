语法基础

这一章带你走完 CN 的地基：变量、类型、函数、控制流和结构体。 会中文就会读 CN 代码——这门语言的关键字只有 46 个。

程序结构

一个 CN 程序由顶层声明组成（函数、结构体、枚举、类、导入等）， 入口是 主 函数：

程序结构.cnCN

// 顶层声明……
导入 容器::向量;          // 导入标准库容器

函数 主() -> 整32 {       // 入口函数
    打印("你好");         // 语句以分号结尾
    返回 0;               // 返回 0 表示成功
}

注释与 C 家族一致：// 行注释、/* */ 块注释。 每条语句以分号 ; 结束。

变量与常量

用 变量 声明变量。类型可推断，也可显式标注； 常量 声明不可变绑定；静态 声明静态变量：

变量.cnCN

函数 主() -> 整32 {
    变量 x = 10;          // 类型推断：整32
    整数 y = 20;          // 显式类型（整数 = 整32 的别名）
    整32 z = 30;          // 位宽类型
    浮64 比例 = 0.5;      // 64 位浮点
    布尔 开关 = 真;        // 布尔：真 / 假
    常量 PI = 3.14;       // 常量：不可重新赋值
    静态 整32 计数 = 0;   // 静态变量

    字符串 名字 = "小明";  // 字符串
    字符 首字 = '小';      // 字符（Unicode，4 字节）

    打印(x, y, z, 比例, 开关, PI, 名字, 首字);
    返回 0;
}

基本类型

CN 的整数类型精确到位宽，命名即文档：

类别类型说明
默认别名整数（=整32）、小数（=浮64）日常使用
有符号整数整8 整16 整32 整64 整1281~16 字节
无符号整数正8 正16 正32 正64 正128非负整数
浮点浮32 浮64IEEE 754
其他布尔 字符 字符串 空类型字符为 Unicode 标量

还有复合类型：指针 类型*、数组、结构体、枚举、联合体、 函数指针，以及错误处理专用的 结果<T, E> 与 可选<T> （见安全与并发）。

函数

函数 声明函数，参数写「类型 名字」，返回类型跟在 -> 后：

函数.cnCN

函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b;
}

// 无返回值可省略 -> 类型
函数 打印问候() {
    打印行("你好");
}

// 默认参数
函数 问候(字符串 名字 = "世界") {
    打印行("你好，" + 名字);
}

// 引用参数：T& 写穿到调用方
函数 交换(整32& a, 整32& b) -> 空类型 {
    整32 临时 = a;
    a = b;
    b = 临时;
}

// 重载：同名函数按参数类型与个数区分
函数 最大值(整32 a, 整32 b) -> 整32 { 如果 a > b { 返回 a; } 返回 b; }
函数 最大值(浮64 a, 浮64 b) -> 浮64 { 如果 a > b { 返回 a; } 返回 b; }

函数 主() -> 整32 {
    问候();           // 你好，世界
    问候("张三");     // 你好，张三
    整32 x = 1;
    整32 y = 2;
    交换(x, y);       // x=2, y=1
    打印(加(1, 2), 最大值(x, y));
    返回 0;
}

还有 lambda（匿名函数）：

lambda.cnCN

函数 主() -> 整32 {
    变量 加倍 = [](整32 v) -> 整32 { 返回 v * 2; };
    打印(加倍(21));   // 42
    返回 0;
}

控制流

五大控制流，全部中文关键字。条件的括号可写可不写：

控制流.cnCN

函数 主() -> 整32 {
    // 如果 / 否则
    整32 x = -5;
    如果 x > 0 {
        打印行("正数");
    } 否则 如果 x < 0 {
        打印行("负数");
    } 否则 {
        打印行("零");
    }

    // 当循环
    整数 i = 0;
    当 i < 3 {
        打印行(i);    // 0 1 2
        i++;
    }

    // 循环（C 的 for 风格）
    循环 (整32 j = 0; j < 3; j++) {
        打印行(j);    // 0 1 2
    }

    // 选择（switch 风格，支持字符串与多值分组）
    字符串 命令 = "开始";
    选择 (命令) {
        情况 "开始", "继续":
            打印行("执行");
            中断
        默认:
            打印行("未知");
    }

    // 遍历……中每个（range-for）
    循环 (整32 k = 0; k < 5; k++) {
        如果 k % 2 == 0 { 继续; }   // 跳过偶数
        如果 k > 3 { 中断; }        // 提前退出
        打印行(k);    // 1 3
    }
    返回 0;
}

结构体与枚举

结构体把数据打包；构造字面量用 类型{ 字段 = 值 }（字段穷举）：

结构体.cnCN

结构体 点 {
    浮64 x;
    浮64 y;
}

枚举 颜色 {
    红,
    绿,
    蓝,
    自定义 = 100   // 可指定底层值
}

函数 主() -> 整32 {
    点 原点 = 点{ x = 0.0, y = 0.0 };
    点 目标 = 点{ x = 3.0, y = 4.0 };
    浮64 距离平方 = (目标.x - 原点.x) * (目标.x - 原点.x)
                 + (目标.y - 原点.y) * (目标.y - 原点.y);
    打印("距离平方: ", 距离平方);   // 25

    颜色 c = 颜色.蓝;
    选择 (c) {
        情况 红:   { 打印行("红色"); }
        情况 蓝:   { 打印行("蓝色"); }
        默认:      { 打印行("其他色"); }
    }
    返回 0;
}
