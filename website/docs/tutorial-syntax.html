教程·语法基础

变量、类型、运算符、控制流、函数、数组、字符串、结构体、枚举——写过程式 CN 的全部基础。

程序骨架与语句

CN 源文件 UTF-8 编码、.cn 扩展名；顶层由函数/结构体/枚举/类/接口/导入/全局变量声明组成；入口=名为 主 的函数。

主.cnCN

函数 主() -> 整32 {
    打印("你好，世界");
    返回 0;
}

输出：你好，世界

分号是语句边界的唯一标记与 C/Rust 同款：每条语句必须以分号 ; 结束。换行在词法层只是空白——表达式可以任意换行续写，但行尾漏分号不会被「自动补分号」救回来，而是直接报语法错误。这避免了行尾/行首词法拼接类的事故。

变量与常量

声明即初始化是 CN 的默认姿势——未初始化的局部值类型变量读取是编译错误（编译期数据流检查，零运行时成本）。

常量 上限 = 100;

  • 常量 值在编译期折叠进引用处，可为算术表达式（常量 尺寸2 = 尺寸 * 2;）。
  • 静态 变量生存期=整个进程；顶层静态无初值=零初始化放行，函数内静态必须显式初值（静态 整32 槽; 无初值=编译拒绝），写入须在 不安全 域。
  • 未初始化读取（整32 x; 打印(x);）是编译错误——不会读到垃圾值。

全局变量与静态变量

形态默认可见性初始化规则写限制
裸全局（无 静态 前缀）默认外部可见（跨模块无须 公开:）仅限常量表达式（字面量/常量引用/常量算术）——函数调用/构造调用=编译错误「初始值必须是常量表达式」仅限 不安全 函数 体内
静态（顶层）文件私有（公开: 可放行）常量=加载期直存；非常量=入口注入通道同上
静态（函数内）函数内局部名常量=加载期直存；非常量=声明点守卫快照（首调求值一次、再调不重初始化）同上（初始化求值不属写执法面）

  • 裸全局无初始化器=零初始化（.bss）；跨模块同名的裸全局定义=重定义编译错误；写入限制统一（赋值/复合赋值/自增自减仅限 不安全 函数 体内）——安全函数内写全局容器的方法调用（追加/设置/清空…）同样拒绝，读方法（大小/元素/读取/获取/包含）放行。
  • 函数内静态守卫双槽（主槽+哨兵）：首触哨兵为零→求值写主槽并置哨兵；再调直读主槽、跨调用保持。数组初值=整块拷贝（按数组类型精确字节数·非首元素/非截断）；可折叠常量初值由 .data 直存（守卫只承载非常量初值）。
  • 守卫快照初始化不算「可变静态写」——安全函数内的函数内静态照常可带非常量初值；静态变量本身的显式改写仍须 不安全 函数。
  • 跨线程初始化=单线程语义（哨兵为普通布尔槽·无锁非原子）——多线程并发首触的竞争语义为未来扩展项；需要跨线程初始化保障的场景用 互斥锁 自行组织（见安全与并发）。

窄类型的算术语义（资深提示）同宽窄整数算术保持窄域（整8 + 整8 = 整8），溢出=错误码 8 确定性失败（127+1 运行时终止；需回绕语义用显式 回绕加/回绕减/回绕乘）；字面量向窄类型赋值做编译期值域检查（整16 甲 = 40000; 拒绝）。混合符号（整N × 正M）变量运算编译期拒绝、字面量豁免——详见类型参考。

函数 主() -> 整32 {

    整64 负 = -1;
    正64 大 = 9223372036854775808;
    整32 累计 = 0;

  • 降宽：低位截断。
  • 字符串拼接语境例外："编号-" + 7 自动把数值转字符串（布尔转「真/假」），见字符串节。

运算符与优先级

全套 C 风格运算符，13 级优先级；这里只讲 CN 有立法规矩的部分，完整优先级表见词法参考。

主.cnCN

类 复数 {
公开:
    整32 实部;
    整32 虚部;

    函数 复数(整32 r, 整32 i) {
        实部 = r;
        虚部 = i;
    }

    // 运算符+ ：返回新复数（构造调用返回类对象）
    函数 运算符+(复数 右) -> 复数 {
        返回 复数(实部 + 右.实部, 虚部 + 右.虚部);
    }

    // 运算符== ：比较实部虚部
    函数 运算符==(复数 右) -> 布尔 {
        返回 (实部 == 右.实部) && (虚部 == 右.虚部);
    }

    // 运算符!= ：取反 ==
    函数 运算符!=(复数 右) -> 布尔 {
        返回 !((实部 == 右.实部) && (虚部 == 右.虚部));
    }

    // 普通方法：显示复数
    函数 显示() -> 字符串 {
        返回 整数转字符串(实部) + "+" + 整数转字符串(虚部) + "i";
    }
}

函数 主() -> 整32 {
    打印("===== 运算符重载（Task 3.7）=====");

    // ---- 1. 复数加法（运算符+ 重载）----
    复数 甲 = 复数(1, 2);
    复数 乙 = 复数(3, 4);
    复数 和 = 甲 + 乙;           // 调用 复数.运算符+
    打印("甲: ", 甲.显示());     // 1+2i
    打印("乙: ", 乙.显示());     // 3+4i
    打印("和: ", 和.显示());     // 4+6i

    // 注意：链式运算（甲 + 乙 + 丙）的中间对象（运算符+ 返回的 NewObject 堆对象）
    //   作为左操作数传给第二次 + 时字段读取错乱（输出垃圾值）——这是"运算符重载
    //   返回类对象赋值语义"的已知遗留风险（plans 阶段3 文档记录），留待 Debug

    复数 丙 = 复数(10, 20);
    复数 两步 = 甲 + 乙;          // 单次重载（中间对象直接赋值，无链式）

    // 链式运算（缺陷2 修复验证）：甲+乙+丙 = 14+26i

    // ---- 3. 相等比较（运算符== 重载）----

控制流：如果/当/循环/选择/遍历

条件括号可选（裸条件与带括号均合法）；中断 绑定最近的循环或选择；选择 默认贯穿（fall-through）、显式 中断 停住。

主.cnCN

函数 主() -> 整32 {
    // ---- 1. 如果/否则 链 ----
    整数 x = 5;
    如果 (x > 10) {
        打印("x>10");
    } 否则 如果 (x > 3) {
        打印("3<x<=10");
    } 否则 {
        打印("x<=3");
    }

    // ---- 2. 当循环 + 继续 ----
    整数 i = 0;
    当 (i < 6) {
        i++;
        如果 (i == 3) {
            继续;        // 跳过3
        }
        如果 (i > 5) {
            中断;        // 提前退出
        }
        打印(i);
    }

    // ---- 3. 循环（for风格）+ 中断 ----
    循环 (整32 j = 0; j < 10; j++) {
        如果 (j == 4) {
            中断;
        }
        打印(j);
    }

    // ---- 4. 选择语句：每个分支显式中断 ----
    整数 v = 2;
    选择(v) {
        情况 1:
            打印("一");
            中断;
        情况 2:
            打印("二");
            中断;
        情况 3:
            打印("三");
            中断;
        默认:
            打印("其他");
    }

    // ---- 5. 选择语句：默认缺省（无匹配不输出） ----
    选择(v) {
        情况 10:
            打印("十");
            中断;
        情况 20:
            打印("二十");
            中断;
    }

    // ---- 6. 选择语句：字符匹配 ----
    字符 c = 'B';
    选择(c) {
        情况 'A':
            打印("A");
            中断;
        情况 'B':
            打印("B");
            中断;
        默认:
            打印("其他字符");
    }

    // ---- 7. 嵌套选择：switch 内嵌 if/当 ----
    选择(v) {
        情况 2:
            整数 n = 0;
            当 (n < 2) {
                打印("嵌套");
                n++;
            }
            中断;
        默认:
            打印("默认");
    }

    // ---- 8. 选择语句：fallthrough（无中断贯穿到下一情况） ----
    整数 w = 1;
    选择(w) {
        情况 1:
            打印("fall1");
            // 无中断：贯穿到 情况 2

    打印(张三加.成绩);            // 85
    打印("原成绩: ");
    打印(张三.成绩);              // 80（按值传递，原对象不变）

    // ---- 3. 结构体数组元素作为参数 ----
    学生[2] 名单;
    名单[0] = 学生{ 学号 = 7, 成绩 = 60, 班级 = 1 };
    名单[1] = 学生{ 学号 = 9, 成绩 = 70, 班级 = 2 };
    打印("数组元素参数: ");
    打印(取学号(名单[0]));        // 7
    打印(取学号(名单[1]));        // 9

    // ---- 4. 结构体整体赋值（b = a 整体拷贝） ----
    点对 a = 点对{ x = 100, y = 200 };
    点对 b = a;                           // 声明并整体赋值
    打印("整体赋值b.x: ");
    打印(b.x);                     // 100
    打印("整体赋值b.y: ");
    打印(b.y);                     // 200
    // 修改 a 不影响 b（拷贝语义）
    a.x = 999;
    打印("改a后b.x: ");
    打印(b.x);                     // 100（b 是独立副本）

    // ---- 5. 含数组字段结构体整体赋值 ----
    班级 一班 = 班级{ 编号 = 1, 分数 = { 80, 90, 70 } };
    班级 一班副本 = 一班;                 // 整体赋值拷贝数组字段
    打印("含数组拷贝[1]: ");
    打印(一班副本.分数[1]);        // 90
    一班副本.分数[1] = 0;
    打印("改副本后原[1]: ");
    打印(一班.分数[1]);            // 90（原对象数组不受影响）
    打印("改副本后副[1]: ");
    打印(一班副本.分数[1]);        // 0

    // ---- 6. 链式赋值（b = a; c = b） ----
    点对 c = a;                           // a.x=999, a.y=200
    点对 d = c;
    打印("链式d.x: ");
    打印(d.x);                     // 999
    打印("链式d.y: ");
    打印(d.y);                     // 200

    // ---- 7. 大结构体返回（含数组字段） ----
    班级 翻倍一班 = 翻倍(一班);
    打印("翻倍[0]: ");
    打印(翻倍一班.分数[0]);        // 160
    打印("翻倍[1]: ");
    打印(翻倍一班.分数[1]);        // 180
    打印("翻倍[2]: ");
    打印(翻倍一班.分数[2]);        // 140

    // ---- 8. 结构体整体赋值后修改再重新赋值 ----
    点对 e = 点对{ x = 1, y = 1 };
    点对 f = e;
    e.x = 50;
    f = e;                               // 重新整体赋值
    打印("重新赋值f.x: ");
    打印(f.x);                     // 50
    打印("重新赋值f.y: ");
    打印(f.y);                     // 1

    返回 0;
}

输出：小结构体传参: 移后.x: 11 移后.y: 22 原.x: 1 大结构体传参: 加后成绩: 85 原成绩: 80 数组元素参数: 7 9 整体赋值b.x: 100 整体赋值b.y: 200 改a后b.x: 100 含数组拷贝[1]: 90 改副本后原[1]: 90 改副本后副[1]: 0 链式d.x: 999 链式d.y: 200 翻倍[0]: 160 翻倍[1]: 180 翻倍[2]: 140 重新赋值f.x: 50 重新赋值f.y: 1

  • 成员访问统一 .；指针左侧自动解引用一级（p.x 等价 (*p).x）——-> 已废除。
  • 缺字段/多写字段/重复字段全部编译期拒绝（静默零填禁入安全域）。
  • 拥有型字段（字符串/容器）的释放随结构体变量作用域自动级联（RAII）。
  • 不能自己装自己：值字段（非指针/引用）直接或间接自包含 = 无穷大小类型，编译期拒绝——诊断「值字段递归」并指路「改该字段为指针或改用类」（类字段=句柄不落值布局·Rust E0072 同类）。

枚举：命名常量族

枚举成员=命名整数常量，可显式赋值（含负数）；引用形态=枚举名.成员（点号）；选择 内可裸写成员名。

导入 工具::错误码;

// 454 枚举全链（418-a D40 细分防线·v2 闭环多文件）
// 覆盖：枚举声明（显式值）/跨模块导入（模块::枚举名+公开性）/成员链常量
//       折叠（错误码.成员→编译期常量）/枚举变量类型位/转换 整32()
// 退出码校验和 = 越界(2)*10 + 参数(6) + 除零(1)*100 = 126
函数 主() -> 整32 {
    错误码 e = 错误码.越界;
    返回 整32(e) * 10 + 整32(错误码.参数) + 整32(错误码.除零) * 100;
}
