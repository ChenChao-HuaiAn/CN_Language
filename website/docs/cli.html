命令行参考

cn 编译器的全部子命令、选项与调试手段——单命令工具链。

七个子命令

命令作用产物
cn build 文.cn编译并链接可执行文件（--output 可改名）
cn run 文.cn编译+运行一步到位（临时产物）
cn compile 文.cn仅编译到汇编.asm（win）/ .s（linux）
cn check 文.cn仅语法+类型检查无（秒级反馈）
cn ir 文.cn输出中间表示IR 文本（调试用）
cn ast 文.cn输出语法树AST 文本（调试用）
cn token 文.cn输出词元流Token 列表（调试用）

全部选项

选项作用
--target <平台>目标平台：win-x64 | linux-x86_64 | linux-arm64
-O0 ~ -O3 / --opt <级>优化级别（见下表）
--output <路径>输出文件路径
--发布 / --release发布构建：内建常量 调试模式=假
--debug汇编中嵌入源码位置注释
--no-regalloc关闭寄存器分配（保持全栈帧·阶段C 调试用）
--verbose详细输出
--stdlib <路径>指定内置 stdlib 目录（默认相对可执行文件探测）
--货舱 <路径>指定 货舱.toml（默认入口同目录自动发现）
--链接 <库>附加链接库（FFI；可多次；别名 --link-lib）
--version / -v · --help / -h版本与帮助

优化级别

级别内容
-O0无优化（默认）
-O1常量折叠+死代码消除+代数简化+复写传播
-O2+ 公共子表达式消除+跨块死代码消除+寄存器分配
-O3+ 全局值传播

运行时环境变量与诊断通道

变量/通道作用
CN_RT_MEM_STATS=1进程退出时 stderr 打印 8 档分配直方图（内存观测·默认关闭）
运行时错误(错误码N): 消息stdout·运行时错误诊断行，打印后终止（退出码 1）
[cnrt] cn_realloc 拒绝异常尺寸 Nstderr·重新分配 >2GiB 拒绝（返回 无 不终止）
[crash]/[veh] 系列stderr·仅未处理异常时输出（寄存器+回溯 RVA）；正常启动零输出
  • E2E 只比对 stdout——诊断走 stderr 不进比对面，但都是用户可观察行为契约。
  • 交叉编译示例：cn build 主.cn --target linux-arm64 -O2（在本机产出 ARM64 汇编，链接与运行在对应目标机）。
