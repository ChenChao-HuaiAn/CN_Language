命令行参考

cn 编译器全量命令与选项。

用法CLI

cn <命令> [选项] <文件>

命令

命令作用
build编译 + 链接，产出可执行文件
compile仅编译（汇编产物）
run编译后直接运行
check只做语法/语义检查，不生成代码
ir输出中间表示（IR）
ast输出语法树
token输出词元流

选项

选项作用
--target win-x64|linux-x86_64|linux-arm64目标平台（Linux 上 build 必须显式指定）
-O0 ~ -O3（--opt <N> 等价）优化级别（SSA/内联/DCE/CSE/LICM/强度削减/尾调用/寄存器分配）
--debug / --发布（--release）构建模式
--验证-irIR 结构不变量校验（SSA/CFG/def-use）
--cfi控制流完整性：接口间接调用校验（默认关）
--output <路径>产物路径（深层目录自动创建）
--货舱 / --stdlib包清单与标准库路径
--verbose / --version / --help常规

优化级别说明

优化器为全链路 SSA 形式：常量折叠、死代码消除（DCE）、公共子表达式消除（CSE）、 循环不变量外提（LICM）、强度削减、内联、尾调用、线性扫描寄存器分配。 运行时安全检查（越界/空指针）在 -O2 亦默认生效——优化不牺牲安全防线。
