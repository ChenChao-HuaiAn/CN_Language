类与泛型

给数据以行为：类、继承、接口多态、运算符重载，以及跑在编译期的泛型。

类与访问控制

类 把数据与方法绑在一起。访问控制用标签式写法—— 公开: / 私有: / 保护:，默认私有。 与类同名的函数是构造函数，~类名 是析构函数（RAII，离开作用域自动调用）：

栈.cnCN

导入 容器::向量;

类 栈 {
私有:
    向量<整32> 数据;
公开:
    函数 压入(整32 值) {
        数据.追加(值);
    }
    函数 弹出() -> 整32 {
        整32 顶 = 数据.元素(数据.大小() - 1);
        数据.弹出尾();
        返回 顶;
    }
    常量 函数 大小() -> 整64 {
        返回 数据.大小();
    }
}

函数 主() -> 整32 {
    栈 s = 栈();
    s.压入(10);
    s.压入(20);
    打印(s.弹出(), s.大小());   // 20 1
    返回 0;   // s 离开作用域，自动析构
}

继承与虚函数

用 类 子 : 父 继承。虚拟 声明可被重写的函数， 重写 在子类中实现它：

动物.cnCN

类 动物 {
公开:
    虚拟 函数 叫声() -> 字符串 {
        返回 "...";
    }
}

类 狗 : 动物 {
公开:
    重写 函数 叫声() -> 字符串 {
        返回 "汪汪";
    }
}

类 猫 : 动物 {
公开:
    重写 函数 叫声() -> 字符串 {
        返回 "喵喵";
    }
}

函数 主() -> 整32 {
    狗 旺财 = 狗();
    猫 咪咪 = 猫();
    动物* a = &旺财;
    动物* b = &咪咪;
    打印行(a.叫声());   // 汪汪（运行时分派）
    打印行(b.叫声());   // 喵喵
    返回 0;
}

接口多态

接口是一组纯虚约定。类实现接口后，接口类型的变量/参数/返回值都能以运行时多态持有它—— 这是 CN 表达「能做什么」的方式：

形状.cnCN

接口 形状 {
    虚拟 函数 面积() -> 整32
}

类 圆 : 形状 {
公开:
    整32 半径;
    函数 圆(整32 r) { 半径 = r; }
    重写 函数 面积() -> 整32 { 返回 半径 * 半径 * 3; }
}

类 矩形 : 形状 {
公开:
    整32 宽;
    整32 高;
    函数 矩形(整32 w, 整32 h) { 宽 = w; 高 = h; }
    重写 函数 面积() -> 整32 { 返回 宽 * 高; }
}

函数 主() -> 整32 {
    形状 图1 = 圆(5);
    打印行(图1.面积());     // 75

    形状 图2 = 矩形(4, 6);
    打印行(图2.面积());     // 24
    返回 0;
}

运算符重载与静态成员

复数.cnCN

类 复数 {
公开:
    浮64 实部;
    浮64 虚部;

    函数 运算符+(复数 右) -> 复数 {
        返回 复数{实部 + 右.实部, 虚部 + 右.虚部};
    }
    函数 运算符==(复数 右) -> 布尔 {
        返回 实部 == 右.实部 且 虚部 == 右.虚部;
    }
}

类 计数器 {
公开:
    静态 整32 总数 = 0;      // 全类共享
    函数 计数器() { 总数++; }
    静态 函数 获取总数() -> 整32 { 返回 总数; }
}

函数 主() -> 整32 {
    复数 a = 复数{1.0, 2.0};
    复数 b = 复数{3.0, 4.0};
    复数 c = a + b;          // 调用 运算符+

    计数器 x = 计数器();
    计数器 y = 计数器();
    打印(计数器.获取总数());  // 2
    返回 0;
}

泛型

泛型 <类型 T> 声明类型参数，编译期单态化——每个用到的具体类型 都生成一份专属代码，零运行时开销。类型参数还能用接口约束（对标 trait bound）：

泛型.cnCN

// 泛型函数
泛型 <类型 T>
函数 交换(T& a, T& b) -> 空类型 {
    T 临时 = a;
    a = b;
    b = 临时;
}

// 泛型类
泛型 <类型 T>
类 盒子 {
私有:
    T 值;
公开:
    函数 装入(T v) { 值 = v; }
    函数 取出() -> T { 返回 值; }
}

函数 主() -> 整32 {
    整32 m = 1;
    整32 n = 2;
    交换(m, n);              // T = 整32

    盒子<字符串> 盒 = 盒子<字符串>();
    盒.装入("中文泛型");
    打印行(盒.取出());
    返回 0;
}

标准库的 向量<T>、映射<K, V>、互斥锁<T> 都是泛型类——日常开发直接用它们，见标准库。
