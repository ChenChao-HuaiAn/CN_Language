教程·类与泛型

类、构造与析构、可见性、继承与接口、泛型类与泛型函数、运算符重载——面向对象与泛型编程全套。

第一个类：字段、方法、可见性

类=字段+方法的蓝图；公开:/保护:/私有: 标签分段控制可见性（默认私有）；实例化即 类名() 表达式，方法用 . 调用。

栈.cnCN

类 计数器 {
私有:
    整64 值槽;              // 私有字段：类外不可访问
公开:
    函数 计数器() {         // 构造函数：与类同名
        值槽 = 0;
    }

    函数 自增() -> 空类型 {
        值槽 = 值槽 + 1;
    }

    函数 读值() -> 整64 {
        返回 值槽;
    }
}

函数 主() -> 整32 {
    计数器 c = 计数器();
    c.自增();
    c.自增();
    c.自增();
    打印(c.读值());       // 3
    返回 0;
}

输出：3

  • 公开:（类外可访问）/ 保护:（子类可访问）/ 私有:（仅本类）——标签分段，影响其后所有成员直到下一标签。
  • 构造函数与类同名、无返回类型；可有多个重载（按实参区分）。
  • 类实例赋值/传参=句柄（引用语义，见构造析构与类参考）。

构造与析构：RAII 的根基

构造函数=与类同名的函数（可重载）；析构函数=~类名，作用域结束自动调用——资源获取即初始化（RAII），忘记释放不可能。

RAII.cnCN

类 日志 {
私有:
    字符串 名字;
公开:
    函数 日志(字符串 名) {
        名字 = 名;
        打印("[开] ", 名字);
    }

    函数 ~日志() {          // 析构：作用域结束自动调用
        打印("[关] ", 名字);
    }

    函数 写(字符串 消息) {
        打印("[写] ", 消息);
    }
}

函数 主() -> 整32 {
    日志 l = 日志("主日志");
    l.写("程序运行中");
    返回 0;                 // l 的析构在这里自动触发
}

输出：[开] 主日志 [写] 程序运行中 [关] 主日志

  • 拷贝构造=函数 类名(类名& 其他)——定义了它，容器元素、按值传参等拷贝场合都会深拷（标准库容器全部定义了拷贝构造）。
  • 析构顺序与构造相反；成员对象、容器元素、字符串全部自动级联释放。
  • 构造函数重载已支持：无参构造+带参构造可共存。

继承与多态：虚拟/重写/自身/父类

单继承 类 子 : 父；父类方法标 虚拟，子类 重写；自身 指本实例（this），父类.方法() 调父类实现。经父类引用/指针调用=动态分派。

多态.cnCN

类 动物 {
公开:
    字符串 名称;

    函数 动物(字符串 名) { 名称 = 名; }

    虚拟 函数 叫声() -> 字符串 {
        返回 "…";
    }

    函数 自我介绍() -> 空类型 {
        打印(名称 + " 说：" + 自身.叫声());   // 动态分派到重写
    }
}

类 狗 : 动物 {
公开:
    函数 狗(字符串 名) : 动物(名) {   // 父类构造：初始化列表形态
    }

    重写 函数 叫声() -> 字符串 {
        返回 "汪汪";
    }
}

类 猫 : 动物 {
公开:
    函数 猫(字符串 名) : 动物(名) {
    }

    重写 函数 叫声() -> 字符串 {
        返回 "喵";
    }
}

函数 主() -> 整32 {
    狗 d = 狗("阿黄");
    猫 m = 猫("咪咪");
    d.自我介绍();
    m.自我介绍();
    返回 0;
}

输出：阿黄 说：汪汪 咪咪 说：喵

自身 是保留字自身（this）在任何标识符位（字段名/变量名/参数名）都不可用——Rust self 同款硬保留。

接口：行为契约

接口=纯虚拟方法集合；类 实现类 : 接口 实现全部方法；接口引用可指向任何实现类实例（鸭子类型的静态版）。

接口.cnCN

接口 可发声 {
    虚拟 函数 发声() -> 字符串
}

类 警报 : 可发声 {
公开:
    重写 函数 发声() -> 字符串 { 返回 "呜哇呜哇"; }
}

类 门铃 : 可发声 {
公开:
    重写 函数 发声() -> 字符串 { 返回 "叮咚"; }
}

函数 触发(可发声 设备) -> 空类型 {   // 接口形参：任何实现类都收
    打印(设备.发声());
}

函数 主() -> 整32 {
    触发(警报());
    触发(门铃());
    返回 0;
}

输出：呜哇呜哇 叮咚

泛型类：向量 的原理

泛型 <类型 T> 声明类型参数；使用处 类名<实参> 实例化——编译期单态化（每个实例化生成一份专用代码，零运行时开销）。

盒子.cnCN

泛型 <类型 T>
类 盒子 {
私有:
    T 内容;
    布尔 有货;
公开:
    函数 盒子(T 初值) {
        内容 = 初值;
        有货 = 真;
    }

    函数 取出() -> T { 返回 内容; }
    函数 空否() -> 布尔 { 返回 !有货; }
}

函数 主() -> 整32 {
    盒子<整64> 数盒 = 盒子<整64>(42);
    盒子<字符串> 文盒 = 盒子<字符串>("礼物");
    打印(数盒.取出(), " ", 文盒.取出());
    返回 0;
}

输出：42 礼物

  • 实际工程不重复造轮子：标准库有现成的 向量/链表/栈/队列、映射/集合。
  • 泛型类型参数可约束为接口（泛型 <类型 T : 可比较>）。

静态成员与常量成员函数

静态 字段全类共享（类名.字段 访问）；常量 函数 承诺不改对象状态——可在常量上下文调用。

静态.cnCN

类 实例计数器 {
公开:
    静态 整64 总数 = 0;      // 全类共享一份

    函数 实例计数器() {
        总数 = 总数 + 1;
    }

    常量 函数 编号() -> 整64 { 返回 1; }   // 常量成员函数
}

函数 主() -> 整32 {
    实例计数器 a = 实例计数器();
    实例计数器 b = 实例计数器();
    打印(实例计数器.总数);     // 2（经类名访问）
    打印(a.编号());
    返回 0;
}

输出：2 1

运算符重载

成员函数 函数 运算符X(参数) 自定义运算符语义；仅限成员（左操作数必须本类实例）；双目单参数、单目无参数。

复数.cnCN

类 复数 {
公开:
    浮64 实;
    浮64 虚;

    函数 复数(浮64 r, 浮64 i) { 实 = r; 虚 = i; }

    函数 运算符+(复数 右) -> 复数 {
        返回 复数(实 + 右.实, 虚 + 右.虚);
    }

    函数 运算符==(复数 右) -> 布尔 {
        返回 实 == 右.实 && 虚 == 右.虚;
    }
}

函数 主() -> 整32 {
    复数 a = 复数(1.0, 2.0);
    复数 b = 复数(3.0, 4.0);
    复数 c = a + b;          // 调用 运算符+
    打印(c.实, " ", c.虚, " ", a == b, " ", a + b == c);
    返回 0;
}

输出：4.000000 6.000000 假 真

  • 可重载集合：+ - * / % == != < > <= >= && || ! & | ^ ~ << >> [] ()。
  • 决议：先精确匹配内置运算符，无匹配才查左操作数类型的成员 运算符X。
  • 字符串 + 数值 拼接是语言内置（自动转字符串），无需重载。
