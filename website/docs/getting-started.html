快速开始

十分钟：装好工具链，写出、编译、运行你的第一个 CN 程序。

第一步：获取编译器

两条路线：直接拿可执行文件（快），或从源码构建（想参与项目/在 Linux/ARM64 上使用）。

路线 A：源码构建（当前主推）

项目暂未发布安装包，从源码构建只需一步——编译器自身是 C++ 项目，依赖仅有 CMake + 一个 C++17 编译器 +汇编器/链接器：

构建（Windows·MSVC）SHELL

git clone https://gitcode.com/ChenChao_GitCode/CN_Language.git
cd CN_Language
cmake -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
:: 产物：build\Release\cn.exe（或按 CMake 配置命名）

构建（Linux / macOS 等价流程）SHELL

git clone https://gitcode.com/ChenChao_GitCode/CN_Language.git
cd CN_Language
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
# 产物：build/cn
三平台支持编译器可生成三种目标平台的代码：win-x64（MASM）、linux-x86_64（GAS）、linux-arm64（GAS）——用 --target 选择（详见命令行参考）。编译器本身目前主要在 Windows 与 Linux x86_64 上运行。

第二步：Hello World

CN 的源文件以 .cn 为扩展名，UTF-8 编码。程序入口是 主 函数。

你好.cnCN

函数 主() -> 整32 {
    打印("你好，CN！");
    返回 0;
}

三个要点：①函数 声明函数；②-> 整32 是返回类型（操作系统退出码，0=成功）；③打印 是内置变参输出，末尾自动换行，多参数直接逗号排开。

第三步：编译、运行、检查

cn 是单命令工具链：build 出可执行文件、run 一键编译并运行、check 只做语法与类型检查不生成代码。

工作流SHELL

cn build 你好.cn              :: 编译出 你好.exe
你好.exe                       :: 运行 → 你好，CN！
cn run 你好.cn                :: 编译+运行一步到位
cn check 你好.cn              :: 只检查错误，不生成代码
cn build 你好.cn -O2          :: 开优化（-O0 ~ -O3）
  • cn build 默认输出与源文件同名的可执行文件；用 --output 路径 改名。
  • cn run 适合脚本式迭代——改一行跑一次。
  • cn check 秒级反馈，大改动时先 check 再 build 省时间。
  • 报错都是中文诊断并带行列定位，例如：你好.cn:5:5: 错误: 未声明的标识符 '打印'。
标准库在哪？编译器按可执行文件位置自动探测内置 stdlib/ 目录（与仓库同构部署即可）；特殊布局用 --stdlib 路径 指定。标准库的 187 个 API 全部有逐函数文档：见标准库。

第四步：稍大一点的程序

一个猜数小游戏，串起输入、循环、条件、类型转换与结果检查——这些都是日常写 CN 的核心动作。

猜数.cn（完整程序·逻辑演示）CN

导入 IO::读取整数;
导入 随机数::随机数生成器;

函数 主() -> 整32 {
    随机数生成器 生成器 = 随机数生成器(20261008);
    整64 答案 = 生成器.下一个范围(100) + 1;   // 1~100
    整32 次数 = 0;
    当 (真) {
        打印("猜一个 1~100 的数：");
        结果<整64, 整32> 输入 = 读取整数();
        如果 (输入.正常) {
            次数++;
            如果 (输入.值 < 答案) {
                打印("小了");
            } 否则 {
                如果 (输入.值 > 答案) {
                    打印("大了");
                } 否则 {
                    打印("猜中了！共 ", 次数, " 次");
                    中断;
                }
            }
        } 否则 {
            打印("输入结束，未猜中。答案是 ", 答案);
            中断;
        }
    }
    返回 0;
}
  • 读取整数() 返回 结果<整64, 整32>——必须检查（.正常），直接当数值用是编译错误。
  • 输入.值 只能在「已检查 .正常」的分支里访问，编译器帮你把关。
  • 随机数生成器(种子) 同种子同序列——把种子换成当前时间戳() 即可每次不同（见随机数）。

常见问题

现象原因与解法
错误: 未声明的标识符 'xxx'函数/变量名拼错，或忘了 导入 模块::名;。标准库函数（打印/字符串长度 等）是内置的，不需要导入。
结果<正常,错误> 返回值被丢弃未检查返回 结果 的调用不能当裸语句——按结果检查纪律接收并检查。
[安全区边界] xxx 应在 不安全 函数 内裸指针/手动内存操作须放在 不安全 函数 里，见进阶篇·安全区边界。
中文显示乱码（Windows 控制台）CN 源码与输出均为 UTF-8；老式 cmd 需先 chcp 65001 切到 UTF-8 代码页（Windows Terminal 默认即可）。
链接阶段报缺 MASM/GASwin 目标需随 Visual Studio 安装的主题组件（masm）；linux 目标需 binutils。交叉目标用 --target 指定。
