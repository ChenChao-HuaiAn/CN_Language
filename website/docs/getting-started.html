快速开始

五分钟内：拿到编译器、写出并运行你的第一个 CN 程序。

前置要求 Windows 需 VS2022（MSVC 工具链）；Linux x86_64 / ARM64 需 CMake ≥ 3.20 与 C++17 编译器（GCC/Clang）。CN 编译器本身用 C++ 写成——这是自举前的宿主， CN 版编译器 v2 已能编译自己。

第一步 · 获取源码

shellSH

git clone https://gitcode.com/ChenChao_GitCode/CN_Language.git
cd CN_Language

第二步 · 构建编译器

Windows（PowerShell）：

powershellSH

# 一键构建（-Test 追加全量测试门禁）
.\build.ps1

# 或手动
cmake -S . -B target/build
cmake --build target/build --config Debug

Linux（x86_64 / ARM64）：

bashSH

cmake -S . -B target/build
cmake --build target/build -j"$(nproc)"

第三步 · 你的第一个程序

新建 你好.cn：

你好.cnCN

// 入口函数 主 返回 整32，返回 0 表示成功
函数 主() -> 整32 {
    打印("你好，世界");
    返回 0;
}

编译并运行：

shellSH

# Windows
target\Debug\cn.exe build 你好.cn --output target\你好.exe
target\你好.exe
# 输出：你好，世界

# Linux（build 必须显式指定目标平台）
./target/cn build 你好.cn --target linux-x86_64 --output target/你好
./target/你好
Linux 平台提示 build 不指定 --target 时按缺省目标 win-x64 处理会失败—— Linux 上务必显式 --target linux-x86_64 或 linux-arm64。

第四步 · 记住这几条命令

命令作用
cn build 文件.cn编译 + 链接，产出可执行文件
cn run 文件.cn编译后直接运行
cn check 文件.cn只做语法/语义检查，不生成代码
cn ir 文件.cn查看中间表示（IR）
cn ast 文件.cn查看语法树
-O0 ~ -O3优化级别（SSA / 内联 / DCE 等）

完整选项见命令行参考。
