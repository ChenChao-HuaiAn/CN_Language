整数运算语义（四条法规）

  • 常量溢出/除零=编译错误：两侧均为字面量的常量表达式编译期预演（2147483647 + 1、10 / 0 直接拒绝）。
  • 变量面两补码回绕：INT_MIN / -1 ≡ INT_MIN、INT_MIN % -1 ≡ 0——全位宽一致，优化级别间行为一致（O0=O3）。
  • 窄类型保持窄域：整8/整16/正8/正16 的二元算术结果保持操作数宽度（整8 + 整8 = 整8），溢出回绕（127+1≡-128）；与更宽操作数混算按宽化规则提升。
  • 字面量窄化值域检查：整16 甲 = 40000; 编译拒绝（域内字面量豁免：整8 a = 10 合法）。

类型转换：显式位模式语义

类型名(表达式) 构造转换覆盖宽化/窄化/浮整/指针↔整数；规则与 Rust as 逐条同款。

方向语义例
宽化（隐式放行）有符号源=符号扩展；无符号源=零扩展整64 大 = 整32值;
同宽跨符号（显式）位模式重解释整64(正64(2^63)) = -2^63
降宽（显式）低位截断整32(大值) 取低 32 位
浮→整（显式）截断（向零取整）整32(3.99) = 3
整→浮（显式）精确转换浮64(3) / 4 = 0.75
指针↔整数（显式）位模式往返整64(指针) / 指针(地址)
混合符号禁隐式有符号（整N）×无符号（正M）的变量间二元运算/赋值/传参一律编译期拒绝（隐式宽化会静默反转值语义）；字面量豁免——一侧为字面量时按另一侧类型参与（正64 b = 5、大 > 100 照常）。同符号混合宽度维持宽化放行。

转换实证.cnCN

函数 主() -> 整32 {
    正64 位模式 = 正64(整32(-1));     // 符号扩展 → 2^64-1
    整64 重解释 = 整64(位模式);       // 位模式重解释（全 1 位模式）
    整32 截断 = 整32(3.99);
    打印(位模式 == 18446744073709551615, " ", 截断);
    打印(重解释 == 0 - 1);            // 全 1 位模式 = -1
    返回 0;
}

输出：真 3 真

确定初始化（def-init）

未初始化的局部值类型变量不得读取——编译期数据流拒绝（Rust E0381 对照），零运行时成本。

面内容
登记无初始化器的纯值类型声明：标量、数组（元素级跟踪）、结构体（叶子字段级）
置位赋值（含下标/字段左值）、复合赋值、自增自减（先读后写·读面拒绝）
豁免拥有型（类/容器/字符串/结果/可选——默认构造兜底）、指针/引用、静态（零初始化）、函数参数
控制流敏感如果=两支汇合取并集；返回终止的分支不参与；当/循环体内赋值不外溢（可能 0 次执行）
取地址=初始化通道&x 视为「可能被写」（出参惯用法）——取地址后读取放行

def-init.cn（负例·编译拒绝）CN

函数 主() -> 整32 {
    整32 x;
    打印(x);              // ✗ 编译错误：读取未初始化变量
    返回 0;
}

控制流敏感.cnCN

函数 主() -> 整32 {
    整32 x;
    如果 真 {
        x = 1;
    } 否则 {
        x = 2;
    }
    打印(x);              // 两支都赋值 → 汇合后已初始化 ✓
    返回 0;
}

输出：1

复合类型细则

类型语法要点
指针类型*不安全域解引用；空类型* 与任意指针互转
数组类型[长度]长度=编译期常量表达式（字面量/常量名/常量算术）；整体赋值=整块值拷贝（元素为字符串/类对象时句柄共享）
结构体结构体 名 {...}值聚合；指定初始化器穷举纪律
联合体联合体 名 {...}成员限可平凡复制类型（Rust union 成员须 Copy 同款）；拥有型成员编译硬错误，逃生舱=手动释放 标注+不安全域自行管理；字段访问=不安全操作
枚举枚举 名 {...}成员可显式赋值（含负数）；引用=枚举名.成员
函数指针返回(*名)(参数)代码指针恒可搬运；见函数参考
结果/可选结果<T,E> / 可选<T>错误处理类型，见错误处理参考

数组长度常量表达式.cnCN

常量 基数 = 4;

函数 主() -> 整32 {
    整32[基数 * 2] 表;          // 长度=常量算术 → 8
    表[7] = 8;
    打印(表[7]);
    返回 0;
}
