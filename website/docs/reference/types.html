类型系统

精确到位宽的整数、Unicode 字符、结构化复合类型——类型即文档。

整数与浮点

类型大小范围
整81 字节-128 ~ 127
整162 字节-32768 ~ 32767
整32（别名 整数）4 字节-2^31 ~ 2^31-1
整648 字节-2^63 ~ 2^63-1
整12816 字节-2^127 ~ 2^127-1
正8 ~ 正1281~16 字节0 ~ 2^位-1（无符号）
浮324 字节IEEE 754 单精度
浮64（别名 小数）8 字节IEEE 754 双精度

字符与字符串

  • 字符：Unicode 标量值，4 字节（'中' 是一个字符）。
  • 字符串：拥有型 UTF-8 字符串（\0 结尾），不可变——修改走拼接重建。 下标读按字节（返回整8），下标写编译期拒绝。

复合类型

类型语法说明
指针类型*指向类型的指针（底层操作限不安全区）
数组整32[5]定长数组，越界运行时检查
结构体结构体 名 {…}值语义；构造字面量 类型{字段=值}（字段穷举）
枚举枚举 名 {…}可指定底层值 自定义 = 100
联合体联合体 名 {…}拥有型成员编译期限定；手动释放 逃生舱
引用类型&参数/变量/返回位的左值别名
结果结果<T, E>成功或失败（见错误处理）
可选可选<T>有值或无（见错误处理）
函数指针整32(*)(整32, 整32)C 风格函数指针

确定初始化

局部变量必须先初始化再使用——编译器做数据流分析，未初始化使用 = 编译错误， 「未初始化读」这类 C 语言经典深渊在 CN 不存在。

类型转换

宽化/窄化/浮整/指针↔整数一律显式触发，C 风格构造转换语法：

转换.cnCN

浮64 比例 = 浮64(3) / 4;     // 显式转浮点
整32 截断 = 整32(3.99);      // 浮点转整（截断）
整64 地址 = 整64(指针值);     // 指针转整数（不安全域语义）
