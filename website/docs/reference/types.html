整数运算语义（五条法规）

  • 常量溢出/除零=编译错误：两侧均为字面量的常量表达式编译期预演（2147483647 + 1、10 / 0 直接拒绝）。
  • 运行期溢出=错误码 8 确定性失败（非回绕、非 UB）：安全区二元 + - *、自增自减、复合赋值在结果超出操作数类型值域时立即报运行时错误(错误码8): 溢出错误 终止（O0=O3、三后端一致）；整MIN / -1、整MIN 一元取负同族纳入（x % -1 ≡ 0 定义保留）；不安全 函数内不插检查。
  • 显式回绕走内置函数：确需两补码回绕语义用 回绕加/回绕减/回绕乘（全整型族·按实参类型分派·宽化与混合符号规则同运算符；编译期常量实参按回绕折叠不报错）；回绕语义已自变量面收缩为显式知情通道。
  • 窄类型保持窄域：整8/整16/正8/正16 的二元算术结果保持操作数宽度（整8 + 整8 = 整8），运行期溢出同按错误码 8 终止；与更宽操作数混算按宽化规则提升。
  • 字面量窄化值域检查：整16 甲 = 40000; 编译拒绝（域内字面量豁免：整8 a = 10 合法；负号形态按数学负值判域——各类型 MIN 如 -2147483648 合法书写）。
  • 移位量超宽=确定性失败：常量移位量 ≥ 位宽=编译期硬错误（5 << 40、「移位量超宽」诊断）；变量移位量=运行期错误码 8终止；确需取模手写 a << (k % 位宽) 显式闭环；移位丢高位不属检查对象（1 << 31 合法）。

字面量定级与值域检查（三分法）

  • ①无后缀非负字面量=随侧豁免：参与类型随另一侧整数操作数定级（正64 b = 5、大 > 100 惯用形态）；负号字面量不随侧（无符号域不承载负值）；两侧均无后缀=各自恒定级 整32。
  • ②带后缀字面量按后缀严格定级（L→整64 / LL→整128 / U→正32 / UL→正64 / ULL→正128），不随另一侧——结果宽于目标=赋值/声明初始化/返回/守卫四通道编译期拒绝（甲 = 3000000000L + 0; 拒；混合符号字面量豁免与复合赋值字面量豁免仍适用：癸 + 1U、丁 += 1L 放行）。
  • ③窄伴侣拉窄放行：一侧为窄整数（整8/整16/正8/正16）、另一侧为字面量（含带后缀）时，字面量按窄侧参与——仅算术面 + - * / %（整8 甲; 甲 = 甲 + 1L; 放行）；位面/移位面无此适配、按严格面判定（甲 = 1L & 2;、甲 = 1L << 2; 拒）。
  • ④128→64 同符号窄化特例：整128→整64、正128→正64 的表达式源隐式放行；跨符号组合不在特例内（随混合符号面拒）。
  • ⑤值域门槛先行：字面量直赋通道（初始化/赋值/返回/推断）先查目标类型值域——超域一律编译期拒绝（含同型直赋 整32 甲 = 3000000000;；负号形态按数学负值判域，-2147483648 合法）；推断通道无后缀字面量恒定级=整32、装不下即拒并指引显式类型（变量 甲 = 3000000000; 拒 → 改 整64 甲 = 3000000000;）；超 整64 域无后缀字面量在表达式求值与显式目标类型场景按整128 域求值（整128 x = 巨字面量），推断声明通道不适用。

类型转换：显式位模式语义

类型名(表达式) 构造转换覆盖宽化/窄化/浮整/指针↔整数；规则与 Rust as 逐条同款。

方向语义例
宽化（隐式放行）有符号源=符号扩展；无符号源=零扩展整64 大 = 整32值;
同宽跨符号（显式）位模式重解释整64(正64(2^63)) = -2^63
降宽（显式）低位截断整32(大值) 取低 32 位
浮→整/字符（显式）饱和截断（非 UB·NaN→0、超域钳制到边界，详下节）整32(3.99) = 3；整32(1.0e18) = 2147483647
整→浮（显式）精确转换浮64(3) / 4 = 0.75
指针↔整数（显式）位模式往返整64(指针) / 指针(地址)
混合符号禁隐式有符号（整N）×无符号（正M）的变量间二元运算/赋值/传参一律编译期拒绝（隐式宽化会静默反转值语义）；字面量豁免——一侧为字面量时按另一侧类型参与（正64 b = 5、大 > 100 照常）。同符号混合宽度维持宽化放行。

浮点→整数/字符：饱和截断

浮源显式转换全定义、零 UB——C 系的超域/NaN 未定义行为在此不存在；语义与 Rust as 逐条对齐。整数族间的位模式变换（上表）不受影响——浮点→整数不在位模式变换域内。

输入结果
NaN0
正超域（含 +inf）目标类型 MAX（整N 为 2^(N-1)-1，正N 为 2^N-1）
负超域（含 -inf）有符号目标 MIN；无符号目标 0
域内向零截断（整32(3.99) = 3、整32(-3.99) = -3）
字符目标按 Unicode 标量域 [0, 0x10FFFF] 钳制：上超域→0x10FFFF、非正值→0；代理区 [0xD800, 0xDFFF] 域内透传
常数 vs 运行期编译期常量折叠与运行期三后端发射同语义

确定初始化（def-init）

未初始化的局部值类型变量不得读取——编译期数据流拒绝（Rust E0381 对照），零运行时成本。

面内容
登记无初始化器的纯值类型声明：标量、数组（元素级跟踪）、结构体（叶子字段级）
置位赋值（含下标/字段左值）、复合赋值、自增自减（先读后写·读面拒绝）
豁免拥有型（类/容器/字符串/结果/可选——默认构造兜底）、指针/引用、函数参数；静态 豁免仅限顶层静态（无初值=零初始化）——函数内 静态 类型 名; 无初值=编译拒绝（须显式初值·Rust static 同款）
控制流敏感如果=两支汇合取并集；返回终止的分支不参与；当/循环体内赋值不外溢（可能 0 次执行）
取地址=初始化通道&x 视为「可能被写」（出参惯用法）——取地址后读取放行

复合类型细则

类型语法要点
指针类型*不安全域解引用；空类型* 与任意指针互转
数组类型[长度]长度=编译期常量表达式（字面量/常量名/常量算术）；整体赋值=整块值拷贝（元素为字符串/类对象时句柄共享）
