函数

定义、重载、默认参数、引用、lambda、函数指针——以及参数传递的确切语义。

定义与原型

函数.cnCN

函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b;
}

函数 打印问候() {          // 无返回值省略 -> 类型
    打印行("你好");
}

函数 计算(整32 n) -> 整32;   // 原型声明（前向引用）

重载与默认参数

  • 重载按参数类型与个数区分；仅返回类型不同不构成重载。
  • 默认参数从右向左连续声明；调用按位置补缺省。

重载.cnCN

函数 加(整32 a, 整32 b) -> 整32 { 返回 a + b; }
函数 加(浮64 a, 浮64 b) -> 浮64 { 返回 a + b; }
函数 加(字符串 a, 字符串 b) -> 字符串 { 返回 a + b; }   // 拼接

函数 问候(字符串 名字 = "世界") -> 空类型 {
    打印行("你好，" + 名字);
}

参数传递语义

形态语义
类类型按值形参引用语义（写穿）：类变量是指针槽模型，体内经句柄改字段，调用方可见
结构体/标量按值形参副本语义：体内写落副本，不影响实参
T& 引用形参传左值地址，读写写穿（标量/结构体/类均可）
常量 T&只读借用：体内改它 = 编译错误；借用互斥编译期检查

lambda

lambda.cnCN

变量 加倍 = [](整32 x) -> 整32 { 返回 x * 2; };
// 捕获：[] 不捕获 / [=] 值捕获 / [&] 引用捕获 / [变量] 显式捕获

函数指针

函数指针.cnCN

函数 加(整32 a, 整32 b) -> 整32 { 返回 a + b; }

函数 主() -> 整32 {
    整32(*回调)(整32, 整32);   // 声明
    回调 = 加;                 // 赋值
    整32 结果 = 回调(10, 20);  // 调用 → 30
    返回 0;
}

泛型函数

泛型函数.cnCN

泛型 <类型 T>
函数 交换(T& a, T& b) -> 空类型 {
    T 临时 = a;
    a = b;
    b = 临时;
}
// 编译期单态化：每个用到的 T 生成一份专属代码
