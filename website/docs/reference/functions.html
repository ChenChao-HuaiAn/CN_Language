函数

声明与调用、重载、默认参数、按值/引用/常量引用传参、泛型单态化、函数指针、lambda。

声明与调用

形态.cnCN

// 完整形态
函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b;
}

// 无返回值：-> 空类型（可省略标注）
函数 打印问候() {
    打印("你好");
}

// 前向声明（原型）：先声明后实现
函数 递归和(整32 n) -> 整32;

函数 主() -> 整32 {
    打印(加(1, 2), " ");
    打印问候();
    打印(递归和(4));
    返回 0;
}

函数 递归和(整32 n) -> 整32 {
    如果 n <= 0 { 返回 0; }
    返回 n + 递归和(n - 1);
}

输出：3 你好 10

重载与默认参数

  • 重载：同名函数按参数类型与个数区分；仅返回类型不同不构成重载；名称修饰按签名编码。
  • 默认参数：从右向左连续声明（有默认值的参数右侧不得出现无默认值参数）；调用按位置补缺省。

重载与默认.cnCN

函数 描述(整32 n) -> 字符串 { 返回 "整数"; }
函数 描述(浮64 x) -> 字符串 { 返回 "浮点"; }
函数 描述(整32 a, 整32 b) -> 字符串 { 返回 "一对整数"; }

函数 幂底(浮64 底, 浮64 指数 = 2.0) -> 浮64 {   // 浮点默认参数
    浮64 结果值 = 1.0;
    循环 (整32 i = 0; i < 整32(指数); i++) { 结果值 = 结果值 * 底; }
    返回 结果值;
}

函数 主() -> 整32 {
    打印(描述(1), " ", 描述(1.5), " ", 描述(1, 2));
    打印(幂底(3.0), " ", 幂底(2.0, 10.0));
    返回 0;
}

输出：整数 浮点 一对整数 9.000000 1024.000000

传参语义：副本 / 引用 / 只读借用 / 类=写穿

CN 传参有四种语义，按形参类型决定——这是最容易被其他语言经验带偏的地方，务必读全。

形参形态语义体内写对调用方的影响
标量 / 结构体 按值副本（整块值拷贝）无影响
T& 引用写穿（左值地址传递）直接影响调用方
常量 T&只读借用（体内写=编译错误）无影响（也不可能）
类类型按值引用语义（形参槽=对象句柄拷贝，体内经句柄写同一堆对象）字段写/方法调用写穿调用方

四语义.cnCN

类 盒子 {
公开:
    整64 值槽;
    函数 盒子(整64 初) { 值槽 = 初; }
}

结构体 点 {
    整64 x;
}

函数 改标量(整32 v) -> 空类型 { v = 99; }        // 副本
函数 改结构(点 p) -> 空类型 { p.x = 99; }        // 副本
函数 改类(盒子 b) -> 空类型 { b.值槽 = 99; }     // 句柄：写穿！
函数 改引用(整64& v) -> 空类型 { v = 99; }       // 引用：写穿

函数 主() -> 整32 {
    整32 标 = 1;
    点 结构点 = 点{x = 1};
    盒子 对象 = 盒子(1);
    整64 引值 = 1;
    改标量(标);
    改结构(结构点);
    改类(对象);
    改引用(引值);
    打印(标, " ", 结构点.x, " ", 对象.值槽, " ", 引值);
    返回 0;
}

输出：1 1 99 99

引用族.cnCN

函数 传回(整32& x) -> 整32& {        // 返回引用：返回被引用左值的地址
    返回 x;
}

函数 主() -> 整32 {
    整32 x = 10;
    整32& r = x;                      // 引用变量：r 是 x 的别名
    r = 20;                           // 经引用写 = 直接改 x
    打印("经引用变量写回: ", x);       // 20
    整32 值 = 100;
    整32& 别名 = 传回(值);             // 接收函数返回的引用
    别名 = 200;
    打印("经返回引用写: ", 值);        // 200
    传回(值) = 300;                    // 返回引用可作赋值目标
    打印("返回引用作赋值目标: ", 值);   // 300
    返回 0;
}

输出：经引用变量写回: 20 经返回引用写: 200 返回引用作赋值目标: 300

  • 引用变量 整32& r = x;：绑定既有左值，读自动解引用、赋值经地址写回原变量（C++ 引用语义）。
  • 函数返回 T&：返回被引用左值的地址（可继续作赋值目标/绑定新引用）；返回本函数局部变量地址=编译错误「引用返回不能返回局部变量的地址」——悬垂引用在编译期拦下（Rust 同构）。
  • 实参须左值：引用形参传字面量/纯右值（含显式取址 f(&x)——&x 是指针不同类型，不是同类型左值）=编译错误「引用参数要求左值实参」（右值无处取址；静默物化临时槽=被调方写参落空）。
  • 引用默认值禁止：函数 f(整32& a = 值)=编译错误「引用参数不能有默认值（引用须绑定调用方左值）」。
  • 借用互斥（第一版·语句级）：同一调用中同一变量以可变引用借出两次=编译错误「… 被可变借用两次（别名可变冲突）」（双改(x, x)）；可变引用实参与常量引用实参解析到同一基础变量=编译错误「… 的可变借用与只读借用互斥」（混(甲, 甲)）。常量引用只读三纪律（体内赋值/复合赋值/转传可变引用=编译错误「是只读借用，不能赋值/传参」）见 教程·安全与并发·借用。

返回局部引用.cn（负例·编译拒绝）CN

函数 坏() -> 整32& {
    整32 局部 = 5;
    返回 局部;                 // ✗ 悬垂：局部变量随函数返回失效
}

函数 主() -> 整32 {
    返回 0;
}

双可变借用.cn（负例·编译拒绝）CN

函数 双改(整64& 甲, 整64& 乙) -> 空类型 {
    甲 = 甲 + 乙;
}

函数 主() -> 整32 {
    整64 x = 5;
    双改(x, x);                // ✗ 同一变量可变借用两次
    返回 0;
}
  • 要与「副本语义」传类，传前显式 复制(对象)（深拷克隆）。
  • 容器元素读取（元素/获取）返回副本（快照）——写回用 设置、写穿用 元素引用：与形参语义正交。
  • 临时实参传类形参合法（编译器物化临时槽）。
  • 字符串元素容器的访问器（元素/读取/栈顶/队首/头部元素/读取头部/读取尾部/获取）返回元素句柄浅拷=借出视图——容器失效方法（删除/设置/清空/弹出/出队/删除头部/删除尾部/释放内部数组）之后该视图悬垂，编译期拒绝（NLL 顺序近似，Rust E0502 同构）；正则见 教程·安全与并发·借出视图。

泛型函数：编译期单态化

泛型.cnCN

泛型 <类型 T>
函数 首个或默认(T* 表, 整64 长度, T 缺省) -> T {
    如果 长度 > 0 { 返回 表[0]; }
    返回 缺省;
}

函数 主() -> 整32 {
    整32[3] 数 = {5, 6, 7};
    浮64[2] 实 = {1.5, 2.5};
    打印(首个或默认<整32>(数, 3, 0), " ", 首个或默认<浮64>(实, 0, 9.9));
    返回 0;
}

输出：5 9.900000

  • 泛型调用双形态：显式 名<类型>(实参) 与省略类型的隐式推导 名(实参) 均合法——实参类型可唯一确定时（含后置定义的泛型函数）省略 <类型>；推导不适用的形态（如引用形参位）写显式 <类型> 即可。
  • 每个实例化生成一份专用代码：零运行时开销、可内联优化。
  • 类型参数可约束接口：泛型 <类型 T : 可比较>。

函数指针与 lambda

函数指针.cnCN

函数 加(整32 a, 整32 b) -> 整32 { 返回 a + b; }
函数 乘(整32 a, 整32 b) -> 整32 { 返回 a * b; }

函数 折叠(整32[3] 表, 整32(*二元)(整32, 整32)) -> 整32 {
    整32 累 = 表[0];
    循环 (整32 i = 1; i < 3; i++) { 累 = 二元(累, 表[i]); }
    返回 累;
}

函数 主() -> 整32 {
    整32[3] 表 = {2, 3, 4};
    打印(折叠(表, 加), " ", 折叠(表, 乘));
    变量 加倍 = [](整32 x) -> 整32 { 返回 x * 2; };   // lambda
    打印(加倍(21));
    返回 0;
}

输出：9 24 42

  • 函数名可衰减为函数指针（折叠(表, 加)）；函数指针=代码指针，恒可搬运（可传给新线程）。
  • 声明位形态：整32(*名)(整32, 整32)；字段/数组元素/返回位/静态位全部支持（规格 §5.8）。
  • 来源封口：合法来源仅两种——函数名衰减（含静态方法 类名.静态方法、泛型实例名）与同签名函数指针；整数/空指针等任何其他类型赋给函数指针=编译错误「无法将 … 隐式转换为 '函数指针<…>'」（代码地址与数据地址通道分离——函数指针恒指向真实函数）。
  • 空调用防线：零值（未赋值）函数指针间接调用=运行期确定性失败——每个间接调用点内置判零检查，零值报 运行时错误(错误码3): 空指针解引用（Rust 裸 fn pointer 调用为 UB；CN 安全区更严）。
  • 方法作值：静态方法 类名.方法 可直接作函数指针值（实参位/变量初值/返回位全通）；实例方法 对象.方法 作值=绑定 this 的闭包——经变量调用（变量 cb = 对象.方法; cb(实参)）捕获对象地址、读最新状态，不可直接作裸 fnptr 实参（裸地址无法携带 this=编译错误「须先赋值给变量」）。
  • lambda 捕获形态：[] 不捕获 / [=] 值捕获 / [&] 引用捕获 / [变量] 显式捕获。
  • [&] 引用捕获逃逸限制：引用捕获 lambda 持有定义帧局部变量地址——赋给局部变量+同帧调用（含立即调用）放行；作返回值（含经局部变量的传播链）/作实参传出/存长寿命载体=编译错误「逃逸当前栈帧」（指路：改 [=] 值捕获快照，或改在 不安全 函数 内定义豁免——责任上移）；分析不确定按逃逸拒绝（永不静默放行）。值捕获/空捕获=快照语义无悬垂面，不受限（可安全逃逸）。

逃逸当前栈帧.cn（负例·编译拒绝）CN

函数 得闭包() -> 整32(*)() {
    变量 x = 5;
    返回 [&]() -> 整32 { 返回 x; };   // ✗ 编译错误：逃逸当前栈帧
}

函数 主() -> 整32 {
    返回 0;
}

值捕获安全逃逸.cnCN

函数 造取() -> 整64(*)() {
    整64 基 = 5000000000;
    变量 取 = [=]() -> 整64 { 返回 基 * 2; };
    返回 取;               // 值捕获快照：逃逸定义帧合法
}

函数 主() -> 整32 {
    变量 取 = 造取();
    打印(取());
    返回 0;
}

输出：10000000000
