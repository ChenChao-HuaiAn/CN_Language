并发

线程生命周期、实参语义、可搬运法则、互斥锁<T> 的类型化守护——宁严勿松的并发模型。

新线程 / 并入线程

函数签名语义
新线程不安全 函数 新线程(整64(*入口)(空类型*), 空类型* 实参) -> 结果<空类型*, 整32>启动线程；入口=函数指针（可由函数名衰减）；实参按值拷贝进新线程（无别名）
并入线程不安全 函数 并入线程(空类型* 句柄) -> 整64等待结束并取回入口返回值；同步点=顺序一致；每句柄恰好并入一次

生命周期.cnCN

导入 线程::{新线程, 并入线程};

不安全 函数 作业(空类型* 未用) -> 整64 {
    整64 计数 = 0;
    循环 (整64 i = 0; i < 5000; i++) { 计数 = 计数 + 1; }
    返回 计数;
}

不安全 函数 主() -> 整32 {
    结果<空类型*, 整32> 建一 = 新线程(作业, 无);   // 形态①：函数名衰减
    如果 (建一.正常) {
        打印(并入线程(建一.值) == 5000);
    } 否则 { 返回 1; }
    整64(*入口)(空类型*) = 作业;                    // 形态②：函数指针变量
    结果<空类型*, 整32> 建二 = 新线程(入口, 无);
    如果 (建二.正常) {
        打印(并入线程(建二.值) == 5000);
    } 否则 { 返回 1; }
    返回 0;
}
宁严勿松未并入的线程在 主 返回时=运行时错误（运行时层退出链）——忘记 并入 不是静默泄漏而是立刻报错。linux=pthread 真实现；win 后端为运行时错误桩（路线图波次内）。

可搬运（Send）法则

跨线程传递的值必须可搬运——含裸指针字段（空类型*/字符串/容器句柄等）的类型默认不可搬运，编译期拦截；豁免窗口=顶层 空类型* 实参位（新线程(f, 无)）。Rust Send 同位。

不可搬运.cn（负例·编译拒绝）CN

导入 线程::{新线程, 并入线程};

不安全 函数 作业(空类型* 盒) -> 整64 { 返回 0; }

不安全 函数 主() -> 整32 {
    整64 局部 = 5;
    整64* 指向局部 = &局部;
    结果<空类型*, 整32> 建 = 新线程(作业, 指向局部);   // ✗ 裸指针不可跨线程
    返回 0;
}
  • 互斥锁<T> 可搬运 ⇔ T 可搬运（容器名单基名判定）。
  • 函数指针=代码指针，恒可搬运。
  • 确需跨线程传裸指针：以「所有权移交设计」重构（由目标线程独占）或等待后续显式豁免立法——默认路径零豁免。

互斥锁<T> 与过渡 API

形态形态成员定位
互斥锁<T>（推荐）互斥锁(T 初值) / 上锁() / 解锁() / 公开字段 值锁与数据类型化绑定；可搬运联动；实例=对象句柄（跨线程共享实例=共用锁）
过渡函数（不推荐）互斥锁新建/互斥锁上锁/互斥锁解锁/互斥锁释放裸句柄无类型=可锁错对象；立法前过渡，新代码禁用
  • 上锁/解锁 显式配对（RAII 锁守卫在路线图）；必须由加锁者解锁。
  • 裸句柄互斥锁释放须未加锁态。
  • 线程六个包装函数全部 不安全（001 §5.8b sunset 收窄）。
