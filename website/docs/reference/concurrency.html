并发

可搬运标记（对标 Send）+ 互斥锁<T> 类型化句柄——数据竞争在类型层面设防。

新线程

标准库 线程 模块：新线程(入口, 实参) 启动线程， 并入线程 等待汇合（对标 join）。Linux x64 为真 pthread 实现。

可搬运（对标 Rust Send）

可搬运 = 该类型的值可安全按值拷贝进另一线程。自动推导，用户零负担：

类型可搬运性
标量、字符串、函数指针恒可搬运
结果<T> / 可选<T>⇔ T 可搬运
容器 / 数组⇔ 元素类型可搬运
结构体 / 类⇔ 全部字段可搬运（递归，含继承）
含裸指针字段（T*）默认不可搬运——数据竞争温床

新线程 实参位的每个值都须可搬运，违例 = 编译错误 （诊断含类型名与字段链）。确需跨线程的含指针类型可显式声明 不安全 可搬运——声明人自担安全责任（对标 unsafe impl Send）。

互斥锁<T>（对标 Rust Mutex<T>）

标准库泛型类，锁与受护数据类型化绑定——「拿 A 锁护 B 数据」在类型检查下不可表达：

互斥锁.cnCN

导入 线程::互斥锁;

函数 主() -> 整32 {
    互斥锁<整32> 计数 = 互斥锁(0);   // 带初值构造

    计数.上锁();
    计数.值 = 计数.值 + 1;           // 受护值经 .值 访问
    计数.解锁();

    返回 0;
}
  • API：互斥锁(初值) / 上锁() / 解锁() 显式对；析构自动释放句柄。
  • 可搬运联动：互斥锁<T> 可搬运 ⇔ T 可搬运。
诚实边界 第一版为显式 上锁/解锁 对（RAII 锁守卫随析构链成熟另立）；未锁直访 .值 暂不拦截（收紧为编译期拒绝在计划内）。原子库与跨线程共享语法另立任务。
