主.cnCN

函数 主() -> 整32 {
    打印("===== 系统库（Task 6.5）=====");

    // ==================== 1. 参数个数（含可执行文件名本身） ====================
    整64 个数 = 系统::参数个数();
    打印("参数个数: ", 个数);             // 3（exe + hello + CN语言）

    // ==================== 2. 参数按索引取 argv ====================
    打印("参数个数>=1: ", 个数 >= 1);     // 1

    // argv[0]：可执行文件名本身（非空）
    字符* 程序名 = 系统::参数(0);
    如果 (程序名 != 无) {
        打印("argv[0]非空: ", 字符串长度(程序名) > 0);  // 1
    } 否则 {
        打印("argv[0]为空");
    }

    // argv[1]：hello
    字符* 参数一 = 系统::参数(1);
    如果 (参数一 != 无) {
        打印("argv[1]: ", 参数一);        // hello
    } 否则 {
        打印("argv[1]为空");
    }

    // argv[2]：CN语言（中文参数）
    字符* 参数二 = 系统::参数(2);
    如果 (参数二 != 无) {
        打印("argv[2]: ", 参数二);        // CN语言
    } 否则 {
        打印("argv[2]为空");
    }

    // 越界：超出 argc-1 → nullptr → 失败
    字符* 越界 = 系统::参数(99);
    如果 (越界 != 无) {
        打印("越界参数: ", 越界);
    } 否则 {
        打印("越界参数失败");             // 失败
    }

    打印("===== 系统库测试完成 =====");
    返回 0;
}

输出：===== 系统库（Task 6.5）===== 参数个数: 3 参数个数>=1: 真 argv[0]非空: 真 argv[1]: hello argv[2]: CN语言 越界参数失败 ===== 系统库测试完成 =====

主.cnCN

函数 主() -> 整32 {
    整64 甲 = 0xFF;                // 255
    整64 乙 = 0b1010;              // 10
    整64 丙 = 0o777;               // 511
    整64 丁 = 42L;                 // 42
    整64 戊 = 7U;                  // 7
    整64 己 = 36028797018963968;   // 2^55（超 imm32 域十进制）
    整64 庚 = 0x7FFFFFFFFFFFFFFF;  // 2^63-1（int64 正上界）
    整64 辛 = -255;                // 负常量（补码 neg 路径）
    打印(甲);
    打印(乙);
    打印(丙);
    打印(丁);
    打印(戊);
    打印(己);
    打印(庚);
    打印(辛);
    如果 (甲 == 255 && 乙 == 10 && 丙 == 511 && 丁 == 42 && 戊 == 7) {
        如果 (己 == 36028797018963968 && 庚 == 9223372036854775807 && 辛 == 0 - 255) {
            返回 0;
        }
    }
    返回 1;
}

输出：255 10 511 42 7 36028797018963968 9223372036854775807 -255

  • 后缀：f→浮32、L→整64、LL→整128、U→正32、UL→正64、ULL→正128。
  • 无后缀大字面量超出 整64 域时提升为 整128（在整128 域内求值）。
  • 不支持数字下划线分隔。

运算符与 13 级优先级

优先级运算符说明
13（最高）() [] . ++ -- ?后缀：调用/下标/成员/后缀自增自减（值=原值）/后缀错误传播
12! ~ - ++ -- * &一元：非/按位非/负/前缀自增自减（值=新值）/解引用/取地址
11* / %乘除余
10+ -加减（字符串 + 数值 自动拼接）
9<< >>移位（超宽=确定性失败：常量移位量编译期硬错误、变量移位量错误码 8；丢高位不属检查对象）
8< <= > >=关系（字符串=字典序）
7== !=相等（字符串=内容比较）
6&按位与
5^按位异或
4|按位或
3&&逻辑与（短路）
2||逻辑或（短路）
1.5条件 ? 真值 : 假值三元（右结合·惰性求值）
1（最低）= += -= …赋值与复合赋值
  • 位运算仅整型；>> 有符号=算术右移、无符号=逻辑右移；~x ≡ x ^ -1。
  • 成员访问统一 .，指针左侧自动解引用一级；-> 已废除（仅保留于返回类型标注 -> 类型）。
  • &类变量 产对象地址（非句柄槽地址）；&标量/结构体 =槽地址。
  • 类/结构体可重载的运算符集合与决议规则见类与对象·运算符重载。

语句终止：分号强制

每条语句必须以 ; 结束（C/Rust 同款）；换行是纯空白，表达式内可自由续行。行尾漏分号=语法错误（诊断「语句缺少分号 ';'」），不存在自动分号插入——行首/行尾词法拼接类事故被结构性根除。

  • 空语句非法：裸 ; 不合法（诊断「预期表达式」）——合法的空循环体写 当(x) { }（空块合法）。
  • 循环体强制块：当(x); 是语法错误（诊断「预期 '{'」）——当/循环/如果 的体一律 { }，不做单语句体。
  • 单行多语句合法：变量 a = 1; 变量 b = 2; 由分号分隔，行内最后一条同样须 ;；行内块 { x = 1; } 内部语句同样强制分号。
  • } 自终结：块/如果/当/循环/选择体、函数体、结构体/类/接口/枚举体后不加分号（} 即边界）；模块级声明（导入/顶层常量/静态/全局变量）须分号。

条件编译（#定义 / #如果定义）

编译期开关：以宏旗标在词法层裁剪源码分支——被裁分支不产生任何 token。宏是无值旗标；没有带参宏、宏体展开与 #包含（这些职责由模块系统与常量表达式承担）。

指令形态说明
#定义 宏名整行（行首可缩进）定义宏（无值旗标·仅存在性判定）；父层被裁剪时不生效
#如果定义(宏名) 或 #如果定义 宏名整行条件开始：括号形式与空白形式等价
#否则整行条件分支（每层至多一个）
#结束如果整行条件结束（与 #如果定义 严格配对；纯空分支合法）
词法层裁剪模型非选中分支的整行在词法层被替换为空白（行号与换行保留）——不产生任何 token，即使内含语法错误也不诊断。宏名由 ASCII 字母/数字/下划线或中文组成。

主.cnCN

#定义 发布模式

函数 主() -> 整32 {
    // ---- 1. 源码内 #定义 宏 + #如果定义 选择 ----
    #如果定义 发布模式
    打印("发布模式: 开启");
    #否则
    打印("发布模式: 关闭")
    #结束如果

    // ---- 2. 未定义宏分支裁剪：语法错误代码被裁剪不应报错 ----
    #如果定义 不存在的宏
    这行是非法语法，不应被解析
    #否则
    打印("未定义宏分支: 已裁剪");
    #结束如果

    // ---- 3. 嵌套条件编译 ----
    #如果定义 发布模式
    打印("外层: 真");
    #如果定义 调试模式
    打印("内层: 调试")
    #否则
    打印("内层: 非调试");
    #结束如果
    #否则
    打印("外层: 假")
    #结束如果

    // ---- 4. 空宏名占位（宏未定义时的 #结束如果 正确闭合）----
    #如果定义 调试模式
    #结束如果
    打印("空分支: 已闭合");

    // ---- 5. 括号形式与空白形式等价 ----
    #如果定义(发布模式)
    打印("括号形式: 命中");
    #结束如果
    #如果定义 发布模式
    打印("空白形式: 命中");
    #结束如果

    返回 0;
}

输出：发布模式: 开启 未定义宏分支: 已裁剪 外层: 真 内层: 非调试 空分支: 已闭合 括号形式: 命中 空白形式: 命中

  • 嵌套：条件块可嵌套（上例第 3 段）——父层被裁剪时，内层 #定义 不生效、内层 #如果定义 恒假（C 语义）。
  • 上游注入：命令行 -D 宏名（可多次）与货舱.toml [特性] 的启用名单并入同一宏集合，等价源内 #定义——见命令行参考·选项、模块系统·货舱。
  • 行尾无关性：裁剪与源文件行尾格式（CRLF/LF）无关，两种行尾形态编译产物一致。
  • 不支持：带参宏、宏体展开、#包含、#取消定义、常量表达式条件——与 C 预处理器的能力边界划清。
