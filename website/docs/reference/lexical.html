词法结构

源文件、注释、字面量、运算符与优先级、分号规则——语言的原子层。

源文件

  • 扩展名 .cn，编码必须为 UTF-8。
  • 入口约定：程序入口是 主 函数（入口文件命名 主.cn 仅为约定）。

// 单行注释
/* 块注释，
   支持嵌套 */

运算符

算术 + - * / %；比较 == != < > <= >=；逻辑 && || !； 位 & | ^ ~ << >>（仅整型）；赋值 = += -= *= /= %= &= |= ^= <<= >>=； 指针 &（取地址）*（解引用）；成员 .；下标 []；三元 ? :。

两条重要语义 ①成员访问统一用 .：-> 不是成员运算符（它只用于函数返回类型标注）； 指针左侧的 . 自动解引用一级（p.x 等价 (*p).x）。 ②字符串下标 s[i] 按 UTF-8 字节索引读（返回整8），写是编译期拒绝—— 字符串是不可变拥有型。

分号规则

语句必须以分号 ; 终结（Rust/C++ 同款）；换行只是空白， 不是语句边界。块结构（}）自终结——块、函数体、类体之后不写分号：

分号.cnCN

函数 主() -> 整32 {
    整32 a = 1;        // ✓ 语句有分号
    如果 a > 0 {       // 控制流头不需要分号
        a = a + 1;     // ✓
    }                  // ✓ 块后不加分号
    返回 a;
}                      // ✓ 函数体后不加分号

    #结束如果
    返回 0;
}
