字面量

整数字面量

进制与后缀CN

函数 主() -> 整32 {
    打印(42, " ", 0xFF, " ", 0b1010, " ", 0o777);   // 42 255 10 511
    打印(100L, " ", 5U, " ", 7ULL);            // 100 5 7（整64/正32/正128）
    打印(1.5f, " ", 2.5, " ", 1.5e10);         // 浮32/浮64/科学计数
    返回 0;
}

输出：42 255 10 511 100 5 7 1.500000 2.500000 15000000000.000000

  • 后缀：f→浮32、L→整64、LL→整128、U→正32、UL→正64、ULL→正128。
  • 无后缀大字面量超出 整64 域时提升为 整128（在整128 域内求值）。
  • 不支持数字下划线分隔。

字符与字符串字面量

字符串形态CN

函数 主() -> 整32 {
    字符 c1 = '甲';             // Unicode 码点（4 字节）
    字符 c2 = '\n';             // 转义
    字符 c3 = '\u{4E2D}';       // Unicode 转义 = '中'
    字符串 普通 = "第一行\n";
    字符串 原样 = 原始"正则^\d+$";     // 反斜杠不转义
    字符串 多行文 = 多行"""第一行
第二行""";                     // 内部仍处理转义
    打印(字符串长度(普通), 字符串长度(原样), 字符串长度(多行文));
    返回 0;
}
  • 常用转义：\n 换行、\t 制表、\0 空、\\ 反斜杠、\" 引号、\u{码点}。
  • 原始"..." 反斜杠原样；多行"""...""" 跨行（内部仍处理转义）；原始多行"""...""" 完全原始。

运算符与 13 级优先级

优先级运算符说明
13（最高）() [] . ++ -- ?后缀：调用/下标/成员/后缀自增自减（值=原值）/后缀错误传播
12! ~ - ++ -- * &一元：非/按位非/负/前缀自增自减（值=新值）/解引用/取地址
11* / %乘除余
10+ -加减（字符串 + 数值 自动拼接）
9<< >>移位（移位量按位宽取模）
8< <= > >=关系（字符串=字典序）
7== !=相等（字符串=内容比较）
6&按位与
5^按位异或
4|按位或
3&&逻辑与（短路）
2||逻辑或（短路）
1.5条件 ? 真值 : 假值三元（右结合·惰性求值）
1（最低）= += -= …赋值与复合赋值
  • 位运算仅整型；>> 有符号=算术右移、无符号=逻辑右移；~x ≡ x ^ -1。
  • 成员访问统一 .，指针左侧自动解引用一级；-> 已废除（仅保留于返回类型标注 -> 类型）。
  • &类变量 产对象地址（非句柄槽地址）；&标量/结构体 =槽地址。
  • 类/结构体可重载的运算符集合与决议规则见类与对象·运算符重载。

语句终止：分号强制

每条语句必须以 ; 结束（C/Rust 同款）；换行是纯空白，表达式内可自由续行。行尾漏分号=语法错误，不存在自动分号插入——行首/行尾词法拼接类事故被结构性根除。
