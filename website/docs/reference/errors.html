错误处理

没有异常——失败是值：结果<T, E> 与 可选<T>，编译器强制检查。

结果类型

结果.cnCN

函数 除法(整32 a, 整32 b) -> 结果<整32, 整32> {
    如果 b == 0 {
        返回 错误(1);       // 错误码 1：除零
    }
    返回 正常(a / b);
}

函数 主() -> 整32 {
    结果<整32, 整32> 商 = 除法(10, 0);
    如果 商.正常 {
        打印行(商.值);
    } 否则 {
        打印行("除零错误: ", 商.错误);
    }
    返回 0;
}

正常() / 错误() 是内置构造器（编译器预置，不可重定义）。

可选类型

可选.cnCN

函数 查找(整32 键) -> 可选<整32> {
    如果 表.包含(键) {
        返回 某些(表[键]);
    }
    返回 无;
}
// 访问 .值 前必须检查 .有值

强制检查三规则

规则内容级别
规则 1结果<T,E> 返回值不检查就丢弃编译错误
规则 2检查 .正常 后未处理错误分支警告
规则 3可选<T> 访问 .值 前未检查 .有值编译错误

? 错误传播

后缀 ?：正常/有值则取 .值 继续；失败则从当前函数返回错误 （Rust ? 同语义）。当前函数返回类型须兼容：

传播.cnCN

函数 除法传播(整32 a, 整32 b) -> 结果<整32, 整32> {
    整32 商 = 除法(a, b)?;   // 失败即上抛
    返回 正常(商);
}
