结果<T, E> 与 可选<T>

类型构造检查取值

主.cnCN

函数 找值(整32 编号) -> 可选<字符串> {
    如果 编号 == 1 {
        返回 某些("甲");
    }
    返回 无;
}
函数 主() -> 整32 {
    可选<字符串> 甲 = 找值(2);
    如果 甲.有值 {
        打印行(甲.值);
    } 否则 {
        打印行("无值路径");
    }
    返回 0;
}

输出：无值路径

三条强制检查规则（编译期）

规则内容诊断示例
① 禁丢弃结果/可选 返回值当裸语句=错误返回值被丢弃未检查（须用 结果.正常 检查后处理两个分支）
② 禁未检取值未检查 .正常 直接访问 .值=错误访问 结果.值 前必须检查 结果.正常
③ 检查器数据流链式 x().值、跨语句守卫跟踪（检查状态=变量属性，遮蔽声明 kill）同上，含行定位
  • 守卫跟踪是流敏感的：如果 (x.正常) { 用 x.值; } 合法；x = f(); 重新赋值后检查状态重置。
  • 复合条件不受守卫：如果 (a.正常 && b.正常) 内取 a.值 会被拒（保守方向）——分开嵌套写。

错误传播：后缀 ?

表达式?：正常/有值→取 .值 继续；失败→构造错误结果从当前函数返回（须函数返回类型兼容）。Rust ? 同构。

主.cnCN

函数 底层(整32 v) -> 结果<整32, 整32> {
    如果 v < 0 { 返回 错误(6); }
    返回 正常(v * 2);
}

函数 中层(整32 v) -> 结果<整32, 整32> {
    整32 值 = 底层(v)?;
    返回 正常(值 + 1);
}

函数 顶层(整32 v) -> 结果<整32, 整32> {
    整32 值 = 中层(v)?;
    返回 正常(值);
}

函数 主() -> 整32 {
    结果<整32, 整32> 好 = 顶层(5);
    如果 好.正常 {
        打印("链式好: ", 好.值);
    } 否则 { }
    结果<整32, 整32> 坏 = 顶层(-1);
    如果 坏.正常 { } 否则 {
        打印("链式坏: ", 坏.错误);
    }
    返回 0;
}

输出：链式好: 11 链式坏: 6

? 与三元的词法消歧后缀 ?（优先级13）与三元 ?: 按同层 : 配对前瞻区分——? 后同层存在配对 : 判三元，否则判传播；a ? -b : c 无需加括号。

错误码全表（附录 B）

码枚举成员典型来源
1错误码.除零整数除零（运行期）
2错误码.越界数组/容器下标越界；字符串字节下标越界
3错误码.空指针空指针解引用
4错误码.内存分配失败（容器扩容等）
5错误码.文件文件打开/读写失败；标准输入 EOF
6错误码.参数无效参数（解析失败/越界实参）；断言失败
7错误码.未初始化读取未初始化数据（如空栈弹出/映射未命中）
8错误码.溢出运行期算术溢出（+ - */自增自减/复合赋值）、整MIN / -1 与 整MIN 一元取负、变量移位量超宽
9—（运行时输出·未入枚举）栈溢出：深递归耗尽线程栈 → 确定性终止（安全/不安全区同拦；手工线程须先调用 cn_install_thread_stack_guard）
  • 运行时错误(码) 内置：打印 运行时错误(错误码N): 消息 并终止进程（退出码 1）——标准库「直读越界即中止」就是它。
  • 错误码 8 的触发面（不安全 函数内不插检查）：运行期算术溢出、整MIN / -1、整MIN 一元取负、变量移位量 ≥ 位宽——常量面溢出/移位超宽=编译期硬错误（不产生退出码）；确需回绕用 回绕加/回绕减/回绕乘。
  • 入口退出码：主 返回 结果<整32, E> 时，正常 → 退出码取 .值；失败 → 退出码取 .错误（Rust Termination 同构；.值 非数值的结果形态=编译期诊断）。
  • 栈溢出防线（错误码 9）的实现性质：进程级信号兜底——运行时入口一次性安装，零热路径开销（不在函数体内插任何栈检查）；判据=故障地址与栈指针比邻的指纹匹配，匹配不到=不拦截（恢复平台默认崩溃，宁漏勿误、不作承诺）；不安全 函数内同样生效（防线面向整个进程）。安装与手工线程细节见命令行参考·环境。
  • win 崩溃诊断（[crash]/[veh] 系列带寄存器与回溯）仅未处理异常时输出到 stderr，正常启动零输出。
