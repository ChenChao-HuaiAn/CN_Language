类与对象

类、继承、接口、静态成员、常量成员、友元、运算符重载。

类定义与访问控制

访问控制为标签式：公开: / 私有: / 保护:，默认私有。 与类同名的函数是构造函数，~类名 是析构函数（RAII）：

类.cnCN

类 动物 {
公开:
    字符串 名称;
    虚拟 函数 叫声() -> 字符串 {
        返回 "...";
    }
保护:
    整32 年龄;
私有:
    整32 内部ID;
}

继承与重写

继承.cnCN

类 狗 : 动物 {
公开:
    重写 函数 叫声() -> 字符串 {
        返回 "汪汪";
    }
    函数 狗(字符串 名) { 名称 = 名; }
    函数 ~狗() { /* 析构 */ }
}

类 子类 : 父类 {
公开:
    重写 函数 方法() -> 空类型 {
        自身.字段 = 10;    // 访问自身成员
        父类.方法();       // 调用父类方法
    }
}

接口实现语法为 类 名 : 接口名；单一实现的接口调用会去虚拟化直连， 多实现走运行时虚表分派。

静态成员与常量成员

静态.cnCN

类 计数器 {
公开:
    静态 整32 总数 = 0;
    函数 计数器() { 总数++; }
    静态 函数 获取总数() -> 整32 { 返回 总数; }
}
// 类外访问：计数器.总数 / 计数器.获取总数()

类 只读包装 {
    整32 值;
公开:
    常量 函数 获取() -> 整32 {   // 承诺不修改成员
        返回 值;
    }
}

友元

友元.cnCN

类 账户 {
私有:
    整64 余额;
公开:
    友元 函数 审计(账户& 账);
}

函数 审计(账户& 账) -> 整64 {
    返回 账.余额;    // 友元可访问私有（最小授权，谨慎使用）
}

运算符重载

仅限成员函数；左操作数必须是本类实例。可重载集合： + - * / % == != < > <= >= && || ! & | ^ ~ << >> [] ()。 单目无参数、双目单参数：

运算符.cnCN

类 复数 {
公开:
    浮64 实部; 浮64 虚部;
    函数 运算符+(复数 右) -> 复数 {
        返回 复数{实部 + 右.实部, 虚部 + 右.虚部};
    }
}
复数 c = a + b;    // 调用 运算符+

泛型类

泛型类.cnCN

泛型 <类型 T>
类 向量 {
私有:
    T* 数据;
    整64 长度;
公开:
    函数 推入(T 值) { /* … */ }
    函数 获取(整64 索引) -> T { 返回 数据[索引]; }
}
向量<整32> 列表 = 向量<整32>();
// 类型参数可约束为接口：泛型 <类型 T : 接口名>
