类与对象

类布局、可见性、构造析构链、继承与接口的精确规则、静态成员、友元、运算符重载。

类与实例：句柄模型

类变量槽存对象句柄（不是对象本体）——赋值/传参传句柄、体内写穿同一堆对象；实例在无引用后由 RAII 链释放。

主.cnCN

// 官网文档示例 · reference/oop.html · 布局（任务 1060 同源化：本文件即官网展示内容，
//   经 run_e2e 门禁实测——展示与门禁同一份文件，单一事实源）
类 计数 {
公开:
    整64 n;
    函数 计数(整64 初) { n = 初; }
}

函数 改写(计数 b) -> 空类型 {
    b.n = 42;                // 形参=句柄：写穿调用方同一对象
}

函数 主() -> 整32 {
    计数 a = 计数(1);
    改写(a);
    打印(a.n);               // 42（传参写穿）
    计数 c = 计数(1);
    计数 d = c;              // 声明初始化=拷贝构造（无=逐字段拷贝→独立）
    d.n = 7;
    打印(c.n, " ", d.n);
    返回 0;
}

输出：42 1 7

  • 两种「拷贝」要分清：传参/返回=句柄拷贝（写穿同一对象）；b = a 声明初始化=拷贝构造——类定义了拷贝构造（如标准库容器）按其语义深拷；没有则逐字段浅拷、对象独立。
  • 要独立副本：定义拷贝构造 函数 类名(类名&) 并用 复制(对象) 克隆（标准库容器全部定义了深拷构造）。
  • 取地址 &a 产对象地址（解包句柄），与 C++ &obj 语义一致。

可见性、构造、析构、静态

  • 公开:/保护:/私有: 标签分段；缺省=私有。友元 函数名/类名 可越权访问私有。
  • 构造=与类同名（可重载）；类类型字段自动级联默认构造（用户构造未显式构造的字段同此）——构造/析构对称。
  • 析构=~类名；作用域结束自动调用，先成员后自身、与构造反序。
  • 静态 字段/函数属于类（类名.成员 访问）；常量 函数 承诺不改状态。
  • 虚拟 函数 动态分派；重写 显式标注覆盖；抽象 纯虚（接口成员）。

主.cnCN

// 官网文档示例 · reference/oop.html · 成员（任务 1060 同源化：本文件即官网展示内容，
//   经 run_e2e 门禁实测——展示与门禁同一份文件，单一事实源）
类 引擎 {
公开:
    函数 引擎() { 打印("[引擎就绪]"); }
}

类 汽车 {
公开:
    引擎 动力;               // 类类型字段：自动级联默认构造
    函数 汽车() { 打印("[汽车就绪]"); }
}

函数 主() -> 整32 {
    汽车 c = 汽车();
    返回 0;
}

输出：[引擎就绪] [汽车就绪]

继承与接口

  • 单继承：类 子 : 父；接口实现同形态：类 实现类 : 接口。
  • 虚拟 开启动态分派；重写 覆盖父类虚拟；父类.方法() 调父类实现；父类.构造(实参) 在子类构造内调用父类构造。
  • 自身 是保留字——任何标识符位不可用。
  • 接口实现三查（逐接口方法校验）：①存在——缺实现报「未实现接口 'I' 的方法 'M'」（多层继承未实现有指路诊断）；②签名一致——参数类型与返回类型须与接口精确一致，不一致=编译错误「签名不一致」（防静默错位/截断）；③修饰——实现方法须 虚拟 或 重写 修饰。
  • 抽象成员=纯虚声明：抽象 函数 名(参数) -> 返回类型 不得带实现体（带体=编译错误「抽象方法不得带实现体」）；含抽象成员的类与接口不可实例化（「不能实例化」），派生类/实现类须实现全部抽象成员。
  • 接口可含虚拟函数声明（无体）；接口引用可指任何实现类实例。
  • 析构链：子类析构自动级联父类析构（容器元素同此）。

接口签名不一致.cn（负例·编译拒绝）CN

接口 通道 {
    虚拟 函数 发(整32 数据) -> 整32
}
接口 回执 {
    虚拟 函数 收() -> 整32
}
类 设备 : 通道 {
公开:
    重写 函数 发(整64 数据) -> 整32 { 返回 1; }   // ✗ 参数类型不一致（整64 vs 整32）
}
类 终端 : 回执 {
公开:
    重写 函数 收() -> 整64 { 返回 2; }             // ✗ 返回类型不一致（整64 vs 整32）
}

函数 主() -> 整32 {
    返回 0;
}

抽象带体.cn（负例·编译拒绝）CN

类 基 {
公开:
    抽象 函数 f() -> 整64 { 返回 1; }   // ✗ 抽象方法不得带实现体
}

函数 主() -> 整32 {
    返回 0;
}

运算符重载

  • 成员函数形态：函数 运算符X(参数) -> 返回类型；左操作数必须本类实例；双目单参数、单目无参数。
  • 可重载集合：+ - * / % == != < > <= >= && || ! & | ^ ~ << >>（-> 已随成员访问统一废除；[]/() 解析层显式拒绝——请求重载即报「不支持重载」，改用 lambda 或函数指针）。
  • 使用点参数个数校验：单目 运算符X() 须 0 个右操作数、双目须 1 个——个数不符报「重载期望 N 个右操作数」。
  • 决议：①优先精确匹配内置运算符；②无内置匹配→按左操作数类型查找成员 运算符X；③仍无→「类型不兼容」错误。

主.cnCN

// 官网文档示例 · reference/oop.html · 重载（任务 1060 同源化：本文件即官网展示内容，
//   经 run_e2e 门禁实测——展示与门禁同一份文件，单一事实源）
类 复数 {
公开:
    浮64 实;
    浮64 虚;
    函数 复数(浮64 r, 浮64 i) { 实 = r; 虚 = i; }
    函数 运算符-() -> 复数 {      // 一元负：取共轭（无参数）
        返回 复数(实, -虚);
    }
}

函数 主() -> 整32 {
    复数 c = 复数(3.0, 4.0);
    复数 共 = -c;
    打印(共.实, " ", 共.虚);
    返回 0;
}

输出：3.000000 -4.000000
