模块系统

导入形态、公开面、内置命名空间、标准库组织——CN 的代码组织单位。

导入形态

导入 文件::关闭文件;

输出：文件模块独立导入编译运行通过

  • 导入 模块::符号 后纯名直用（公开符号合并机制）；多符号 导入 模块::{a, b, c}，项内可重命名 导入 模块::{a 作为 b}；模块级别名 导入 路径 作为 别名（绑定模块路径本身，供 别名::符号 限定访问）。
  • 通配 导入 路径::*：把模块的公开 API 批量引入纯名（引入层级=最低级，见「内置命名空间」的冲突矩阵——本模块显式定义或显式导入同名项可合法遮蔽它，通配×通配同名=使用点歧义错误）。整模块导入 导入 模块; 同属此层。
  • 再导出 公开 导入 网络::连接：与普通 导入 同语法，加 公开 前缀=把该符号继续对外导出，调用方导入包根路径即直达（见下例与「包与 crate」）——库 crate 的包.cn 用「模块聚合 + 公开 导入」组装公开 API 面。
  • 限定名直调形态始终可用：数学::平方根(2.0)（无需导入）。
  • 顶层 模块 名; 只在包根成员聚合/父模块挂子模块两种位置合法（见下节「模块声明与加载」）；文件顶层 公开: 标签控制导出面（v2.0 默认私有、显式 公开: 导出）。

再导出断面（库 crate 包根聚合·E2E 370 实测）CN

模块 图形库;

// —— 图形库/图形库.cn（crate 内部模块）——
公开:

    返回 7;
}

// —— 主.cn（消费方：导入包根路径即可用再导出符号，无关内部布局）——

    打印("绘制: ", 绘制());        // 7
    返回 0;
}

模块声明与加载

模块路径由文件名 + 目录层级唯一决定；模块 声明只出现在两个树结构位置，声明 = 自动加载（Rust mod 对齐）。

  • 定位收紧：①包根成员聚合（包.cn 内 模块 网络;，声明包的组成、不引入名字）；②父模块挂子模块（网络.cn 内 模块 传输控制;，建立 网络::传输控制 完整路径）。普通源文件使用 模块 声明=编译诊断「模块声明 'X' 非当前模块 'Y' 的子模块（模块 声明仅限 包根成员聚合/父模块挂子模块）」。
  • 自动加载强语义：被 模块 声明引用的模块文件恒被加载编译——哪怕无人 导入 它，其内错误也在自身编译期暴露（fail fast，库完整性保证）；触发源 = 声明本身，非目录扫描（未声明的同目录杂散文件不参与编译，封闭树）。
  • 循环导入拒绝：模块导入图出现环（直接互引或经中间模块的间接互引）=编译错误——诊断「模块循环依赖」并打印环路径（如 循环乙 → 循环甲 → 循环乙）；加载按依赖拓扑序（被依赖者先编译），不设豁免通道。

定位收紧断面（声明仅限两位置）CN

// —— 网络库.cn（普通依赖文件：非包根、非父模块）——
模块 兄弟件;        // ✗ 编译诊断：兄弟件.cn 是同目录文件而非 网络库/ 子目录成员
                    //   挂载只允许「父挂子」（网络库/兄弟件.cn）

// —— 合法位置①：父模块挂子模块 ——
// 网络.cn 内写：模块 传输控制;   → 建立 网络::传输控制（网络/传输控制.cn）

// —— 合法位置②：包根成员聚合（包.cn 内）——
// 模块 图形库;        → 声明包的组成（不引入名字）

可见性交集（取最严）

符号最终可见性 = 各层级可见性的交集（取最严格）——模块级私有一票否决类内 公开:。

类层级成员层级同文件同包跨文件跨包
模块公开类内公开可可可
模块公开类内私有可不可不可
模块私有类内公开可不可不可
模块私有类内私有可不可不可
  • 模块公开 × 类内私有：类可跨模块实例化，但私有方法跨文件调用拒（诊断「私有成员」）。
  • 模块私有 × 类内公开：整个类跨文件不可见（「未声明的标识符」）——模块私有一票否决，类内 公开: 不突破模块边界。
  • 文件顶层 公开: 标签显式放行导出；无标签=默认私有（v2.0）。

内置命名空间与名称解析

运行时内置按域分组（IO:: 数学:: 文件:: 时间:: 系统:: 线程:: 解析:: 内存:: 字符串构建器::）；标准库模块把它们包装成结果 风格公开函数。纯名引用按作用域链唯一绑定——冲突绝不静默。

优先级名字来源说明
1本地作用域局部变量/参数（遮蔽一切同名）
2本模块显式项本文件顶层定义（函数/结构体/常量/静态）
3显式导入导入 m::符号 / 导入 m::{a, b} / 导入 m::符号 作为 别名（具名绑定）
4通配引入导入 m;（模块整体导入=公开 API 批量引入） / 导入 m::*
5内置函数/构造器打印/字符串长度/分配…与 正常/错误/某些/转移/复制 等
  • 冲突判定矩阵（同为纯名）：本模块项 × 显式导入同名=编译错误「导入与本地定义同名（E0255）」（改名或删其一）；显式导入 × 显式导入同名=「多次显式导入同名」；通配 × 通配同名=使用点歧义「符号歧义：来自 模块A/模块B（E0659）」（仅当该名字被实际引用时报）；本模块项/显式导入 遮蔽 通配=合法（唯一允许的遮蔽）。
  • 限定调用恒明确：模块::符号(...)（含多级 a::b::c）直接决议到指定模块的公开符号——不参与遮蔽、永无歧义、无须先导入；未导入的模块路径引用=「未声明的标识符」（核心包 prelude 内置例外）。
  • 决议失败绝不静默：歧义/未命中一律编译诊断，禁止「先收集文件赢」式静默绑定（静默吞=错误绑定）。

三级解析实测（本模块项遮蔽通配）CN

// —— 工具库.cn ——
公开:
函数 版本() -> 整64 {
    返回 200;
}
函数 双倍(整64 数值) -> 整64 {
    返回 数值 * 10;
}

// —— 主.cn ——（只写整体导入=③ 通配层；不得再写 导入 工具库::版本）
导入 工具库;

函数 版本() -> 整64 {
    返回 100;
}

函数 主() -> 整32 {
    打印("主 版本(): ", 版本());             // 100（①遮蔽③）
    打印("工具库::版本(): ", 工具库::版本()); // 200（限定调用恒明确）
    打印("工具库 双倍(5): ", 双倍(5));       // 50（③glob 纯名直调）
    返回 0;
}
stdlib 与内置的名字分工标准库模块公开函数与内置纯名不冲突：如 stdlib IO 模块的 读取行()（返回 结果）与内置 IO::读取行()（返回裸串）以限定名区分。业务代码用 stdlib 包装版（显式错误处理），内置为底层。

工程组织：货舱.toml

  • 多文件工程由 货舱.toml 声明模块依赖；编译器默认按入口文件同目录自动发现（--货舱 路径 显式指定）。
  • 标准库随编译器分发（--stdlib 路径 可指定）；stdlib/*.cn 本身就是「模块=文件」的活样板。
  • 跨模块链接符号冲突（同名公开函数）在导入解析期诊断。

特性声明制（[特性]）

宏名的受控来源：[特性] 节声明启用名单，每个启用特性即一个条件编译旗标（与 -D 同通道）——声明制=宏名有单一事实来源（对齐 Cargo features）。

货舱.toml（片段）TOML

[货舱]
名称 = "特性示例包"

[特性]
启用 = ["网络", "压缩"]

// 注：本用例宿主-only（239-a 宿主 preprocessor 实装）——双编译对照面待 v2 [特性] 货舱通道轮上架（D12 主面=546·注入通道后置）。

包与 crate：多包工程

包（crate）= 一个 货舱.toml 描述的编译单元，也是命名空间边界——跨包同名符号互不冲突（链接符号带 包名$ 前缀）。包根 包.cn 聚合包内模块并再导出公共 API。

概念形态要点
包 / crate货舱.toml + 依赖/ 子目录一个编译单元、一个命名空间边界；本地依赖放 依赖/包名/
包根包.cn模块 包名; 聚合 + 公开 导入 再导出
跨包导入导入 网络库::连接包名作路径首段——消费方不感知包内文件划分
同名隔离链接符号 包名$ 前缀甲库::双倍 与 乙库::双倍 各自独立
核心包 prelude默认可见打印/字符串 API/数学:: 限定名等基础项无需导入

包根与再导出：工程断面

核心包 prelude

核心包基础项默认可见（等价隐式 导入 核心::*）——以下程序无任何导入语句：

主.cnCN

// 主入口（第 7 层：48_prelude 核心包 prelude E2E，规格书08-六/09-五）
// 验证 v2.0 核心包 prelude：编译器隐式提供 导入 核心::* 级别的基础项——
//   内置函数（打印/格式化/字符串 API/数学限定名）无需显式导入即可用
//   （v2.0 将内置函数归入核心包 prelude，替代 v1.0 无前缀硬编码扁平表）。
// 本文件**无任何导入语句**，全部调用依赖 prelude 默认可见：
//   ① 打印（println 语义，自动换行）
//   ② 格式化（sprintf 风格 %d/%f/%s，返回动态内存需 字符串释放）
//   ③ 整数转字符串（字符串 API 族，返回动态内存需 字符串释放）
//   ④ 数学::平方根（内置限定名——核心包 prelude 成员，无需导入）
//   ⑤ 字符串长度 / 字符串比较（字符串 API 族）
//   ⑥ 布尔转字符串（返回 真/假 中文文本）
// 注：布尔 多参数直接传 打印 走 __cn_format 转 1/0；拼接方式输出 真/假。
//   导入 核心::* 通配导入核心包（扩展符号）由单测 UseImportWildcard 覆盖。

函数 主() -> 整32 {
    打印("===== 核心包 prelude（第 7 层）=====");

    // ---- ① 打印（println）：prelude 基础函数 ----
    打印("prelude 打印 可用");

    // ---- ② 格式化：%d/%f/%s 占位符 ----
    字符串 格1 = 格式化("值%d 浮点%f", 42, 3.14);
    打印("格式化: ", 格1);                        // 格式化: 值42 浮点3.140000

    // ---- ③ 整数转字符串：字符串 API 族 ----
    字符串 数字串 = 整数转字符串(42);
    打印("整数转字符串: ", 数字串);               // 整数转字符串: 42

    // ---- ④ 数学::平方根：内置限定名 prelude（无需导入）----
    浮64 根 = 数学::平方根(9.0);
    打印("数学::平方根(9.0): ", 根);              // 3.000000

    // ---- ⑤ 字符串长度 / 字符串比较：字符串 API 族 ----
    整64 长度 = 字符串长度("abcd");
    打印("字符串长度: ", 长度);                   // 4
    布尔 相等 = 字符串比较("ab", "ab");
    打印("字符串比较相等: ", 相等);               // 1（多参数直接传转 1/0）

    // ---- ⑥ 布尔转字符串：拼接输出中文文本 ----
    字符串 布尔串 = 布尔转字符串(相等);
    打印("布尔转字符串: ", 布尔串);               // 真

    打印("===== 核心包 prelude 测试完成 =====");
    返回 0;
}
