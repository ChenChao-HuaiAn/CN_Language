模块系统

导入形态、公开面、内置命名空间、标准库组织——CN 的代码组织单位。

导入形态

导入.cnCN

导入 容器::向量;                    // 单符号（公开符号合并→纯名直用）
导入 容器::{链表, 栈, 队列};        // 多符号花括号
导入 数学::平方根;                  // 限定名亦可省（纯名直用）

函数 主() -> 整32 {
    向量<整64> 表 = 向量<整64>();
    结果<空类型, 整32> 加 = 表.追加(9);
    打印(表.大小(), " ", 平方根(4.0));
    返回 0;
}

输出：1 2.000000

  • 导入 模块::符号 后纯名直用（公开符号合并机制）；多符号 导入 模块::{a, b, c}；重命名 导入 路径 作为 别名。
  • 限定名直调形态始终可用：数学::平方根(2.0)（无需导入）。
  • 顶层 模块 名 声明本模块名（分号可选）；文件顶层 公开: 标签控制导出面（v2.0 默认私有、显式 公开: 导出）。

内置命名空间与三层名字解析

运行时内置按域分组（IO:: 数学:: 文件:: 时间:: 系统:: 线程:: 解析:: 内存:: 字符串构建器::）；标准库模块把它们包装成结果 风格公开函数。纯名引用按三级优先级解析。

优先级名字来源说明
1本地作用域局部变量/参数
2当前模块符号本文件顶层声明+已导入符号（公开符号合并）
3内置函数/构造器打印/字符串长度/分配…与 正常/错误/某些/转移/复制 等
stdlib 与内置的名字分工标准库模块公开函数与内置纯名不冲突：如 stdlib IO 模块的 读取行()（返回 结果）与内置 IO::读取行()（返回裸串）以限定名区分。业务代码用 stdlib 包装版（显式错误处理），内置为底层。

工程组织：货舱.toml

  • 多文件工程由 货舱.toml 声明模块依赖；编译器默认按入口文件同目录自动发现（--货舱 路径 显式指定）。
  • 标准库随编译器分发（--stdlib 路径 可指定）；stdlib/*.cn 本身就是「模块=文件」的活样板。
  • 跨模块链接符号冲突（同名公开函数）在导入解析期诊断。
