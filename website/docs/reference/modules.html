模块系统 v2.0

文件即模块、路径 ::、默认私有、包=crate、货舱.toml 依赖。

文件即模块

每个 .cn 文件天然是一个模块，模块路径由文件名+目录层级决定： 网络/传输控制.cn 即 网络::传输控制，无需声明。 模块 名 声明仅用于两种树结构位置：包根聚合（包.cn） 与父模块挂子模块。

导入语法（全形式）

导入.cnCN

导入 核心::可选::{某些, 无};        // 导入多项
导入 核心::集合;                   // 导入模块
导入 核心::列表 作为 动态数组;      // 重命名
导入 核心::集合::*;                // 通配
导入 包::网络::连接;               // 从包导入
公开 导入 网络::连接;              // 再导出（包.cn 聚合 API）

可见性

默认私有（模块级与类内）。公共 API 须显式 公开:。 跨模块可见性按「交集规则」合成——一个符号要被外部看到，路径上每层都得公开。

可见性.cnCN

公开:
    函数 公开函数() { }
私有:
    函数 内部函数() { }

函数 默认私有() { }      // 无标签 → 默认私有

包与货舱

  • 包（crate）= 分发单元，根为 包.cn（聚合 公开 导入 形成包 API）。
  • 依赖声明在 货舱.toml；编译用 --货舱 选项指定清单。
  • 核心包提供 prelude 常用符号。
