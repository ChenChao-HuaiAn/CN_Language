控制流

如果/当/循环/选择/遍历 的精确语义：括号可选、贯穿规则、中断绑定、确定初始化交互。

如果 / 否则：括号可选

主.cnCN

函数 主() -> 整32 {
    如果 (调试模式) {
        打印行("调试分支运行");
    } 否则 {
        打印行("发布分支运行");
    }
    如果 (调试模式 == 真) {
        打印行("显式比较真: 命中");
    }
    返回 0;
}

输出：调试分支运行显式比较真: 命中

裸条件消歧条文裸条件（无括号）的条件表达式内，类型名{...} 裸结构体初始化字面量=编译期拒绝（{ 归条件后的语句块）；带括号条件不在此限。Rust 同款。

当 / 循环：两种循环

主.cnCN

函数 主() -> 整32 {
    // ① 基本
    整32 总 = 0;
    循环 (整32 i = 0; i < 5; i++) {
        总 = 总 + i;
    }
    打印(总);
    // ② 继续→step（跳过 3：i++ 仍执行防死循环）
    整32 计 = 0;
    循环 (整32 k = 0; k < 8; k++) {
        如果 (k == 3) {
            继续;
        }
        计 = 计 + k;
    }
    打印(计);
    // ③ 中断
    循环 (整32 m = 0; m < 100; m++) {
        如果 (m == 6) {
            中断;
        }
        打印(m);
    }
    // ④ init 作用域：循环后 i 不可见（用新变量验证循环值不泄漏）
    整32 i = 99;
    打印(i);
    // ⑤ 空 cond（恒真）+ 中断退出
    整32 w = 0;
    循环 (; ; ) {
        w = w + 3;
        如果 (w >= 9) {
            中断;
        }
    }
    打印(w);
    // ⑥ 赋值 step
    循环 (整32 d = 1; d < 10; d = d + 2) {
        打印(d);
    }
    // ⑦ 嵌套（内层中断·外层继续）
    整32 网总 = 0;
    循环 (整32 行 = 0; 行 < 3; 行++) {
        如果 (行 == 1) {
            继续;
        }
        循环 (整32 列 = 0; 列 < 4; 列++) {
            如果 (列 == 2) {
                中断;
            }
            网总 = 网总 + 行 * 10 + 列;
        }
    }
    打印(网总);
    // ⑧ 后缀自减 step（倒序）
    循环 (整32 倒 = 3; 倒 > 0; 倒--) {
        打印(倒);
    }
    返回 0;
}

输出：10 25 0 1 2 3 4 5 99 9 1 3 5 7 9 42 3 2 1

选择：贯穿语义与三种增强

分支体不写 中断/返回 自动贯穿下一分支（C 语义）；支持多值分组、字符串情况、裸枚举成员。

主.cnCN

函数 主() -> 整32 {
    // ① 数值多值（命中第二值）
    选择 (2) {
        情况 1, 2: 打印(100);
        情况 3: 打印(200);
        默认: 打印(900);
    }
    // ② 字符多值（三值·命中第二值）
    选择 ('b') {
        情况 'a', 'b', 'c': 打印(300);
        默认: 打印(900);
    }
    // ③ 字符串多值（__cn_str_eq 路径·命中第二值）
    选择 ("乙") {
        情况 "甲", "乙": 打印(400);
        默认: 打印(900);
    }
    // ④ 无命中走默认
    选择 (9) {
        情况 1, 2: 打印(100);
        默认: 打印(900);
    }
    // ⑤ 单值回归（存量形态）
    选择 (3) {
        情况 3: 打印(200);
        默认: 打印(900);
    }
    返回 0;
}

输出：100 200 900 300 900 400 900 900 200 900

  • 上例 情况 0: 无 中断 → 贯穿进 情况 1,2,3 体（n=0 时 结果文 被覆盖为「小」）——C 贯穿语义原样。
  • 中断 绑定最近进入的 选择 或 循环；选择体内的 继续 绑定最近循环。
  • 字符串情况可多值分组 情况 "开始", "继续":；枚举条件可裸写成员名（按条件类型定向解析）。
  • 情况常量须在条件类型表示范围内（整8..整128/正族按各域、枚举与字符按整32存储域）；承载族按字面量后缀（无后缀=整128±2^127、正128后缀=2^128-1）；超域=编译期拒绝（用户令 #1076：字面量超出上下文类型表示范围即拒）。
  • 枚举名::成员 非法（:: 保留给模块路径）。

导入 容器::向量;

函数 造数据() -> 向量<整32> {
    向量<整32> 数据 = 向量<整32>();
    结果<空类型, 整32> 加1 = 数据.追加(10);
    如果 (加1.正常) { } 否则 { 返回 数据; }
    结果<空类型, 整32> 加2 = 数据.追加(20);
    如果 (加2.正常) { } 否则 { 返回 数据; }
    结果<空类型, 整32> 加3 = 数据.追加(30);
    如果 (加3.正常) { } 否则 { 返回 数据; }
    返回 数据;
}

函数 主() -> 整32 {
    打印("===== 遍历 表达式（P3-24）=====");
    整32 总和 = 0;
    遍历 造数据() 中 每个 x {
        打印("x: ", x);
        总和 = 总和 + x;
    }
    打印("总和: ", 总和);   // 60
    打印("===== 完成 =====");
    返回 0;
}

输出：===== 遍历 表达式（P3-24）===== x: 10 x: 20 x: 30 总和: 60 ===== 完成 =====

  • 迭代变量=元素副本（快照语义）——要写穿用 元素引用(i)（不安全域）。
  • 标准库全部容器（向量/链表/栈/队列）均支持遍历。
