控制流

如果、当、循环、选择、遍历——全部中文关键字，条件的括号可写可不写。

如果与否则

如果.cnCN

如果 x > 0 {
    打印行("正数");
} 否则 如果 x < 0 {
    打印行("负数");
} 否则 {
    打印行("零");
}
裸条件消歧 条件的括号可选；但裸条件的表达式里写「结构体字面量 类型{"..."}」会被拒绝—— 须用括号包裹条件（{ 在裸条件尾部会和语句块产生歧义）。带括号条件不受影响。

当与循环

循环.cnCN

整数 i = 0;
当 i < 10 {          // while
    打印行(i);
    i++;
}

循环 (整32 j = 0; j < 10; j++) {   // for
    打印行(j);
}

选择

选择（switch 风格）支持整数、枚举与字符串；多值分组用逗号； 分支不写 中断 会贯穿到下一分支（与 C 一致）：

选择.cnCN

字符串 命令 = "开始";
选择 (命令) {
    情况 "开始", "继续":    // 字符串 + 多值分组
        打印行("执行");
        中断
    默认:
        打印行("未知");
}

枚举 颜色 { 红, 绿, 蓝 }
颜色 c = 颜色.蓝;
选择 (c) {
    情况 红: { 打印行("红色"); 中断 }
    情况 蓝: { 打印行("蓝色"); 中断 }
    默认:    { 打印行("其他"); }
}

遍历……中每个

对数组与容器迭代（对标 range-for）。类容器通过 大小() + 元素() 支撑：

遍历.cnCN

整32[5] 数据 = { 10, 20, 30, 40, 50 };
遍历 数据 中 每个 x {
    打印行(x);           // 10 20 30 40 50
}

向量<整32> 数表 = 向量<整32>();
遍历 数表 中 每个 v { 打印行(v); }

中断与继续

  • 中断 跳出最近进入的一层 选择 或 循环（谁近绑谁，与 C 的 break 一致）。
  • 继续 进入最近循环的下一轮（仅对循环有意义）。
