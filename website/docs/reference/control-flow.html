控制流

如果/当/循环/选择/遍历 的精确语义：括号可选、贯穿规则、中断绑定、确定初始化交互。

如果 / 否则：括号可选

双形态.cnCN

函数 分级(整32 分) -> 字符串 {
    如果 分 >= 90 { 返回 "优"; }          // 裸条件（括号可选）
    如果 (分 >= 60) { 返回 "及格"; }      // 带括号（同合法）
    返回 "不及格";
}

函数 主() -> 整32 {
    打印(分级(95), " ", 分级(70), " ", 分级(30));
    返回 0;
}

输出：优 及格 不及格

裸条件消歧条文裸条件（无括号）的条件表达式内，类型名{...} 裸结构体初始化字面量=编译期拒绝（{ 归条件后的语句块）；带括号条件不在此限。Rust 同款。

当 / 循环：两种循环

循环.cnCN

函数 主() -> 整32 {
    整32 i = 0;
    当 i < 3 {                   // 当：前测循环
        打印行(i, " ");
        i++;
    }
    打印("");
    循环 (整32 j = 10; j > 0; j -= 4) {   // 初始;条件;更新
        打印行(j, " ");
    }
    打印("");
    返回 0;
}

输出：0 1 2 10 6 2

选择：贯穿语义与三种增强

分支体不写 中断/返回 自动贯穿下一分支（C 语义）；支持多值分组、字符串情况、裸枚举成员。

贯穿与多值.cnCN

函数 分类(整32 n) -> 字符串 {
    字符串 结果文 = "";
    选择 (n) {
        情况 0:
            结果文 = "零";
        情况 1, 2, 3:            // 多值分组
            结果文 = "小";
            中断;
        默认:
            结果文 = "大";
    }
    返回 结果文;
}

函数 主() -> 整32 {
    打印(分类(0), " ", 分类(2), " ", 分类(9));
    返回 0;
}

输出：小 小 大

  • 上例 情况 0: 无 中断 → 贯穿进 情况 1,2,3 体（n=0 时 结果文 被覆盖为「小」）——C 贯穿语义原样。
  • 中断 绑定最近进入的 选择 或 循环；选择体内的 继续 绑定最近循环。
  • 字符串情况可多值分组 情况 "开始", "继续":；枚举条件可裸写成员名（按条件类型定向解析）。
  • 枚举名::成员 非法（:: 保留给模块路径）。

遍历…中每个：迭代协议

遍历.cnCN

导入 容器::向量;

函数 主() -> 整32 {
    整32[3] 数组 = {7, 8, 9};
    遍历 数组 中 每个 x { 打印行(x, " "); }     // 数组：元素副本
    打印("");
    向量<字符串> 表 = 向量<字符串>();
    结果<空类型, 整32> 加 = 表.追加("甲");
    加 = 表.追加("乙");
    遍历 表 中 每个 s { 打印行(s, " "); }        // 类容器：大小()+元素(i)
    打印("");
    返回 0;
}

输出：7 8 9 甲 乙

  • 迭代变量=元素副本（快照语义）——要写穿用 元素引用(i)（不安全域）。
  • 标准库全部容器（向量/链表/栈/队列）均支持遍历。
