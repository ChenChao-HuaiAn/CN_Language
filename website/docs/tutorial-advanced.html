安全区边界：不安全 域

CN 的安全默认不靠运行时罚站——危险操作在编译期就要求位于 不安全 函数 内（安全函数内=编译错误「[安全区边界] …」），把审计责任显式化。

#仅限 不安全 函数 体内的操作（001 §747 全清单）
1指针算术——裸指针 加减 整数（含数组退化）
2指针下标写——p[i] = x
3裸指针解引用读——*p
4裸指针解引用写——*p = x
5指针下标读——p[i]
6指针成员访问——p.字段（隐含解引用）
7联合体字段访问——含结构体内联合体嵌套
8可变静态/全局变量写——赋值/复合赋值/自增自减（含全局容器写方法调用：追加/设置/清空/插入/弹出…；读方法 大小/元素/读取/获取/包含 安全区放行）
9外部函数调用——FFI/C 边界
10裸释放——释放(裸指针)

常量空指针.cn（负例·编译拒绝）CN

不安全 函数 主() -> 整32 {
    整64* p = 无;
    整64 v = *p;           // ✗ 编译错误：编译期常量空指针解引用（B11）
    返回 整32(v);
}
  • 豁免与例外：字符串/字符* 为字符串视图（非裸指针）——清单 1/3/5/6 对其不适用（拼接/视图读=安全操作）；字符*（借用视图）下标访问=编译期拒绝（视图按 UTF-8 字节序列解释，与裸指针步进错位——先 字符串复制(...) 转拥有串再下标）；字符串 下标读安全（字节语义·越界=运行期错误码 2）；取地址、指针比较、指针类型转换=安全（Rust 对照）。
  • B11 常量空指针=独立硬错误（不属十项清单、不因不安全区豁免）：无 字面量解引用/成员访问/下标（*无/无.x/无[0]），及「变量经 无 初始化且全函数无其他写入」的常量传播形态——编译期硬错误「编译期常量空指针解引用」（§1.1a①编译期能证必须编译期拦；运行期数据面判零由错误码 3 兜底）。
  • 调用 不安全 函数=允许（责任上移；审计面=不安全函数清单）；不安全 是保留字（46 个保留字之一）。
  • 溢出检查在此豁免：不安全 函数 内不插溢出检查（按两补码回绕继续执行）——「真零运行期检查」；对照：安全区变量面溢出=错误码 8 确定性失败（见 类型参考·整数）。
  • 标准库容器内部全是不安全域，但使用容器不需要不安全——危险面被库收口，这正是安全区的意义。

  • 链接：cn build 程序.cn --链接 库名（可多次）；库搜索遵循平台惯例。
  • 字符串契约：字符*=借用（C 层持有的视图，不释放）；字符串=拥有（RAII）。借用转拥有用 字符串复制，反之直接传。
  • 返回类型白名单：仅标量（整数族/浮点，含 字符/布尔）/ 指针 / 字符串（句柄）；聚合（类/结构体/结果）与引用（T&）返回=编译期拒绝「外部 函数 返回类型 '<T>' 不支持」（待 sret 跨语言约定立法后放行）；无返回值（缺 -> 或 空类型）不属限制面。

字符串与容器的性能面

拥有型字符串的每一次 + 都是分配+拷贝。高频拼接用字符串构建器（摊销 O(n)），高频读取用引用访问。加号链适合少量短拼接；循环/大段拼接（k 段累计 O(k²)）请用构建器（编译器不报提示·这条边界须自觉）。

    // ① 内建层：追加多段（含中文 UTF-8）+追加字节（33='!'）
    整64 句甲 = 字符串构建器::新建();
    字符串构建器::追加(句甲, "你好，");
    字符串构建器::追加(句甲, "构建器");
    字符串构建器::追加字节(句甲, 33);
    字符串 内建串 = 字符串构建器::完成(句甲);
    打印(内建串);

    // ② stdlib 门面 + 追加整数便利
    整64 句乙 = 字符串构建器新建();
    字符串构建器追加(句乙, "编号=");
    字符串构建器追加整数(句乙, 366);
    字符串 门面串 = 字符串构建器完成(句乙);
    打印(门面串);

    // ③ 连接对照：64 段同源——朴素逐段连接 vs 构建器一次成型
    字符串 片段 = "片段";
    字符串 朴素 = "";
    整64 句丙 = 字符串构建器::新建();
    循环 (整64 k = 0; k < 64; k++) {
        朴素 = 字符串连接(朴素, 片段);
        字符串构建器::追加(句丙, 片段);
    }
    字符串 构建串 = 字符串构建器::完成(句丙);
    如果 (字符串比较(构建串, 朴素)) {
        打印("对照: 相等 长度=", 整数转字符串(字符串长度(构建串)));
    } 否则 {
        打印("对照: 不等");
    }

    // ④ 边界：空串追加（缓冲仍空）→ 出串=空串（长 0）
    整64 句丁 = 字符串构建器::新建();
    字符串构建器::追加(句丁, "");
    字符串构建器::追加(句丁, "");
    字符串 空串 = 字符串构建器::完成(句丁);
    打印("空缓冲长=", 整数转字符串(字符串长度(空串)));

    // ⑤ 大串出串校验：100 段×6 字节（"片段" UTF-8）=600
    整64 句丙二 = 字符串构建器::新建();
    循环 (整64 k = 0; k < 100; k++) {
        字符串构建器::追加(句丙二, 片段);
    }
    字符串 大出串 = 字符串构建器::完成(句丙二);
    打印("出串长=", 整数转字符串(字符串长度(大出串)));

    // ⑥ 泄漏断言：出串计 1（tracked）+函数退出 RAII 回落差=0（216 口径）
    //   断言窗口（基线→回落差）内零打印零传参——打印变参临时/变量传参形参槽
    //   均存在既有缺口（另案立项），不得混入本断言。
    整64 基线 = 内存::活动分配数();
    整64 出串差 = 出串段();
    整64 回落差 = 内存::活动分配数() - 基线;
    打印("出串差=", 整数转字符串(出串差));
    打印("回落差=", 整数转字符串(回落差));

    // ⑦ 弃置：错误路径中途放弃（不取串·句柄一次性）——只验全链不崩
    整64 句戊 = 字符串构建器::新建();
    循环 (整64 k = 0; k < 100; k++) {
        字符串构建器::追加(句戊, 片段);
    }
    字符串构建器::弃置(句戊);
    打印("弃置: 完成");
    返回 0;
}

输出：你好，构建器! 编号=366 对照: 相等 长度=384 空缓冲长=0 出串长=600 出串差=1 回落差=0 弃置: 完成

类 甲 {
公开:
    整32 x;
    函数 甲(整32 v) { x = v; }
    虚拟 函数 取() -> 整32 {
        返回 x;
    }
    函数 翻倍() -> 整32 {
        返回 x * 2;
    }
}
类 乙 : 甲 {
公开:
    函数 乙(整32 v) : 甲(v) { }
    重写 函数 取() -> 整32 {
        返回 x + 100;
    }
}
函数 读(甲& 参) -> 整32 {
    返回 参.x;
}
函数 主() -> 整32 {
    甲 对 = 甲(7);
    甲& 参 = 对;
    打印(参.x);          // 7  字段读
    参.x = 42;             //    字段写
    打印(参.x);          // 42 写后读
    打印(对.x);          // 42 别名可见
    打印(参.翻倍());     // 84 非虚直调
    甲& 参1 = 对;
    甲& 参2 = 参1;
    打印(参2.x);         // 42 引用再绑
    打印(读(参));        // 42 转发引用形参
    乙 对象 = 乙(5);
    甲& 虚参 = 对象;
    打印(虚参.取());     // 105 虚分派
    对 = 甲(60);           //    别名重赋
    打印(参.x);          // 60 别名语义
    打印(参1.x);         // 60 同源别名
    返回 0;
}

输出：7 42 42 84 42 42 105 60 60

优化级别与调试

四级优化 -O0 ~ -O3；--debug 在汇编中嵌入源码位置注释；调试模式 编译期常量做发布/调试分支（死分支零开销消除）。

级别内容
-O0不做优化（默认）——编译最快，逐语句直译
-O1常量折叠+死代码消除+代数简化+复写传播
-O2增加 公共子表达式消除（CSE）+跨块死代码消除+寄存器分配启用
-O3增加 全局值传播

自举与双编译对照（项目故事）

CN 的终极目标是用 CN 编译器自己编译 CN 编译器。项目保持「宿主 C++ 实现」与「v2 CN 自举实现」两套功能完全一致的编译器，全部测试双跑对照（dual）——这也是文档示例可信的根基。

  • 自举固定点：v2 编译出的编译器再编译自己，产物逐字节一致（fix_p ≡ fix_s）——语言已完备到能承载自身工具链。
  • 双编译对照：每个用例同时跑宿主与 v2 两侧，任何行为分叉=缺陷（零分叉红线）。你看到的文档输出都经此流程。
  • 性能双目标：①编译速度对标 C++ 编译器；②内存安全对标 Rust（悬垂/越界/泄漏零容忍）——冲突时提交用户裁决。
