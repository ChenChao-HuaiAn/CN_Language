两句话理解语言设计

  • 默认安全：变量必须初始化才能读；结果<T, E> 必须显式检查（丢弃即编译错误）；资源随作用域自动释放（RAII）；裸指针/手动内存收进 不安全 域。
  • 性能不妥协：零成本抽象（检查全部在编译期）、C 风格内存布局、可下探到汇编级的手动控制（分配/释放/复制内存）、三后端（win-x64 / linux-x86_64 / linux-arm64）。
