三十秒速览

CN 是全中文语法的系统级编程语言。这段代码涵盖了变量、函数、容器、遍历与打印—— 每一行都是合法的 CN 源码：

速览.cnCN

导入 容器::向量;

// 定义一个函数：构造整32向量并返回
函数 造数据() -> 向量<整32> {
    向量<整32> 数据 = 向量<整32>();
    数据.追加(10);
    数据.追加(20);
    数据.追加(30);
    返回 数据;
}

函数 主() -> 整32 {
    整32 总和 = 0;
    遍历 造数据() 中 每个 x {   // 遍历容器中每个元素
        总和 = 总和 + x;
    }
    打印("总和: ", 总和);        // 总和: 60
    返回 0;
}
