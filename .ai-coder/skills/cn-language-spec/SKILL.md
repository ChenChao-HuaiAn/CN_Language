# CN Language Spec Skill（C++风格版）

## When to Use This Skill

使用本技能的场景：

- 需要查询CN语言的特定语法规则（如关键字、类型系统、OOP规则等）
- 需要验证代码是否符合CN语言语法规范
- 需要跨文档引用语法规则（如从OOP章节引用类型系统章节的规则）
- 需要对比CN语言与其他语言（C++/Rust/Go等）的语法差异
- 需要生成CN语言特定模块的语法摘要
- 用户提到"CN语言规范"、"语法规则"、"语法设计"、"C++风格"等关键词
- 需要确认某个语法特性的设计决策和理由
- 编写任何与CN语言有关的文件（代码、测试、文档）时的第一选择

## When NOT to Use This Skill

不要使用本技能的场景：

- 讨论的是其他编程语言的语法（非CN语言）
- 需要的是编译器实现细节而非语法规范查询
- 用户在讨论构建配置（CMake）而非语言规范
- 需要的是项目文件管理而非语言规则

## Capabilities

- **规范查询**: 根据关键字、章节编号或语法类别快速定位语法规则
- **EBNF检索**: 提取和展示特定语法结构的EBNF定义
- **跨文档引用**: 在不同规范文档间建立引用关系（如OOP章节引用类型系统）
- **规范验证**: 检查代码片段是否符合CN语言语法规范
- **语法对比**: 对比CN语言与其他系统编程语言的语法差异
- **设计决策追溯**: 查询特定语法设计决策的原因和替代方案

## Patterns

### 规范快速查询
根据用户问题定位到具体的规范文档章节，返回精确的语法规则定义

```
用户问题 → 关键词提取 → 文档定位 → 章节定位 → 返回规则+EBNF+示例
```

### 跨文档引用链
当一个问题涉及多个规范文档时，自动构建引用链

```
例如：类继承规则 → 引用OOP(06) → 引用类型系统(02) → 引用函数指针(04)
```

### 规范验证模式
对代码片段进行语法合规性检查

```
代码片段 → 词法分析(01a/01b) → 类型检查(02) → 语义验证(03-08) → 合规报告
```

### 语法对比分析
将CN语言语法与其他语言进行系统性对比

```
CN语法规则 → 识别对应特性 → 查找其他语言等价语法 → 差异分析表
```

## Anti-Patterns

### ❌ 凭记忆回答规范问题
必须从规范文档中引用原文，不得凭AI记忆编造语法规则

### ❌ 忽略版本差异
规范文档可能更新，必须引用最新版本的内容（当前版本：C++风格版v1.0）

### ❌ 断章取义
引用语法规则时必须包含完整的上下文（包括约束条件和例外情况）

### ❌ 混淆规范与实现
语法规范是设计文档，不等同于编译器实际实现

### ❌ 沿用旧版（Rust风格）语法
本技能为C++风格版，旧版Rust风格（让/可变/匹配/所有权等）已废弃，禁止混用

## Query Workflow

### Step 1: 识别查询类型
- 语法规则查询 → 定位到具体文档章节
- EBNF定义查询 → 搜索EBNF代码块
- 设计决策查询 → 查找"设计决策"章节
- 代码验证 → 多文档交叉检查
- 语法对比 → 查找对应规则+对比分析

### Step 2: 定位规范文档
根据查询关键词映射到文档编号：

- 关键字/标识符/注释/源文件/设计决策 → 01a
- 字面量/运算符/优先级/字符串/原始/多行/Unicode → 01b
- 类型/整数/浮点/字符/布尔/指针/数组/联合体/结果/可选/隐式转换 → 02
- 变量/常量/函数/如果/否则/当/循环/选择/情况/默认/中断/继续 → 03
- 函数指针/递归/构造器/原型 → 04
- 结构体/枚举/负数枚举 → 05
- 类/继承/接口/虚拟/重写/抽象/实现/自身/父类/保护/构造/析构/虚表 → 06
- 错误处理/错误码/正常/错误/某些/有值 → 07
- 模块/导入/从/公开/私有/可见性/路径 → 08

### Step 3: 读取并返回
1. 读取对应文档的指定章节（从 `specs/` 目录读取）
2. 提取EBNF定义（如有）
3. 提取中文示例代码
4. 提取设计决策说明（如有）
5. 检查是否需要跨文档引用

### Step 4: 引用格式
引用规范时使用以下格式：

```
[规范编号]-[章节名]（[文件名]，第X节）
```

示例：
- [01a]-关键字（01a-词法结构-总览与关键字.md，第二节）
- [06]-虚函数（06-OOP面向对象.md，第四节）

## 与旧版（Rust风格）的关键差异

| 维度 | 旧版(Rust风格) | 新版(C++风格) |
|------|---------------|---------------|
| 关键字 | 54个(让/可变/匹配/跳出/特征/泛型/所有权...) | 53个(变量/常量/选择/情况/默认/类/接口/继承...) |
| 内存管理 | 所有权+借用+生命周期 | 指针+手动内存管理 |
| OOP | 无(结构+特征) | 完整OOP(类/接口/继承/虚拟/重写) |
| 错误处理 | 结果+?运算符 | 结果+可选(错误码，无?运算符) |
| 控制流 | 匹配/跳出 | 选择/情况/默认/中断 |
| 模块路径 | :: 分隔 | . 分隔 |
| 可见性 | 逐项修饰(公开 函数) | 标签式(公开:/私有:) |
| 函数指针 | 无 | 有(C风格) |
