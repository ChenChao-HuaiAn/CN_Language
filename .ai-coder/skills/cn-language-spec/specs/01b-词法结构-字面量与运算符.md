# 01b 词法结构：字面量与运算符

> 文档编号：01b
> 所属技能：cn-language-spec（C++风格版v1.0）
> 基准文档：[plans/001 CN语言编译器设计规格书.md](../../../../plans/001%20CN语言编译器设计规格书.md)
> 内容范围：整数字面量、浮点字面量、字符字面量（含Unicode转义）、字符串字面量（含原始/多行）、运算符7类、优先级13级

---

## 一、整数字面量

### EBNF

```
整数字面量 = 十进制整数 | 十六进制整数 | 二进制整数 | 八进制整数
十进制整数 = 数字+, 后缀?
十六进制整数 = "0x", 十六进制数字+, 后缀?
二进制整数 = "0b", (0|1)+, 后缀?
八进制整数 = "0o", 八进制数字+, 后缀?
后缀 = "f" | "L" | "LL" | "U" | "UL" | "ULL"
```

### 示例代码

```
变量 a = 42        // 十进制
变量 b = 0xFF      // 十六进制
变量 c = 0b1010    // 二进制
变量 d = 0o777     // 八进制
```

### 类型后缀映射表

| 后缀 | 映射类型 | 说明 |
|------|---------|------|
| `f` | 浮32 | 浮点字面量 |
| `L` | 整64 | 64位有符号 |
| `LL` | 整128 | 128位有符号 |
| `U` | 正32 | 32位无符号 |
| `UL` | 正64 | 64位无符号 |
| `ULL` | 正128 | 128位无符号 |

### 设计决策

- **不支持数字下划线分隔**（与Rust不同）：`1_000_000` 是非法写法，须写 `1000000`。
- 后缀使用英文大写字母，与C/C++风格保持一致，便于底层编程人员理解。

## 二、浮点字面量

### EBNF

```
浮点字面量 = 小数形式 | 科学计数法
小数形式 = 数字+, ".", 数字+
科学计数法 = 数字+, ".", 数字+, ("e"|"E"), ["+"|"-"], 数字+
```

### 示例代码

```
变量 x = 3.14       // 小数形式
变量 y = 1.5e10     // 科学计数法
变量 z = 2.5E-3     // 科学计数法（负指数）
```

### 默认类型

- 浮点字面量默认类型为 `浮64`（`小数`别名）
- 如需 `浮32` 需显式标注类型或使用后缀 `f`

---

## 三、字符字面量

### EBNF

```
字符字面量 = "'", (普通字符 | 转义序列 | Unicode转义), "'"
转义序列 = "\n" | "\t" | "\0" | "\\" | "\'" | "\""
Unicode转义 = "\u{", 十六进制数字+, "}"
```

### 示例代码

```
变量 字符1 = 'A'           // 普通字符
变量 字符2 = '中'          // 中文字符
变量 字符3 = '\n'          // 换行
变量 字符4 = '\t'          // 制表符
变量 字符5 = '\0'          // 空字符
变量 字符6 = '\u{4E2D}'    // Unicode转义，等同于'中'
```

### 设计决策

- 字符类型为4字节Unicode标量值（见[02-类型系统.md](02-类型系统.md)）。
- **Unicode转义（新增）**：`'\u{4E2D}'` 语法与Rust一致，支持任意Unicode标量值，中文字符可直接书写也可用转义表示。

---

## 四、字符串字面量

### EBNF

```
字符串字面量 = 普通字符串 | 原始字符串 | 多行字符串 | 原始多行字符串
普通字符串 = '"', 任意字符*, '"'          // 内部处理转义
原始字符串 = "原始", '"', 任意字符*, '"'   // 反斜杠不需转义
多行字符串 = "多行", '"""', 任意字符*, '"""'  // 支持跨行，内部仍处理\n\t转义
原始多行字符串 = "原始多行", '"""', 任意字符*, '"""'  // 完全原始多行文本
```

### 示例代码

```
变量 普通 = "你好"                       // 普通字符串
变量 正则 = 原始"^\d+\.\d+$"             // 原始字符串，\d无需转义
变量 多行文本 = 多行"""第一行
第二行
第三行"""                              // 多行字符串
变量 原始多行文本 = 原始多行"""第一行\n第二行"""  // 完全原始，\n不转义
```

### 转义语义规则

| 字符串形式 | 转义处理 | 跨行支持 |
|-----------|---------|---------|
| 普通 `"..."` | 处理 `\n`、`\t` 等转义 | 否 |
| 原始 `原始"..."` | 不处理转义，反斜杠原样 | 否 |
| 多行 `多行"""..."""` | 处理 `\n`、`\t` 等转义 | 是 |
| 原始多行 `原始多行"""..."""` | 完全不处理转义 | 是 |

### 设计决策

- **原始字符串（新增）**：适用于正则表达式、Windows路径等反斜杠密集场景，避免双重转义。
- **多行字符串（新增）**：适用于多行文本块（文档、SQL等）。
- **组合使用**：`原始` 与 `多行` 可组合为 `原始多行`，获得完全原始的多行文本。
- 字符串以 `\0` 结尾，UTF-8编码，运行时字符串为指针（见[02-类型系统.md](02-类型系统.md)）。

## 五、运算符（8类）

### 5.1 算术运算符（5个）

```
+   -   *   /   %
```

### 5.2 比较运算符（6个）

```
==   !=   <   >   <=   >=
```

### 5.3 逻辑运算符（3个）

```
&&   ||   !
```

### 5.4 位运算符（6个）

```
&   |   ^   ~   <<   >>
```

### 5.5 赋值运算符（12个）

```
=   +=   -=   *=   /=   %=   &=   |=   ^=   <<=   >>=
```

### 5.6 指针运算符（3个）

```
&    // 取地址
*    // 解引用
->   // 成员访问（通过指针）
```

### 5.7 其他运算符（3个）

```
.    // 成员访问
[]   // 下标
()   // 函数调用/分组
```

### 5.8 条件运算符（三元，1个）

```
条件 ? 真值 : 假值     // 右结合，惰性求值，仅对选中分支求值
```

### 5.8B 错误传播运算符（后缀 ?，2026-08，C-1）

```
后缀表达式?    // 结果<T,E>/可选<T> 取值；失败构造错误结果并从当前函数返回
```

- 后缀 `?`（错误传播，优先级13）与三元 `?`（优先级1.5）共用 token，按位置区分：`?` 后跟表达式起点（字面量/标识符/( 等）为三元；否则为后缀传播。详见 [07-错误处理.md](07-错误处理.md) 一B。

### 重要说明

- **成员包含判断**：使用标准库函数 `包含()` 而非运算符（如 `表.包含(键)`），**"在"不是运算符**。
- `&` 同时用于取地址（一元）和按位与（二元），由上下文区分。
- `*` 同时用于解引用（一元）和乘法（二元），由上下文区分。
- **运算符重载**：类/结构体可定义成员 `函数 运算符X(参数) -> 返回类型` 自定义运算符语义（`X` ∈ `+ - * / % == != < > <= >= && || ! & | ^ ~ << >> [] () ->`）。重载决议：① 优先内置运算符；② 无内置匹配按左操作数类型查成员 `运算符X`；③ 无匹配报"类型不兼容"。`运算符` 为**上下文关键字**（非保留字），仅当后随运算符符号且处于类/结构体函数定义上下文时识别。
- **字符串 `+` 拼接**：由编译器隐式调用 `整数转字符串/浮点转字符串/字符转字符串` 转换 + `字符串连接` 实现，无需用户重载。

## 六、运算符优先级（13级，从高到低）

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 13（最高） | `()` `[]` `.` `->` `?`（后缀错误传播，2026-08 C-1） | 后缀 |
| 12 | `!` `~` `-`（负）`*`（解引用）`&`（取地址） | 一元 |
| 11 | `*` `/` `%` | 乘除 |
| 10 | `+` `-` | 加减 |
| 9 | `<<` `>>` | 移位 |
| 8 | `<` `<=` `>` `>=` | 比较 |
| 7 | `==` `!=` | 相等 |
| 6 | `&` | 按位与 |
| 5 | `^` | 按位异或 |
| 4 | `\|` | 按位或 |
| 3 | `&&` | 逻辑与 |
| 2 | `\|\|` | 逻辑或 |
| 1.5 | `条件 ? 真值 : 假值` | 三元条件（右结合） |
| 1（最低） | `=` `+=` `-=` 等 | 赋值 |

### 示例验证

```
变量 结果 = 2 + 3 * 4        // 结果 = 14（乘法优先于加法）
变量 结果2 = (2 + 3) * 4     // 结果2 = 20（括号改变优先级）
变量 结果3 = 1 << 2 + 1      // 结果3 = 8（加法优先于移位）
```

### 设计决策

- 13级优先级与C/C++基本一致，仅保留语法层面的差异；三元条件表达式插入 1.5 级（高于赋值、低于逻辑或），右结合。
- 赋值运算符优先级最低（1级），保证表达式完整求值后再赋值。
- 语法分析器采用Pratt parser处理优先级（见编译器架构）。
