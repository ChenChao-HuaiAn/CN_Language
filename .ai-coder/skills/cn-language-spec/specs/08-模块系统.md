## 一、文件即模块原则

### EBNF

```
模块 = 源文件（每个.cn文件是一个模块）
模块名 = 文件名（不含.cn扩展名）
```

### 原则说明

| 原则 | 说明 |
|------|------|
| 文件即模块 | 每个 `.cn` 文件就是一个模块，模块名为文件名（不含扩展名） |
| 顶层声明 | 函数/结构体/枚举/类/接口/导入/全局变量均为模块级声明 |
| 模块边界 | 模块间的可见性通过公开:/私有:标签控制（见第四节） |

### 设计决策

- 与旧版Rust风格差异：旧版使用 `模块 名称 { }` 块式模块 + `::` 路径分隔；新版**文件即模块**，无块式模块语法，路径使用 `.` 分隔。

## 二、导入语法

### EBNF

```
导入声明 = "导入", 模块路径
          | "从", 模块路径, "导入", 名称列表
模块路径 = 标识符, {".", 标识符}          // . 分隔路径
名称列表 = 名称, {",", 名称}
```

### 示例代码

```
// 导入整个模块
导入 数学.平方根

// 从模块导入指定名称
从 数学 导入 正弦, 余弦

// 嵌套路径导入
导入 网络协议.HTTP.请求
```

### 设计决策

- **`.路径分隔符`**：模块路径用 `.` 分隔（对应文件系统目录），替代Rust的 `::`。
- `导入 模块.子模块` 导入整个模块；`从 模块 导入 名1, 名2` 选择性导入（类似Python的from-import）。

## 三、可见性（标签式）

### EBNF

```
可见性标签 = "公开:" | "私有:"
可见性段 = 标签, 声明*
```

### 示例代码

```
// 数学.cn
公开:
    函数 平方根(浮64 x) -> 浮64 {
        返回 运行时平方根(x)
    }
    常量 PI = 3.14159

私有:
    函数 内部辅助(整32 n) -> 整32 {
        返回 n * 2
    }
```

### 可见性规则

| 标签 | 语义 | 对应C++ |
|------|------|---------|
| `公开:` | 模块外可访问（可被导入使用） | public |
| `私有:` | 仅模块内部可访问 | 匿名命名空间/static |

### 设计决策

- **标签式可见性**：`公开:`/`私有:` 为块级标签，标签后所有声明继承该可见性直到下一个标签。
- 与旧版Rust风格的逐项修饰（`公开 函数`）不同：新版为C++风格的标签式，更简洁。

## 四、入口文件约定

### EBNF

```
程序入口 = 文件 "主.cn", 定义函数 "主", 签名 "函数 主() -> 整32"
```

### 约定细则

| 约定项 | 规则 | 说明 |
|--------|------|------|
| 入口文件 | `主.cn` | 仅为约定，内部须定义 `主` 函数 |
| 入口函数 | `函数 主() -> 整32` | 返回0表示成功 |
| 文件绑定 | 无 | 文件名与函数名无强制绑定关系 |

### 示例代码

```
// 主.cn
导入 数学.平方根

函数 主() -> 整32 {
    变量 结果 = 数学.平方根(16.0)
    打印行("平方根: ", 结果)
    返回 0
}
```
