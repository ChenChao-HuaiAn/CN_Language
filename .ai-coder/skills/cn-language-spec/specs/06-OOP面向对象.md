## 一、类定义与继承

### EBNF

```
类定义 = "类", 标识符, [":", 父类列表], "{", 类体, "}"
父类列表 = 父类名 | 接口名
类体 = 访问标签段*
访问标签段 = ("公开:" | "保护:" | "私有:"), 成员声明*
成员声明 = 字段声明 | 方法声明 | 构造函数声明 | 析构函数声明
```

### 示例代码

```
类 动物 {
公开:
    字符串 名称
    虚拟 函数 叫声() -> 字符串 {
        返回 "..."
    }
保护:
    整32 年龄
私有:
    整32 内部ID
}

类 狗 : 动物 {        // 单继承：冒号后跟父类名
公开:
    重写 函数 叫声() -> 字符串 {
        返回 "汪汪"
    }
}
```

### 设计决策

- **完整OOP**（决策7）：类/接口/继承/保护/虚拟/重写/抽象/实现/自身/父类全部保留。
- 继承语法 `类 狗 : 动物` 与C++一致（冒号后父类）。
- 与旧版Rust风格的关键差异：旧版无类继承概念（使用结构+特征），新版为完整面向对象。

## 二、访问控制（标签式）

### EBNF

```
访问控制 = "公开:" | "保护:" | "私有:"
```

### 访问控制表

| 标签 | 访问范围 | 对应C++ |
|------|---------|---------|
| `公开:` | 所有代码可访问 | public |
| `保护:` | 自身与子类可访问 | protected |
| `私有:` | 仅自身可访问 | private |

### 示例代码

```
类 账户 {
公开:
    字符串 用户名
    函数 存款(整32 金额) -> 空类型 {
        余额 += 金额
    }
保护:
    整32 余额
私有:
    整32 密码哈希
}
```

### 设计决策

- **标签式可见性**：`公开:`/`保护:`/`私有:` 为块级标签，标签后的所有成员继承该可见性，直到下一个标签出现。
- 与旧版Rust风格的逐项修饰（`公开 函数`）不同：新版为C++风格的标签式，更简洁。

## 三、构造函数与析构函数

### EBNF

```
构造函数 = "函数", 类名, "(", 参数列表, ")", 函数体
析构函数 = "函数", "~", 类名, "(", ")", 函数体
```

### 示例代码

```
类 狗 : 动物 {
公开:
    // 构造函数（与类同名）
    函数 狗(字符串 名) {
        名称 = 名
    }
    
    // 析构函数（~类名）
    函数 ~狗() {
        // 清理资源
    }
}
```

### 设计决策

- 构造函数 `函数 类名(...)`，析构函数 `函数 ~类名()`，与C++同名构造/析构语义一致。
- 构造函数返回对象指针；析构函数内联清理资源后调用父类析构（见编译器架构-运行时布局）。

## 四、虚函数与重写

### EBNF

```
虚函数 = "虚拟", "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
重写函数 = "重写", "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
```

### 示例代码

```
类 动物 {
公开:
    虚拟 函数 叫声() -> 字符串 {      // 虚函数声明
        返回 "..."
    }
}

类 狗 : 动物 {
公开:
    重写 函数 叫声() -> 字符串 {      // 重写父类虚函数
        返回 "汪汪"
    }
}

类 猫 : 动物 {
公开:
    重写 函数 叫声() -> 字符串 {
        返回 "喵喵"
    }
}
```

### 设计决策

- `虚拟` 声明多态函数（vtable分发），`重写` 显式标注子类覆盖（编译期校验签名匹配）。
- 调用虚函数经vtable间接跳转（`调用 虚调用` IR指令）。

## 五、虚表内存布局

### 内存布局

```
类实例内存布局（单继承）：
┌─────────────────────────────┐
│ vtable指针（8字节）            │ ← 实例首地址
├─────────────────────────────┤
│ 父类成员区                     │
├─────────────────────────────┤
│ 自身成员区                     │
└─────────────────────────────┘
```

### 虚函数表（vtable）

- vtable为函数指针数组，子类重写时覆盖对应槽位。
- 接口实现采用附加vtable（预留）。
- 虚调用指令经vtable间接跳转分发。

### 示例代码

```
类 形状 {
公开:
    虚拟 函数 面积() -> 浮64 {
        返回 0.0
    }
}

类 圆形 : 形状 {
公开:
    浮64 半径
    重写 函数 面积() -> 浮64 {
        返回 3.14159 * 半径 * 半径
    }
}
```

## 六、接口定义与实现

### EBNF

```
接口定义 = "接口", 标识符, "{", 虚拟函数签名列表, "}"
接口实现 = "类", 类名, ":", 接口名, "{", 类体, "}"
```

### 示例代码

```
// 接口定义：只含虚拟函数签名（无实现）
接口 可绘制 {
    虚拟 函数 绘制() -> 空类型
}

// 接口实现：类冒号后实现接口
类 圆形 : 可绘制 {
公开:
    浮64 半径
    重写 函数 绘制() -> 空类型 {
        // 实现绘制逻辑
    }
}

类 矩形 : 可绘制 {
公开:
    重写 函数 绘制() -> 空类型 {
        // 实现绘制逻辑
    }
}
```

### 设计决策

- 接口只包含虚函数签名（无实现体），由实现类通过 `重写` 提供实现。
- 接口实现采用附加vtable（预留），支持多接口实现。

## 七、自身和父类访问

### EBNF

```
自身访问 = "自身", ".", 成员名
父类访问 = "父类", ".", 方法名, "(", 实参列表, ")"
```

### 示例代码

```
类 父类 {
公开:
    整32 字段 = 10
    函数 方法() -> 空类型 {
        打印行("父类方法")
    }
}

类 子类 : 父类 {
公开:
    重写 函数 方法() -> 空类型 {
        自身.字段 = 20       // 访问自身成员（this->字段）
        父类.方法()          // 调用父类方法（父类::方法()）
    }
}
```

### 设计决策

- `自身` 对应C++的 `this`，`父类` 对应C++的 `父类::` 限定调用。
- 2026-08-12变更：`基类` 更名为 `父类`，更符合中文面向对象表达习惯。

## 八、抽象类（抽象关键字）

### EBNF

```
抽象成员 = "抽象", 函数签名      // 纯虚函数，子类必须实现
```

### 示例代码

```
类 形状 {
公开:
    抽象 函数 面积() -> 浮64    // 抽象方法，无实现，子类必须重写
}

类 圆形 : 形状 {
公开:
    浮64 半径
    重写 函数 面积() -> 浮64 {
        返回 3.14159 * 半径 * 半径
    }
}
```

### 设计决策

- `抽象` 声明纯虚函数（类似C++的 `= 0`），含抽象成员的类不可直接实例化，子类必须实现全部抽象成员。
