## 一、类定义与继承

### EBNF

```
类定义 = "类", 标识符, [":", 父类列表], "{", 类体, "}"
父类列表 = 父类名 | 接口名
类体 = 访问标签段*
访问标签段 = ("公开:" | "保护:" | "私有:"), 成员声明*
成员声明 = 字段声明 | 方法声明 | 构造函数声明 | 析构函数声明
```

### 示例代码

```
类 动物 {
公开:
    字符串 名称
    虚拟 函数 叫声() -> 字符串 {
        返回 "..."
    }
保护:
    整32 年龄
私有:
    整32 内部ID
}

类 狗 : 动物 {        // 单继承：冒号后跟父类名
公开:
    重写 函数 叫声() -> 字符串 {
        返回 "汪汪"
    }
}
```

### 设计决策

- **完整OOP**（决策7）：类/接口/继承/保护/虚拟/重写/抽象/实现/自身/父类全部保留。
- 继承语法 `类 狗 : 动物` 与C++一致（冒号后父类）。
- 与旧版Rust风格的关键差异：旧版无类继承概念（使用结构+特征），新版为完整面向对象。

## 二、访问控制（标签式 + 默认私有）

### EBNF

```
访问控制 = "公开:" | "保护:" | "私有:"
```

### 访问控制表

| 标签 | 访问范围 | 对应C++ |
|------|---------|---------|
| `公开:` | 所有代码可访问 | public |
| `保护:` | 自身与子类可访问 | protected |
| `私有:` | 仅自身可访问 | private |
| （无标签） | **默认私有**（v2.0 变更，原默认公开） | 默认 private |

### 示例代码

```
类 账户 {
    字符串 用户名              // 无标签 → 默认私有（v2.0）
    函数 内部函数() { }        // 无标签 → 默认私有
公开:
    函数 存款(整32 金额) -> 空类型 {
        余额 += 金额
    }
保护:
    整32 余额
私有:
    整32 密码哈希
}
```

### 设计决策

- **标签式可见性**：`公开:`/`保护:`/`私有:` 为块级标签，标签后的所有成员继承该可见性，直到下一个标签出现。
- **默认私有**（v2.0 变更）：类体开头无任何标签时，成员默认私有。公共 API（字段/方法/构造/析构）须显式 `公开:` 标注。
- **可见性交集**（v2.0）：类内 `公开:` 仅赋予"成员在类层级可见的前提下的公开访问"——若类本身是模块私有（模块级 `私有:` 或无标签默认私有），则类内公开成员跨文件也不可见（取交集最严格），见[08-模块系统.md](08-模块系统.md) 第四节。
- 与旧版Rust风格的逐项修饰（`公开 函数`）不同：新版为C++风格的标签式，更简洁。

## 三、构造函数与析构函数

### EBNF

```
构造函数 = "函数", 类名, "(", 参数列表, ")", 函数体
析构函数 = "函数", "~", 类名, "(", ")", 函数体
```

### 示例代码

```
类 狗 : 动物 {
公开:
    // 构造函数（与类同名）
    函数 狗(字符串 名) {
        名称 = 名
    }
    
    // 析构函数（~类名）
    函数 ~狗() {
        // 清理资源
    }
}
```

### 设计决策

- 构造函数 `函数 类名(...)`，析构函数 `函数 ~类名()`，与C++同名构造/析构语义一致。
- 构造函数返回对象指针；析构函数内联清理资源后调用父类析构（见编译器架构-运行时布局）。

## 四、虚函数与重写

### EBNF

```
虚函数 = "虚拟", "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
重写函数 = "重写", "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
```

### 示例代码

```
类 动物 {
公开:
    虚拟 函数 叫声() -> 字符串 {      // 虚函数声明
        返回 "..."
    }
}

类 狗 : 动物 {
公开:
    重写 函数 叫声() -> 字符串 {      // 重写父类虚函数
        返回 "汪汪"
    }
}

类 猫 : 动物 {
公开:
    重写 函数 叫声() -> 字符串 {
        返回 "喵喵"
    }
}
```

### 设计决策

- `虚拟` 声明多态函数（vtable分发），`重写` 显式标注子类覆盖（编译期校验签名匹配）。
- 调用虚函数经vtable间接跳转（`调用 虚调用` IR指令）。

---

## 五、虚表内存布局

### 内存布局

```
类实例内存布局（单继承）：
┌─────────────────────────────┐
│ vtable指针（8字节）            │ ← 实例首地址
├─────────────────────────────┤
│ 父类成员区                     │
├─────────────────────────────┤
│ 自身成员区                     │
└─────────────────────────────┘
```

### 虚函数表（vtable）

- vtable为函数指针数组，子类重写时覆盖对应槽位。
- 接口实现采用附加vtable（预留）。
- 虚调用指令经vtable间接跳转分发。

### 示例代码

```
类 形状 {
公开:
    虚拟 函数 面积() -> 浮64 {
        返回 0.0
    }
}

类 圆形 : 形状 {
公开:
    浮64 半径
    重写 函数 面积() -> 浮64 {
        返回 3.14159 * 半径 * 半径
    }
}
```

## 六、接口定义与实现

### EBNF

```
接口定义 = "接口", 标识符, "{", 虚拟函数签名列表, "}"
接口实现 = "类", 类名, ":", 接口名, "{", 类体, "}"
```

### 示例代码

```
// 接口定义：只含虚拟函数签名（无实现）
接口 可绘制 {
    虚拟 函数 绘制() -> 空类型
}

// 接口实现：类冒号后实现接口
类 圆形 : 可绘制 {
公开:
    浮64 半径
    重写 函数 绘制() -> 空类型 {
        // 实现绘制逻辑
    }
}

类 矩形 : 可绘制 {
公开:
    重写 函数 绘制() -> 空类型 {
        // 实现绘制逻辑
    }
}
```

### 设计决策

- 接口只包含虚函数签名（无实现体），由实现类通过 `重写` 提供实现。
- 接口实现采用附加vtable（预留），支持多接口实现。

## 七、自身和父类访问

### EBNF

```
自身访问 = "自身", ".", 成员名
父类访问 = "父类", ".", 方法名, "(", 实参列表, ")"
```

### 示例代码

```
类 父类 {
公开:
    整32 字段 = 10
    函数 方法() -> 空类型 {
        打印行("父类方法")
    }
}

类 子类 : 父类 {
公开:
    重写 函数 方法() -> 空类型 {
        自身.字段 = 20       // 访问自身成员（this->字段）
        父类.方法()          // 调用父类方法（父类::方法()）
    }
}
```

### 设计决策

- `自身` 对应C++的 `this`，`父类` 对应C++的 `父类::` 限定调用。
- 2026-08-12变更：`基类` 更名为 `父类`，更符合中文面向对象表达习惯。

## 八、抽象类（抽象关键字）

### EBNF

```
抽象成员 = "抽象", 函数签名      // 纯虚函数，子类必须实现
```

### 示例代码

```
类 形状 {
公开:
    抽象 函数 面积() -> 浮64    // 抽象方法，无实现，子类必须重写
}

类 圆形 : 形状 {
公开:
    浮64 半径
    重写 函数 面积() -> 浮64 {
        返回 3.14159 * 半径 * 半径
    }
}
```

### 设计决策

- `抽象` 声明纯虚函数（类似C++的 `= 0`），含抽象成员的类不可直接实例化，子类必须实现全部抽象成员。

## 九、运算符重载（成员）

### 示例代码

```
类 复数 {
公开:
    浮64 实部
    浮64 虚部

    函数 运算符+(复数 右) -> 复数 {
        返回 复数{实部 + 右.实部, 虚部 + 右.虚部}
    }

    函数 运算符==(复数 右) -> 布尔 {
        返回 实部 == 右.实部 且 虚部 == 右.虚部
    }
}

复数 a = 复数{1.0, 2.0}
复数 b = 复数{3.0, 4.0}
复数 c = a + b        // 调用 复数.运算符+
布尔 相同 = a == b    // 调用 复数.运算符==
```

### 设计决策

- 重载运算符仅限成员函数，左操作数必须是本类实例；单目运算符（`-`/`!`/`~`）无参数，双目运算符单参数（右操作数）。
- `运算符` 为**上下文关键字**（非保留字）：仅当后随运算符符号且处于类/结构体函数定义上下文时识别。
- 字符串 `+` 拼接由编译器隐式转换，不与用户重载冲突。

## 十、静态成员

### 示例代码

```
类 计数器 {
公开:
    静态 整32 总数 = 0        // 类静态字段（全类共享）

    函数 计数器() {
        总数++               // 类内直接访问
    }

    静态 函数 获取总数() -> 整32 {
        返回 总数
    }
}

计数器.总数 = 10              // 类外通过 类名.静态成员 访问
整32 当前 = 计数器.获取总数()
```

### 设计决策

- 静态成员全类共享（`.data` 段分配）；静态方法无 this，不可访问非静态成员。
- 类外访问用 `类名.静态成员`。

## 十一、常量成员函数

### 示例代码

```
类 只读包装 {
私有:
    整32 值
公开:
    函数 只读包装(整32 v) { 值 = v }

    常量 函数 获取() -> 整32 {   // 常量成员：不修改任何成员
        返回 值
    }
}
```

### 设计决策

- `常量` 修饰的成员函数承诺不修改成员；常量对象仅能调用常量成员函数；违反时编译器报错。

## 十二、友元

### 示例代码

```
类 账户 {
私有:
    整64 余额
公开:
    友元 函数 审计(账户& 账)   // 声明友元函数，可访问私有成员
}

函数 审计(账户& 账) -> 整64 {
    返回 账.余额                // 友元可访问私有
}
```

### 设计决策

- `友元` 授予外部函数或类访问本类私有/保护成员的权限（最小授权原则，谨慎使用）。

## 十三、泛型 / 模板

### 示例代码

```
泛型 <类型 T>
类 向量 {
私有:
    T* 数据
    整64 长度
公开:
    函数 向量(整64 容量) { 数据 = 分配(T 大小 * 容量); 长度 = 0 }
    函数 推入(T 值) { 数据[长度] = 值; 长度++ }
    函数 获取(整64 索引) -> T { 返回 数据[索引] }
}

向量<整32> 整数列表 = 向量<整32>(10)
整数列表.推入(42)

泛型 <类型 T>
函数 交换(T& a, T& b) -> 空类型 {
    T 临时 = a
    a = b
    b = 临时
}
```

### 设计决策

- 泛型采用**编译期单态化**（每实例化生成一份具体类型代码）。
- `泛型 <类型 T>` 声明类型参数，`类型名<实参>` 实例化；支持泛型类与泛型函数；类型参数可约束为接口（`泛型 <类型 T : 接口>`）。
