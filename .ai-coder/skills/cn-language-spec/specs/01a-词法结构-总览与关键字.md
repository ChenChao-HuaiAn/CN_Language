## 二、源文件约定

### EBNF

```
源文件 = 文件编码 UTF-8, 扩展名 ".cn", 内容为 程序结构
程序结构 = 顶层声明*
顶层声明 = 函数声明 | 结构体声明 | 枚举声明 | 类声明 | 接口声明 | 导入声明 | 全局变量声明
```

### 约定细则

| 约定项 | 规则 | 说明 |
|--------|------|------|
| 扩展名 | `.cn` | 每个.cn文件是一个模块 |
| 编码 | UTF-8（必须） | 支持中文字符与多字节标识符 |
| 入口文件 | `主.cn` | 仅为约定，内部须定义 `主` 函数作为程序入口 |
| 入口函数 | `函数 主() -> 整32` | 返回0表示成功；文件名与函数名无强制绑定关系 |

## 三、注释

### EBNF

```
注释 = 单行注释 | 块注释
单行注释 = "//", 任意字符直到行尾
块注释 = "/*", (任意字符 | 块注释)*, "*/"    // 支持嵌套
```

### 示例代码

```
// 单行注释
函数 主() -> 整32 {
    /* 块注释 */
    /* 外层注释
        /* 内层嵌套注释（支持嵌套） */
    */
    返回 0
}
```

### 设计决策

- **块注释支持嵌套**：与C/C++不同（C/C++块注释不支持嵌套），CN语言允许 `/* */` 嵌套，便于在注释中临时屏蔽大段代码。

## 五、标识符规则

### EBNF

```
标识符 = (中文字符 | 字母 | "_"), (中文字符 | 字母 | 数字 | "_")*
```

### 规则细则

| 规则 | 说明 |
|------|------|
| 开头 | 中文字符、字母或下划线 `_` 开头 |
| 后续 | 可包含中文、字母、数字、下划线 |
| UTF-8 | 支持UTF-8多字节字符（中文字符按单字处理） |
| 保留字 | 所有关键字均为保留字，不可用作标识符 |
| 区分大小写 | 关键字为中文，无大小写问题；英文字母区分大小写 |

### 示例代码

```
变量 中文变量 = 10        // 中文字符开头
变量 _私有值 = 20         // 下划线开头
变量 myVar = 30           // 字母开头
// 变量 如果 = 1          // ❌ 错误：关键字不可用作标识符
```

### 设计决策

- **中文优先**：标识符允许中文字符，全中文语法风格一致，降低中文开发者学习成本。
- **关键字即保留字**：所有53个关键字均为保留字，编译器词法分析阶段直接拒绝用作标识符。
- **最长匹配**：中文关键字采用最长匹配原则，关键字后必须有空格或符号分隔（见词法分析器设计）。
