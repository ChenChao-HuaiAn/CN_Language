# 04 函数与函数指针

> 文档编号：04
> 所属技能：cn-language-spec（C++风格版v1.0）
> 基准文档：[plans/001 CN语言编译器设计规格书.md](../../../../plans/001%20CN语言编译器设计规格书.md)
> 内容范围：函数定义、函数原型声明、递归、函数指针（C风格）、内置构造器（正常/错误/某些）

## 一、函数定义

### EBNF

```
函数定义 = "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
参数列表 = [参数, {",", 参数}]
参数 = 类型, 标识符
返回类型 = 类型 | "空类型"
函数体 = "{", 语句*, "}"
```

### 示例代码

```
函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b
}

函数 打印问候() {
    打印行("你好")
}

函数 主() -> 整32 {
    打印问候()
    返回 0
}
```

### 设计决策

- 无返回值函数省略 `-> 类型`（即 `-> 空类型` 可省略）。
- 参数为类型前置：`类型 参数名`，与C/C++一致。

## 二、函数原型声明（前向引用）

### EBNF

```
函数原型声明 = "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], ";"
```

### 示例代码

```
// 前向声明
函数 计算(整32 n) -> 整32

// 先调用后定义（依赖原型声明）
函数 使用() -> 整32 {
    返回 计算(10)
}

// 实际定义
函数 计算(整32 n) -> 整32 {
    返回 n * 2
}
```

### 设计决策

- 语法分析器采用两趟解析：第一趟收集顶层声明，第二趟解析函数体，天然支持前向引用（见编译器架构-语法分析器）。
- 函数原型声明用于模块间/函数间的相互调用。

---

## 三、递归

### EBNF

```
递归函数 = 函数定义, 函数体内调用自身
```

### 示例代码

```
函数 阶乘(整32 n) -> 整32 {
    如果 n <= 1 {
        返回 1
    }
    返回 n * 阶乘(n - 1)   // 递归调用自身
}

函数 斐波那契(整32 n) -> 整32 {
    如果 n < 2 {
        返回 n
    }
    返回 斐波那契(n - 1) + 斐波那契(n - 2)
}
```

### 设计决策

- 递归依赖函数原型机制，先有声明后有调用。
- 尾递归可被优化器转换为循环（尾调用优化TCO，见编译器架构-优化Pass清单）。

---

## 四、函数指针（C风格）

### EBNF

```
函数指针声明 = 返回类型, "(*", 标识符, ")", "(", 参数类型列表, ")"
函数指针赋值 = 标识符, "=", 函数名
函数指针调用 = 标识符, "(", 实参列表, ")"
```

### 示例代码

```
// 声明函数指针类型变量
整32(*回调)(整32, 整32)

// 赋值：将函数地址赋给函数指针
回调 = 加

// 调用函数指针
整32 结果 = 回调(10, 20)
```

### 设计决策

- **采用C风格声明语法**：`整32(*回调)(整32, 整32)`，与C/C++函数指针语法保持一致，便于底层编程人员理解。
- 与旧版Rust风格不同：旧版无函数指针概念（Rust使用 `fn` 类型与闭包），新版明确支持C风格函数指针。
- 函数指针用于回调模式、事件分发等场景；IR层通过间接调用指令（`调用 间接`）实现。

## 五、内置构造器（正常/错误/某些）

### EBNF

```
内置构造器 = "正常", "(", 表达式, ")"       // 构造结果<T,E>的正常值
            | "错误", "(", 错误码, ")"      // 构造结果<T,E>的错误值
            | "某些", "(", 表达式, ")"      // 构造可选<T>的有值
```

### 示例代码

```
函数 除法(整32 a, 整32 b) -> 结果<整32, 整32> {
    如果 b == 0 {
        返回 错误(1)   // 构造错误值，错误码1: 除零
    }
    返回 正常(a / b)   // 构造正常值
}

函数 查找(整32 键) -> 可选<整32> {
    如果 表.包含(键) {
        返回 某些(表[键])  // 构造有值
    }
    返回 无              // 返回无（空可选）
}
```

### 重要身份说明

- `正常()`、`错误()`、`某些()` 为**内置构造器函数**，由编译器预置符号表。
- 它们**不是保留关键字**，但用户不可重定义（预置符号表独占）。
- 详细规则见 [07-错误处理.md](07-错误处理.md)。
