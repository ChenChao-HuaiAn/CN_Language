## 一、包（crate）概念

### 1.1 定义

- **包（crate）= 命名空间边界 + 编译单元边界**：一个可执行程序或库 = 一个 crate。
- **crate 隔离**：跨包同名符号不冲突——`包A::工具` 与 `包B::工具` 是两个独立符号，链接时符号加 `包名$` 前缀隔离。
- **crate 根**：
  - 可执行程序：`主.cn`（入口文件）
  - 库：`包.cn`（聚合模块 + 再导出公共 API）

### 1.2 包与模块的关系

| 概念 | 说明 | 示例 |
|------|------|------|
| 包（crate） | 最大组织单元，命名空间边界 | `网络库` |
| 模块 | 包内组织单元，文件即模块 | `网络库::传输控制` |
| 符号 | 函数/类/结构体/枚举/常量/静态 | `网络库::传输控制::发送` |

### 1.3 EBNF

```
包 = "包" 标识符              // 包概念关键字（crate 名上下文）
crate根 = "主.cn" | "包.cn"
模块树 = 模块声明* 与 目录层级（"::" 对应 "/"）
跨包路径 = 包名 "::" (模块名 "::")* 符号名
```

## 二、货舱.toml 完整规范

### 2.1 文件位置与格式

- 文件：`货舱.toml`（位于包根目录，UTF-8 编码）
- 格式：TOML 子集（`[节]` + `键 = "值"`，支持 `#` 注释）
- 必填节：`[货舱]`；可选节：`[依赖]`

### 2.2 `[货舱]` 节

| 键 | 必填 | 说明 | 示例 |
|----|------|------|------|
| `名称` | ✅ | 包（crate）名，跨包导入路径首段（`导入 名称::模块::符号`） | `名称 = "我的程序"` |
| `版本` | ✅ | 语义化版本（`主.次.修订`） | `版本 = "0.1.0"` |

### 2.3 `[依赖]` 节

| 键 | 说明 | 示例 |
|----|------|------|
| `名称 = "版本"` | 声明依赖包；`核心 = "内置"` 表示内置核心包 | `核心 = "内置"` |
| 版本约束 | `"1.2"` = >=1.2 且 <2.0（兼容性约束） | `网络库 = "1.2"` |
| 多依赖 | 每行一个依赖 | 见下方示例 |

### 2.4 完整示例

```toml
# 货舱.toml — 包元数据与依赖
[货舱]
名称 = "我的程序"
版本 = "0.1.0"

[依赖]
核心 = "内置"        # 内置核心包（prelude 来源）
网络库 = "1.2"       # 外部依赖：版本 1.2（>=1.2 <2.0）
工具库 = "0.3"
```

### 2.5 使用依赖

```
// 代码中使用 货舱.toml 声明的依赖
导入 网络库::连接              // 包名::模块符号
导入 网络库::请求::获取        // 包名::模块::符号
导入 工具库::{格式化, 解析}    // 花括号选择性导入

函数 主() -> 整32 {
    连接()
    打印行(格式化("结果: {0}", 42))
    返回 0
}
```

## 三、包.cn 结构（库 crate 根）

### 3.1 角色

`包.cn` 是库包的 crate 根，职责：
1. **聚合模块**：用 `模块 名` 声明引用包内模块（加载同名 .cn 文件 / 子目录模块树）。
2. **再导出公共 API**：`公开 导入 路径` 将模块符号再导出为包级 API，外部通过 `包名::符号` 使用。

### 3.2 示例

```
// 包.cn — 库 crate 根
模块 网络
模块 存储

公开 导入 网络::连接          // 再导出：外部 网络库::连接
公开 导入 网络::传输控制::发送
公开 导入 存储::存储器

// 私有内部聚合（不导出）
模块 内部工具
```

```
// 项目目录布局
网络库/
├── 货舱.toml
├── 包.cn                 // crate 根（库）
├── 网络.cn               // 模块 网络
├── 网络/
│   ├── 传输控制.cn       // 模块 网络::传输控制
│   └── 用户数据报.cn     // 模块 网络::用户数据报
├── 存储.cn               // 模块 存储
└── 内部工具.cn           // 模块 内部工具（私有，不导出）
```

### 3.3 外部使用

```
// 使用者 crate 的 货舱.toml
[依赖]
网络库 = "1.2"

// 使用代码
导入 网络库::连接
导入 网络库::传输控制::发送

函数 主() -> 整32 {
    连接()
    发送()
    返回 0
}
```

## 四、crate 边界（命名空间隔离）

### 4.1 隔离规则

| 规则 | 说明 |
|------|------|
| 命名空间边界 | 每个 crate 独立命名空间：`包A::工具` ≠ `包B::工具` |
| 链接隔离 | IR/codegen 符号加 `包名$` 前缀（`包名$符号名`），杜绝跨包链接冲突 |
| 泛型命名 | 泛型实例化统一 `包名$类型$参数`，与 crate 前缀不混淆 |
| 跨包访问 | 仅通过 `导入 包名::...` 访问公开符号；未在货舱.toml 声明的包不可导入 |
| 可见性 | 跨包可见性 = 各层级交集（模块公开 × 类内公开，取最严格） |

### 4.2 示例：同名符号跨包隔离

```
// 包A（包A/包.cn）
公开 导入 网络::连接
模块 网络
// 包A/网络.cn
公开:
函数 连接() -> 空类型 { }      // 符号：包A$网络$连接

// 包B（包B/包.cn）
公开 导入 网络::连接
模块 网络
// 包B/网络.cn
公开:
函数 连接() -> 空类型 { }      // 符号：包B$网络$连接（与包A 的互不冲突）

// 使用者（货舱.toml 声明 包A、包B 依赖）
导入 包A::连接
导入 包B::连接 作为 连接B

函数 主() -> 整32 {
    连接()          // 包A 的连接
    连接B()         // 包B 的连接
    返回 0
}
```

## 五、核心包 prelude

### 5.1 规则

| 规则 | 说明 |
|------|------|
| 隐式可见 | 核心包基础项**默认可见**（无需显式导入）：编译器隐式提供 prelude |
| 基础项范围 | 基础类型构造器（整型/浮点/布尔/字符/字符串）、结果/可选 构造器（正常/错误/某些/无）、打印行 等基础函数 |
| 显式扩展 | `导入 核心::*` 或 `导入 核心::{符号列表}` 显式引入更多核心包符号 |
| 内置函数归属 | 内置函数族归入核心包 prelude，替代无前缀硬编码扁平表 |

### 5.2 示例

```
// 无需导入即可使用 prelude 基础项
函数 主() -> 整32 {
    打印行("你好")                    // 打印行：prelude
    整32 n = 42                       // 整32：prelude 类型
    结果<整32, 字符串> 结果值 = 正常(42)   // 结果/正常：prelude
    可选<整32> 某些值 = 某些(7)       // 可选/某些：prelude
    返回 0
}

// 显式扩展核心包
导入 核心::数学::平方根
导入 核心::{格式化, 解析}
```

## 六、依赖解析流程

```
1. 读取 货舱.toml
2. 校验 [货舱] 名称/版本 必填
3. 解析 [依赖]：核心 = 内置（编译器内置）；外部依赖 = 版本约束查找
4. 构建依赖图：主 crate → 依赖 crate → 传递依赖
5. 编译期：按 crate 边界加载模块树，符号加 包名$ 前缀
6. 未声明依赖的包名出现在 `导入 包名::...` → 编译错误（未声明的包）
```

### 错误示例

```
// 货舱.toml 未声明 网络库
导入 网络库::连接     // ❌ 编译错误：未声明的包 '网络库'（请在货舱.toml [依赖] 中声明）
```
