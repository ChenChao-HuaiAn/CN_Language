# 07 错误处理

> 文档编号：07
> 所属技能：cn-language-spec（C++风格版v1.0）
> 基准文档：[plans/001 CN语言编译器设计规格书.md](../../../../plans/001%20CN语言编译器设计规格书.md)
> 内容范围：结果<T,E>类型、可选<T>类型、强制检查规则（3条）、内置构造器函数、错误码约定

---

## 一、错误处理设计总览

### EBNF

```
错误处理 = 结果类型 | 可选类型
结果类型 = "结果", "<", 正常类型, ",", 错误类型, ">"
可选类型 = "可选", "<", 类型, ">"
```

### 设计决策

- **错误码+可选值**（决策6）：替代异常机制，去掉异常关键字（尝试/捕获/抛出/最终）。
- 与旧版Rust风格差异：旧版使用 `结果+?运算符` 传播错误；新版**无 `?` 运算符**，通过显式检查 `.正常`/`.有值` 处理。

---

## 二、结果<T,E>类型

### EBNF

```
结果构造 = "正常", "(", 正常值表达式, ")"
          | "错误", "(", 错误码表达式, ")"
结果检查 = 结果变量, ".正常"        // 布尔：是否正常
结果取值 = 结果变量, ".值"          // 正常值（需先检查）
错误取值 = 结果变量, ".错误"        // 错误码（需先检查）
```

### 示例代码

```
函数 除法(整32 a, 整32 b) -> 结果<整32, 整32> {
    如果 b == 0 {
        返回 错误(1)   // 错误码1: 除零错误
    }
    返回 正常(a / b)
}

// 使用结果类型
除法结果 = 除法(10, 0)
如果 除法结果.正常 {
    打印行(除法结果.值)       // 访问正常值
} 否则 {
    打印行("除零错误: ", 除法结果.错误)  // 访问错误码
}
```

### 错误码约定（附录B）

| 错误码 | 含义 |
|--------|------|
| 1 | 除零错误 |
| 2 | 数组越界 |
| 3 | 空指针解引用 |
| 4 | 内存分配失败 |
| 5 | 文件打开失败 |
| 6 | 无效参数 |
| 7 | 资源未初始化 |
| 8 | 溢出错误 |

---

## 三、可选<T>类型

### EBNF

```
可选构造 = "某些", "(", 值表达式, ")"      // 有值
          | "无"                           // 无值
可选检查 = 可选变量, ".有值"                // 布尔：是否有值
可选取值 = 可选变量, ".值"                  // 值（需先检查有值）
```

### 示例代码

```
函数 查找(整32 键) -> 可选<整32> {
    如果 表.包含(键) {
        返回 某些(表[键])
    }
    返回 无
}

// 使用可选类型
查找结果 = 查找(42)
如果 查找结果.有值 {
    打印行("找到: ", 查找结果.值)
} 否则 {
    打印行("未找到")
}
```

### 设计决策

- `无` 关键字同时是空值常量（对应C++的nullptr），用于构造空可选。
- 可选类型没有 `.错误` 成员，只有 `.有值` 与 `.值`。

---

## 四、强制检查规则（3条）

| 规则 | 描述 | 编译诊断 |
|------|------|---------|
| 规则1 | `结果<T,E>` 类型的返回值如果不被检查就丢弃 | **错误** |
| 规则2 | 检查 `结果.正常` 后未处理错误分支 | **警告** |
| 规则3 | `可选<T>` 类型的值在访问 `.值` 前必须检查 `.有值` | **错误** |

### 示例代码（合规与违规）

```
// ✅ 合规：检查正常后处理两个分支
除法结果 = 除法(10, 2)
如果 除法结果.正常 {
    打印行(除法结果.值)
} 否则 {
    打印行("错误: ", 除法结果.错误)
}

// ❌ 违规（规则1）：结果被丢弃未检查
除法(10, 2)

// ❌ 违规（规则2）：检查正常后未处理错误分支
如果 除法结果.正常 {
    打印行(除法结果.值)
}

// ❌ 违规（规则3）：未检查.有值直接访问.值
打印行(查找结果.值)
```

### 设计决策

- 规则1与规则3为**错误**（编译失败），规则2为**警告**（可编译但提示）。
- 由语义分析器阶段3的错误码传播分析模块实现（错误码分析模块ErrorAnalysis）。

## 五、内置构造器函数

### 身份说明

- `正常()`、`错误()`、`某些()` 为**内置构造器函数**，由编译器预置符号表。
- **不是保留关键字**，但用户不可重定义。

| 构造器 | 用途 | 所属类型 |
|--------|------|---------|
| `正常(值)` | 构造正常值 | 结果<T,E> |
| `错误(错误码)` | 构造错误值 | 结果<T,E> |
| `某些(值)` | 构造有值 | 可选<T> |
| `无` | 空值/空可选 | 可选<T> |

### 示例代码

```
函数 打开文件(字符串 路径) -> 结果<字符串, 整32> {
    如果 文件不存在(路径) {
        返回 错误(5)     // 错误码5: 文件打开失败
    }
    返回 正常(路径)
}

函数 查找用户(整32 id) -> 可选<字符串> {
    用户 = 数据库.查询(id)
    如果 用户.有值 {
        返回 某些(用户.值)
    }
    返回 无
}
```

## 六、类型降级约定（IR层面）

- `结果<正常, 错误>` 降级为 `结构体 { 布尔 是否正常; 联合体 { 正常类型 值; 错误类型 错误值 } }`
- `可选<类型>` 降级为 `结构体 { 布尔 是否某些; 类型 值 }`
- 检查成员 `.正常`/`.某些` 对应结构体首字段读取，未检查即访问 `.值` 由语义分析器在阶段3提前拦截
