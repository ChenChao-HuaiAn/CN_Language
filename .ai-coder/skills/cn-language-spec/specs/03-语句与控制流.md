## 零、语句终止与续行

> **核心事实：CN 语言的语句既不是"换行结尾"也不是"分号结尾"。换行（`\n`/`\r`）在词法层与空格、Tab 一样被当作空白直接跳过，不产生换行 token，因此换行没有语法意义，等同空格。语句的真正边界由"表达式自然解析停止 + 下一条语句的起始关键字"识别。**

### 三层机制

| 层 | 行为 | 判定位置 |
|----|------|---------|
| 词法层 | 换行 `\n`/`\r` 与空格、Tab 完全当作空白跳过，不产生换行 token | 词法分析器（换行无语法意义，等同空格） |
| 语法层 | 分号 `;` 是**可选**终止符："有就吃、没有不报错" | 语法分析器 `consumeSemicolon()` |
| 边界识别 | 语句结束靠"表达式自然解析停止 + 下一条语句起始关键字（返回/如果/当/循环/中断/继续/变量/常量/静态/类型关键字）" | 语法分析器 `parseStmt()` |

### EBNF

```
语句 = 表达式语句 | 声明语句 | 控制流语句 | 返回语句 | ...
      [";"]                            // 分号可选，有就吃、没有不报错
```

### 规则1：语句终止（无终止符 + 可选分号 + 关键字边界）

- 语句**无需终止符**，分号 `;` 可选（兼容 C 习惯写法，如 `变量 a = 1;`）
- 语句边界由"下一条语句起始关键字/类型关键字"识别
- 无分号时依赖关键字边界，`变量 x = 1 整32 y = 2` 合法（`整32` 触发新声明）

### 规则2：续行（换行≡空格，天然无条件续行）

- 换行无语法意义，**任何位置换行都天然续行**，不存在"括号未闭合才可续行"的限制
- 括号 `()`/`[]`/`{}` 未闭合时跨行是**结构上安全**的（函数调用参数、下标、表达式分组天然粘合）

> ⚠️ **警告：行首运算符会被并入上一行**。因为换行≡空格，`返回 a` 换行 `- b` 实际解析为 `返回 a - b`（与 C 语言行首续行效果相同但无文档说明）。建议跨行书写长表达式时把二元运算符留在**行尾**（`a +` 换行 `b`）而非行首，避免歧义。

### 规则3：单行多语句（显式分号支持）

- 显式 `;` 分隔多条语句是**稳定支持**的：`变量 i = 0; ++i; --i;` 合法
- 无分号依赖关键字边界是**偶然可行但未定义**，规范建议统一使用分号表达单行多语句

### 规则4：空语句与空循环体（裸分号非法）

- 裸 `;` 作为空语句**不合法**（报"预期表达式"），CN 语言没有空语句
- 连续分号 `;;` 会报错
- `当(x);` 是**语法错误**（循环体强制要求 `{`），合法空循环体写 `当(x) { }`（空块合法）
- 循环头 `循环(整32 j = 0; j < 10; j++)` 中的分号是**唯一强制分号**（三段分隔符，缺了报错）

### 示例代码

```
变量 a = 1;        // 分号可选（C 习惯）
变量 b = 2         // 无分号合法
变量 x = 1 整32 y = 2   // 合法：整32 触发新声明 y

变量 i = 0; ++i; --i;    // 单行多语句：显式分号分隔（稳定支持）

// 推荐：跨行书写长表达式时二元运算符留在行尾
变量 总和 = a +
           b +
           c

当(x) { }        // 合法：空循环体（空块）
// 当(x);        // ❌ 语法错误：循环体强制要求 {
// ;             // ❌ 错误：空语句非法（预期表达式）
// ;;            // ❌ 错误：连续分号

循环(整32 j = 0; j < 10; j++) {   // 分号是唯一强制分号（三段分隔符）
    打印行(j)
}
```

### 设计决策

- **换行无语法意义**：词法层将换行当作空白跳过，不产生换行 token，彻底纠正"以回车结尾"的误解。语句边界完全由语法层的关键字识别（见[01a-词法结构-总览与关键字.md](01a-词法结构-总览与关键字.md) 第三节）。
- **分号可选**：为兼容 C 习惯保留分号写法，但语法上不强制。循环头分号是**唯一强制分号**（三段分隔符）。
- **单行多语句建议用分号**：无分号依赖关键字边界是偶然可行但未定义，规范建议统一使用分号。

## 一、变量声明（类型前置）

### EBNF

```
变量声明 = "变量", 标识符, "=", 表达式                // 类型推断
          | 类型, 标识符, "=", 表达式                // 显式类型
          | "常量", 标识符, "=", 表达式              // 常量
          | "静态", 类型, 标识符, "=", 表达式        // 静态变量
```

### 示例代码

```
变量 x = 10              // 类型推断（推断为整数/整32）
整数 y = 20              // 显式类型（默认类型别名）
整32 z = 30              // 位宽类型
常量 PI = 3.14           // 常量（不可修改）
静态 整32 计数 = 0       // 静态变量（生命周期贯穿整个程序）
```

### 设计决策

- **类型前置**：类型写在变量名之前（`类型 变量名`），与C/C++一致，区别于Rust的后置类型标注（`变量名: 类型`）。
- `变量` 关键字用于类型推断场景，显式类型场景直接写类型名。
- 常量使用 `常量` 关键字声明，初始化后不可修改。

## 二、函数定义

### EBNF

```
函数定义 = "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
参数列表 = [参数, {",", 参数}]
参数 = 类型, 标识符
返回类型 = 类型 | "空类型"
函数体 = "{", 语句*, "}"
```

### 示例代码

```
函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b
}

// 无返回值时省略 -> 类型
函数 打印问候() {
    打印行("你好")
}

// 函数原型声明（前向引用）
函数 计算(整32 n) -> 整32
```

### 设计决策

- 无返回值函数省略 `-> 类型`，即 `-> 空类型` 可省略。
- 函数原型声明（前向引用）支持两个文件/同文件内的前向调用（见[04-函数与函数指针.md](04-函数与函数指针.md)）。

## 三、控制流

### 3.1 条件语句（如果/否则如果/否则）

#### EBNF

```
条件语句 = "如果", "(", 条件表达式, ")", 代码块
          ["否则 如果", "(", 条件表达式, ")", 代码块]*
          ["否则", 代码块]
条件表达式 = 表达式（结果为布尔）
代码块 = "{", 语句*, "}"
```

#### 示例代码

```
如果 x > 0 {
    打印行("正数")
} 否则 如果 x < 0 {
    打印行("负数")
} 否则 {
    打印行("零")
}
```

### 3.2 当循环（while风格）

#### EBNF

```
当循环 = "当", "(", 条件表达式, ")", 代码块
```

#### 示例代码

```
整数 i = 0
当 i < 10 {
    打印行(i)
    i++
}
```

### 3.3 循环（for风格）

#### EBNF

```
循环语句 = "循环", "(", 初始化表达式, ";", 条件表达式, ";", 更新表达式, ")", 代码块
```

#### 示例代码

```
循环 (整32 j = 0; j < 10; j++) {
    打印行(j)
}
```

### 3.4 选择语句（switch风格）

#### EBNF

```
选择语句 = "选择", "(", 表达式, ")", "{", 分支列表, "}"
分支 = "情况", 常量表达式, ":", 语句* | "默认", ":", 语句*
```

#### 示例代码

```
选择(值) {
    情况 1:
        打印行("一")
        中断
    情况 2:
        打印行("二")
        中断
    默认:
        打印行("其他")
}
```

### 3.5 中断与继续

#### EBNF

```
中断语句 = "中断"
继续语句 = "继续"
```

#### 示例代码

```
循环 (整32 k = 0; k < 100; k++) {
    如果 k % 2 == 0 {
        继续          // 跳过偶数
    }
    如果 k > 50 {
        中断          // 超过50跳出循环
    }
    打印行(k)
}
```

### 设计决策

- 选择语句中的分支需显式 `中断` 跳出，**无fall-through**（与C++的switch不同，C++需要break，但CN要求每个分支显式中断或返回）。
- `选择`/`情况`/`默认`/`中断` 替代Rust风格的 `匹配`/`跳出`（见[SKILL.md](../SKILL.md)差异表）。
- 密集选择语句在优化阶段生成跳转表（见编译器架构-优化器）。
