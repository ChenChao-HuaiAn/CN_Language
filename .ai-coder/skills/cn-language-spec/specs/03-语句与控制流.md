## 一、变量声明（类型前置）

### EBNF

```
变量声明 = "变量", 标识符, "=", 表达式                // 类型推断
          | 类型, 标识符, "=", 表达式                // 显式类型
          | "常量", 标识符, "=", 表达式              // 常量
          | "静态", 类型, 标识符, "=", 表达式        // 静态变量
```

### 示例代码

```
变量 x = 10              // 类型推断（推断为整数/整32）
整数 y = 20              // 显式类型（默认类型别名）
整32 z = 30              // 位宽类型
常量 PI = 3.14           // 常量（不可修改）
静态 整32 计数 = 0       // 静态变量（生命周期贯穿整个程序）
```

### 设计决策

- **类型前置**：类型写在变量名之前（`类型 变量名`），与C/C++一致，区别于Rust的后置类型标注（`变量名: 类型`）。
- `变量` 关键字用于类型推断场景，显式类型场景直接写类型名。
- 常量使用 `常量` 关键字声明，初始化后不可修改。

## 二、函数定义

### EBNF

```
函数定义 = "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
参数列表 = [参数, {",", 参数}]
参数 = 类型, 标识符
返回类型 = 类型 | "空类型"
函数体 = "{", 语句*, "}"
```

### 示例代码

```
函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b
}

// 无返回值时省略 -> 类型
函数 打印问候() {
    打印行("你好")
}

// 函数原型声明（前向引用）
函数 计算(整32 n) -> 整32
```

### 设计决策

- 无返回值函数省略 `-> 类型`，即 `-> 空类型` 可省略。
- 函数原型声明（前向引用）支持两个文件/同文件内的前向调用（见[04-函数与函数指针.md](04-函数与函数指针.md)）。

## 三、控制流

### 3.1 条件语句（如果/否则如果/否则）

#### EBNF

```
条件语句 = "如果", "(", 条件表达式, ")", 代码块
          ["否则 如果", "(", 条件表达式, ")", 代码块]*
          ["否则", 代码块]
条件表达式 = 表达式（结果为布尔）
代码块 = "{", 语句*, "}"
```

#### 示例代码

```
如果 x > 0 {
    打印行("正数")
} 否则 如果 x < 0 {
    打印行("负数")
} 否则 {
    打印行("零")
}
```

### 3.2 当循环（while风格）

#### EBNF

```
当循环 = "当", "(", 条件表达式, ")", 代码块
```

#### 示例代码

```
整数 i = 0
当 i < 10 {
    打印行(i)
    i++
}
```

### 3.3 循环（for风格）

#### EBNF

```
循环语句 = "循环", "(", 初始化表达式, ";", 条件表达式, ";", 更新表达式, ")", 代码块
```

#### 示例代码

```
循环 (整32 j = 0; j < 10; j++) {
    打印行(j)
}
```

### 3.4 选择语句（switch风格）

#### EBNF

```
选择语句 = "选择", "(", 表达式, ")", "{", 分支列表, "}"
分支 = "情况", 常量表达式, ":", 语句* | "默认", ":", 语句*
```

#### 示例代码

```
选择(值) {
    情况 1:
        打印行("一")
        中断
    情况 2:
        打印行("二")
        中断
    默认:
        打印行("其他")
}
```

### 3.5 中断与继续

#### EBNF

```
中断语句 = "中断"
继续语句 = "继续"
```

#### 示例代码

```
循环 (整32 k = 0; k < 100; k++) {
    如果 k % 2 == 0 {
        继续          // 跳过偶数
    }
    如果 k > 50 {
        中断          // 超过50跳出循环
    }
    打印行(k)
}
```

### 设计决策

- 选择语句中的分支需显式 `中断` 跳出，**无fall-through**（与C++的switch不同，C++需要break，但CN要求每个分支显式中断或返回）。
- `选择`/`情况`/`默认`/`中断` 替代Rust风格的 `匹配`/`跳出`（见[SKILL.md](../SKILL.md)差异表）。
- 密集选择语句在优化阶段生成跳转表（见编译器架构-优化器）。
