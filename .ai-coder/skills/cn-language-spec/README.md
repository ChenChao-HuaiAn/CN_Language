# cn-language-spec 技能使用说明

> CN语言语法规范查询与引用技能（C++风格版 v2.0）
> 版本：v2.0 | 日期：2026-08-15 | 基准：[plans/001 CN语言编译器设计规格书.md](../../plans/001%20CN语言编译器设计规格书.md)

## 技能简介

`cn-language-spec` 是CN语言编译器项目的语法规范查询与引用技能，基于 **C++风格** 的中文编程语言设计（参考C++编程范式）。提供以下能力：

- **规范查询**：根据关键字、章节编号或语法类别快速定位语法规则
- **EBNF检索**：提取和展示特定语法结构的EBNF定义
- **跨文档引用**：在不同规范文档间建立引用关系
- **规范验证**：检查代码片段是否符合CN语言语法规范
- **语法对比**：对比CN语言与其他系统编程语言的语法差异
- **设计决策追溯**：查询特定语法设计决策的原因和替代方案

> ⚠️ 本技能为 **C++风格版**，与旧版Rust风格（让/可变/匹配/所有权等）语法完全不同，禁止混用。

## 使用方法

### 1. 触发条件

当需要以下内容时使用本技能：

- 查询CN语言特定语法规则（关键字/类型/OOP等）
- 验证代码是否符合CN语言语法规范
- 编写任何与CN语言有关的文件（第一选择）
- 对比CN语言与其他语言的语法差异
- 确认语法特性的设计决策和理由

### 2. 查询工作流

```
Step 1: 识别查询类型（语法规则/EBNF/设计决策/代码验证/语法对比）
Step 2: 定位规范文档（关键词映射到文档编号）
Step 3: 读取对应文档章节并提取内容
Step 4: 按引用格式输出
```

引用格式：

```
[规范编号]-[章节名]（[文件名]，第X节）
```

示例：`[06]-虚函数（06-OOP面向对象.md，第四节）`

### 3. 输出模板

- **规范查询** → 使用 [spec-query.md](templates/spec-query.md)
- **语法对比** → 使用 [spec-compare.md](templates/spec-compare.md)
- **模块摘要** → 使用 [spec-summary.md](templates/spec-summary.md)

## 配置说明

配置文件位于 `config/default.config.json`，由 `config/schema.json` 验证：

| 配置项 | 说明 |
|--------|------|
| `specRoot` | 规范文档根目录（`specs/`） |
| `specVersion` | 规范版本（`C++风格版v2.0`） |
| `queryTemplates` | 查询/对比/摘要模板路径 |
| `crossReferenceEnabled` | 是否启用跨文档引用 |
| `ebnfExtractionEnabled` | 是否启用EBNF提取 |
| `designDecisionTracing` | 是否启用设计决策追溯 |
| `specDocumentIndex` | 文档编号→文件名索引 |
| `keywordMapping` | 关键词→文档编号映射 |

## 与旧版（Rust风格）的关键差异

| 维度 | 旧版(Rust风格) | 新版(C++风格 v2.0) |
|------|---------------|---------------|
| 关键字 | 54个(让/可变/匹配/跳出/特征/泛型/所有权...) | 61个(变量/常量/选择/情况/默认/类/接口/继承/友元/泛型/自动/常量/模块/作为/包/货舱...) |
| 内存管理 | 所有权+借用+生命周期 | 指针+手动内存管理 |
| OOP | 无(结构+特征) | 完整OOP(类/接口/继承/虚拟/重写) |
| 错误处理 | 结果+?运算符 | 结果+可选(错误码，无?运算符) |
| 控制流 | 匹配/跳出 | 选择/情况/默认/中断 |
| 模块路径 | :: 分隔 | :: 分隔（v2.0 与 Rust 一致） |
| 可见性 | 逐项修饰(公开 函数) | 标签式(公开:/私有:) + **默认私有**（v2.0） |
| 导入语法 | 使用(use) | 导入 + 作为/花括号/通配符（v2.0，删除 `从`） |
| 函数指针 | 无 | 有(C风格) |
