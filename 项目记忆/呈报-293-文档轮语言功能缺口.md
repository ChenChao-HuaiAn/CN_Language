# 293 轮呈报：官方文档全量补齐中实测发现的语言功能缺口与疑似缺陷

> 依据用户令（293 轮进行中批注）：文档写作/示例实测中发现的功能缺失与缺陷，
> 记入本文档，任务完成后统一呈报裁决。每条附实测证据与建议方案。
> 状态标记：〔缺陷〕=实现与 001/预期不符；〔缺口〕=功能缺失（001 未立法或立法未实施）；
> 〔易用性〕=非缺陷但伤新手体验的设计面。

## 一、疑似编译器缺陷（建议立案归因）

### 1.〔缺陷〕浮点默认参数 + 浮点转换 → 汇编失败 A2050
- **复现**：`函数 幂底(浮64 底, 浮64 指数 = 2.0) -> 浮64 { 循环 (整32 i = 0; i < 整32(指数); i++) {...} }`
  → ml64 报 `error A2050: real or BCD number not allowed`（汇编 266 行处）。
- **最小化**：未做（默认参数本身与 浮→整 转换两个因素叠加，需二分）。
- **影响面**：浮点默认参数的函数在 win-x64 目标无法编译（本次文档示例被迫改整型演示）。
- **建议**：立案最小化归因（嫌疑=默认参数实参展开位浮点常量发射或 浮64→整32 转换发射）。

### 2.〔缺陷〕运算符 `()` 调用重载解析失败
- **复现**：`函数 运算符()(整64 x) -> 整64 { 返回 x * 10; }`（类体内）→ 解析崩
  （「预期顶层声明，实际为 '}'」——类体解析中断）。
- **对照**：001 §4.6 运算符重载集合明列 `()` 可重载。
- **影响面**：可重载集合与实现不一致（`[]` 未测，`+`/`==`/一元`-` 实测可用）。
- **建议**：立案；或 001 收窄可重载集合（移除 `()`/`[]`）与实现对齐——二选一呈裁决。

## 二、功能缺口（建议立项评估）

### 3.〔缺口〕`类型大小` 不接受变量（仅类型名）
- **复现**：`整32[8] 表; 类型大小(表)` → 「未声明类型 '表'」。
- **对照**：C++ `sizeof(表达式)` 对变量/表达式可用。
- **建议**：P3 易用性——`类型大小(表达式)` 按表达式类型求值（编译期，无运行时成本）。

### 4.〔易用性〕`打印(字符)` 输出码点数字而非字符
- **复现**：`字符 等级 = '甲'; 打印(等级);` → `30002`（码点数值）。
- **对照**：直觉期望输出字符形态 `甲`（打印 变参对 字符 按码点转 UTF-8 输出）。
- **现状绕道**：`打印(字符转字符串(等级))`。
- **建议**：打印 变参对 字符 类型改按 UTF-8 编码输出（或加 `打印字符` 内置）——呈裁决。

### 5.〔易用性〕泛型函数调用无实参推导，必须显式 `<类型>`
- **复现**：`交换泛型(甲, 乙)` → 「未找到匹配的函数」；必须 `交换泛型<整32>(甲, 乙)`。
- **对照**：Rust/Haskell/Swift 均从实参推导；C++ 模板亦推导。
- **影响面**：每个泛型调用点多写 `<类型>`，且是新手高频卡点（文档三处示例被迫显式标注）。
- **建议**：P2——语义层对泛型自由函数补「实参推导」（优先精确匹配显式形态，
  无显式时按实参类型唯一解推导，多义拒绝）。属语言易用性立法，须用户裁决。

### 6.〔易用性〕结果守卫不识别 `&&` 复合条件与「非正分支提前返回」形态
- **复现**：①`如果 (a.正常 && b.正常) { 用 a.值; }` 拒；②`如果 (!x.正常) { 返回 err; }`
  之后 `用 x.值` 也拒（提前返回语义等价于守卫，但检查器不认）。
- **影响面**：②是高频惯用形态（Rust let-else 同款），当前必须改写成
  「如果 (正常){...} 否则 {...}」嵌套——文档示例三处被迫如此。
- **建议**：P2——守卫数据流补两规则：`&&` 双守卫/提前返回（返回终结分支取反守卫）。
  属检查器增强（非语义变化），风险面=守卫跟踪精度，建议单独任务。

### 7.〔缺口〕`遍历` 无下标形态（无 enumerate）
- **复现**：需要「第 i 个元素」时只能退回 `循环 (整64 i = 0; ...)` + 下标访问。
- **建议**：P3——`遍历 表 中 每个 (i, x)` 或 `遍历 表 中 每个 x 对 i` 语法立法（后者
  `对` 已是上下文关键字）。低优先。

### 8.〔观察·非缺陷〕类赋值双语义需文档显式区分（已写入文档）
- 实测：传参/返回=句柄（写穿同一对象）；`b = a` 声明初始化=拷贝构造
  （无拷贝构造=逐字段浅拷、对象独立；有=按拷贝构造语义）。两者正交并存，
  新手最易混——已写入 <a>oop 参考·句柄模型</a> 与教程。此处留档呈报知悉。
