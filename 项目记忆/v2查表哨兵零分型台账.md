**消费点等价映射总口径**（复刻 #1541 纪律）：
- 谓词 `!= 0` ⇔ `.有值`（返回值域=键基ID/名称ID/类型ID 恒>0，0 不是合法值——
  与 1541 查结构体大小「0=合法空结构体」场景不同，无 `.有值` 顶替语义风险）；
- `== 0` ⇔ `!.有值`；
- 取值型 `整64 k = 查(...); 如果 (k > 0/!= 0)` → `可选<整64> k查 = 查(...);`
  `如果 (k查.有值) { 整64 k = k查.值; ... }`（无值=原 miss 分支契约不变）；
- 实参直传 → 拆局部（miss 传 0·下游 `>0/==0` 门契约不变，下游 0 判据属既有冻结面）；
- 条件侧禁「.有值+取值」复合形态（宿主短路缺陷·1541 教训）——取值一律拆局部。
