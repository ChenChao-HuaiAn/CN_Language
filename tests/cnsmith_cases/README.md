## 行为级对拍常态轨（#1130）

CN-Smith 四轨道入口=`scripts/cnsmith_run.py`（随机/负向/矩阵/对拍）。第四轨「对拍」
自 #1130 起为**独立可复用实现**（`scripts/cnsmith_dual.py`）：同一份 CN 源码分别用宿主
编译器与 v2p 编译运行，逐行比对 stdout+退出码（stderr 按需），差异=分叉候选，报告给出
「建议立案标题」清单（**不自动写服务端台账**）。

- 单轨：`python scripts/cnsmith_run.py --轨道 对拍`（`--track` 同义别名）
- 周采样推荐：`--对拍样本 24 --对拍矩阵 16 --对拍内置 5 --对拍预算秒 1800`
- 目录批量：`--对拍目录 tests/e2e/<用例>[,<目录>…]`（含 主.cn 或 `v2闭环.txt`/
  `双编译对照.txt` 的目录=一个多文件样本，自动读取配置的源文件/退出码/借链/供给/
  负测/诊断锚；纯 v2 用例宿主侧不支持时显式跳过——**不生成假分叉**；否则每个顶层
  .cn 各为一个样本）
- 报告：`target/cnsmith_runs/<轮次>/对拍/差异报告.{json,md}`（源码路径/两侧输出/首差异
  行/退出码/判定+原因闭集/建议立案）；预算耗尽或配置不对齐样本显式计「跳过」，
  **跳过>0 时轨道状态=无效（exit 2）——无结果不算过，禁当绿**。
- **新特性轮强制**：任何语义/语法/内建符号/代码生成改动，集成前必须跑一轮对拍
  （新特性相关 E2E 用例目录以 `--对拍目录` 一并纳入）；发现分叉先立案或当场修复。
- 自校验：`python scripts/cnsmith_dual.py --selftest`（判定层正/反例+轨道级跳过
  无效断言+报告结构；`--selftest --实跑` 附加端到端真跑）。
