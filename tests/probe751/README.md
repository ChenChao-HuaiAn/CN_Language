# #751 证据探针（可复跑·非 E2E 用例·不参与门禁）

本目录保存 #751（JSON 解析侧接子 O(1) + API 硬化 + 模块拆分）的验收证据探针，
供独立复核复跑。不属 `tests/e2e/` 用例目录，不占用例号、不进覆盖矩阵。

## 复跑

```bash
python tests/probe751/对拍751.py          # 负例 20 + 泄漏 4×2000 对拍
python tests/probe751/对拍751.py --perf   # 追加性能四负载（当前侧 3 轮）
```

前置：宿主编译器已构建（`target/cn` 或 `target/cn.exe`）；`git` 可用（基线还原）。

## 最近一次结果（2026-10-22· #751 返工）

- 负例 20 例：原始基线 vs 拆分+硬化版 stdout **逐字节零差异**。
- 泄漏 4 形态×2000 轮：两侧回落差均 **0**、失败码均 0。
- 性能（最终态 A/B·同机交替 3 runs×3 轮中位·原始 3893cdd3a vs 本版）：
  8192 数字 194→50ms（约 3.9×）；32768 数字 3095→745ms（约 4.1×）；
  8192 短串 203→58ms（约 3.5×）；286729B 长串 2704→2545ms（约 1.06×，
  剩余主成本=编译器字符串下标 `__cn_str_len(strlen)`·已立项 #1310）。
  文档长度 16393/32777/286729/65545B（32768 数字口径修正）。
