# 1472（#1415 P2-1/P2-4）：主返回结果 wrapper「返回前释放」锚定——
# 全文 __cn_str_free 符号调用 = 打印临时 5 + 返回前 3（局部串 1 + 字符串数组元素 2）。
# 修复前 = 5（仅打印临时；返回后局部资源无人释放）→ 阈值 8 使回退必红。
# 断言用**助记符无关**裸符号（win `call` / arm64 `bl` / x86_64 `call` 均命中；
#   原 `call __cn_str_free` 在 arm64 计数 0=平台轮转假红）。
# 实测：win v2=8/host=8；arm64 v2=8×bl/host=9×bl；x86_64 v2=8/host=9 → 阈值 8 三平台过。
