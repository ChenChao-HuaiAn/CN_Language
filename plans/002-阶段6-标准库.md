## 阶段六：标准库

> 目标：核心标准库（集合/IO/文件系统）、字符串处理与格式化、数学库与128位辅助、构建系统集成、测试框架完善。里程碑：可开发命令行工具（规格书阶段五）。

### Task 6.1: 核心库
**文件：**
- Create: `stdlib/核心.cn`（列表/字典/集合，规格书阶段五）
- Create: `tests/e2e/20_stdlib/核心库.cn` + `核心库.expected`

### Task 6.2: IO库（含输入）
**文件：**
- Create: `stdlib/IO.cn`（标准输出/标准错误/文件读写）
- Modify: `src/runtime/io_api.cpp`（新增 `读取行`/`读取整数`/`读取浮点` 运行时函数：`__cn_read_line`/`__cn_read_int`/`__cn_read_float`，规格书 10.6）
- Modify: `src/cn_compiler/semantic/semantic.cpp`（registerBuiltins 注册输入 API）
- Create: `tests/e2e/21_io/IO库.cn` + `IO库.expected`

**验证标准：** `打印`/`打印行`/`格式化` 输出；`读取行()` 从标准输入读一行（不含换行）；`读取整数()`/`读取浮点()` 读数值；文件读写（打开/读取/写入/关闭）。

### Task 6.3: 数学库
**文件：**
- Create: `stdlib/数学.cn`（浮点运算辅助/128位整数运算辅助/常用数学函数，规格书10.5）
- Modify: `src/runtime/math_api.cpp`（`__cn_mul_i128`、`__cn_div_i128`、`__cn_div_u128` 等 + `数学.平方根`/`数学.幂`/`数学.正弦`/`数学.余弦`/`数学.正切`/`数学.绝对值`/`数学.向上取整`/`数学.向下取整` 运行时封装，对应 `__cn_sqrt/pow/sin/cos/tan/fabs/ceil/floor`）
- Modify: `src/cn_compiler/semantic/semantic.cpp`（registerBuiltins 注册数学 API）
- Create: `tests/unit/runtime/test_math_api.cpp`

**验证标准：** 128 位整数运算辅助正确；`数学.平方根(16.0) == 4.0`、`数学.幂(2, 10) == 1024`、`数学.绝对值(-5) == 5`、三角函数精度达标。

### Task 6.4: 集合库
**文件：**
- Create: `stdlib/集合.cn`（表.包含(键)等标准函数，规格书4.4说明）
- Create: `tests/e2e/22_collections/集合库.cn` + `集合库.expected`

### Task 6.5: 字符串处理库（含格式化）
**文件：**
- Create: `stdlib/字符串.cn`（长度/比较/连接/复制/查找/格式化）
- Modify: `src/runtime/string_api.cpp`（`格式化()` 运行时 `__cn_format`：sprintf 风格 `%d/%u/%f/%s/%c/%x/%X/%o/%p` 占位符，变参 ABI 展开；`字符串从布尔` `__cn_str_from_bool`）——如已在 Task 2.9 实现则此处仅提供 `stdlib/字符串.cn` 包装
- Create: `tests/e2e/23_strings/字符串库.cn` + `字符串库.expected`

**验证标准：** `格式化("值%d 浮点%f", 42, 3.14)` 正确；`字符串从布尔(真)` 返回 `"真"`；格式化返回字符串由调用方释放。
