## 一、家机 win-x64 节（本机维护）

### 1.1 本轮（**229-a**，基线 d423a07）：**F1-30-ASan 三项之①——AddressSanitizer 构建接入 + 内存错误检出**

> 任务依据=plans/021 §3-F **F1-30**（「三项均未做…优先=**ASan 类运行时检测**（安全线收益）」·plans/021 优先级建议③）；
> 参照 plans/004 C-3「泄漏检测手段（ASan 集成/分配计数跟踪）❌ 无」与 plans/003 B-8「无内存泄漏检测手段——
> 容器/字符串手写内存管理下的泄漏难以发现」。**避让**：深度机 227-a（A7 本体·v2 编译器）、单位机
> （mem2reg/D8/F2-33 候选）——写集=`CMakeLists.txt` + 构建/验证流程，与两者**零交叠**。
> 准绳=**性能第一、安全第二**（ASan 仅开发期可选构建，**发布构建零影响**）。

**1. 目标与验收判据**

- 目标：① 宿主（C++ 编译器）接入 **AddressSanitizer 可选构建**（`cmake -DCN_ENABLE_ASAN=ON`）；
  ② **用 ASan 构建跑单测 + 关键 E2E**，检出宿主/单测的内存错误（泄漏/越界/UAF）；
  ③ **发现的缺陷按「缺陷零容忍」当场根治**（无则作为基线记录）。
- 验收判据：① ASan 构建**零警告**通过（`/W4 /WX` 保持）；② ASan 下**单测全过** + 关键 E2E 通过；
  ③ 检出结果**逐项报告**（有错→根治+反证；无错→留档基线 + 说明覆盖面）；④ **默认（非 ASan）构建产物零变化**
  （锚定链逐字节不变）。

**2. 写集（精确文件清单）**

- `CMakeLists.txt`（新增 `CN_ENABLE_ASAN` 选项块：MSVC `/fsanitize=address` + 移除 `/RTC1` 冲突；GCC `-fsanitize=address`）
- （如需）`scripts/` 新增 ASan 门禁脚本；`target/build-asan/`（构建产物·gitignore）
- 文档：`plans/021`（§3-F F1-30 行 + 戳）、本节、`更新日志.md`、`HANDOFF.md`、`lessons.md`、`三机任务看板.md`

**3. 实施步骤**

1. **CMake 接入**：`option(CN_ENABLE_ASAN ...)` + 平台分支（MSVC `/fsanitize=address`·需 `string(REPLACE "/RTC1" ...)` 处理 Debug 运行时检查冲突·`/INCREMENTAL:NO`；GCC `-fsanitize=address -fno-omit-frame-pointer`）。
2. **独立构建目录**（`target/build-asan`——不污染主构建）→ **零警告构建**。
3. **跑 ASan 版单测**（`cn_unit_tests.exe`）→ **记录 ASan 报告**（泄漏/越界/UAF 逐项）。
4. **跑关键 E2E**（ASan 版 cn.exe 编译/运行典型用例）→ 记录。
5. **缺陷处置**：发现的内存错误**当场根治**（含反证）；无错则留档（含覆盖面说明=单测+E2E 用例数）。
6. **验证默认构建零影响**（主构建重建 → 锚定链逐字节不变）。

**4. 验证链（命令级）**

`cmake -S . -B target/build-asan -DCN_ENABLE_ASAN=ON` → `cmake --build target/build-asan --config Debug`（零警告）→
`target/build-asan/Debug/cn_unit_tests.exe`（ASan 报告）→ ASan 版 `cn.exe` 跑典型 E2E → 主构建重建 + 锚定链核对。

**5. 边缘情况与诚实边界（开工预判 → 收工回填）**

- 预判：① MSVC ASan 与 `/RTC1` 冲突（Debug 默认）→ 须显式移除；② MSVC ASan 需要运行时 DLL
  （`clang_rt.asan_dynamic-x86_64.dll`，VS 17.4+ 自带）；③ ASan 与 `/WX` 的**新警告**（如 C4996）可能拦截 → 逐项评估；
  ④ ASan 检出**只在被执行的路径**（单测+E2E 覆盖面=检出面）；⑤ **性能**：ASan 构建仅检测用（发布构建不变）。
- 收工回填：见节末。

**6. 与他机交叠分析**

- 深度机 227-a（A7 本体·`CN语言编译器v2/**` + stdlib）：**零交叠** ✓（本轮只改根 `CMakeLists.txt` + 构建流程）
- 单位机（mem2reg `opt/ssa.cpp` / D8 arm64 / F2-33 stdlib）：**零交叠** ✓
- 契约面：**默认构建产物零变化** → 他机无需复跑；ASan 为**开发期可选**构建 ✓
