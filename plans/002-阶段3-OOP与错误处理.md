## 阶段三：OOP与错误处理

> 目标：类/继承/虚函数/接口/访问控制/错误处理（结果/可选）/模块系统。里程碑：可编写中型面向对象程序（规格书阶段三）。

### Task 3.1: 类与继承
**文件：**
- Modify: `src/cn_compiler/parser/parser.cpp`（`类 名 [: 父类] { 公开:/保护:/私有: ... }`，规格书5.6）
- Modify: `src/cn_compiler/semantic/semantic.cpp`（类符号表、成员作用域、继承关系解析、构造/析构函数识别 `函数 类名()` / `函数 ~类名()`）
- Modify: `src/cn_compiler/ir/ir_generator.cpp`（新建对象/删除对象、字段访问经this指针）
- Modify: `src/cn_compiler/codegen/x64/x64_codegen.cpp`（类实例布局 `[vtable指针|父类成员|自身成员]`，规格书8.6）
- Create: `tests/unit/semantic/test_class.cpp`
- Create: `tests/e2e/08_oop_class/类继承.cn` + `类继承.expected`

**验证标准：** 类定义/实例化/字段/方法调用；单继承（成员继承、父类构造调用）；构造/析构函数生命周期；`自身` 与 `父类` 关键字（规格书5.6示例）。

### Task 3.2: 虚函数与多态
**文件：**
- Modify: `src/cn_compiler/semantic/semantic.cpp`（虚拟函数表索引分配、重写覆盖检查）
- Modify: `src/cn_compiler/ir/ir_generator.cpp`（虚调用指令：经vtable间接跳转）
- Modify: `src/cn_compiler/codegen/x64/x64_codegen.cpp`（vtable生成：函数指针数组放入.rdata）
- Create: `tests/unit/ir/test_vtable.cpp`
- Create: `tests/e2e/09_oop_virtual/虚函数.cn` + `虚函数.expected`

**验证标准：** `虚拟 函数` 声明；`重写 函数` 覆盖；父类指针调用子类实现（动态分派）；`父类.方法()` 显式调用父类实现。

### Task 3.3: 接口与实现
**文件：**
- Modify: `src/cn_compiler/parser/parser.cpp`（`接口 名 { 虚拟 函数 ... }`、`类 名 : 接口`）
- Modify: `src/cn_compiler/semantic/semantic.cpp`（接口实现验证：实现类必须实现全部接口方法；附加vtable预留）
- Create: `tests/unit/semantic/test_interface.cpp`
- Create: `tests/e2e/10_oop_interface/接口.cn` + `接口.expected`

**验证标准：** 接口定义（只有虚拟函数签名无实现）；类实现接口（`类 圆形 : 可绘制`）；通过接口类型调用实现方法。

### Task 3.4: 访问控制
**文件：**
- Modify: `src/cn_compiler/semantic/semantic.cpp`（公开/保护/私有可见性检查：私有仅类内、保护类内与子类、公开任意）
- Create: `tests/unit/semantic/test_access.cpp`

**验证标准：** 类外访问私有成员报错误；子类可访问保护成员；`公开:`/`私有:` 标签式可见性（模块级，规格书5.9）。

### Task 3.5: 错误处理（结果/可选类型）
**文件：**
- Modify: `src/cn_compiler/parser/parser.cpp`（`结果<T,E>` / `可选<T>` 类型语法）
- Modify: `src/cn_compiler/semantic/semantic.cpp`（强制检查规则3条：未检查丢弃报错、检查后未处理错误分支报警告、访问.值前必须检查.有值，规格书5.4）
- Modify: `src/cn_compiler/ir/ir_generator.cpp`（结果/可选降级为结构体+联合体，规格书7.6；结果构造/结果检查/可选构造/可选检查指令）
- Create: `tests/unit/semantic/test_error_handling.cpp`
- Create: `tests/e2e/11_error/错误处理.cn` + `错误处理.expected`

**验证标准：** `结果<整32, 整32>` 返回与检查（`.正常`/`.值`/`.错误`）；内置构造器 `正常()`/`错误()`/`某些()`（规格书5.4）；`可选<T>` 的 `.有值` 检查；3条强制检查规则的正反用例。

### Task 3.6: 模块系统
**文件：**
- Modify: `src/cn_compiler/parser/parser.cpp`（`导入 数学.平方根`、`从 数学 导入 正弦, 余弦`，规格书5.9）
- Modify: `src/cn_compiler/semantic/semantic.cpp`（模块路径解析 `.` 分隔、公开/私有可见性标签、入口 `主.cn`）
- Modify: `src/cn_main.cpp`（多文件编译：模块依赖拓扑排序）
- Create: `tests/unit/semantic/test_module.cpp`
- Create: `tests/e2e/12_module/主.cn` + `数学.cn` + `主.expected`

**验证标准：** 多文件模块编译；`导入`/`从...导入` 语法；`公开:` 符号跨模块可见、`私有:` 不可见；`主.cn` 为入口。
