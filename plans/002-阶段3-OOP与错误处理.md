### 3条强制检查规则实现（错误码传播分析）

- **规则1**：`visitExprStmt` 中 CallExpr 返回 结果<T,E> 且未赋值 → 错误"被丢弃未检查"
- **规则2**：`trackIfCheck` 检测 如果(结果.正常) 无 else → 警告"未处理错误分支"
- **规则3**：`checkResultMember` 在访问 .值/.错误 时查 `errorCheckState_` 变量检查状态（if 真分支标记"正常/有值"、否则分支标记"错误"），未检查 → 错误

### vtable 生成与虚调用展开策略

- **vtable 生成**（x64_codegen_vtable.cpp）：`.rdata` 段 `?vtable_类名 dq 函数指针, ...`；槽位顺序 == `ClassInfo.vtableOrder`；重写方法经 `methods[方法名].ownerClass` 取子类实现符号覆盖槽位；继承虚方法防御性取类名符号
- **虚调用展开**（x64_codegen_oop.cpp）：`mov rcx, 对象`（this）→ `mov rax, [rax]`（对象首地址取虚表指针）→ `mov rax, [rax+槽位*8]`（按 classVtableIndex 槽位偏移取函数指针）→ 装载实参 → `call rax`（间接调用）

### 成员方法 this 参数位处理（Win x64 ABI）

- VirtualCall：operand[0] = 对象指针（this），实参从 operand[1] 起；**this 占第 0 参数位（rcx）**，实参从参数位 1 起（rdx/r8/r9/xmm1-3），与隐藏返回指针共存时 paramOffset 逻辑一致（this 后移覆盖）
- 浮点实参按参数位 xmmN + movq 位模式复制到同参数位 GPR（变参 va_arg 兼容）
- i32 实参 mov eax + movsxd 符号扩展；u32 零扩展；指针常量 lea 取地址

### 静态字段 .data 分配策略

- `.data` 段 `?static_类名_字段名 dq 0`（8 字节槽）；i128 双槽 `dq 0, 0`；浮32 `dd 0`
- 全类共享：字段值经符号直接读写（LoadPtr/StorePtr 路径由 IR 层生成）
