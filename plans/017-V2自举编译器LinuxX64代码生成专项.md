## 三、v2 IR 位号 → SysV 寄存器映射（关键设计）

v2 IR 位号约定（共用层注释权威）：**retbuf=0（仅结构体返回调用）、this=1（方法调用）、
实参从 2 起**。SysV 整型参数寄存器序：**rdi, rsi, rdx, rcx, r8, r9**（6 个）。

| IR 位号 | SysV 寄存器 | 说明 |
|---|---|---|
| 位 0 retbuf | **rdi** | 恰为 SysV 隐藏返回指针位——形态A契约「operands[0] 原样传递自然落 rdi」，与宿主 linux_x64 完全一致 |
| 位 1 this | rsi | |
| 位 2~5 实参 | rdx, rcx, r8, r9 | 寄存器实参共 4 个 |
| 位 6+ 实参 | 调用方 `[rsp+8k]` / 被调方 `[rbp+16+8k]` | 无影子空间（锚定基 16，同 arm64） |

- 普通函数调用（无 retbuf/this）：实参自位 0 起 → rdi, rsi, rdx, rcx, r8, r9 前 6 个，
  第 7 起栈——位号即 SysV 寄存器序号，与 ARM64「位号即 xN」同构，映射表干净。
- 用户函数返回结构体：被调方 prologue 位 0（rdi）存 retbuf 槽（槽 1）、声明参数位号
  整体 +1——生成函数 框架逻辑照抄 ARM64 版（生成函数ARM64:519~524 同位）。
- 标量返回 rax；栈对齐纪律：帧大小 16 对齐（共用层 计算帧大小 既有决策，ARM64
  硬件对齐已强制同款）+ 调用点栈参数区 16 对齐（调用栈区大小 既有决策）——
  x86_64 侧注意调用点发射 `sub rsp`/`add rsp` 垫片保持 call 前 rsp%16==0。

## 四、移植纪律与风险前置（lessons 高权重条目，实施轮强制对表）

1. **【权重 9.5，2026-09-05】拷贝/中转临时寄存器必须取「参数寄存器集合之外」**
   ——SysV 参数寄存器 6 个（rdi,rsi,rdx,rcx,r8,r9），发射器数据临时一律 **r10/r11**
   （对齐宿主 linux_x64 修复后约定：r10 主临时 / r11 次临时+i128 常量区寻址）；
   prologue 结构体按值/i128 参数拷贝循环**禁用 r9**（宿主第十八轮缺陷同款形态——
   ARM64 版用 x9/x10/x11/x12 因 x0~x7 之外而结构性安全，**不能直译寄存器编号**，
   必须按 SysV 参数寄存器集合重对表）。

   push-pop 严格逆序配对 / movss·movsd 宽度前缀按类型分派 / 空块条件跳转防御。
3. **【权重 9.5，第十七轮】移植复制的是行为不是注释叙事**：以宿主

4. **【权重 12.0】内存模型 C 布局**：发射器不涉内存模型（IR 层已统一），但结构体

### 冒烟揪出并根治的缺陷（全部实证闭环）

1. **【宿主·重大】linux_x64 被调方栈参数锚定基缺 push rbx 补偿**
   （`linux_x64_codegen.cpp` emitParamSetup 三处）：needHiddenRet（返回结构体/
   i128）时 prologue push rbx 使栈参数实际位于 [rbp+24+8k]，旧锚 [rbp+16+8k]
   把**返回地址当第 7 参数读**——v2p 建IR指令（7 参+返回 IR指令 结构体）类型
   字段被返回地址 0x43EAB6 污染、附加错位承接类型值，IR 全链损坏、产物 asm
   无法汇编。修复=锚 16+8*paramOffset（arm64 侧同构 16+16*needHiddenRet 对照；
   win 无 push rbx 锚恒 48 不受影响）。触发条件「返回结构体+整型参数≥7」为
   E2E 历史空白（153 只有 6 参全走寄存器）。**为何第十八轮冒烟未暴露**：产物
   级验证空白（asm 只验产出未汇编，v2 闭环 23 例平台跳过，单位机绿=arm64 宿主
   构建——同源码不同宿主后端的 v2p 行为分叉）。
2. **【v2】静态赋值存储丢失**（IR生成 赋值分支）：静态目标（计数器=计数器+阶乘(5)）
   「目标槽==0」静默丢存储（防御分支静默降级家族）——补 静态序号们 查表→
   IR_静态存储（与 发射自增自减 同款设施）。
3. **【v2】限定名内置 结果 接收 ABI 错配**（IR生成 结果初始化分支）：
   `结果<字符串,整32> 行 = 文件::读取文件行(h)` 把 C 函数返回的裸 char* 当
   16 字节结构体地址 IR_结构体拷贝（读字符串内容当结构体）——修=检测限定内置
   初始化时合成构造（判空→正常@0、指针→值@8）。
4. **【v2】返回含容器字段结构体的所有权悬垂**（IR生成 返回分支+IR容器 析构器）：
   返回 程序IR 时浅拷入 retbuf 后 RAII 析构局部向量字段→retbuf 悬垂（函数数=
   垃圾实测）——修=发射容器析构/发射容器字段析构 加跳过名ID 参数（返回语句
   所有权转移语义；E2E 148 结构体无容器字段故未暴露）。
5. **【v2】跨文件同名函数符号冲突**：代码生成.cn「生成函数」与 IR生成.cn
   「生成函数」重载（参数不同）但 IR 名=纯声明名→asm 重复定义。修=源码改名
   生成函数W（对齐 生成函数ARM64/X64L 平台后缀命名惯例）——**「跨文件同名
   重载无消歧机制」为机制层缺口，呈报项③**。
