## 二、v2.0 语法规范完整定义

### 2.1 关键字变化
- **新增**：`模块`、`作为`、`包`、`货舱`（均空闲，无冲突）
- **保留**：`导入`（主导入关键字）、`公开`/`私有`/`保护`
- **删除**：`从`

### 2.2 模块声明与路径
```
模块声明 = "模块" 标识符 [;]
路径 = 标识符 ("::" 标识符)*
```

### 2.3 导入语法（全部形式）
```
导入声明 = "导入" 路径 ["作为" 标识符]
          | "导入" 路径 "::" "{" 导入项 ("," 导入项)* "}"
          | "导入" 路径 "::" "*"
导入项 = 标识符 ["作为" 标识符]
示例：
导入 核心::可选::{某些, 无}
导入 核心::集合
导入 核心::列表 作为 动态数组
导入 核心::集合::*
导入 包::网络::连接
```

### 2.4 可见性（标签式 + 默认私有 + 交集规则）
```
公开:
函数 公开函数() {...}
私有:
函数 私有函数() {...}
函数 默认私有() {...}        // 无标签 → 默认私有
类 示例 {
  函数 默认私有方法() {...}   // 类内无标签 → 私有
  公开:
  函数 公开方法() {...}
}
```
**可见性交集规则**（写入 specs/08 可见性章节）：
> 符号的最终可见性 = **各层级可见性的交集（取最严格）**。模块级 `私有:` 块内的类，即使类内标了 `公开:`，跨文件导入时**整个类（含公开成员）不可见**。类内 `公开:` 仅在本模块内有效（允许本模块代码访问该类公开成员），不赋予类跨模块可见性。

| 类层级 | 成员层级 | 同文件 | 同包跨文件（导入后） | 跨包（导入后） |
|--------|---------|--------|-------------------|--------------|
| 模块公开 | 类内公开 | ✅ | ✅ | ✅ |
| 模块公开 | 类内私有 | ✅ | ❌ | ❌ |
| 模块私有 | 类内公开 | ✅ | ❌ | ❌ |
| 模块私有 | 类内私有 | ✅ | ❌ | ❌ |

### 2.5 crate 模型（包 = crate）
```
包.cn（包根，可选）：
  模块 网络
  模块 存储
  公开 导入 网络::连接      // 再导出
文件即模块：每个 .cn = 模块；包根（主.cn 或 包.cn）= crate 根
模块树：模块 网络 → 网络.cn；网络/ 子目录 → 网络::传输控制
crate 间：导入 包名::模块::符号
```

### 2.6 货舱.toml
```toml
[货舱]
名称 = "我的程序"
版本 = "0.1.0"
[依赖]
核心 = "内置"
网络库 = "1.2"
```

## 三、一劳永逸的已知问题解决清单（全部本轮）

| # | 已知问题 | 解决方式 |
|---|---------|---------|
| P1-1 | 未导入限定调用被静默接受 | 语义严格化：无 `导入` 的 `模块::符号` → 报「未声明的标识符」 |
| P1-2 | 多级路径只取首段 | `::` 全路径解析：目录层级 + 模块树 |
| P1-3 | importedModules_ 只存首段 | use 导入表：segments + 别名 + 花括号 + 通配符 |
| P1-4 | 顶层常量不支持 | 支持 `常量 名 = 值` 顶层声明 |
| P2-5 | 内置函数硬编码扁平表 | 归入 `核心` 包 prelude，`导入 核心::*` |
| P2-6 | 符号无 crate 前缀链接冲突 | IR/codegen 符号加 `包名$` 前缀 |
| P2-7 | 泛型 `$` 名与 crate 前缀混淆 | 统一命名：`包名$符号名`、泛型 `包名$类型$参数` |
| P3-8 | 顶层静态变量不支持 | 支持 `静态` 顶层声明 |
| P3-9 | `常量` 关键字复用 | 顶层 `常量` 复用现有语法 |
