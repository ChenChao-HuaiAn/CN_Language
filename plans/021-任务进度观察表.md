## 一、总目标（北极星，不随轮次变化）

1. **终极目标**：全中文语法的系统级编程语言编译器（C++ 风格），从零用 C++17 实现，
   终极目标**真正自举**。全流水线：词法 → 语法 → 语义 → IR → 优化 → 代码生成。
2. **v2 自举双目标（2026-09-01 用户令，最高准绳）**：
   - ① **性能超过 C++ 编译器**；
   - ② **安全接近 Rust 语言**（悬垂指针 / 越界访问 / 泄漏，零容忍）；
   - 二者冲突时向用户呈报裁决。
3. **三后端**：Win x64（MASM）/ Linux ARM64（GAS）/ Linux x86_64（SysV GAS）。
4. **总任务 = 三条主线 + 支撑**（互相咬合，全部服务于双目标）：
   - **线 1｜编译器能力**：v1 推倒 → v2 自举重建（结构化 IR + arena + 符号驻留），三后端，模块系统；
   - **线 2｜编译期安全**（plans/019）：显式转移 / 引用逃逸 / 只读借用与互斥 / 不安全区边界 /
     拥有型字符串与智能指针——对标 Rust 检查器，把 UAF、双释放、泄漏**结构性挡在编译期**；
   - **线 3｜内存安全防线**（plans/020）：拥有权流转矩阵 + 每轮探针实证 / E2E 门禁 / 反证三件
     ——运行时与语义面的零容忍兜底；
   - **支撑**：缺陷根治滚动轮（a 后缀轮次）、跨机轮（win-x64 家机 / arm64 单位机实物验证）、
     测试门禁（单测 + E2E + 锚定链 + 对拍 + 释放路径对照）。
