### Task 4.2: 优化器（循环优化/内联/尾调用）✅（2026-08-14 阶段B 完成）
> 注：CSE/复写传播/代数简化/常量折叠/DCE/跨块DCE/全局值传播已在 Task 完善C 完成（2026-08-13）。

**文件：**
- Create: `src/cn_compiler/opt/licm.hpp/cpp`（循环不变量外提，规格书9.2）
- Create: `src/cn_compiler/opt/strength_reduce.hpp/cpp`（强度削减）
- Create: `src/cn_compiler/opt/inline.hpp/cpp`（函数内联，启发式阈值 kMaxInlineInsts=16，规格书9.2）
- Create: `src/cn_compiler/opt/tail_call.hpp/cpp`（尾调用优化：尾递归转循环）
- Create: `tests/unit/opt/test_licm.cpp` / `test_strength_reduce.cpp` / `test_inline.cpp` / `test_tail_call.cpp`（24 测试）

**实现要点：**
- LICM：自然循环（back edge → header）识别；迭代计算不变寄存器集合（纯运算结果）；外提到 preheader；**副作用指令（Load/Store/Call）与外提引用"循环内 Load 定义寄存器"的指令不外提**（避免 preheader 引用未定义值）
- 强度削减：`Mul x 2^n -> Shl`；`无符号 Div x 2^n -> Shr`；有符号 Div 保守不削减（右移语义不符）
- 内联：单块、≤16 指令、非递归/非入口/非 OOP 方法/非 lambda/非模块函数（含 `#`）/无参数 Store/AddrOf；参数 Load 折叠为实参
- TCO：尾递归（自调用）→ 参数槽 Store + 跳回入口；保守条件（实参匹配、入口无参数 Store、实参非嵌套调用结果、非结构体返回）

**验证标准：** ✅ 各 Pass 独立可插拔（单测验证前后 IR 变化）；-O2 含 LICM+强度削减+TCO，-O3 追加 SSA+内联；-O0/-O2/-O3 三级别 E2E 28/28 一致；949/949 单测；零警告。

### Task 4.3: 寄存器分配优化
> ✅ 完成（2026-08-14 阶段C）

- Create: `tests/unit/codegen/test_reg_alloc.cpp`（9 测试：活跃区间/无冲突/溢出/被调用者保存/类型过滤/保留寄存器）

**实现要点（保守策略，正确性最高优先）：**
- 活跃区间：def-use 链 + 跨块活跃传播（迭代数据流 in/out）；Alloca 结果排除（栈上分配无实际值）
- 线性扫描：区间按 start 升序，活跃集合按 end 小顶堆；空闲物理寄存器分配；不足时溢出到栈槽（spillSlot 递增）
- 仅 i64/u64/ptr 参与分配（浮点/i128/小位宽保持栈槽——避免与发射器宽度假设冲突）
- 仅被调用者保存寄存器（x64 rbx/r12~r15；arm64 x19~x28）；序言 push、尾声 pop（逆序）
- **-O0/-O1 全栈帧不变**（不引入回归）；**-O2 起启用**（`--no-regalloc` 显式关闭）
- structReturn/i128/u128 返回函数强制关闭（epilogue 提前 return 路径，被调用者保存恢复会遗漏）
- arm64：提供 setRegAllocMap 注入 API（reg_alloc 模块独立可用），默认关闭（结果写回点分散，保守全栈帧）

**验证标准：** ✅ reg_alloc 9/9 单测；-O0 无物理寄存器、-O2 有（prologue push/pop 配对）；-O0 与 -O2 E2E 28/28 输出一致；964/964 全量单测；零警告。

> ✅ **reg_alloc -O2 崩溃缺陷已修复（2026-08-14，缺陷修复子任务）**：
> 换新 Win10 环境（MSVC 2022）后 E2E 21/28 崩溃（0xC0000005），对照实验定位为 reg_alloc 启用路径。
> **根因**：[`x64_codegen.cpp`](../../src/cn_compiler/codegen/x64/x64_codegen.cpp) `emitPrologue` 先 `sub rsp, frameSize`（已 16 对齐）
> 后 push 被调用者保存寄存器（rbx/r12~r15），**奇数个 push（1/3/5）破坏函数体内 rsp 16 字节对齐**——
> call 前 `rsp ≡ 8 (mod 16)` 违反 Win x64 ABI，被调方（MSVC 编译运行时）`movaps` 对齐访问崩溃。
> **修复**：`calleeSavedRegs_.size() % 2 == 1` 时 `frameSize += 8`（满足 `F + 8N ≡ 0 mod 16`），最小化改动。
> 新增回归单测 `X64CodegenTest.PrologueStackAlignWithCalleeSaved`（奇数 push 断言 `sub rsp, 24`）。
> **验证**：单测 965/965、E2E 28/28、-O0/-O2/-O3 三级别 84 组合输出一致（详见 lessons.md 权重 20.8 条目，已标记已修复 ✅）。
