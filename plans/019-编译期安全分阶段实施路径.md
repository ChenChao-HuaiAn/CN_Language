## 一、立项背景与裁决记录

v2 自举双目标：① 性能超过 C++ 编译器；② 安全接近 Rust（悬垂指针/越界/泄漏零容忍）。

编译期（使用前拦截），对标 Rust 但**不引入 Rust 语法**（CN v1 前身即 Rust 风格，已裁决废弃）。

### 1.3 审阅修正并入（会话第三轮可行性审阅结论）

前两轮设计呈报有三处乐观度，已修正并入本路径：
1. **字符串整治（原阶段1子项）= 类型系统变更**而非零语法成本（规范 02 明文「字符串变量为指针」）→
   单列为阶段 4'（智能指针与拥有型字符串），置于借用互斥之后、按值语义容器化方案另行呈报。
2. **借用互斥（阶段 3）伴随规范级使用限制**（引用不得存进容器字段等限制规则），非纯检查器逻辑。
3. **联合体必须划入不安全区**（规范 02「所有字段共享同一内存区域」无 tag，Rust union 同为
   unsafe-only）——阶段 4 安全区边界清单必须含：指针算术/下标写、联合体字段访问、FFI、字符串裸释放。

## 二、总体架构：CN 编译期安全分层模型

```
┌─ 不安全区（阶段4划定）────────────────────────────┐
│  不安全 函数 内显式操作裸指针：指针算术/下标、联合体  │
│  字段访问、FFI 外部函数、释放内存。审计面=不安全函数清单│
└──────────────────────────────────────────────┘
┌─ 受检区（阶段2~3 逐步收紧）───────────────────────┐
│  转移检查（仿射）：转移(v) 后 v 禁用                  │
│  逃逸检查：引用/指针不出所指对象生命周期              │
│  借用互斥：常量 T& 只读共存 × T& 可变独占            │
└──────────────────────────────────────────────┘
┌─ 安全区（默认，已具备=阶段0）──────────────────────┐
│  值语义深拷贝（标识符拷贝/容器追加=深拷贝，无别名）    │
│  RAII 析构 + 容器元素自动析构 + 运行时越界/空指针检查  │
│  结果/可选强制检查三规则（编译期 must_use 先例）      │
└──────────────────────────────────────────────┘
```

设计哲学（区别于 Rust 的三句话）：
1. **默认路径零规则**——CN 值语义深拷贝天然无别名，安全区代码不需要学任何新规则
   （这是 CN 相对 Rust 的体验优势：没有所有权概念也能写出安全代码，代价是拷贝）。
2. **显式放弃安全=显式获得性能**——`转移()` 是用户主动声明「此处放弃拷贝换零拷贝/交接所有权」，
   编译器则以「旧名禁用」回报安全保证（双释放/UAF/转移后使用结构性根除）。
3. **危险面收口而非全语言戒严**——指针/联合体/FFI 是系统语言必需能力，收进 不安全 函数
   显式审计，而非从语言中删除。

## 四、阶段 1 详案：显式转移 转移() + 已转移使用检查（本轮实施）

### 4.1 语言语义（规范条文，写入 plans/001 §5.3.1 与 specs/04 第五节）

**转移(表达式)** —— 内置函数（零新关键字）：
- 实参须为**变量标识符**（第一版；成员/下标/解引用形态显式拒绝，诚实边界见 4.5）。
- 实参类型须为**拥有资源语义类型**：指针（含 字符串）、容器（向量/映射/链表/栈/队列）、
  类对象、结构体、结果/可选。**标量（整数/浮点/布尔/字符）拒绝**——复制语义无转移意义
  （诊断：「'X' 具有复制语义，无需转移」；对齐 Rust Copy 类型不适用 move 的惯例）。
- 求值结果 = 实参的值（同一对象/指针的交接），**源变量自调用点起进入「已转移」状态**。
- **已转移变量的任何后续使用均为编译错误**（E0382 对标）：
  读值 / 赋值目标 / 复合赋值 / 自增自减 / 取地址 / 解引用 / 成员访问对象侧 / 下标对象侧 /
  函数调用实参 / 返回语句 / **再次转移** / 作用域出口析构以外的全部消费形态。
  诊断消息：「'v' 已转移，不能继续使用（转移发生在 …）」（含转移点行号定位）。
- 已转移状态**不因作用域退出而恢复**（除遮蔽：内层同名新声明是新变量，不受影响——
  与作用域解析同序判定，天然正确）。
- 第一版**运行行为零变更**（诚实边界 4.5）：转移() 在语义层把调用节点改写为实参标识符
  （AST 改写，wrapRefArgs 同款手法），IR/三后端/析构零改动；容器/类对象仍按现有拷贝
  语义（指针即槽位值天然零拷贝）。**安全收益为纯编译期**：转移后使用（UAF 主形态）与
  转移后再释放（双释放主形态）结构性根除。浅转移零拷贝优化=阶段 3 随借用分析一并落
  （需要 IR 层拷贝路径分派，改动面大，独立排期）。

## 五、阶段 2~5 实施要点（开工前按本节展开为详案）

### 5.1 阶段 2：引用逃逸检查强化（规范已有语法，规则加强）

现状锚点：返回局部引用已拒（semantic_stmt.cpp:744，E2E 103）。扩展面：
1. **引用局部绑定逃逸**：`整32& r = x;` 后 r 存入结构体字段/容器/全局静态/返回 → 悬垂
   （x 出作用域 r 仍活）。检查：引用类型变量的消费白名单收窄（读/写/传引用参/成员基址以外
   的逃逸形态拒绝）。
2. **返回引用经多级间接**：返回 `外层.字段` 形态中 外层 为局部 → 已有；返回 条件?甲:乙 引用
   分支形态补全。
3. 指针逃逸（局部的 &x 返回）已有部分覆盖（refReturnLvalueBase），补全 &局部经容器/字段转发形态。
验收：E2E 负测族 + stdlib/v2 全树零误伤（引用面 559 处 & 使用需过检——预审必须做，误伤即回炉）。

### 5.2 阶段 3：常量 T& 只读借用 + 借用互斥第一版（含转移浅拷贝优化）

1. **语法**：`常量 向量<整64>& 数据`（类型前置 C++ 风格，常量 修饰引用参数）——parser
   参数类型解析扩展；specs/04 引用参数章节扩条文。
2. **只读检查**：常量 T& 参数体内对该参数（及经其成员访问链）赋值/传可变引用/调用可变方法
   （容器 追加/设置 等变更方法清单）→ 硬错误（对齐 C++ const T& 的 constness 检查）。
3. **借用互斥第一版（语句级保守）**：同一调用语句中，可变引用实参与只读引用实参解析到同一
   基础变量 → 歧义别名拒绝（`排序(v, v.大小())` 形态类）。完整 NLL 活跃区间分析（跨语句
   借用生命周期）**不在第一版**——先保守拒绝+显式豁免形态（临时字面量/右值），误报率实测
   （stdlib/v2 全树当语料）后再决定 NLL 深度（rustc 从 AST borrowck 到 NLL 六年的教训：
   一步到位必翻车，渐进实测是正路）。
4. **转移浅拷贝优化**（并入本阶段）：转移() 在 IR 层从「AST 改写回标识符」升级为显式
   槽位交接（容器/类对象跳过深拷贝构造，槽位直拷+源槽禁用标记），运行行为=真零拷贝。
   风险点：RAII 析构路径须跳过已转移槽（语义层 moved 集传 IR）。
验收：E2E 正负双通道 + 性能锚（转移前后 bench 对比，零拷贝收益实证）+ 全树零误伤。

### 5.3 阶段 4：不安全区边界（不安全 函数 修饰，需二次呈报细则后开工）

- `不安全 函数 名(...) {}`：不安全函数体内方可使用——指针算术/指针下标写、联合体字段访问、
  外部 函数 调用、释放内存/释放内部数组 等裸操作。安全函数调用不安全函数**允许**
  （安全责任上移到不安全函数实现者，Rust unsafe fn 同模型）。
- 迁移面：stdlib + v2 全树 60 处指针声明与解引用/下标使用须包进不安全函数（或改写为安全
  抽象）——**分批迁移**：先标记不迁移只警告（观察期），再按模块收口硬错误。
- 关键字 `不安全` 入规范 01a（真实语法消费点=函数修饰位，符合保留字最小化原则）。
- CFI（plans/008 既有 --cfi 基础）与不安全区联动：不安全函数=CFI 目标表之外的外部调用面。

### 阶段 1 诚实边界（2026-09-10 第五十七轮）

- **支持面矩阵**：指针/字符串=任意位置（表达式/声明/赋值/传参/返回）；容器/类/结构体/结果/可选=**仅声明初始化位**（宿主=AST 改写深拷贝既有语义；赋值/传参/返回位拒绝随阶段3 浅拷贝优化）；标量/布尔/字符/枚举/函数指针=拒绝（复制语义）；v2 第一版=指针/字符串全位置（**容器/类位 v2 全拒**，随阶段3 对齐——196_v2 已注记）。
- **运行行为**：第一版转移()零运行时指令（纯编译期标记）；容器/类声明位=深拷贝（指针=槽位值天然零拷贝）；浅转移零拷贝与析构跳过=阶段 3（IR 拷贝路径分派工程）。
- **既有缺陷立案（随本轮呈报，非转移引入）**：①宿主「推断声明（变量）+字符串标识符拷贝」打印打出指针值（probe_f/h 实证：`变量 乙 = 甲` → 4285000；显式 `字符串 丙 = 甲` 正常）——推断类型未传 IR 打印分派，46-c 结构体回填同族，标量/字符串回填涉 184 布尔行为契约须裁决；②v2 语法层不支持 `-> 整64*` 指针返回类型（t2 探针；宿主支持——v2 语法层返回类型解析缺口）。
