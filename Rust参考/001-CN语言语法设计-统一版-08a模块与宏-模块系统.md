## 一、模块系统

### 1.1 核心原则：文件即模块

> **设计决策（最高优先级）**：CN 语言采用"文件即模块"设计原则。
> - 每个 `.cn` 文件天然是一个模块，文件名即模块名
> - 通过 `模块 名;` 声明引用其他文件模块，编译器自动加载同名 `.cn` 文件
> - 与 Rust 的 `mod` 机制一致，鼓励一个文件一个模块的代码组织方式
> - 标准库严格遵循此原则：`stdlib/` 目录下每个文件（如 `数学.cn`、`文本.cn`）都是一个独立模块

```ebnf
模块声明 = "模块" 标识符 ";"
模块项 = 导入声明 | 函数定义 | 结构定义 | 枚举定义
       | 特征定义 | 实现块 | 常量声明 | 静态声明 | 类型别名
```

> **语法说明**：`模块 标识符 ;` 是唯一的模块声明形式，用于引用文件模块。CN 语言不支持内联模块（`模块 名 { ... }` 花括号形式），所有模块必须以独立文件存在。

### 1.2 文件模块（推荐方式）

每个 `.cn` 文件天然构成一个模块，文件名即为模块名。通过 `模块 名;` 声明引用其他文件模块。

```
源码/
├── 主.cn               // 模块 "主"
├── 网络.cn             // 模块 "网络"
├── 网络/               // 子模块目录
│   ├── 传输控制.cn     // 模块 "网络::传输控制"
│   └── 用户数据报.cn   // 模块 "网络::用户数据报"
└── 工具.cn             // 模块 "工具"
```

```cn
// 主.cn 中声明引用文件模块
模块 网络;                      // 引用 网络.cn 文件（推荐方式）
模块 工具;                      // 引用 工具.cn 文件（推荐方式）
```

> **设计决策**：规范总结使用"文件即模块"设计（导入 数学工具），统一后采用Rust-like模块体系（模块 + ::路径分隔）。导入语法从导入/从改为使用，路径分隔从.改为::。
>
> **标准库实践**：`stdlib/` 目录严格遵循文件即模块原则，每个标准库文件是一个独立模块：
> - `stdlib/核心.cn` → 模块 `核心`
> - `stdlib/数学.cn` → 模块 `数学`
> - `stdlib/文本.cn` → 模块 `文本`
> - `stdlib/集合.cn` → 模块 `集合`
> - `stdlib/容器.cn` → 模块 `容器`
> - `stdlib/IO.cn` → 模块 `IO`

### 1.3 可见性

```ebnf
可见性修饰 = "公开" | "私有"?
```

> **与文件模块配合**：在文件模块中，`公开` 关键字用于导出模块的公共 API，其他模块通过 `使用` 导入后只能访问 `公开` 项。未标记的项默认私有，仅当前文件模块内可访问。

```cn
// 文件：我的模块.cn — 这是一个文件模块
公开 函数 公开函数() {}          // 任何地方可访问（通过 使用 导入后）
函数 默认私有() {}               // 仅本文件模块内可访问（默认）
私有 函数 显式私有() {}          // 显式标记私有

公开 结构 公开结构 {
    公开 整32 字段,             // 公开字段
    整32 内部,                  // 私有字段（默认）
}
```

> **设计决策**：规范总结使用公开:/私有:标签式可见性（影响后续所有声明），统一后采用逐项修饰式可见性（公开/私有放在每个声明前），与Rust一致。保护不保留为关键字。

### 1.4 使用与导入

```ebnf
导入声明 = "使用" 导入路径 ("作为" 标识符)? ";"
导入路径 = 标识符 ("::" 标识符)* ("::" "{" 导入项 ("," 导入项)* "}")?
导入项 = 标识符 ("作为" 标识符)?
```

```cn
// 导入单个项
使用 核心::可选::{某些, 无};

// 导入整个模块
使用 核心::集合;

// 导入并重命名
使用 核心::列表 作为 动态数组;

// 通配符导入（不推荐，仅用于测试或预导入）
使用 核心::集合::*;

// 绝对路径导入
使用 包::网络::连接;
```

### 1.5 预导入

CN语言默认预导入以下项（无需显式使用）：

```cn
使用 核心::可选::{某些, 无};
使用 核心::结果::{正常, 异常};
使用 核心::布尔::{真, 假};
使用 核心::打印行;
使用 核心::格式化;
使用 核心::克隆;
使用 核心::默认;
使用 核心::调试;
```

## 二、包系统

### 2.1 包定义

```cn
// 包.cn — 包的根文件
模块 网络;
模块 存储;
模块 工具;

公开 使用 网络::连接;
公开 使用 存储::存储器;
```

### 2.2 包的导入

```cn
// 在 货舱.toml 中声明依赖
// [依赖]
// 网络库 = "1.2"

// 在代码中使用
使用 网络库::连接;
使用 网络库::请求::获取;
```

## 三、属性标注

### 3.1 内联属性

```ebnf
属性 = "#" "[" 标识符 ("(" 属性参数 ")")? "]"
```

```cn
#[内联]                         // 建议内联
函数 快速计算(整32 x) -> 整32 { x * 2 }

#[允许(未使用变量)]              // 允许未使用的变量
函数 辅助函数() {}

#[禁止(未使用导入)]              // 禁止未使用的导入
函数 另一个函数() {}

#[测试]                         // 标记为测试函数
函数 测试加法() {
    断言!(加(2, 3) == 5);
}

#[忽略]                         // 测试时忽略
函数 慢速测试() {}
```

### 3.2 派生属性

```cn
#[派生(调试, 克隆, 相等)]
结构 用户 {
    字符串 姓名,
    整32 年龄,
}
// 自动生成 调试格式化、克隆、相等比较 的实现
```

### 3.3 条件编译

```cn
#[配置(目标操作系统 = "linux")]
函数 平台特定() {
    // 仅在Linux编译
}

#[配置(目标操作系统 = "windows")]
函数 平台特定() {
    // 仅在Windows编译
}

#[配置(调试断言)]
函数 仅调试模式() {
    // 仅在调试模式编译
}
