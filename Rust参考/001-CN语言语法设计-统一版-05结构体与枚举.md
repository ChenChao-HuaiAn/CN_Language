## 一、结构体

### 1.1 命名字段结构体

```ebnf
结构定义 = "结构" 标识符 (泛型参数)? "{" 字段列表? "}"
字段列表 = 字段 ("," 字段)* ","?
字段 = ("公开" | "私有")? 类型 标识符
```

```cn
结构 用户 {
    字符串 姓名,
    整32 年龄,
    可选<字符串> 邮箱,
}

// 创建实例
让 用户1 = 用户 {
    姓名: 字符串::从("张三"),
    年龄: 25,
    邮箱: 某些(字符串::从("zhang@example.cn")),
};

// 从另一个实例更新（结构体更新语法）
让 用户2 = 用户 {
    姓名: 字符串::从("李四"),
    ..用户1                      // 其余字段从用户1复制
};
```

> **设计决策**：结构体字段采用类型前置语法（修改计划3），即 `类型 字段名` 而非 `字段名: 类型`。但结构体实例化仍使用 `字段名: 值`（是赋值不是声明）。

### 1.2 元组结构体

```ebnf
元组结构定义 = "结构" 标识符 (泛型参数)? "(" 类型列表 ")" ";"
```

```cn
结构 颜色(正8, 正8, 正8);
结构 点(浮64, 浮64);

让 红色 = 颜色(255, 0, 0);
让 坐标 = 点(1.0, 2.0);
让 r = 红色.0;                 // 索引访问
```

### 1.3 单元结构体

```ebnf
单元结构定义 = "结构" 标识符 ";"
```

```cn
结构 单元标记;                  // 无字段，用作标记类型
```

### 1.4 结构体方法

```cn
实现 用户 {
    // 关联函数
    函数 新(字符串 姓名, 整32 年龄) -> 自身 {
        自身 { 姓名, 年龄, 邮箱: 无 }
    }

    // 实例方法
    函数 介绍(&自身) -> 字符串 {
        格式化!("我叫{}，今年{}岁", 自身.姓名, 自身.年龄)
    }

    函数 设置邮箱(&可变 自身, 字符串 邮箱) {
        自身.邮箱 = 某些(邮箱);
    }
}

让 可变 用户 = 用户::新(字符串::从("张三"), 25);
用户.设置邮箱(字符串::从("zhang@example.cn"));
打印行!("{}", 用户.介绍());
```

> **设计决策**：规范总结使用类/构造函数/析构函数，统一后采用结构体+实现块模式。无构造函数语法，使用关联函数（如函数 新）替代。无析构函数，所有权系统自动释放资源。

## 二、枚举

### 2.1 简单枚举

```ebnf
枚举定义 = "枚举" 标识符 (泛型参数)? "{" 变体列表 "}"
变体列表 = 变体 ("," 变体)* ","?
变体 = 标识符 | 标识符 "(" 类型列表 ")" | 标识符 "{" 字段列表 "}"
```

```cn
枚举 方向 {
    上,
    下,
    左,
    右,
}

让 当前方向 = 方向::上;
```

### 2.2 带数据的枚举

```cn
枚举 形状 {
    圆形(浮64),
    矩形(浮64, 浮64),
    三角形(浮64, 浮64, 浮64),
}

让 圆 = 形状::圆形(5.0);
让 矩 = 形状::矩形(3.0, 4.0);
```

### 2.3 带命名字段的枚举变体

```cn
枚举 网络消息 {
    连接请求 { 字符串 地址, 整32 端口 },
    数据包 { 列表<正8> 内容, 整32 序号 },
    断开连接 { 字符串 原因 },
}

让 请求 = 网络消息::连接请求 {
    地址: 字符串::从("127.0.0.1"),
    端口: 8080,
};
```

### 2.4 可选与结果（核心枚举）

```cn
// 可选值
枚举 可选<泛型 T> {
    某些(T),                     // 有值
    无,                          // 无值
}

// 结果类型
枚举 结果<泛型 T, 泛型 E> {
    正常(T),                     // 成功
    异常(E),                     // 错误
}

// 使用
让 可选<整32> 有值 = 某些(42);
让 可选<整32> 无值 = 无;

让 结果<整32, &文> 成功 = 正常(42);
让 结果<整32, &文> 失败 = 异常("出错了");
```

> **设计决策**：规范总结使用空值/无表示null，统一后采用可选<T>枚举。规范总结使用异常体系，统一后采用结果<T,E>枚举。无/空值不保留为关键字，无是可选枚举的变体名。

### 2.5 枚举方法

```cn
实现 形状 {
    函数 面积(&自身) -> 浮64 {
        匹配 自身 {
            形状::圆形(半径) => 3.14159 * 半径 * 半径,
            形状::矩形(宽, 高) => 宽 * 高,
            形状::三角形(底, 高, _) => 0.5 * 底 * 高,
        }
    }

    函数 描述(&自身) -> 字符串 {
        匹配 自身 {
            形状::圆形(r) => 格式化!("圆形 r={}", r),
            形状::矩形(w, h) => 格式化!("矩形 {}x{}", w, h),
            形状::三角形(a, b, c) => 格式化!("三角形 {} {} {}", a, b, c),
        }
    }
}
```

## 三、模式匹配详解

### 3.1 匹配结构体

```cn
匹配 用户 {
    用户 { 姓名, 年龄, 邮箱: 某些(邮箱) } => 
        打印行!("{}岁，邮箱{}", 年龄, 邮箱),
    用户 { 姓名, 年龄, 邮箱: 无 } => 
        打印行!("{}岁，无邮箱", 年龄),
}
```

### 3.2 匹配枚举变体

```cn
匹配 消息 {
    网络消息::连接请求 { 地址, 端口 } => 
        打印行!("连接 {}:{}", 地址, 端口),
    网络消息::数据包 { 内容, 序号 } => 
        打印行!("数据包 #{}，{}字节", 序号, 内容.长度()),
    网络消息::断开连接 { 原因 } => 
        打印行!("断开: {}", 原因),
}
```

### 3.3 解构与嵌套匹配

```cn
匹配 结果 {
    正常(某些(值)) => 打印行!("成功: {}", 值),
    正常(无) => 打印行!("成功但无值"),
    异常(错误) => 打印行!("错误: {}", 错误),
}
