## 设计决策总览

| # | 差异点 | 规范总结 | plans文档 | 统一决策 | 理由 |
|---|--------|---------|----------|---------|------|
| 1 | 类型命名 | 整数/小数/布尔/字符串/空类型 | 整8~整128/正8~正128/浮32/浮64/布尔/字符/文/字符串 | 采用plans位宽命名，提供类型别名 | 位宽命名精确无歧义 |
| 2 | 变量声明 | 变量 x = 10 / 常量 x = 10 | 让 x = 10 / 让 可变 x = 10 | 采用让/可变体系，不可变默认 | 系统级语言不可变默认更安全 |
| 3 | OOP vs 结构体+特征 | 类/接口/继承/虚拟/重写/抽象/保护/基类 | 结构/枚举/特征/实现/自身 | 采用结构+特征体系，OOP关键字不保留 | 所有权与OOP继承不兼容 |
| 4 | 控制流 | 选择/情况/默认/中断 | 匹配/跳出/继续/循环/当/对于/在 | 匹配替代选择，跳出替代中断 | 模式匹配更强大 |
| 5 | 错误处理 | 尝试/捕获/抛出/最终 | 结果类型 + ?运算符 + 匹配 | 采用结果类型体系，异常关键字不保留 | 类型系统表达错误更安全 |
| 6 | 函数定义 | 函数 + 重写/静态修饰 | 函数 + 关联函数 | 关联函数方式采用plans设计 | 实现块内无自身参数函数 |
| 7 | 声明语法 | 类型后置 让 名: 类型 = 值 | 类型后置 | 类型前置 让 类型 名 = 值 | 符合中文阅读习惯 |

## 一、源文件

```ebnf
源文件 = UTF8_BOM? 项* EOF
项 = 模块声明 | 导入声明 | 常量声明 | 静态声明 | 函数定义
   | 结构定义 | 枚举定义 | 特征定义 | 实现块 | 类型别名 | 宏定义 | 属性
```

- 文件扩展名: `.cn`
- 编码: UTF-8（必须）
- 入口文件: `主.cn`（可执行项目）或 `库.cn`（库项目）
- 语句结束: 分号 `;`
- 代码块: 花括号 `{}`
- 缩进: 4个空格（不使用Tab）

## 二、注释

```ebnf
行注释 = "//" 任意字符* 行尾
块注释 = "/*" (块注释 | 非"*/"字符)* "*/"
文档注释 = "///" 任意字符* 行尾
模块文档注释 = "//!" 任意字符* 行尾
```

```cn
// 单行注释
/* 块注释 — 可跨行，支持嵌套 /* 内层 */ */
/// 文档注释 — 用于函数/类型文档
//! 模块级文档注释 — 描述当前模块
```

| 绑定 | **让** **可变** | 变量绑定 |

### 3.2 规范总结关键字处理

规范总结中的以下关键字**不保留**，可作为普通标识符使用：

| 已移除关键字 | 替代方案 |
|-------------|---------|
| 变量 | 让 + 可变 |
| 整数/小数/空类型 | 整32/浮64/单元类型()，可通过类型别名兼容 |
| 类/接口/继承 | 结构 + 特征 + 实现 |
| 虚拟/重写/抽象 | 动态 + 特征对象 / 特征实现 / 特征默认方法 |
| 保护/基类 | 公开/私有 / 父级（模块层级） |
| 选择/情况/默认/中断 | 匹配 + 模式 / 跳出 |
| 尝试/捕获/抛出/最终 | 结果类型 + ?运算符 |
| 静态（旧义：静态方法） | 实现块内关联函数 |
| 自身类型 | 本类型 |
| 命名空间 | 模块 |

## 四、标识符

```ebnf
标识符 = 混合标识符 | 纯中文标识符 | 纯英文标识符 | 下划线标识符
混合标识符 = 中文字符+ 英文字母+ (英文字母 | 数字)* | 英文字母+ 中文字符+
纯中文标识符 = 中文字符+ (数字)* 中文字符*
纯英文标识符 = 英文字母 (英文字母 | 数字 | 下划线)*
下划线标识符 = "_" (英文字母 | 数字 | 下划线)*
```

```cn
让 姓名 = "张三";           // 中文标识符 ✅
让 age = 25;                // 英文标识符 ✅
让 _内部计数 = 0;            // 下划线开头 ✅
让 计算2面积 = 0;            // 中文+数字 ✅
让 计算area = 0;            // 中英连写 ✅
// 让 计算 area = 0;        // 空格分隔 ❌
// 让 2计算 = 0;            // 数字开头 ❌
