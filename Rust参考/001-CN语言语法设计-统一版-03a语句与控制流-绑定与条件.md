## 一、语句与表达式

CN语言是表达式导向的——大多数构造既是语句也是表达式，可以产生值。

### 1.1 语句

```ebnf
语句 = 变量绑定 | 表达式语句 | 返回语句 | 跳出语句 | 继续语句
变量绑定 = "让" "可变"? 类型 标识符 ("=" 表达式)? ";"
表达式语句 = 表达式 ";"
```

```cn
让 x = 5;                    // 绑定语句
x += 1;                       // 表达式语句
```

### 1.2 块表达式

```ebnf
块表达式 = "{" 语句* 表达式? "}"
```

```cn
让 结果 = {
    让 x = 5;
    让 y = 10;
    x + y                       // 末尾表达式（无分号）作为块的值
};
// 结果 = 15
```

## 二、变量绑定

### 2.1 不可变绑定

```cn
让 x = 42;                    // 不可变绑定，类型自动推断
让 字符串 名字 = 字符串::从("张三");  // 显式类型标注
```

### 2.2 可变绑定

```cn
让 可变 计数 = 0;              // 可变绑定
计数 += 1;                     // ✅ 可修改
// x += 1;                     // ❌ 不可变绑定不能修改
```

> **设计决策**：规范总结使用变量/常量声明，统一后采用让/可变体系。不可变默认，与Rust一致。变量关键字不保留。

### 2.3 变量遮蔽

```cn
让 x = 5;
让 x = x + 1;                  // 遮蔽：新绑定覆盖旧绑定 ✅
让 可变 x = "字符串";           // 遮蔽甚至可以改变类型 ✅
```

### 2.4 解构绑定

```cn
// 元组解构
让 (a, b) = (1, 2);

// 结构体解构
结构 点 { 浮64 x, 浮64 y }
让 点 { x, y } = 点 { x: 1.0, y: 2.0 };

// 带重命名解构
让 点 { x: 横坐标, y: 纵坐标 } = 点 { x: 1.0, y: 2.0 };

// 忽略部分字段
让 点 { x, .. } = 点 { x: 1.0, y: 2.0 };

// 数组解构
让 [首, .., 尾] = [1, 2, 3, 4, 5];
```

### 2.5 常量与静态变量

```cn
// 编译期常量
常量 整32 最大尺寸 = 1024;
常量 &文 版本 = "0.1.0";

// 静态变量（程序生命周期）
静态 原子共享<整32> 全局计数 = 原子共享::新(0);
```

## 三、条件表达式

### 3.1 如果/否则

```ebnf
条件表达式 = "如果" 表达式 块表达式 ("否则" "如果" 表达式 块表达式)* ("否则" 块表达式)?
```

```cn
让 x = 10;
如果 x > 5 {
    打印行!("大于5");
} 否则 如果 x > 3 {
    打印行!("大于3");
} 否则 {
    打印行!("不大于3");
}
```

### 3.2 如果作为表达式

```cn
让 状态 = 如果 分数 >= 60 { "及格" } 否则 { "不及格" };
让 等级 = 如果 分数 >= 90 {
    "优秀"
} 否则 如果 分数 >= 80 {
    "良好"
} 否则 如果 分数 >= 60 {
    "及格"
} 否则 {
    "不及格"
};
