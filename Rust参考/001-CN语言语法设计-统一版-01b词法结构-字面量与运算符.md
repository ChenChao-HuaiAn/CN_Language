## 五、字面量

### 5.1 整数字面量

```ebnf
整数字面量 = (十进制 | 十六进制 | 八进制 | 二进制) 类型后缀?
十进制 = 数字 (数字)*
十六进制 = "0x" 十六进制数字+
八进制 = "0o" 八进制数字+
二进制 = "0b" 二进制数字+
类型后缀 = "整8" | "整16" | "整32" | "整64" | "整128" | "正8" | "正16" | "正32" | "正64" | "正128"
```

```cn
让 十进制 = 42;
让 十六进制 = 0x2A;
让 八进制 = 0o52;
让 二进制 = 0b101010;
让 大数 = 1000000;           // 不使用下划线分隔
让 类型标注 = 42整32;        // 类型后缀
```

> **设计决策**：移除数字下划线分隔（修改计划2），规范总结使用英文后缀（f/L/LL等），统一采用中文类型后缀（整32/浮64等）。

### 5.2 浮点字面量

```ebnf
浮点字面量 = 数字+ "." 数字+ (("e" | "E") ("+" | "-")? 数字+)? 浮点后缀?
浮点后缀 = "浮32" | "浮64"
```

```cn
让 浮点数 = 3.14;
让 科学计数 = 1.5e10;
让 浮点类型 = 3.14浮64;     // 类型后缀
```

### 5.3 布尔与字符字面量

```ebnf
布尔字面量 = "真" | "假"
字符字面量 = "'" (转义字符 | Unicode字符) "'"
转义字符 = "\n" | "\t" | "\r" | "\\" | "\'" | "\0" | "\x" 十六进制数字 十六进制数字
Unicode转义 = "\u{" 十六进制数字+ "}"
```

```cn
让 是真 = 真;
让 是假 = 假;
让 单字符 = '中';
让 转义字符 = '\n';
让 Unicode = '\u{4E2D}';
```

### 5.4 字符串字面量

```ebnf
字符串字面量 = '"' 字符串字符* '"' | "原始" '"' 任意字符* '"'
```

```cn
让 &文 切片 = "你好世界";           // 字符串切片，不可变引用
让 字符串 堆字符串 = "你好";         // 字符串 类型
让 原始 = 原始"包含\n不转义";       // 原始字符串
```

> **设计决策**：规范总结中字符串字面量直接为字符串类型，统一后区分 &文（切片引用）和字符串（堆分配），与Rust一致。

## 六、运算符

### 6.1 算术运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| + | 加法 | a + b |
| - | 减法 | a - b |
| * | 乘法 | a * b |
| / | 除法 | a / b |
| % | 取余 | a % b |

### 6.2 比较运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| == | 等于 | a == b |
| != | 不等于 | a != b |
| > | 大于 | a > b |
| < | 小于 | a < b |
| >= | 大于等于 | a >= b |
| <= | 小于等于 | a <= b |

### 6.3 逻辑运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| && | 逻辑与 | a && b |
| \|\| | 逻辑或 | a \|\| b |
| ! | 逻辑非 | !a |

### 6.4 位运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| & | 按位与 | a & b |

| ^ | 按位异或 | a ^ b |

| >> | 右移 | a >> n |

### 6.5 赋值与复合赋值

| 运算符 | 含义 | 示例 |
|--------|------|------|
| = | 赋值 | x = 5 |
| += | 加赋值 | x += 1 |
| -= | 减赋值 | x -= 1 |
| *= | 乘赋值 | x *= 2 |
| /= | 除赋值 | x /= 2 |
| %= | 余赋值 | x %= 3 |

### 6.6 引用与类型运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| & | 不可变引用 | &x |
| &可变 | 可变引用 | &可变 x |
| * | 解引用 | *引用 |

### 6.7 其他运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|

## 七、分隔符与标点

| 符号 | 含义 |
|------|------|
| ; | 语句结束 |
| : | 类型标注/字段分隔（结构体实例化、匹配重命名） |
| , | 逗号分隔 |
| () | 函数调用/元组/分组 |
| {} | 代码块/结构体 |
| [] | 数组/索引/泛型参数 |
| -> | 返回类型 |
| => | 匹配分支 |
| @ | 模式绑定 |
| # | 属性标注 |
| ! | 宏调用标记 |

## 八、运算符优先级（从低到高）

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 1 | = += -= *= /= %= | 右结合 |
| 2 | .. ..= | 左结合 |
| 3 | \|\| | 左结合 |
| 4 | && | 左结合 |
| 5 | == != | 左结合 |
| 6 | < <= > >= | 左结合 |
| 7 | \| | 左结合 |
| 8 | ^ | 左结合 |
| 9 | & | 左结合 |
| 10 | << >> | 左结合 |
| 11 | + - | 左结合 |
| 12 | * / % | 左结合 |
| 13 | ! - * & 作为 | 右结合（一元） |

## 九、空白与格式化

- 中文关键字后**必须**加空格，如果紧跟其他字符就判定不是关键字
- 语句以分号 `;` 结尾
- 代码块用花括号 `{}` 包裹
- 缩进4个空格（不使用Tab）
- 官方格式化工具：`货舱 格式化`（类似 cargo fmt）
