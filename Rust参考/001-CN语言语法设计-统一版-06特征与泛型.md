## 一、特征定义

### 1.1 基本特征

```ebnf
特征定义 = "特征" 标识符 (泛型参数)? "{" 特征项* "}"
特征项 = 函数签名 | 函数默认实现 | 关联类型
函数签名 = "函数" 标识符 "(" 参数列表? ")" ("->" 类型)? ";"
函数默认实现 = "函数" 标识符 "(" 参数列表? ")" ("->" 类型)? 块表达式
关联类型 = "类型" 标识符 ("=" 类型)? ";"
```

```cn
特征 描述 {
    函数 描述(&自身) -> 字符串;
}

特征 比较 {
    函数 比较(&自身, &自身 其他) -> 排序结果;
}

枚举 排序结果 {
    小于,
    等于,
    大于,
}
```

> **设计决策**：规范总结使用接口/继承/虚拟/重写/抽象实现OOP多态，统一后采用特征（trait）体系。特征比接口更强大：支持默认方法、关联类型、标记特征。接口/虚拟/重写/抽象不保留为关键字。

### 1.2 带默认实现的特征

```cn
特征 问候 {
    函数 问候语(&自身) -> 字符串 {
        字符串::从("你好")          // 默认实现
    }

    函数 打印问候(&自身) {
        打印行!("{}", 自身.问候语());  // 调用其他方法
    }
}
```

### 1.3 关联类型特征

```cn
特征 迭代器 {
    类型 项;                       // 关联类型

    函数 下一个(&可变 自身) -> 可选<本类型::项>;
}
```

## 二、特征实现

### 2.1 为类型实现特征

```ebnf
特征实现 = "实现" 标识符 (泛型参数)? "对于" 类型 "{" 实现项* "}"
实现项 = 函数定义
```

```cn
结构 矩形 {
    浮64 宽度,
    浮64 高度,
}

实现 描述 对于 矩形 {
    函数 描述(&自身) -> 字符串 {
        格式化!("矩形 {}x{}", 自身.宽度, 自身.高度)
    }
}
```

### 2.2 条件实现

```cn
// 为所有实现描述特征的类型实现打印特征
实现 打印 对于 任意T 其中 T: 描述 {
    函数 打印(&自身) {
        打印行!("{}", 自身.描述());
    }
}
```

### 2.3 标记特征

```cn
// 无方法的特征，仅用于标记类型具有某种属性
特征 发送 {}                      // 可安全跨线程发送
特征 同步 {}                      // 可安全跨线程共享
特征 复制 {}                      // 可按位复制
特征 克隆 {}                      // 可显式克隆
特征 大小 {}                      // 编译期已知大小
```

## 三、泛型

### 3.1 泛型函数

```ebnf
泛型函数 = "函数" 标识符 泛型参数 "(" 参数列表? ")" ("->" 类型)? 其中子句? 块表达式
泛型参数 = "<" 泛型参数项 ("," 泛型参数项)* ">"
泛型参数项 = "泛型" 标识符
其中子句 = "其中" 约束 ("," 约束)*
约束 = 标识符 ":" 特征 ("+" 特征)*
```

```cn
函数 最大值<泛型 T>(T a, T b) -> T
    其中 T: 偏序特征
{
    如果 a >= b { a } 否则 { b }
}

函数 交换<泛型 T>(&可变 T a, &可变 T b) {
    让 临时 = 克隆::克隆(a);
    *a = 克隆::克隆(b);
    *b = 临时;
}
```

### 3.2 泛型结构体

```cn
结构 容器<泛型 T> {
    T 值,
}

实现<泛型 T> 容器<T> {
    函数 新(T 值) -> 自身 {
        自身 { 值 }
    }

    函数 获取(&自身) -> &T {
        &自身.值
    }

    函数 设置(&可变 自身, T 值) {
        自身.值 = 值;
    }
}
```

### 3.3 泛型枚举

```cn
枚举 可选<泛型 T> {
    某些(T),
    无,
}

枚举 结果<泛型 T, 泛型 E> {
    正常(T),
    异常(E),
}
```

### 3.4 泛型约束

```cn
// 单约束
函数 打印描述<泛型 T>(&T 项)
    其中 T: 描述
{
    打印行!("{}", 项.描述());
}

// 多约束
函数 处理<泛型 T>(T 项)
    其中 T: 描述 + 克隆
{
    让 副本 = 项.克隆();
    打印行!("{}", 副本.描述());
}

// 复杂约束
函数 复杂处理<泛型 T, 泛型 U>(T a, U b) -> 字符串
    其中
        T: 描述 + 克隆,
        U: 描述 + 偏序特征,
{
    格式化!("{} 和 {}", a.描述(), b.描述())
}
```

### 3.5 泛型默认类型

```cn
特征 迭代器 {
    类型 项;
    类型 容器 = 列表<本类型::项>;   // 默认关联类型

    函数 收集到容器(&可变 自身) -> 本类型::容器;
}
```

## 四、动态分发

### 4.1 特征对象

```cn
// 动态分发 — 运行时确定调用哪个实现
让 动态 绘图 绘图对象 = 矩形::新(1.0, 2.0);
绘图对象.绘制();

// 动态分发列表
让 列表<盒子<动态 绘图>> 图形列表 = 列表::新();
图形列表.推入(盒子::新(矩形::新(1.0, 2.0)));
图形列表.推入(盒子::新(圆形::新(3.0)));

对于 图形 在 图形列表.迭代() {
    图形.绘制();                  // 动态分发
}
```

### 4.2 静态分发 vs 动态分发

```cn
// 静态分发（编译期确定，零开销）
函数 静态绘制<泛型 T: 绘图>(&T 图形) {
    图形.绘制();
}

// 动态分发（运行时确定，有虚表开销）
函数 动态绘制(&动态 绘图 图形) {
    图形.绘制();
}
```

## 五、运算符重载

```cn
特征 加法 {
    类型 输出;
    函数 加法(自身, 自身 右操作数) -> 本类型::输出;
}

实现 加法 对于 整32 {
    类型 输出 = 整32;
    函数 加法(自身, 自身 右操作数) -> 整32 {
        自身 + 右操作数
    }
}

// 自定义类型运算符重载
结构 向量 {
    浮64 x,
    浮64 y,
}

实现 加法 对于 向量 {
    类型 输出 = 向量;
    函数 加法(自身, 向量 右操作数) -> 向量 {
        向量 { x: 自身.x + 右操作数.x, y: 自身.y + 右操作数.y }
    }
}

让 v1 = 向量 { x: 1.0, y: 2.0 };
让 v2 = 向量 { x: 3.0, y: 4.0 };
让 v3 = v1 + v2;                // 使用重载的+运算符
