## 四、循环

### 4.1 循环（无限循环）

```ebnf
循环表达式 = 标签? "循环" 块表达式
标签 = "'" 标识符 ":"
```

```cn
让 可变 计数 = 0;
循环 {
    如果 计数 >= 10 {
        跳出;
    }
    计数 += 1;
}
```

### 4.2 循环带返回值

```cn
让 结果 = 循环 {
    让 可变 i = 0;
    如果 i == 10 {
        跳出 i * 2;            // 跳出并返回值
    }
    i += 1;
};
```

### 4.3 循环标签

```cn
'外层: 循环 {
    让 可变 i = 0;
    '内层: 循环 {
        如果 i == 5 {
            跳出 '内层;
        }
        如果 某条件 {
            跳出 '外层;
        }
        i += 1;
    }
}
```

### 4.4 当循环（while）

```ebnf
当循环 = 标签? "当" 表达式 块表达式
```

```cn
让 可变 n = 0;
当 n < 10 {
    打印行!("{}", n);
    n += 1;
}
```

### 4.5 对于循环（for-in）

```ebnf
对于循环 = 标签? "对于" 模式 "在" 表达式 块表达式
```

```cn
对于 i 在 0..10 {
    打印行!("{}", i);           // 0到9
}

对于 i 在 1..=5 {
    打印行!("{}", i);           // 1到5
}

让 数字 = [1, 2, 3, 4, 5];
对于 项 在 数字.迭代() {
    打印行!("{}", 项);
}

对于 (索引, 值) 在 数字.迭代().枚举() {
    打印行!("索引: {}, 值: {}", 索引, 值);
}
```

## 五、匹配表达式

### 5.1 基本匹配

```ebnf
匹配表达式 = "匹配" 表达式 "{" 匹配分支+ "}"
匹配分支 = 模式 ("如果" 表达式)? "=>" (表达式 | 块表达式) ","
```

```cn
让 数字 = 3;
匹配 数字 {
    1 => 打印行!("一"),
    2 => 打印行!("二"),
    3 => 打印行!("三"),
    _ => 打印行!("其他"),
}
```

> **设计决策**：规范总结使用选择/情况/默认（switch/case/default），统一后采用匹配（match）。模式匹配比switch更强大、更安全。选择/情况/默认不保留为关键字。

### 5.2 匹配为表达式

```cn
让 描述 = 匹配 数字 {
    1 => "一",
    2 => "二",
    3 => "三",
    _ => "其他",
};
```

### 5.3 匹配守卫

```cn
匹配 数字 {
    n 如果 n < 0 => "负数",
    0 => "零",
    n 如果 n > 100 => "大数",
    _ => "普通数",
}
```

### 5.4 匹配枚举

```cn
枚举 方向 { 上, 下, 左, 右 }

匹配 方向 {
    方向::上 => "向上",
    方向::下 => "向下",
    方向::左 => "向左",
    方向::右 => "向右",
}
```

### 5.5 匹配带数据枚举

```cn
枚举 消息 {
    退出,
    移动 { 整32 x, 整32 y },
    文本(字符串),
}

匹配 消息 {
    消息::退出 => 打印行!("退出"),
    消息::移动 { x, y: 0 } => 打印行!("水平移动到 {}", x),
    消息::移动 { x: 0, y } => 打印行!("垂直移动到 {}", y),
    消息::移动 { x, y } => 打印行!("移动到 ({}, {})", x, y),
    消息::文本(内容) => 打印行!("文本: {}", 内容),
}
```

### 5.6 匹配范围

```cn
匹配 年龄 {
    0..=12 => "儿童",
    13..=17 => "青少年",
    18..=59 => "成年人",
    60..=150 => "老年人",
    _ => "无效年龄",
}
```

### 5.7 匹配绑定

```cn
匹配 数字 {
    绑定值 @ 0..=10 => 打印行!("小数: {}", 绑定值),
    绑定值 @ 11..=100 => 打印行!("中数: {}", 绑定值),
    _ => 打印行!("大数"),
}
```

## 六、跳出/继续/返回

### 6.1 跳出语句

```ebnf
跳出语句 = "跳出" 表达式? ";"
```

```cn
跳出;                   // 跳出当前循环
跳出 值;                // 跳出循环并返回值
跳出 '标签;             // 跳出指定标签的循环
```

> **设计决策**：规范总结使用中断（break），统一后采用跳出，语义更清晰。中断不保留为关键字。

### 6.2 继续语句

```ebnf
继续语句 = "继续" 标签? ";"
```

```cn
继续;                   // 跳过当前迭代
继续 '标签;             // 跳过指定标签的当前迭代
```

### 6.3 返回语句

```ebnf
返回语句 = "返回" 表达式? ";"
```

```cn
函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b;                 // 显式返回
}

函数 加2(整32 a, 整32 b) -> 整32 {
    a + b                       // 末尾表达式隐式返回（无分号）
}

函数 提前返回(整32 值) -> 整32 {
    如果 值 < 0 {
        返回 0;                 // 提前返回
    }
    值 * 2                       // 正常返回
}
