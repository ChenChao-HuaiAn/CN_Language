## 一、基础类型

| 类型 | 大小 | 范围 | 说明 |
|------|------|------|------|
| **整8** | 1字节 | -128 ~ 127 | 8位有符号整数 |
| **整16** | 2字节 | -32768 ~ 32767 | 16位有符号整数 |
| **整32** | 4字节 | -2^31 ~ 2^31-1 | 32位有符号整数（默认整数类型） |
| **整64** | 8字节 | -2^63 ~ 2^63-1 | 64位有符号整数 |
| **整128** | 16字节 | -2^127 ~ 2^127-1 | 128位有符号整数 |
| **正8** | 1字节 | 0 ~ 255 | 8位无符号整数 |
| **正16** | 2字节 | 0 ~ 65535 | 16位无符号整数 |
| **正32** | 4字节 | 0 ~ 2^32-1 | 32位无符号整数 |
| **正64** | 8字节 | 0 ~ 2^64-1 | 64位无符号整数 |
| **正128** | 16字节 | 0 ~ 2^128-1 | 128位无符号整数 |
| **浮32** | 4字节 | IEEE 754 | 32位浮点数 |
| **浮64** | 8字节 | IEEE 754 | 64位浮点（默认浮点类型） |
| **布尔** | 1字节 | 真/假 | 布尔类型 |
| **字符** | 4字节 | Unicode | Unicode标量值 |

> **设计决策**：规范总结使用整数/小数/空类型，统一后采用plans的位宽命名体系。整数/小数/空类型不保留为关键字，但可通过类型别名兼容。

## 二、类型别名

```ebnf
类型别名 = "类型" 标识符 "=" 类型 ";"
```

```cn
类型 整数 = 整32;              // 兼容旧习惯
类型 小数 = 浮64;              // 兼容旧习惯
类型 年龄 = 整32;
类型 用户标识 = 正64;
类型 结果类型 = 结果<字符串, 错误>;
```

> **设计决策**：通过类型别名机制提供兼容性。用户可定义 `类型 整数 = 整32` 来使用旧名称，但语言本身不再将整数/小数作为关键字。

## 三、复合类型

### 3.1 元组

```ebnf
元组类型 = "(" 类型 ("," 类型)* ")" 
```

```cn
让 (浮64, 浮64) 坐标 = (1.0, 2.0);
让 (x, y) = 坐标;              // 解构
让 第一个 = 坐标.0;             // 索引访问
```

### 3.2 数组

```ebnf
数组类型 = "[" 类型 ";" 整数字面量 "]"
```

```cn
让 [整32; 5] 固定数组 = [1, 2, 3, 4, 5];
让 [0; 100] 重复数组 = [0; 100];   // 100个0
让 第一个 = 固定数组[0];
```

### 3.3 切片

```ebnf
切片类型 = "&" "[" 类型 "]"
```

```cn
让 &[整32] 完整 = &固定数组[..];     // 完整切片
让 &[整32] 前三个 = &固定数组[..3];   // 前3个
让 &[整32] 后两个 = &固定数组[3..];   // 后2个
让 &[整32] 中间 = &固定数组[1..4];    // 索引1到3
```

## 四、字符串类型

```cn
让 &文 切片 = "你好";                    // 字符串切片，不可变引用
让 字符串 堆字符串 = 字符串::从("你好");   // 堆分配字符串，拥有所有权
让 可变 字符串 可变字符串 = 字符串::新();  // 空字符串
可变字符串.推入字符('世');
可变字符串.推入字符('界');
```

> **设计决策**：规范总结中字符串是基础类型，统一后区分 &文（切片引用）和字符串（堆分配），与Rust的str/String对应。

## 五、类型推断

```cn
让 x = 42;              // 推断为 整32
让 y = 3.14;            // 推断为 浮64
让 z = 真;              // 推断为 布尔
让 s = "你好";          // 推断为 &文
让 v = 列表::新();      // 推断为 列表<未知> — 需后续使用确定
```

## 六、类型标注（类型前置）

```ebnf
变量绑定 = "让" "可变"? 类型 标识符 ("=" 表达式)? ";"
常量声明 = "常量" 类型 标识符 "=" 表达式 ";"
```

```cn
让 整64 x = 42;
让 字符串 名字 = 字符串::从("张三");
让 列表<整32> 数字列表 = 列表::新();
让 可变 浮64 计数 = 0.0;
常量 整32 最大尺寸 = 1024;
常量 &文 版本 = "0.1.0";
```

> **设计决策**：采用修改计划的类型前置声明语法。规范总结使用类型后置（让 名: 类型 = 值），统一后改为类型前置（让 类型 名 = 值），更符合中文"先定性后命名"的阅读习惯。

## 七、never类型

```ebnf
never类型 = "!"
```

```cn
// 永不返回的函数返回never类型
函数 永远循环() -> ! {
    循环 {
        打印行!("永不停止");
    }
}

函数 致命退出(&文 消息) -> ! {
    打印行!("致命错误: {}", 消息);
    进程::退出(1);
}
```

never类型可以强制转换为任意类型，用于类型推断：

```cn
让 可变 整32 x = 0;
x = 如果 某条件 { 42 } 否则 { 致命退出("不可能") };
// 致命退出返回!，可强制转换为整32
```

## 八、单元类型

```ebnf
单元类型 = "()"
```

```cn
函数 无返回() {
    打印行!("无返回值");
    // 隐式返回单元值 ()
}
让 单元 = 无返回();            // 单元 = ()
```

> **设计决策**：规范总结使用空类型表示无返回值，统一后采用单元类型()，与Rust一致。空类型不保留为关键字。

## 九、裸指针类型（FFI，v1.2.0-alpha.1新增）

```ebnf
裸指针类型 = "*" ("可变" | "只读") 类型
```

```cn
外部 "C" {
    函数 malloc(大小: 整64) -> *可变 整8;    // 可变裸指针
    函数 free(指针: *可变 整8);
    函数 strlen(指针: *只读 整8) -> 正64;   // 只读裸指针
}
```

- **`*可变 T`**（可变裸指针）：对应C的 `T*`，可读写指向的内存
- **`*只读 T`**（只读裸指针）：对应C的 `const T*`，只可读指向的内存
- 裸指针**不保证**指向有效内存，**不进行借用检查**
- 裸指针只能在**不安全块**中解引用，或作为参数传给extern函数
- 裸指针是Copy类型，按指针位复制，不拥有指向的数据（不需要Drop）
- LLVM IR映射为 `ptr` 类型（LLVM 15+统一指针类型）

```cn
让 只读指针: *只读 整32 = ...;
让 可变指针: *可变 整32 = ...;
让 值 = 不安全 { *只读指针 };      // 在不安全块中解引用读取
不安全 { *可变指针 = 42; }          // 在不安全块中解引用写入
```

> **设计决策**：裸指针语法 `*可变 T`/`*只读 T` 与CN关键字体系一致（`可变`复用绑定关键字，`只读`对应const语义）。裸指针与引用（&T）的区别在于：引用保证有效并受借用检查器约束，裸指针不提供任何保证，用于FFI边界传递C指针。

## 十、空类型（FFI，v1.2.0-alpha.1新增）

```ebnf
空类型 = "空"
```

```cn
外部 "C" {
    函数 free(指针: *可变 整8) -> 空;   // 映射C的void返回类型
}
```

- **`空`**：仅用于extern函数的返回类型，映射C的 `void`，表示无返回值
- **不**能用作变量类型、参数类型或普通函数返回类型
- CN自身无返回值的普通函数使用单元类型 `()`（见第八章）
- LLVM IR映射为 `void` 类型

> **设计决策**：`空`关键字专用于FFI边界映射C的void。CN内部函数无返回值统一使用单元类型()，与Rust一致；仅在extern声明中需要区分C的void签名。
