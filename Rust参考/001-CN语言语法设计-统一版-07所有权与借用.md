## 一、所有权规则

### 1.1 三条核心规则

1. **每个值有且仅有一个所有者**
2. **当所有者离开作用域，值被自动释放**
3. **所有权可以移动，移动后原变量失效**

```cn
让 s1 = 字符串::从("你好");
让 s2 = s1;                     // s1 的所有权移动到 s2
// 打印行!(s1);                 // ❌ 编译错误：s1 已失效
打印行!("{}", s2);               // ✅ s2 是有效所有者
```

> **设计决策**：规范总结使用指针+手动内存管理（新建/删除），统一后采用所有权系统自动管理内存。这是CN语言从解释执行OOP语言演进为编译执行系统级语言的核心变化。

### 1.2 克隆（显式深复制）

```cn
让 s1 = 字符串::从("你好");
让 s2 = s1.克隆();              // 显式深复制，s1 仍然有效
打印行!("{} {}", s1, s2);       // ✅ 两者都有效
```

### 1.3 复制语义（栈上类型自动复制）

```cn
让 x = 42;
让 y = x;                       // 整32 实现了复制特征，自动复制
打印行!("{} {}", x, y);         // ✅ 两者都有效
```

### 1.4 函数中的所有权转移

```cn
函数 处理(字符串 数据) {
    打印行!("{}", 数据);
}                                 // data 在此释放

让 s = 字符串::从("数据");
处理(s);                         // s 的所有权移动到函数
// 打印行!(s);                   // ❌ s 已失效

// 返回值转移所有权
函数 创建字符串() -> 字符串 {
    让 结果 = 字符串::从("新字符串");
    返回 结果;                   // 所有权移动给调用者
}
```

## 二、借用与引用

### 2.1 不可变引用

```cn
函数 计算长度(&字符串 s) -> 正64 {
    s.长度()                     // 借用，不获取所有权
}

让 s1 = 字符串::从("你好");
让 长度 = 计算长度(&s1);         // 借用s1
打印行!("{} 长度 {}", s1, 长度); // ✅ s1 仍然有效
```

### 2.2 可变引用

```cn
函数 追加世界(&可变 字符串 s) {
    s.推入字符('世');
    s.推入字符('界');
}

让 可变 s = 字符串::从("你好");
追加世界(&可变 s);               // 可变借用
打印行!("{}", s);                 // ✅ "你好世界"
```

### 2.3 借用规则

同一时刻，对于同一块数据：
- 可以有**任意多个**不可变引用（&T）
- 或者有**仅一个**可变引用（&可变 T）
- **两者不可同时存在**

```cn
让 可变 数据 = 字符串::从("数据");

让 r1 = &数据;                   // ✅ 第一个不可变引用
让 r2 = &数据;                   // ✅ 第二个不可变引用
打印行!("{} {}", r1, r2);        // ✅ r1和r2同时有效

// 让 r3 = &可变 数据;           // ❌ 不可变引用存在时不能可变借用

让 可变 值 = 42;
让 r1 = &可变 值;                // ✅ 第一个可变引用
// 让 r2 = &可变 值;             // ❌ 不能同时有两个可变引用
// 让 r3 = &值;                  // ❌ 可变引用存在时不能不可变借用
```

### 2.4 引用的作用域（NLL — 非词法生命周期）

```cn
让 可变 数据 = 字符串::从("数据");
让 r1 = &数据;
打印行!("{}", r1);                // r1 最后一次使用在此

// r1 不再使用，可以创建可变引用
让 r2 = &可变 数据;              // ✅ NLL允许，r1已不再使用
r2.推入字符('!');
打印行!("{}", r2);
```

## 三、生命周期

### 3.1 生命周期标注

```ebnf
生命周期参数 = "'" 标识符
```

```cn
// 生命周期参数用 '名称 表示
函数 最长<'a>(&'a 文 s1, &'a 文 s2) -> &'a 文 {
    如果 s1.长度() > s2.长度() { s1 } 否则 { s2 }
}
```

### 3.2 结构体中的生命周期

```cn
结构 摘要<'a> {
    &'a 文 内容,                 // 引用必须标注生命周期
}

实现<'a> 摘要<'a> {
    函数 新(&'a 文 内容) -> 摘要<'a> {
        摘要 { 内容 }
    }
}
```

### 3.3 生命周期省略规则

编译器在以下情况可自动推断生命周期，无需显式标注：

```cn
// 规则1：每个引用参数有自己的生命周期
函数 长度(&文 s) -> 正64 { s.长度() }

// 规则2：只有一个输入生命周期时，输出生命周期等于输入
函数 首字符(&文 s) -> &文 { &s[..1] }

// 规则3：多个输入但有&self时，输出等于self的生命周期
```

### 3.4 静态生命周期

```cn
让 &'静态 文 静态字符串 = "永久存在的字符串";
常量 &'静态 文 版本 = "0.1.0";
```

## 四、智能指针

### 4.1 盒子（Box）— 堆分配

```cn
让 堆值 = 盒子::新(42);          // 在堆上分配
让 递归结构 = 盒子::新(节点 {     // 递归类型必须用盒子
    值: 1,
    下一个: 无,
});
```

### 4.2 共享（Rc）— 引用计数

```cn
使用 核心::共享;

让 数据 = 共享::新(字符串::从("共享数据"));
让 引用1 = 共享::克隆(&数据);    // 引用计数+1
让 引用2 = 共享::克隆(&数据);    // 引用计数+1
打印行!("引用计数: {}", 共享::强引用计数(&数据));  // 3
```

### 4.3 原子共享（Arc）— 线程安全引用计数

```cn
使用 核心::原子共享;

让 数据 = 原子共享::新(字符串::从("线程安全数据"));
让 引用1 = 原子共享::克隆(&数据);  // 原子操作+1
// 可安全跨线程传递
```

### 4.4 可借用盒子（RefCell）— 运行时借用检查

```cn
使用 核心::可借用盒子;

让 数据 = 可借用盒子::新(42);
*数据.可变借用() += 1;            // 运行时检查借用规则
```
