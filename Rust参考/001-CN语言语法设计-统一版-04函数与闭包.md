## 一、函数定义

### 1.1 基本函数

```ebnf
函数定义 = "函数" 标识符 "(" 参数列表? ")" ("->" 类型)? 块表达式
参数列表 = 参数 ("," 参数)*
参数 = 类型 标识符
```

```cn
函数 加(整32 a, 整32 b) -> 整32 {
    a + b                       // 末尾表达式作为返回值
}

函数 打印问候(&文 名字) {     // 无返回值 = 返回单元类型
    打印行!("你好, {}!", 名字);
}
```

> **设计决策**：函数参数采用类型前置语法（修改计划3），即 `类型 参数名` 而非 `参数名: 类型`。规范总结使用类型后置，统一后改为类型前置。

### 1.2 函数参数

```cn
// 引用参数
函数 修改(&可变 整32 值) {
    *值 += 1;
}

// 切片参数
函数 求和(&[整32] 数值) -> 整32 {
    数值.迭代().汇总(|累加, 当前| 累加 + 当前)
}

// 默认参数 — 不支持（与Rust一致，用构建器模式替代）
```

### 1.3 函数指针

```ebnf
函数指针类型 = "函数" "(" 参数类型列表? ")" ("->" 类型)?
```

```cn
函数 加(整32 a, 整32 b) -> 整32 { a + b }
函数 乘(整32 a, 整32 b) -> 整32 { a * b }

让 函数(整32, 整32) -> 整32 运算 = 加;
让 结果 = 运算(3, 4);          // 结果 = 7
```

## 二、方法

### 2.1 关联函数（类似静态方法）

```cn
结构 矩形 {
    浮64 宽度,
    浮64 高度,
}

实现 矩形 {
    // 关联函数 — 用 类型::函数名 调用
    函数 正方形(浮64 边长) -> 自身 {
        自身 { 宽度: 边长, 高度: 边长 }
    }
}

让 正方形 = 矩形::正方形(5.0);
```

> **设计决策**：规范总结使用静态关键字声明静态方法，统一后采用Rust的关联函数模式——在实现块内定义无自身参数的函数即为关联函数。静态关键字仅用于静态变量和静态生命周期，不保留旧义。

### 2.2 实例方法

```cn
实现 矩形 {
    // 不可变借用自身
    函数 面积(&自身) -> 浮64 {
        自身.宽度 * 自身.高度
    }

    // 可变借用自身
    函数 缩放(&可变 自身, 浮64 比例) {
        自身.宽度 *= 比例;
        自身.高度 *= 比例;
    }

    // 获取所有权
    函数 消耗(自身) -> 浮64 {
        自身.宽度 * 自身.高度
    }
}
```

## 三、闭包

### 3.1 基本闭包

```ebnf
闭包表达式 = "移动"? "|" 参数列表? "|" ("->" 类型)? 表达式
闭包参数 = 类型 标识符
```

```cn
让 加法 = |a, b| a + b;
让 结果 = 加法(3, 4);          // 结果 = 7
```

### 3.2 带类型标注的闭包

```cn
让 乘法 = |整32 a, 整32 b| -> 整32 { a * b };
```

### 3.3 捕获环境变量

```cn
让 x = 10;
让 加x = |y| y + x;              // 不可变捕获
让 结果 = 加x(5);                // 结果 = 15

让 可变 计数 = 0;
让 增加计数 = || 计数 += 1;       // 可变捕获
增加计数();
增加计数();
打印行!("{}", 计数);              // 2
```

### 3.4 移动捕获

```cn
让 数据 = 字符串::从("数据");
让 处理 = 移动 || {
    打印行!("{}", 数据);          // 数据的所有权移动到闭包
};
处理();
// 数据 已失效，不能再使用
```

### 3.5 闭包作为参数

```cn
函数 应用(|整32| -> 整32 操作, 整32 值) -> 整32 {
    操作(值)
}

让 结果 = 应用(|x| x * 2, 5);   // 结果 = 10
```

### 3.6 迭代器适配器中的闭包

```cn
让 数字 = [1, 2, 3, 4, 5];

让 倍数 = 数字.迭代()
    .映射(|x| x * 2)
    .筛选(|x| *x > 5)
    .收集::<列表<整32>>();

让 总和 = 数字.迭代()
    .汇总(|累加, 当前| 累加 + 当前);
```

## 四、错误处理函数

### 4.1 可选值链式调用

```cn
让 用户 = 获取用户(标识);
让 城市 = 用户.并且然后(|u| u.地址).并且然后(|a| a.城市);
// 等价于
让 城市 = 用户?.地址?.城市;
```

### 4.2 结果链式调用

```cn
函数 读取配置(&文 路径) -> 结果<配置, 错误> {
    让 内容 = 文件系统::读取到字符串(路径)?;
    让 配置 = 解析配置(&内容)?;
    返回 正常(配置);
}
```

> **设计决策**：规范总结使用尝试/捕获/抛出/最终（异常体系），统一后采用结果类型 + ?运算符。异常与所有权系统不兼容，尝试/捕获/抛出/最终不保留为关键字。
