## 一、结构体定义

### EBNF

```
结构体定义 = "结构体", 标识符, "{", 字段列表, "}"
字段列表 = 字段声明*
字段声明 = 类型, 标识符
```

### 示例代码

```
结构体 点 {
    浮64 x
    浮64 y
}

结构体 矩形 {
    点 左上角          // 结构体嵌套
    点 右下角
}
```

### 设计决策

- 结构体字段为类型前置声明：`类型 字段名`。
- 结构体是值类型，与类（引用/指针语义）不同（见[06-OOP面向对象.md](06-OOP面向对象.md)）。

## 二、结构体实例化与字段访问

### EBNF

```
结构体实例化 = 标识符, "{", 字段赋值列表, "}"
字段赋值 = 标识符, "=", 表达式
字段访问 = (实例 | 实例指针), ".", 字段名    // 值访问；指针自动解引用一级（v2.1）
```

### 示例代码

```
结构体 点 {
    浮64 x
    浮64 y
}

函数 主() -> 整32 {
    // 实例化
    点 原点 = 点{ x = 0.0, y = 0.0 }
    
    // 字段访问（值访问）
    浮64 横坐标 = 原点.x
    
    // 字段修改
    原点.x = 1.5
    
    // 指针访问（自动解引用一级，≡ (*指针).y）
    点* 指针 = 取地址(原点)
    浮64 纵坐标 = 指针.y         // . 成员访问（v2.1 统一）
    
    返回 0
}
```

### 设计决策

- 实例化使用 `类型{ 字段 = 值 }` 语法（与C++的 `{}` 初始化列表类似，但使用 `=` 而非 `:`）。
- **成员访问统一为 `.`（v2.1，2026-09-03）**：`.` 左侧为指针时自动解引用**一级**（Go 先例，对齐 Rust 无 `->` 的惯例与旧版 Rust 风格 CN）；多级指针（`点**`）不继续解引用，报错。原 `指针->字段` 形式已废除——编译硬错误并附迁移提示「请改用 .」。注意 `->` 记号仍用于函数返回类型与 lambda 返回标注，与成员访问无关。

## 三、枚举定义

### EBNF

```
枚举定义 = "枚举", 标识符, "{", 成员列表, "}"
成员列表 = 成员, [",", 成员]*, [","]
成员 = 标识符 | 标识符, "=", 常量表达式
```

### 3.1 简单枚举

```
枚举 颜色 {
    红,
    绿,
    蓝
}
```

### 3.2 赋值枚举

```
枚举 颜色 {
    红,
    绿,
    蓝,
    自定义 = 100      // 显式赋值，后续成员自动递增
}
```

### 3.3 负数枚举（新增特性）

```
枚举 方向 {
    上 = -1,
    中 = 0,
    下 = 1
}
```

### 设计决策

- **枚举支持负数**：成员值可为负整数常量，扩展了枚举的取值空间（旧版Rust风格枚举不支持负数值，如 `上 = -1` 不可行）。
- 未赋值的成员自动按前一个成员值+1递增（首个成员默认从0开始，与C/C++一致）。
- 枚举成员在IR中降级为整型常量。
