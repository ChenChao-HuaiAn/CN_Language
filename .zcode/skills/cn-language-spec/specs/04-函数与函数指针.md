## 一、函数定义

### EBNF

```
函数定义 = "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
参数列表 = [参数, {",", 参数}]
参数 = 类型, 标识符
返回类型 = 类型 | "空类型"
函数体 = "{", 语句*, "}"
```

### 示例代码

```
函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b
}

函数 打印问候() {
    打印行("你好")
}

函数 主() -> 整32 {
    打印问候()
    返回 0
}
```

### 设计决策

- 无返回值函数省略 `-> 类型`（即 `-> 空类型` 可省略）。
- 参数为类型前置：`类型 参数名`，与C/C++一致。

## 一B、函数重载

### EBNF

```
函数重载 = 多个同名函数, 参数类型/个数不同
```

### 示例代码

```
函数 加(整32 a, 整32 b) -> 整32 { 返回 a + b }
函数 加(浮64 a, 浮64 b) -> 浮64 { 返回 a + b }
函数 加(字符串 a, 字符串 b) -> 字符串 { 返回 a + b }
```

### 设计决策

- 同名函数按**参数类型与个数**区分（重载决议）；仅返回类型不同**不构成重载**。
- 名称修饰（mangling）按签名编码（见基准规格书附录C）。

## 一C、默认参数

### 示例代码

```
函数 问候(字符串 名字 = "世界") -> 空类型 {
    打印行("你好，" + 名字)
}
问候()          // 你好，世界
问候("张三")    // 你好，张三
```

### 设计决策

- 默认参数从右向左连续声明；调用时按位置补缺省实参；默认参数在原型声明中给出（避免重复）。

---

## 一D、lambda 表达式（匿名函数）

### 示例代码

```
自动 加倍 = [](整32 x) -> 整32 { 返回 x * 2 }
整32 结果 = 加倍(21)   // 42
```

### 设计决策

- lambda 支持 `[捕获]`（`[]` 不捕获 / `[=]` 值捕获 / `[&]` 引用捕获 / `[变量]` 显式捕获）。
- 无返回类型标注时由编译器推导（单一 `返回` 表达式或空类型）。

---

## 一E、强制类型转换

### 示例代码

```
浮64 比例 = 浮64(3) / 4        // 显式转浮点
整32 截断 = 整32(3.99)         // 浮点转整（截断）
指针 原始 = 指针(地址)          // 整数转指针
整64 地址 = 整64(指针)          // 指针转整数
```

### 设计决策

- 提供 C 风格构造转换 `类型名(表达式)`，语义同 static_cast/位重解释组合；宽化/窄化/浮整转换/指针↔整数 均显式触发，避免隐式危险转换。

## 一F、引用参数（2026-08，A-1）

### EBNF

```
引用参数 = 类型, "&", 标识符
函数定义含引用 = "函数", 标识符, "(", 参数列表含引用, ")", ["->", 返回类型], 函数体
```

### 规则

- `类型& 参数名`：引用参数（C++ 引用语义）——实参传**左值地址**，参数读取自动解引用、赋值经指针写回调用方（对标 C++ `T&` / Rust `&mut T`）。
- 引用可用于**函数参数**（含泛型 `T&`）、**引用变量**（`整32& r = x`，见一F2）与**函数返回类型 `T&`**（见一F2）；引用默认值仍编译报错。
- 实参须为左值（变量/数组元素/成员）；字面量与临时值报错。
- 支持友元函数引用参数访问私有成员（见 06-十二 友元）。

### 常量 只读引用参数（2026-09-10 plans/019 阶段3 · 编译期安全）

```
函数 求和(常量 向量<整64>& 数据) -> 整64 { ... }
```

- `常量 类型& 名` = **只读借用**（Rust `&T` 对标；C++ `const T&` 同构）。
- 体内对该参数（含经成员访问链）赋值/复合赋值 → 编译错误。
- 传给可变引用形参（`T&`）→ 编译错误（只读借用不能借出可变）。
- 同一调用中某变量的可变引用实参与常量引用实参解析到同一基础变量 →
  编译错误（借用互斥第一版：语句级保守）。

### 示例代码

```
函数 交换(整32& a, 整32& b) -> 空类型 {
    整32 临时 = a
    a = b
    b = 临时
}

泛型 <类型 T>
函数 引用交换(T& a, T& b) -> 空类型 {
    T 临时 = a
    a = b
    b = 临时
}

函数 主() -> 整32 {
    整32 x = 1
    整32 y = 2
    交换(x, y)              // x=2, y=1（写回调用方）
    引用交换<整64>(p, q)     // 泛型引用参数
    返回 0
}
```

### 设计决策

- 引用参数是**指针的语法糖**（IR 层 byRef 机制：参数槽存地址，读取解引用/赋值写回），提供左值传递语义且免去调用方 `&` 书写；与指针参数（`T*`，显式取地址）并存。

## 一F2、引用变量与引用返回（2026-08，P3-18）

### EBNF

```
引用变量声明 = [变量], 类型, "&", 标识符, "=", 左值表达式
引用返回     = "函数", 标识符, "(", 参数列表, ")", "->", 类型, "&", 函数体
左值表达式   = 标识符 | 下标访问 | 解引用 | 成员访问 | 引用返回调用
```

### 规则

- 引用变量 `整32& r = x`：`r` 是变量 `x` 的别名（同一存储），读 `r` 即读 `x`、写 `r` 即写 `x`；须在声明处绑定一个左值初始化器（变量/数组元素/解引用/成员），无初始化器或初始化器非左值报错。P3-18 已实现（e2e 94）。
- 引用返回类型 `函数 获取() -> 整32&`：返回**被引用左值的地址**；`返回` 表达式须为左值（变量/数组元素/解引用/成员/引用返回调用）。调用方可：
  - `整32& r = 获取()` 绑定返回的引用；
  - `获取() = 值` 经返回引用写回；
  - `&获取()` 取得被引用者地址。
- **禁止返回本函数局部变量（含参数）的地址**——该存储随栈帧消亡，形成悬垂引用，编译报错（e2e 103 负向）。
- 全局/静态对象、数组元素、成员字段、外层引用形参可被返回（存活期覆盖调用方使用域）。
- 引用返回类型不参与重载签名（仅返回类型不同不构成重载）。

### 示例代码

```
整32 数据[4] = { 10, 20, 30, 40 }
函数 取元素(整32 下标) -> 整32& {
    返回 数据[下标]
}
函数 主() -> 整32 {
    整32& r = 取元素(1)   // r 是 数据[1] 的别名
    打印(r)               // 20
    取元素(2) = 99        // 经返回引用写回 数据[2]
    打印(数据[2])         // 99
    // 函数 坏() -> 整32& { 整32 局部 = 5; 返回 局部 }   // ❌ 返回局部变量地址
    返回 0
}
```

### 设计决策

- 引用返回与引用变量共用 IR `byRef`/`lvalueAddress` 机制：引用返回类型在 IR 映射为指针（`ptr`），`返回 左值` 生成左值地址作为返回值；调用方持地址读写（零拷贝、可写回）。

## 一G、外部 函数 声明（FFI，2026-08，C-3）

### EBNF

```
外部函数声明 = "外部", "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型]
```

### 规则

- **FFI 最小集**：声明 C 链接外部函数（无函数体，链接期由外部库解析符号）。
- 链接符号 = **函数名本身**（C 符号：无重载 mangling、无模块前缀），故函数名须与 C 符号一致（如 `strlen`/`toupper`/`GetTickCount64`）。
- 声明带函数体编译报错；同名同签名重复声明允许（C 语义）；同名 CN 定义签名须与外部声明一致（外部锁签名）。
- 附加链接库：编译选项 `--链接 <库>`（可多次；ASCII 别名 `--link-lib`）。

### 示例代码

```
外部 函数 strlen(字符串 s) -> 整64
外部 函数 toupper(整32 c) -> 整32
外部 函数 GetTickCount64() -> 正64

函数 主() -> 整32 {
    打印行("长度: ", strlen("中文"))      // 6（UTF-8 字节数）
    打印行("大写: ", toupper(97))        // 65
    返回 0
}
```
> 编译：`cn build 主.cn --链接 user32.lib`（默认链接 libucrt/kernel32/shell32）。

## 二、函数原型声明（前向引用）

### EBNF

```
函数原型声明 = "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], ";"
```

### 示例代码

```
// 前向声明
函数 计算(整32 n) -> 整32

// 先调用后定义（依赖原型声明）
函数 使用() -> 整32 {
    返回 计算(10)
}

// 实际定义
函数 计算(整32 n) -> 整32 {
    返回 n * 2
}
```

### 设计决策

- 语法分析器采用两趟解析：第一趟收集顶层声明，第二趟解析函数体，天然支持前向引用（见编译器架构-语法分析器）。
- 函数原型声明用于模块间/函数间的相互调用。

## 三、递归

### EBNF

```
递归函数 = 函数定义, 函数体内调用自身
```

### 示例代码

```
函数 阶乘(整32 n) -> 整32 {
    如果 n <= 1 {
        返回 1
    }
    返回 n * 阶乘(n - 1)   // 递归调用自身
}

函数 斐波那契(整32 n) -> 整32 {
    如果 n < 2 {
        返回 n
    }
    返回 斐波那契(n - 1) + 斐波那契(n - 2)
}
```

### 设计决策

- 递归依赖函数原型机制，先有声明后有调用。
- 尾递归可被优化器转换为循环（尾调用优化TCO，见编译器架构-优化Pass清单）。

## 四、函数指针（C风格）

### EBNF

```
函数指针声明 = 返回类型, "(*", 标识符, ")", "(", 参数类型列表, ")"
函数指针赋值 = 标识符, "=", 函数名
函数指针调用 = 标识符, "(", 实参列表, ")"
```

### 示例代码

```
// 声明函数指针类型变量
整32(*回调)(整32, 整32)

// 赋值：将函数地址赋给函数指针
回调 = 加

// 调用函数指针
整32 结果 = 回调(10, 20)
```

### 设计决策

- **采用C风格声明语法**：`整32(*回调)(整32, 整32)`，与C/C++函数指针语法保持一致，便于底层编程人员理解。
- 与旧版Rust风格不同：旧版无函数指针概念（Rust使用 `fn` 类型与闭包），新版明确支持C风格函数指针。
- 函数指针用于回调模式、事件分发等场景；IR层通过间接调用指令（`调用 间接`）实现。

### 方法作值（P3-23，2026-08）

**静态方法作值**（既有，e2e 98）：`类名.静态方法` 可直接作函数指针值——静态方法无 `this`，链接符号即裸函数地址。

**实例方法作值**（P3-23 补完，e2e 104/107）：`对象.实例方法` 作值为**绑定 this 的闭包**：
- 经闭包变量调用：`自动 cb = 对象.方法; cb(实参)`——闭包捕获 `this`（对象地址，**引用语义**：之后修改对象状态，闭包读到最新）。
- 每对象独立绑定：`自动 cb2 = 对象2.方法` 与 `cb` 互不干扰。
- **不可直接作裸函数指针实参传递**：fnptr 是裸地址无法携带 this；`助手(对象.方法, 5)` 编译报错（提示先赋值给变量，e2e 107 负向）。

### 设计决策

- 实例方法作值复用 lambda 闭包/捕获机制：编译器合成隐藏匿名函数（捕获对象地址 + 用户参数），闭包变量调用时展开捕获实参（与 lambda `[&]` 捕获同路径）。
- 绑定是"引用捕获"：捕获的是对象地址而非快照，调用时始终读对象当前状态。

## 五、内置构造器（正常/错误/某些/转移）

### EBNF

```
内置构造器 = "正常", "(", 表达式, ")"       // 构造结果<T,E>的正常值
            | "错误", "(", 错误码, ")"      // 构造结果<T,E>的错误值
            | "某些", "(", 表达式, ")"      // 构造可选<T>的有值
            | "转移", "(", 变量, ")"        // 所有权转移（2026-09-10 plans/019 阶段1）
```

### 示例代码

```
函数 除法(整32 a, 整32 b) -> 结果<整32, 整32> {
    如果 b == 0 {
        返回 错误(1)   // 构造错误值，错误码1: 除零
    }
    返回 正常(a / b)   // 构造正常值
}

函数 查找(整32 键) -> 可选<整32> {
    如果 表.包含(键) {
        返回 某些(表[键])  // 构造有值
    }
    返回 无              // 返回无（空可选）
}
```

### 转移()：显式所有权转移（2026-09-10 plans/019 阶段1 · 编译期安全）

```
变量 v = 向量<整64>();
变量 u = 转移(v);        // u 接管 v 的值，v 进入「已转移」状态
打印行(v.大小());        // ✗ 编译错误：'v' 已转移，不能继续使用
```

- **实参须为变量标识符**（成员/下标/解引用形态报错「转移目标须为变量」）。
- **实参类型须为资源语义类型**（指针/字符串/容器/类对象/结构体/结果/可选）；
  标量（整数/浮点/布尔/字符）拒绝——复制语义无转移意义（Rust Copy 类型惯例，
  诊断「'X' 具有复制语义，无需转移」）。
- 求值结果=实参的值（交接）；**源变量自该点起任何使用均为编译错误**
  （读值/赋值目标/复合赋值/自增自减/取地址/解引用/成员与下标对象侧/调用实参/
  返回/再次转移，对标 Rust E0382），诊断含转移点定位。
- 已转移状态不因作用域退出恢复；内层同名新声明是新变量（遮蔽语义不受影响）。
- 第一版运行行为零变更（语义层 AST 改写；指针即值天然零拷贝，容器/类仍按拷贝语义，
  浅转移优化随 plans/019 阶段3）。C++ `std::move` 同构。
- 安全保证=编译期拦截「转移后使用」（UAF 主形态）与「转移后再释放」（双释放主形态）。

### 重要身份说明

- `正常()`、`错误()`、`某些()`、`转移()` 为**内置构造器函数**，由编译器预置符号表。
- 它们**不是保留关键字**，但用户不可重定义（预置符号表独占）。
- 详细规则见 [07-错误处理.md](07-错误处理.md)。
