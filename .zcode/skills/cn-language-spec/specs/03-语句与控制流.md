## 零、语句终止与续行

> **核心事实（2026-09-04 方案B 反转，plans/015 用户裁决）：CN 语言的语句必须以分号 `;` 终结（Rust/C++ 同款「表达式语句必须 `;`」模型）。换行（`\n`/`\r`）在词法层仍与空格、Tab 一样被当作空白直接跳过，不产生换行 token——换行在表达式**内部**仍无语法意义（续行不受影响），但**不再是语句边界**；语句边界唯一由强制分号标记，行尾与下行行首词法可拼导致的静默粘连事故链就此结构性根除。**

### 三层机制

| 层 | 行为 | 判定位置 |
|----|------|---------|
| 词法层 | 换行 `\n`/`\r` 与空格、Tab 完全当作空白跳过，不产生换行 token（表达式内部续行天然支持） | 词法分析器 |
| 语法层 | 分号 `;` 是**强制**终止符：语句解析完成后必须消费 `;`——缺失即报错「语句缺少分号 ';'」（错误即诊断，杜绝静默粘连），诊断后继续解析保证一次编译报全量位置 | 语法分析器 `consumeSemicolon()` |
| 边界识别 | 语句边界=分号；`}` 自终结（块/如果/当/循环/函数体/结构体/类/接口/枚举体后**不加**分号） | 语法分析器 `parseStmt()` |

### EBNF

```
语句 = 表达式语句 | 声明语句 | 返回语句 | 中断语句 | 继续语句
      ";"                              // 分号强制（语句终结符）
控制流语句 = 如果语句 | 当语句 | 循环语句 | 遍历语句 | 选择语句      // 块体 } 自终结，不加分号
```

### 规则1：语句终止（强制分号）

- 语句**必须**以分号 `;` 终结：变量声明、赋值、自增自减、复合赋值、表达式语句、返回、中断、继续、顶层常量与静态声明、导入语句 均须 `;`
- `}` 自终结：块/如果/当/循环/选择体、函数体、结构体/类/接口/枚举体后**不加**分号（`}` 即边界）
- 行内块 `{ x = 1; }` 内部语句同样须 `;`
- 缺失分号是**编译错误**（含行列定位的诊断），不再依赖关键字边界推断

### 规则2：续行（换行≡空格，表达式内部天然续行）

- 换行无语法意义，**表达式内部任何位置换行都天然续行**，不存在"括号未闭合才可续行"的限制
- 括号 `()`/`[]`/`{}` 未闭合时跨行是**结构上安全**的（函数调用参数、下标、表达式分组天然粘合）
- 语句已由分号终结，跨行表达式建议二元运算符留在**行尾**（`a +` 换行 `b;`）

> ⚠️ **注意：行首运算符仍会被并入上一行**（表达式内部换行≡空白）：`变量 a = 1 +` 换行 `2;` 与 `变量 a = 1 + 2;` 等价。若在**语句终结后**行首出现运算符（如上行缺分号），解析器会在语句终结处报「语句缺少分号」而非静默粘连。

### 规则3：单行多语句（分号分隔）

- 单行多语句由 `;` 分隔：`变量 i = 0; ++i; --i;` 合法
- 每条语句独立终结，行内最后一条语句同样须 `;`

### 规则4：空语句与空循环体（裸分号非法）

- 裸 `;` 作为空语句**不合法**（报"预期表达式"），CN 语言没有空语句
- `当(x);` 是**语法错误**（循环体强制要求 `{`），合法空循环体写 `当(x) { }`（空块合法）
- 循环头 `循环(整32 j = 0; j < 10; j++)` 中的分号是**三段分隔符**（与语句终结符语义无关，保持不变）

### 规则5：模块级声明的分号（2026-09-04 plans/015 裁决）

- 导入语句：`导入 路径;`（对齐 Rust `use ...;`）
- 顶层常量/静态声明：`常量 T = 2;` / `静态 类型 名 = 值;`（对齐 C++ `const`/`static` 声明）
- 枚举声明、结构体/类/接口体：`}` 自终结，**不加分号**

### 示例代码

```
变量 a = 1;        // 分号强制（缺失报错）
变量 b = 2; 整32 c = 3;   // 单行多语句：分号分隔

变量 i = 0; ++i; --i;    // 单行多语句

// 跨行书写长表达式：二元运算符留在行尾（表达式内部换行≡空白，续行不受影响）
变量 总和 = a +
           b +
           c;

当(x) { }        // 合法：空循环体（空块）
// 当(x);        // ❌ 语法错误：循环体强制要求 {
// ;             // ❌ 错误：空语句非法（预期表达式）
// 变量 d = 4    // ❌ 错误：语句缺少分号 ';'

循环(整32 j = 0; j < 10; j++) {   // 循环头分号是三段分隔符（与语句终结无关）
    打印行(j);
}
```

### 设计决策

- **强制分号（2026-09-04 plans/015 方案B 反转，用户裁决）**：原「可选分号+关键字边界」模型下行尾与下行行首词法可拼时解析器无从知晓两条语句意图，只能靠检查器事后拦截（实测多起静默粘连事故）；改为 Rust 式强制分号后，块截断静默家族整体消亡（孤儿 token 即缺分号诊断）。循环头分号保持三段分隔符语义。
- **换行仍无语法意义**：词法层将换行当作空白跳过不变——表达式内部续行天然支持（运算符悬挂行尾写法不受影响）；变化仅在语句边界必须显式分号（见[01a-词法结构-总览与关键字.md](01a-词法结构-总览与关键字.md) 第三节）。
- **单行多语句由分号分隔**：每条语句独立终结。

## 一、变量声明（类型前置）

### EBNF

```
变量声明 = "变量", 标识符, "=", 表达式                // 类型推断
          | 类型, 标识符, "=", 表达式                // 显式类型
          | "常量", 标识符, "=", 表达式              // 常量
          | "静态", 类型, 标识符, "=", 表达式        // 静态变量
```

### 示例代码

```
变量 x = 10              // 类型推断（推断为整数/整32）;
整数 y = 20              // 显式类型（默认类型别名）;
整32 z = 30              // 位宽类型;
常量 PI = 3.14; // 常量（不可修改）;
静态 整32 计数 = 0; // 静态变量（生命周期贯穿整个程序）;
```

### 设计决策

- **类型前置**：类型写在变量名之前（`类型 变量名`），与C/C++一致，区别于Rust的后置类型标注（`变量名: 类型`）。
- `变量` 关键字用于类型推断场景，显式类型场景直接写类型名。
- 常量使用 `常量` 关键字声明，初始化后不可修改。

## 二、函数定义

### EBNF

```
函数定义 = "函数", 标识符, "(", 参数列表, ")", ["->", 返回类型], 函数体
参数列表 = [参数, {",", 参数}]
参数 = 类型, 标识符
返回类型 = 类型 | "空类型"
函数体 = "{", 语句*, "}"
```

### 示例代码

```
函数 加(整32 a, 整32 b) -> 整32 {
    返回 a + b;
}

// 无返回值时省略 -> 类型
函数 打印问候() {
    打印行("你好");
}

// 函数原型声明（前向引用）
函数 计算(整32 n) -> 整32;
```

### 设计决策

- 无返回值函数省略 `-> 类型`，即 `-> 空类型` 可省略。
- 函数原型声明（前向引用）支持两个文件/同文件内的前向调用（见[04-函数与函数指针.md](04-函数与函数指针.md)）。

## 三、控制流

### 3.1 条件语句（如果/否则如果/否则）

#### EBNF

```
条件语句 = "如果", "(", 条件表达式, ")", 代码块
          ["否则 如果", "(", 条件表达式, ")", 代码块]*
          ["否则", 代码块]
条件表达式 = 表达式（结果为布尔）
代码块 = "{", 语句*, "}"
```

#### 示例代码

```
如果 x > 0 {
    打印行("正数");
} 否则 如果 x < 0 {
    打印行("负数");
} 否则 {
    打印行("零");
}
```

### 3.2 当循环（while风格）

#### EBNF

```
当循环 = "当", "(", 条件表达式, ")", 代码块
```

#### 示例代码

```
整数 i = 0;
当 i < 10 {
    打印行(i);
    i++;
}
```

### 3.3 循环（for风格）

#### EBNF

```
循环语句 = "循环", "(", 初始化表达式, ";", 条件表达式, ";", 更新表达式, ")", 代码块
```

#### 示例代码

```
循环 (整32 j = 0; j < 10; j++) {
    打印行(j);
}
```

### 3.3B 遍历...中每个 迭代语句（range-for，2026-08，C-2）

对标 C++ range-for / Python for-in：遍历 容器 逐元素迭代。

#### EBNF

```
迭代语句 = "遍历", 迭代对象, "中", "每个", 标识符, 语句
迭代对象 = 名称式表达式                    // 变量/自身/父类/成员/下标；函数调用等由语义层拒绝
```

#### 支持形态

| 迭代对象 | 降级语义 | 元素 |
|---------|---------|------|
| 数组 `T[N]` | 编译期长度，`容器[索引]` 下标遍历 | T |
| 类容器（如 `向量<T>`） | `容器.大小()` + `容器.元素(整64)` 方法调用遍历 | 元素() 返回类型 |

#### 示例代码

```
整32[5] 数据 = { 10, 20, 30, 40, 50 };
遍历 数据 中 每个 x {
    打印行(x);
}

向量<整32> 数表 = 向量<整32>();
遍历 数表 中 每个 v {
    打印行(v);
}
```

#### 规则

- 循环变量为**值拷贝**（每轮迭代新值），作用域限循环体；支持 中断/继续；
- 迭代对象须为名称式（变量/自身/父类/成员/下标）；函数调用等临时值暂不支持（先赋局部变量）；
- 类容器须提供 `大小() -> 整64` 与 `元素(整64) -> T` 方法（与 向量<T> 同形态），缺失编译报错；
- `遍历`/`中`/`每个` 为**上下文关键字**（仅"遍历 迭代对象 中 每个 变量名"形态触发，不占保留字）。

### 3.4 选择语句（switch风格）

#### EBNF

```
选择语句 = "选择", "(", 表达式, ")", "{", 分支列表, "}"
分支 = "情况", 情况值列表, ":", 语句* | "默认", ":", 语句*
情况值列表 = 情况值, {",", 情况值}        // C-4：多值分组（等价多个连续标签）
情况值 = 整型/字符常量 | 字符串字面量 | 枚举引用 | 裸枚举成员名
```

#### 支持的值形态（C-4，2026-08）

| 形态 | 示例 | 说明 |
|------|------|------|
| 整型/字符常量 | `情况 1:` `情况 'A':` | 基本形态 |
| **字符串字面量** | `情况 "开始":` | **字符串选择**：`选择(字符串表达式)`，按字符串相等匹配（运行时比较） |
| 枚举引用 | `情况 颜色.红:` | 限定枚举成员（值=成员整数值） |
| **裸枚举成员名** | `情况 红:` | 按 `选择` 条件表达式类型定向解析（条件须为枚举类型） |
| **多值分组** | `情况 0, 1, 2:` | 等价连续标签，任一命中即进入该组体（前序标签体为空自动落入） |

#### 示例代码

```
选择(值) {
    情况 1:
        打印行("一");
        中断;
    情况 2:
        打印行("二");
        中断;
    默认:
        打印行("其他");
}

// 字符串选择 + 多值分组
字符串 命令 = "开始";
选择 (命令) {
    情况 "开始", "继续":
        打印行("执行");
        中断;
    默认:
        打印行("未知命令");
}

// 裸枚举成员名（条件为枚举类型时）
枚举 颜色 { 红, 绿, 蓝 }
颜色 c = 颜色.蓝;
选择 (c) {
    情况 红:
        打印行("红色");
        中断;
    情况 蓝:
        打印行("蓝色");
        中断;
}
```

#### 一致性约束（C-4）

- 字符串情况值仅用于字符串选择（`选择` 条件为 `字符串`），反之整型/枚举情况值不可用于字符串选择；
- 裸枚举成员名仅用于枚举选择，且成员须存在于条件枚举类型；
- 同组/跨组情况值重复编译报错。

### 3.5 中断与继续

#### EBNF

```
中断语句 = "中断"
继续语句 = "继续"
```

#### 示例代码

```
循环 (整32 k = 0; k < 100; k++) {
    如果 k % 2 == 0 {
        继续          // 跳过偶数;
    }
    如果 k > 50 {
        中断          // 超过50跳出循环;
    }
    打印行(k);
}
```

### 设计决策

- **`中断` 绑定最近进入的选择或循环**（用户裁决 2026-09-11 方案B·C 语义）：`中断` 跳出**最近进入**的一层 选择 或 循环（谁近绑谁，与 C 的 `break` 一致）——循环内选择体写 `中断` 只跳出该选择、循环继续下一轮；从选择内跳出外层循环无直接语法（与 C 相同，须经由条件变量或重构）。`继续` 仅对循环有意义（选择体内的 `继续` 绑定最近循环，与 C 一致）。
- 选择语句 **fall-through 与 C 语言一致**（用户裁决 2026-08）：分支体不写 `中断`/`返回` 时自动贯穿到下一分支；须显式 `中断` 跳出（多值分组 `情况 0, 1:` 的前序标签体为空即利用贯穿落入组体）。
- `选择`/`情况`/`默认`/`中断` 替代Rust风格的 `匹配`/`跳出`（见[SKILL.md](../SKILL.md)差异表）。
- 密集选择语句在优化阶段生成跳转表（见编译器架构-优化器）。

## 三b、模块级可见性（默认私有，v2.0）

> **v2.0 变更**：模块级顶层声明（函数/结构体/枚举/类/接口/常量/静态/全局变量）**默认私有**——文件顶部无任何 `公开:` 标签时，声明仅本模块内可见。显式 `公开:` 标签声明公共 API（可被其他模块导入使用）。

### EBNF

```
可见性标签 = "公开:" | "私有:"
可见性段 = 标签, 声明*          // 无标签段 → 默认私有
```

### 示例代码

```
// 网络.cn
公开:
    函数 连接() -> 空类型 { }   // 模块公开：可被导入

    函数 内部辅助() -> 整32 {    // 无标签（私有段内）→ 私有
        返回 0;
    }

函数 默认私有() { }              // 文件顶部无标签 → 默认私有
```

### 设计决策

- **默认私有**（v2.0 变更，原默认公开）：信息隐藏最佳实践——公共 API 必须显式 `公开:` 声明，避免意外暴露。标准库模块文件顶部须显式 `公开:` 以导出 API。
- 模块级可见性与类内可见性**取交集（最严格）**，见[08-模块系统.md](08-模块系统.md) 第四节「可见性交集规则」。
