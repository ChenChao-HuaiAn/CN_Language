## 一、错误处理设计总览

### EBNF

```
错误处理 = 结果类型 | 可选类型
结果类型 = "结果", "<", 正常类型, ",", 错误类型, ">"
可选类型 = "可选", "<", 类型, ">"
```

### 设计决策

- **错误码+可选值**（决策6）：替代异常机制，去掉异常关键字（尝试/捕获/抛出/最终）。
- **错误传播运算符（2026-08，C-1）**：后缀 `表达式?`（Rust `?` 同语义）——操作数为 `结果<T,E>`/`可选<T>` 时提取其值，失败则构造错误结果并**从当前函数返回**（传播语义）。与显式检查 `.正常`/`.有值` 两条路径并存：显式检查适合就地处理；`?` 适合沿调用链上抛。

---

## 一B、错误传播运算符 表达式?（2026-08，C-1）

### EBNF

```
错误传播 = 后缀表达式, "?"
```

### 规则

- 操作数须为 `结果<T,E>` 或 `可选<T>` 类型；其他类型编译报错。
- **结果<T,E> 传播**：正常（.正常==真）→ 表达式值为 T（.值）；失败 → 构造 `结果{正常=假, 错误=E}` 并从当前函数返回（沿调用链上抛）。
- **可选<T> 传播**：有值 → 表达式值为 T；无值 → 构造 `可选{有值=假}` 并从当前函数返回。
- 当前函数返回类型须兼容：结果→结果（**值类型 T 精确一致**、错误类型 E 可转换）、可选→可选（T 一致）；否则编译报错。
- 后缀优先级最高（与 `++`/`--` 同级）：`x? + 1` 读作 `(x?) + 1`。
- `?` 与三元运算符 `条件?真值:假值` 的区分：`?` 后跟表达式起点为三元；否则为后缀传播。

### 示例代码

```
函数 安全除法(整32 a, 整32 b) -> 结果<整32, 整32> {
    如果 b == 0 {
        返回 错误(1)   // 错误码1: 除零错误
    }
    返回 正常(a / b)
}

// 传播：正常取 .值，失败沿调用链上抛（Rust ? 语义）
函数 除法传播(整32 a, 整32 b) -> 结果<整32, 整32> {
    整32 商 = 安全除法(a, b)?   // 除零时直接返回 错误(1)
    返回 正常(商)
}

函数 主() -> 整32 {
    结果<整32, 整32> r = 除法传播(10, 0)
    如果 r.正常 {
        返回 r.值
    }
    打印行("除零错误码: ", r.错误)   // 除零错误码: 1
    返回 1
}
```

### 设计决策

- **对标 Rust `?` 与 C++23 std::expected 传播**：嵌套调用（读文件→解析→取数）免去逐层 if 分支；与 3 条强制检查规则并存（`?` 本身即"检查"）。

## 二、结果<T,E>类型

### EBNF

```
结果构造 = "正常", "(", 正常值表达式, ")"
          | "错误", "(", 错误码表达式, ")"
结果检查 = 结果变量, ".正常"        // 布尔：是否正常
结果取值 = 结果变量, ".值"          // 正常值（需先检查）
错误取值 = 结果变量, ".错误"        // 错误码（需先检查）
```

### 示例代码

```
函数 除法(整32 a, 整32 b) -> 结果<整32, 整32> {
    如果 b == 0 {
        返回 错误(1)   // 错误码1: 除零错误
    }
    返回 正常(a / b)
}

// 使用结果类型
除法结果 = 除法(10, 0)
如果 除法结果.正常 {
    打印行(除法结果.值)       // 访问正常值
} 否则 {
    打印行("除零错误: ", 除法结果.错误)  // 访问错误码
}
```

### 错误码约定（附录B）

| 错误码 | 含义 |
|--------|------|
| 1 | 除零错误 |
| 2 | 数组越界 |
| 3 | 空指针解引用 |
| 4 | 内存分配失败 |
| 5 | 文件打开失败 |
| 6 | 无效参数 |
| 7 | 资源未初始化 |
| 8 | 溢出错误 |

## 三、可选<T>类型

### EBNF

```
可选构造 = "某些", "(", 值表达式, ")"      // 有值
          | "无"                           // 无值
可选检查 = 可选变量, ".有值"                // 布尔：是否有值
可选取值 = 可选变量, ".值"                  // 值（需先检查有值）
```

### 示例代码

```
函数 查找(整32 键) -> 可选<整32> {
    如果 表.包含(键) {
        返回 某些(表[键])
    }
    返回 无
}

// 使用可选类型
查找结果 = 查找(42)
如果 查找结果.有值 {
    打印行("找到: ", 查找结果.值)
} 否则 {
    打印行("未找到")
}
```

### 设计决策

- `无` 关键字同时是空值常量（对应C++的nullptr），用于构造空可选。
- 可选类型没有 `.错误` 成员，只有 `.有值` 与 `.值`。

## 四、强制检查规则（3条）

| 规则 | 描述 | 编译诊断 |
|------|------|---------|
| 规则1 | `结果<T,E>` 类型的返回值如果不被检查就丢弃 | **错误** |
| 规则2 | 检查 `结果.正常` 后未处理错误分支 | **警告** |
| 规则3 | `可选<T>` 类型的值在访问 `.值` 前必须检查 `.有值` | **错误** |

### 示例代码（合规与违规）

```
// ✅ 合规：检查正常后处理两个分支
除法结果 = 除法(10, 2)
如果 除法结果.正常 {
    打印行(除法结果.值)
} 否则 {
    打印行("错误: ", 除法结果.错误)
}

// ❌ 违规（规则1）：结果被丢弃未检查
除法(10, 2)

// ❌ 违规（规则2）：检查正常后未处理错误分支
如果 除法结果.正常 {
    打印行(除法结果.值)
}

// ❌ 违规（规则3）：未检查.有值直接访问.值
打印行(查找结果.值)
```

### 设计决策

- 规则1与规则3为**错误**（编译失败），规则2为**警告**（可编译但提示）。
- 由语义分析器阶段3的错误码传播分析模块实现（错误码分析模块ErrorAnalysis）。

## 五、内置构造器函数

### 身份说明

- `正常()`、`错误()`、`某些()` 为**内置构造器函数**，由编译器预置符号表。
- **不是保留关键字**，但用户不可重定义。

| 构造器 | 用途 | 所属类型 |
|--------|------|---------|
| `正常(值)` | 构造正常值 | 结果<T,E> |
| `错误(错误码)` | 构造错误值 | 结果<T,E> |
| `某些(值)` | 构造有值 | 可选<T> |
| `无` | 空值/空可选 | 可选<T> |

### 示例代码

```
函数 打开文件(字符串 路径) -> 结果<字符串, 整32> {
    如果 文件不存在(路径) {
        返回 错误(5)     // 错误码5: 文件打开失败
    }
    返回 正常(路径)
}

函数 查找用户(整32 id) -> 可选<字符串> {
    用户 = 数据库.查询(id)
    如果 用户.有值 {
        返回 某些(用户.值)
    }
    返回 无
}
```

## 五A、守卫传导完整规则清单

> 任务 1642 条文（第162反思⑤/审计①·与双侧实现对读一致；规则3 执法=045b·E2E 598/599~602/1524/1525/944 锁面）

### 定义

**守卫**：条件位上形如 `X.正常`/`X.有值` 的成员布尔直判（含其取反与短路组合）。
守卫为真时，编译器对相应变量授予「已检查」语境——该语境覆盖范围内访问 `X.值`
（结果款还有 `X.错误`）合法；范围外访问=**编译错误**（规则3 错误级）。

### 规则清单

1. **守卫识别三形态**（条件位识别·与写法形态一一对应）：
   - **纯守卫**：`如果 (r.正常) { … }` / `如果 (x.有值) { … }`；
   - **取反**：逻辑非包成员——`如果 (!r.正常) { 错误侧 } 否则 { 正常侧 }`；
   - **短路**：`且` 左操作数为守卫时向右传导——`如果 (甲.有值 && 甲.值 > 0)`；
     多守卫链 `甲.有值 && 乙.有值 && 甲.值 > 0 && 乙.值 > 0` 各自成立；
     `或` 左取反同判据——`如果 (!甲.有值 || 甲.值 > 0)`（左假=甲有值 → 右侧合法）。
2. **取反两支互换**：`!r.正常` 的**真块=错误语境**（可访问 `.错误`）、**否则块=
   正常语境**（可访问 `.值`）；可选取反同理（`!x.有值` 真块=无值语境、否则=有值
   语境）。非取反守卫的真块=正常/有值语境。
3. **传导范围**：真语境标传导至①条件中短路右侧（`&&` 右操作数）②真块；
   **否则块**（非取反形态）不授予正常语境（规则2 对其告警）；嵌套 `否则如果`
   支=独立如果，按其自身条件重新识别。
4. **清标与失效**：离开授予语境的分支块即清（语境不出块）；守卫后对同一变量
   **重新赋值=守卫失效**（重赋值引入未检查新值，再访问 `.值`=错误·E2E 944）；
   语境不跨函数边界。
5. **早退模式**：`如果 (!x.正常) { 返回 …; }` 之后同函数内裸访问 `x.值` **合法**
   （早退=错误路径已截断·守卫增强规则②）——仅当守卫块以 `返回`/`中断`/`继续`
   等不落回语句结束时成立。
6. **违规分级**：未守卫即访问 `.值`/`.错误`=**错误**（规则3·实现不得降级为警告）；
   检查 `.正常` 后未处理错误分支（无否则且非早退）=**警告**（规则2·不进诊断计数）。
7. **结果与可选不跨族**：`.正常` 守卫只授予 `.值`/`.错误`（结果族）；`.有值` 守卫
   只授予 `.值`（可选族）；守卫与被访问成员须同一变量。

### 示例代码

```
结果<整32, 字符串> r = 造();
如果 (r.正常 && r.值 > 0) {          // 短路守卫：右侧与真块合法
    打印行(r.值);
} 否则 {
    打印行("失败: ", r.错误);         // 否则块访问 .错误 合法（规则1 取反互换的对称面：
}                                     //   非取反守卫的否则块授予错误语境）
```

> 注：非取反守卫的否则块授予**错误语境**（可访问 `.错误`、不可访问 `.值`）——
> 与取反形态「否则=正常语境」恰好互补，两支语义恒互斥。

```
如果 (!x.有值) {
    返回;
}
打印行(x.值);                          // ✅ 早退模式（规则5）

y = 某些(1);
如果 (y.有值) { 打印行(y.值); }
y = 某些(2);
打印行(y.值);                          // ❌ 编译错误：重赋值守卫失效（规则4·E2E 944 同款）
```

### 设计决策

- 规则曾在双侧实现中分批落点（宿主 trackIfCheck/574-a → v2 检查如果重构=045b
  守卫识别先行），本清单即双侧已一致的**合并快照**：以后任一侧改动以本清单
  为对读基准，漂移=分叉缺陷。
- 「重赋值失效」防的是「已检查」标记误留导致漏报（漏报比误报危险——安全检查
  面宁误报不漏报）。

## 五B、合成体载荷转换细则

> 任务 1642 条文（第161审计②·与双侧实现对读一致；#1588/1591 立法面·E2E 1531/1532/1572 锁面）

### 规则

- **族匹配**：`正常`/`错误` 只能用于 `结果<T,E>` 目标、`某些` 只能用于 `可选<T>`
  目标；族不符=编译错误（如 `'正常' 不能用于目标 '可选$整64'（正常/错误 须用于
  结果，某些 须用于 可选）`）。
- **目标语境**（构造器按「目标类型」校准载荷——语境决定目标）：
  - **直接语境**：声明初始化位（`可选<整64> 甲 = 某些(7);`）、静态声明位、
    赋值位（标识符/字段/数组元素/下标链左值 `乙 = 某些(7);`）、返回位
    （`返回 某些(7);`）；
  - **间接语境**：调用实参位——构造器作另一构造器实参时按**外层构造器的载荷**
    重查（`某些(正常(1))` 内层按 `结果<...>` 载荷语境）；普通调用实参按形参
    类型语境/自然推导；容器元素位按元素类型（`表.追加(正常(31))` 按载荷 T 校准）。
  - 三元条件 `条件 ? 某些(1) : 某些(2)` 双分支均为构造器调用时，源按目标同型
    物化（分支与目标同型由语义保证）。
- **载荷兼容检查**：实参类型 → 目标载荷类型（`正常`/`某些` → T；`错误` → E）
  须可转换——允许：结果/可选递归同构、结构体同型、用户类同型/类→接口上行、
  枚举↔整数、`字符*`↔`字符串`、指针/空类型*；数值族按既有转换判据（窄化/
  混合符号等既有规则照常生效）。不可转=编译错误，诊断指明实参类型、目标合成名
  与载荷类型（`内置构造器 '某些' 实参无法将 '整32' 隐式转换为目标 '可选$字符串'
  的载荷类型 '字符串'`）。
- **泛型形参豁免**：载荷或实参为类型形参名（模板态、单态化前无具体类型）时
  不按具体类型判——单态化后再按实例类型全检。
- **推断声明**：`变量 甲 = 某些(5);` 按构造器自然类型推断为 `可选<整32>`；
  推断声明链与显式声明载荷链同规。

### 示例代码

```
可选<整64> 乙;
乙 = 某些(7);                          // ✅ 赋值位直接语境

可选<字符串> 甲 = 某些(7);             // ❌ 编译错误：整32 → 字符串 载荷不可转
结果<整32, 字符串> 果 = 错误(7);       // ❌ 编译错误：错误侧载荷=字符串，整32 不可转
可选<整64> 丁 = 正常(7);               // ❌ 编译错误：族不符（正常 须用于 结果）

向量<结果<整32, 整32>> 表;
表.追加(正常(31));                     // ✅ 元素位间接语境：按载荷 整32 校准
```

### 设计决策

- 「构造器产物类型=目标类型」是校准模型的核心（非「按实参自然类型构造再转换」）
  ——声明/赋值/返回/实参四语境全走同一目标栈语义（宿主构造器目标上下文压栈
  与 v2 语境设置/恢复单点同构）。
- 载荷兼容矩阵与 [02-类型系统.md](02-类型系统.md) 第七节隐式转换表同源，
  构造器位不引入第二套转换规则（防「构造器位特别宽」的静默错值通道·#1588 根治面）。

## 六、类型降级约定（IR层面）

- `结果<正常, 错误>` 降级为 `结构体 { 布尔 是否正常; 联合体 { 正常类型 值; 错误类型 错误值 } }`
- `可选<类型>` 降级为 `结构体 { 布尔 是否某些; 类型 值 }`
- 检查成员 `.正常`/`.某些` 对应结构体首字段读取，未检查即访问 `.值` 由语义分析器在阶段3提前拦截

## 入口函数返回 结果 的退出码（2026-09-16·246-a）

- `主` 返回 `结果<整32, E>`：正常 → 退出码 `.值`（截断 int）；错误 → 退出码 `.错误` 码（与运行时错误码同一契约·Rust Termination 同构）
- 实现方式：编译器自动合成整32 包装入口；其他聚合类型暂不支持（编译期诊断）
