## 三、语句终止与续行

> **核心事实（2026-09-04 方案B 反转，plans/015 用户裁决）：CN 语言的语句必须以分号 `;` 终结（Rust/C++ 同款「表达式语句必须 `;`」模型）。换行（`\n`/`\r`）在词法层仍与空格、Tab 一样被当作空白直接跳过，不产生换行 token——换行在表达式**内部**仍无语法意义（续行不受影响），但**不再是语句边界**；语句边界唯一由强制分号标记，行尾与下行行首词法可拼导致的静默粘连事故链就此结构性根除。**

### 三层机制

| 层 | 行为 | 判定位置 |
|----|------|---------|
| 词法层 | 换行 `\n`/`\r` 与空格、Tab 完全当作空白跳过，不产生换行 token（表达式内部续行天然支持） | 词法分析器 |
| 语法层 | 分号 `;` 是**强制**终止符：语句解析完成后必须消费 `;`——缺失即报错「语句缺少分号 ';'」（错误即诊断，杜绝静默粘连），诊断后继续解析保证一次编译报全量位置 | 语法分析器 `consumeSemicolon()` |
| 边界识别 | 语句边界=分号；`}` 自终结（块/如果/当/循环/函数体/结构体/类/接口/枚举体后**不加**分号） | 语法分析器 `parseStmt()` |

### EBNF

```
语句 = 表达式语句 | 声明语句 | 返回语句 | 中断语句 | 继续语句
      ";"                              // 分号强制（语句终结符）
控制流语句 = 如果语句 | 当语句 | 循环语句 | 遍历语句 | 选择语句      // 块体 } 自终结，不加分号
```

### 规则1：语句终止（强制分号）

- 语句**必须**以分号 `;` 终结：变量声明、赋值、自增自减、复合赋值、表达式语句、返回、中断、继续、顶层常量与静态声明、导入语句 均须 `;`
- `}` 自终结：块/如果/当/循环/选择体、函数体、结构体/类/接口/枚举体后**不加**分号（`}` 即边界）
- 行内块 `{ x = 1; }` 内部语句同样须 `;`
- 缺失分号是**编译错误**（含行列定位的诊断），不再依赖关键字边界推断

### 规则2：续行（换行≡空格，表达式内部天然续行）

- 换行无语法意义，**表达式内部任何位置换行都天然续行**，不存在"括号未闭合才可续行"的限制
- 括号 `()`/`[]`/`{}` 未闭合时跨行是**结构上安全**的（函数调用参数、下标、表达式分组天然粘合）
- 语句已由分号终结，跨行表达式建议二元运算符留在**行尾**（`a +` 换行 `b;`）

> ⚠️ **注意：行首运算符仍会被并入上一行**（表达式内部换行≡空白）：`变量 a = 1 +` 换行 `2;` 与 `变量 a = 1 + 2;` 等价。若在**语句终结后**行首出现运算符（如上行缺分号），解析器会在语句终结处报「语句缺少分号」而非静默粘连。

### 规则3：单行多语句（分号分隔）

- 单行多语句由 `;` 分隔：`变量 i = 0; ++i; --i;` 合法
- 每条语句独立终结，行内最后一条语句同样须 `;`

### 规则4：空语句与空循环体（裸分号非法）

- 裸 `;` 作为空语句**不合法**（报"预期表达式"），CN 语言没有空语句
- `当(x);` 是**语法错误**（循环体强制要求 `{`），合法空循环体写 `当(x) { }`（空块合法）
- 循环头 `循环(整32 j = 0; j < 10; j++)` 中的分号是**三段分隔符**（与语句终结符语义无关，保持不变）

### 规则5：模块级声明的分号（2026-09-04 plans/015 裁决）

- 导入语句：`导入 路径;`（对齐 Rust `use ...;`）
- 顶层常量/静态声明：`常量 T = 2;` / `静态 类型 名 = 值;`（对齐 C++ `const`/`static` 声明）
- 枚举声明、结构体/类/接口体：`}` 自终结，**不加分号**

### 示例代码

```
变量 a = 1;        // 分号强制（缺失报错）
变量 b = 2; 整32 c = 3;   // 单行多语句：分号分隔

变量 i = 0; ++i; --i;    // 单行多语句

// 跨行书写长表达式：二元运算符留在行尾（表达式内部换行≡空白，续行不受影响）
变量 总和 = a +
           b +
           c;

当(x) { }        // 合法：空循环体（空块）
// 当(x);        // ❌ 语法错误：循环体强制要求 {
// ;             // ❌ 错误：空语句非法（预期表达式）
// 变量 d = 4    // ❌ 错误：语句缺少分号 ';'

循环(整32 j = 0; j < 10; j++) {   // 循环头分号是三段分隔符（与语句终结无关）
    打印行(j);
}
```

### 设计决策

- **强制分号（2026-09-04 plans/015 方案B 反转，用户裁决）**：原「可选分号+关键字边界」模型下行尾与下行行首词法可拼时解析器无从知晓两条语句意图，只能靠检查器事后拦截（实测多起静默粘连事故）；改为 Rust 式强制分号后，块截断静默家族整体消亡（孤儿 token 即缺分号诊断）。循环头分号保持三段分隔符语义。
- **换行仍无语法意义**：词法层将换行当作空白跳过不变——表达式内部续行天然支持（运算符悬挂行尾写法不受影响）；变化仅在语句边界必须显式分号。
- **单行多语句由分号分隔**：每条语句独立终结。

## 四、注释

### EBNF

```
注释 = 单行注释 | 块注释
单行注释 = "//", 任意字符直到行尾
块注释 = "/*", (任意字符 | 块注释)*, "*/"    // 支持嵌套
```

### 示例代码

```
// 单行注释
函数 主() -> 整32 {
    /* 块注释 */
    /* 外层注释
        /* 内层嵌套注释（支持嵌套） */
    */
    返回 0
}
```

### 设计决策

- **块注释支持嵌套**：与C/C++不同（C/C++块注释不支持嵌套），CN语言允许 `/* */` 嵌套，便于在注释中临时屏蔽大段代码。

## 六、标识符规则

### EBNF

```
标识符 = (中文字符 | 字母 | "_"), (中文字符 | 字母 | 数字 | "_")*
```

### 规则细则

| 规则 | 说明 |
|------|------|
| 开头 | 中文字符、字母或下划线 `_` 开头 |
| 后续 | 可包含中文、字母、数字、下划线 |
| UTF-8 | 支持UTF-8多字节字符（中文字符按单字处理） |
| 保留字 | 所有关键字均为保留字，不可用作标识符 |
| 区分大小写 | 关键字为中文，无大小写问题；英文字母区分大小写 |

### 示例代码

```
变量 中文变量 = 10        // 中文字符开头
变量 _私有值 = 20         // 下划线开头
变量 myVar = 30           // 字母开头
// 变量 如果 = 1          // ❌ 错误：关键字不可用作标识符
```

### 设计决策

- **中文优先**：标识符允许中文字符，全中文语法风格一致，降低中文开发者学习成本。
- **关键字即保留字**：所有59个关键字均为保留字，编译器词法分析阶段直接拒绝用作标识符。
- **最长匹配**：中文关键字采用最长匹配原则，关键字后必须有空格或符号分隔（见词法分析器设计）。

## 七、词法预处理（条件编译）（2026-09-16 新增·B2 方案甲）

> 来源：237-a 规范覆盖矩阵发现「实装有、规范无」→ 用户裁决方案甲入规范。权威条文=plans/001 §4.7；
> 语法形态以 E2E 24（`tests/e2e/24_preprocessor/`）实测为准。

- **指令**：`#定义 宏名`｜`#如果定义(宏名)` 或 `#如果定义 宏名`（括号与空白形式等价）｜`#否则`｜`#结束如果`｜命令行 `-D 宏名`
- **语义**：词法层裁剪——被裁分支不产生 token（含语法错误也不诊断）；宏=无值旗标（不支持带参宏/宏体/`#包含`/常量表达式条件）；支持嵌套；`#结束如果` 严格配对（空分支合法）
- **实装**：宿主 ✓（lexer/preprocessor.cpp）；**v2 未实现**（缺口登记 plans/021 §3-D）

```
#定义 发布模式
函数 主() -> 整32 {
    #如果定义 发布模式
    打印("发布模式: 开启");
    #否则
    打印("发布模式: 关闭");
    #结束如果
    返回 0;
}
```
