## 一、默认类型（别名）

### EBNF

```
默认类型 = "整数" -> 整32 | "小数" -> 浮64
```

### 默认类型表

| 类型关键字 | 等价于 | 说明 |
|-----------|--------|------|
| 整数 | 整32 | 默认整数类型 |
| 小数 | 浮64 | 默认浮点类型 |

### 设计决策

- 保留中文命名习惯：`整数`/`小数` 作为常用别名，位宽类型（整32/浮64）用于精确控制。
- 别名在类型检查阶段解析为对应位宽类型，IR层统一按位宽类型处理。

## 二、位宽整数类型

### EBNF

```
位宽整数 = 有符号整数 | 无符号整数
有符号整数 = "整8" | "整16" | "整32" | "整64" | "整128"
无符号整数 = "正8" | "正16" | "正32" | "正64" | "正128"
```

### 位宽整数表

| 类型 | 大小 | 范围 | 说明 |
|------|------|------|------|
| 整8 | 1字节 | -128 ~ 127 | 8位有符号整数 |
| 整16 | 2字节 | -32768 ~ 32767 | 16位有符号整数 |
| 整32 | 4字节 | -2^31 ~ 2^31-1 | 32位有符号整数 |
| 整64 | 8字节 | -2^63 ~ 2^63-1 | 64位有符号整数 |
| 整128 | 16字节 | -2^127 ~ 2^127-1 | 128位有符号整数 |
| 正8 | 1字节 | 0 ~ 255 | 8位无符号整数 |
| 正16 | 2字节 | 0 ~ 65535 | 16位无符号整数 |
| 正32 | 4字节 | 0 ~ 2^32-1 | 32位无符号整数 |
| 正64 | 8字节 | 0 ~ 2^64-1 | 64位无符号整数 |
| 正128 | 16字节 | 0 ~ 2^128-1 | 128位无符号整数 |

### 设计决策

- **中文位宽命名**（决策12）：`整` 前缀表示有符号（signed），`正` 前缀表示无符号（unsigned），直观表达语义。
- 整128/正128的乘除取余等运算由运行时辅助函数实现（`__cn_mul_i128` 等），见运行时设计。

## 四、其他基础类型

### EBNF

```
基础类型 = "布尔" | "字符" | "字符串" | "空类型"
```

### 基础类型表

| 类型 | 大小 | 说明 |
|------|------|------|
| 布尔 | 1字节 | 真/假 |
| 字符 | 4字节 | Unicode标量值（支持中文字符） |
| 字符串 | - | 字符串类型（以\0结尾，UTF-8编码） |
| 空类型 | 0字节 | void，用于函数返回类型和空指针 |

### 示例代码

```
布尔 是否有效 = 真
字符 首字母 = 'A'
字符串 姓名 = "张三"
函数 无返回值() -> 空类型 {   // 显式空类型返回
    打印行("无返回值")
}
```

### 设计决策

- 字符串采用UTF-8编码、以`\0`结尾；字符串字面量在编译期进入只读数据段。
- **拥有型字符串**（2026-09-10 plans/019 阶段4' 方案A）：`字符串` 局部变量为拥有类型
  ——初始化落堆（字面量/拷贝经 `__cn_str_copy`）、赋值=free 旧+拥有化新、返回块 RAII
  自动释放（返回=所有权移出）、`转移()` 零拷贝衔接、裸视图用 `字符*`；拥有判定白名单
- **返回拥有契约（A2 2026-09-11 方案甲 用户批准）**：返回类型 `字符串`=拥有（调用方登记 RAII 自动
  释放——Rust `fn f() -> String` 同款）；返回类型 `字符*`=借用（调用方不释放零拷贝，`&str` 同款）。
  函数返回位借用形态（参数直传/成员/下标/解引用借出/字符*/全局静态）拒绝——须显式 字符串复制(...)
  或改返回类型 字符*。**隐式转换方向收紧**：拥有→借用（字符串→字符*）自动放行（安全方向）；
  借用→拥有（字符*→字符串 变量初始化/赋值）拒绝，须显式 字符串复制(...)——分配成本可见
  （Rust `&str -> String` 的 to_string 哲学）。函数返回类型 字符串 的字面量返回由编译器自动
  拥有化（copy 落堆——字面量驻只读段）。
  （字面量/标识符/内置分配族），其余调用形态退出 RAII；参数=借用。
- **容器元素引用访问器（2026-09-28；065 A 账 829 轮实装·〔基准=019〕危险面收口）**：
  `向量<T>.元素引用(整64 位置) -> T&`=引用返回零拷贝借用视图（Rust `&v[i]` 同款），只读/原地写均
  写穿容器，越界=运行时错误（同 元素）。`不安全 函数` 修饰收口（借出视图可绕过值语义无别名保证，
  责任上移显式审计）。与 `元素()`（副本快照）/`设置()`（写回）构成三形态正交并存——权威条文
  plans/001 §5.3「正交边界」。
- **最后使用消除（LUE·2026-09-28 立；2026-09-29 双端追平·AGENTS §3.1 第四句 (a) 立法承载·〔基准=019〕）**：
  对「源在拷贝后不再被使用」的**字符串/容器**拷贝，编译器自动降级为转移（move 发射=句柄直取+源槽清零，
  跳过深拷）——Rust last-use move elision / C++ NRVO 同构。触发（极保守）=实参为纯局部标识符+拷贝点后
  至函数边界无同名出现（读写均算）+**循环跨迭代保守**（拷贝点被循环包围时源须在同一最内层循环体内声明·
  每轮重初始化；874 实证修正）+类型限字符串/容器（结构体族随任务 078 扩面）。**双端现状（874 追平）**：
  v2 自举编译器（854）与宿主编译器（083·判据同构）**均已实现**——E2E 285 单态断言
  （字符串/容器 增==0）+549 循环回边门禁。权威条文 plans/001 §5.3「最后使用消除」。
- **字符串驻留（2026-08-25 用户批准；对标 rustc Symbol / LLVM StringPool）**：`驻留(字符串)` -> 整64 返回唯一整数 ID（相同内容同 ID、内容只存一份，驻留表进程级常驻）；`驻留文本(整64)` -> 字符* ID 反查（A2 2026-09-11 方案甲：返回驻留表内部指针=借用视图——持有须 字符串复制(...) 落堆）；`驻留计数()` -> 整64。Token/AST/IR/符号表的文本字段用整型 ID 引用（O(1) 比较），消除重复字符串分配——性能最优自举编译器的符号表示基石。
- **字符串构建器（#366·2026-10-13 用户批准·Rust `String::push_str` 同款）**：字符串不可变、
  `字符串连接` 每次新分配+整串拷贝（拼 k 段均摊 O(k²)）——循环/大批量拼接走构建器一趟 O(L)。
  **用法警示（#728i·2026-10-14 补位）**：加号链 `甲 + 乙 + 丙` 仅适合**少量短拼接**；
  循环体内拼接、大段文本组装（k 段累计拷贝 O(k²) 字节）必换构建器——编译器对加号链无
  任何提示（不设诊断·静态不可知运行时规模），此边界须自觉。
  内建层（限定名直调·无需导入）：`字符串构建器::新建/追加/追加字节/完成/弃置`（句柄=整64 不透明值；
  完成=出新分配串+释放缓冲、弃置=仅释放防错误路径泄漏；句柄一次性）。stdlib 门面：`导入 字符串扩展::{...}`
  纯名 `字符串构建器新建/追加/追加字节/追加整数/完成/弃置`。完成返回串=调用方拥有（A2 RAII）。
  权威条文 plans/001 §10.3。
- **字符串内置函数字节级口径（T10 收口·495-a·2026-09-20）**：`字符串子串(字符串, 整64 起始, 整64 长度)`
  与 `字符串长度`/`字符串查找` 等**一律按 UTF-8 字节**（非码点——与「字符串长度按字节」同口径），
  越界**钳位不报错**（安全方向·实现唯一归属 `__cn_str_sub`）：`起始<0` 钳位 0；`长度<0` 计 0（返回空串）；
  `起始≥字节长` 返回空串；`长度` 超出剩余字节截断至串尾。**字节级切割可能劈开多字节序列**
  （如 `"甲乙丙"` 子串(1,3) 得半字符乱码——多字节完整性由调用方保证）。
  对照：Rust `&str::get(..)` 越界返回 None / `[..]` 越界 panic——CN 取静默钳位（无恐慌语义面，
  与整数溢出回绕 T9 同族哲学：运行期安全兜底、编译期不拦）。例：`字符串子串(s, 2, 99)`（s="abc"）=`"c"`；
  `字符串子串(s, 5, 2)`=`""`；`字符串子串(s, -1, 2)`=`"ab"`。
- **字符串下标字节语义（T48 收口·504-a·2026-09-20 用户裁决甲；910 修订=112 甲·分层安全①）**：
  `字符串[i]` **读**按 **UTF-8 字节**索引、结果类型 **整8**（带符号字节值——与 IR 层 i8 符号扩展
  装载自 A-1 起一致；原「字符」标注与本节「字符=Unicode 标量值」定义矛盾，属规范空白，已关闭）。
  下标须为整型；越界=运行期错误码 2（与数组同通道·T4 防线=分层安全②确定性失败）。
  `字符串[i]` **写=编译期拒绝**（112 甲·2026-09-30 用户裁决）：字符串为**不可变拥有型**——修改走
  拼接/字符串子串 重建，原地字节操作用 `字符` 数组或不安全区指针（与 069「字符* 视图下标拒绝」
  同一语义家族·宿主+v2 双侧同拒）。
- **分层安全总则（2026-09-30 用户裁决「方案一」立法）**：①编译期能证明的必须编译期拦
  （常量下标越界/常量除零/常量空指针解引用）；②编译期证不了的安全区以确定性失败兜底
  （错误码+立即终止·Rust panic 同款·非 UB）；③完备访问通道并行提供结果化 API（用户自选）；
  ④不安全 函数=真零运行期检查（既有检查面降级为纵深防御）。权威条文=plans/001 §1.1a。
- **分层①具体化——常量下标越界/常量除零编译期硬错误（912 轮实施·任务 114）**：
  字面量下标 × 静态数组长度（`整32[3] 表; 表[5]`）=编译期硬错误——读/写共用路径、
  含一元负号（`表[-1]`）与 `0x` 十六进制字面量、**不安全 函数内同拦**（编译期确定性
  错误无条件·rustc 常量下标 deny 同款）、宿主+v2 双侧同拒；常量除零/取余零（字面量对
  `10/0`、`10%0`）同为编译期硬错误。运行期错误码 2 越界检查保留=分层②兜底；常量传播面
  （变量持有常量初值作下标/除数）随常量折叠后续波。**与 `字符` 的分工**：`字符`=完整 Unicode 标量值（4 字节）；
  字节碎片经 `字符转字符串`（值 <0 或 ≤0xFF 单字节直放——U+0080~00FF 边界按单字节直放，
  T40 双来源兼容临时态本轮闭合为明文口径）重建多字节序列；码点路径（>0xFF）按 UTF-8 编码。
  例：`"内存好"`（9 字节）的 `s[0]`=-27、`s[4]`=-83；`字符转字符串(s[6])+字符转字符串(s[7])
  +字符转字符串(s[8])`=`"好"`。
- `空类型` 对应C++的 `void`，同时用于空指针类型（见复合类型-指针）。

## 四B、静态字符串使用指导

> 任务 1642 联动条文（第178反思①/审计①·与双侧实现对读一致；执法权威=plans/001 §10.3 A2「静态源拥有返回禁令」）

### 规则

- **函数内静态局部活得比调用久**：静态局部变量的存储期=进程生命周期（非函数调用
  生命周期），初值走守卫快照初始化（[03-语句与控制流.md](03-语句与控制流.md) 1.1b）。
  多数场景**不必要**——建议优先普通局部变量（每次调用独立、RAII 自动回收），
  静态局部仅用于确需跨调用保持状态的场景（计数器/缓存等）。
- **静态面拥有型收口**：函数内静态局部唯一可达的拥有型=**字符串**（静态 类/容器/
  数组/结构体 声明双侧编译期拒绝）；顶层静态与裸全局的字符串为拥有型。
- **静态源拥有返回禁令**（#1614 甲案·2026-10-26 用户批准）：返回类型为 `字符串`
  （拥有）而返回源=全局/静态/类字段时，双侧编译期拒绝——须显式 `字符串复制(...)`
  落堆、或改返回类型 `字符*`（借用零拷贝）。函数内静态局部串返回同拒，
  诊断以合成名 `名$静态$函数名` 指认来源。**禁止隐式拷贝静态源返回**：
  静默搬槽/隐式拷贝会掩盖「返回的是共享状态还是副本」的语义分歧。
- 需要跨调用共享串内容时，显式选择语义：改返回 `字符*`（共享借用视图）或
  `字符串复制`（独立副本）——让「共享还是拷贝」出现在源码面上。

### 示例代码

```
函数 牌() -> 字符串 {
    静态 字符串 s = "甲";      // 静态局部：跨调用保持（确需再用）
    返回 s;                     // ❌ 编译期拒绝：静态源拥有返回禁令
}

函数 牌复制() -> 字符串 {
    静态 字符串 s = "甲";
    返回 字符串复制(s);         // ✅ 显式落堆=独立副本
}

函数 牌视图() -> 字符* {
    静态 字符串 s = "甲";
    返回 s;                     // ✅ 借用视图=共享（返回类型 字符* 即借用契约）
}

函数 局部() -> 字符串 {
    字符串 s = "甲";            // ✅ 多数场景的正解：普通局部（RAII 自动回收）
    返回 s;                     // 返回=所有权移出（A2 返回拥有契约）
}
```

### 设计决策

- 「静态局部活得比调用久」+「多数场景不必要」是指导性条文（优先局部变量）；
  「静态源拥有返回禁令」是执法性条文（双侧同拒·E2E 1566 负例/1567 正例锁面）。
  指导面劝、执法面拦，两层分工。
- 函数内静态面收口完整性的实现边界：静态类/容器/数组声明已双侧拒绝（997），
  字符串是唯一可达拥有型——禁令覆盖面因此是闭集。

## 五、复合类型

### EBNF

```
复合类型 = 指针类型 | 数组类型 | 结构体类型 | 枚举类型 | 函数指针类型 | 联合体类型
指针类型 = 类型, "*"
数组类型 = 类型, "[", 长度, "]"
结构体类型 = "结构体", 标识符, "{", 字段列表, "}"
枚举类型 = "枚举", 标识符, "{", 枚举成员列表, "}"
联合体类型 = "联合体", 标识符, "{", 字段列表, "}"
函数指针类型 = 返回类型, "(*", 标识符, ")", "(", 参数类型列表, ")"
```

### 复合类型表

| 类型 | 语法 | 说明 |
|------|------|------|
| 指针 | 类型* | 指向类型的指针 |
| 数组 | 类型[长度] | 固定长度数组 |
| 结构体 | 结构体 名 { ... } | 自定义结构体 |
| 枚举 | 枚举 名 { ... } | 枚举类型 |
| 联合体 | 联合体 名 { ... } | 所有字段共享同一内存区域，同一时间只有一个字段有效 |
| 函数指针 | 返回类型(*名)(参数) | 函数指针 |

### 示例代码

```
整32* 指针变量              // 指向整32的指针
整32[10] 数组变量           // 10个整32元素的数组

结构体 点 {
    浮64 x
    浮64 y
}

枚举 颜色 {
    红,
    绿,
    蓝
}

联合体 数值 {
    整32 整数部分
    浮64 浮点部分
}

整32(*回调)(整32, 整32)     // 函数指针
```

### 设计决策

- **指针+手动内存管理**（决策5）：与C/C++一致，提供完整指针运算（取地址`&`、解引用`*`、成员访问`.`——v2.1 成员访问统一，`->` 已废除）。
- **取地址语义一致化（2026-09-21 用户裁决甲·588-a）**：`&类变量`（含顶层静态类变量）产**对象地址**——类变量为指针槽模型（变量槽存句柄），取地址=解包句柄（Load 槽），与 `类名*` 类型标注一级语义对齐（C++ `&obj` / Rust `&T` 对照）；`点* p2 = &p1;` 后 `p2.x`、`p2.方法()`、`p2.x = v` 均作用于 p1 对象本身。`&结构体变量`/`&标量变量` 维持槽地址（值类型槽=存储本身）。`T&` 引用形参的实参自动取地址为编译器内部机制（形参槽存被引用左值地址），与用户级 `&` 表达式语义无关。
- **联合体**：源语言层面可用，同时编译器内部用于结果/可选类型降级（见[07-错误处理.md](07-错误处理.md)）。
- **函数指针采用C风格声明**：`整32(*回调)(整32, 整32)`，与C/C++保持一致，便于底层编程人员理解（见[04-函数与函数指针.md](04-函数与函数指针.md)）。

### EBNF

### 规则

- **内建编译期求值表达式**（C++ `sizeof` 运算符等价物），**不是函数**：由编译器直接求值为字节数常量（整64），不产生函数调用、不可取地址、不可作函数指针。

## 六C、合成体内存布局（结果/可选·判别式存储）

> 任务 1642 条文（第158审计③·2026-10-28 与双侧实现对读一致）

### 规则

- **判别式存储**：`可选<T>` 与 `结果<T,E>` 统一按「判别式（tag）+ 载荷」两段布局，
  判别式是**显式的首字段布尔**，不是指针复用/NaN 装箱等隐式手法（Rust `Option<&T>`
  的 nich 优化 CN 不做——布局稳定优先，跨后端一致）。
- **`可选<T>` 降级布局**（权威条文 [07-错误处理.md](07-错误处理.md) 第六节·本节定内存形态）：
  合成结构体 `{ 布尔 是否某些; T 值 }`——判别式在偏移 0（布尔 1 字节，占位对齐至
  8 字节槽），载荷 `值` 紧随其后按 8 字节对齐。总大小 = 8 + 圆整8(载荷大小)：
  `可选<整64>`=16、`可选<字符串>`=16（串=8 字节句柄）、窄标量载荷（整8/整16 等）
  亦圆整至 8（`可选<整8>`=16）、结构体载荷按其真实大小圆整（20 字节类 → 8+24=32）。
- **`结果<T,E>` 降级布局**：合成结构体 `{ 布尔 是否正常; 联合体 { T 值; E 错误值 } }`
  ——判别式在偏移 0；T 与 E **共用同一联合体槽**（正常态槽内=T 载荷、错误态槽内=
  E 载荷，持有型载荷的条件释放按判别式取反分流：错误态才摘句柄/深拷）。总大小 =
  8 + max(圆整8(T), 圆整8(E))。
- **嵌套合成体**：`可选<可选<T>>`/`结果<结果<...>,...>` 按上述规则递归——外层布局
  时内层必已降级（先内后外的布局依赖顺序由编译器保证，用户无感知）。
  E2E 543（三层嵌套/大内层）与 1568（八字节载荷字段/元素位）为双侧锁面。

### 示例代码

```
可选<可选<整32>> 槽 = 某些(某些(7));
如果 (槽.有值) {
    可选<整32> 内 = 槽.值;       // 外层载荷=完整的内层可选（判别式+载荷整体拷出）
    如果 (内.有值) {
        打印行(内.值);            // 7
    }
}
```

### 设计决策

- 判别式与载荷分离、判别式恒为显式布尔首字段：`.有值`/`.正常` 检查就是首字段读取
  （[07-错误处理.md](07-错误处理.md) 强制检查规则 3 条是同一判别式的消费面）。
- 载荷圆整 8：句柄语义（串/类/容器=8 字节句柄）与标量统一，拷贝/释放按整槽进行，
  杜绝截断拷贝（543 治理前「猜 5B 真实 16B」的教训固化为布局条文）。

## 六D、字符串连接的生存期与视图边界

> 任务 1642 条文（第165审计③·与双侧实现对读一致；含第174反思④设计约束成文）

### 规则

- **连接产物=新分配串**：`字符串 + 字符串`（含 `字符串 + 数值` 隐式拼接）每次
  分配新串并整串拷贝（拼 k 段均摊 O(k²)·批量拼接用 字符串构建器，见第四节设计决策）。
- **临时串生存期=所在完整表达式语句结束**：连接产生的临时串由编译器在其**消费点**
  结算、语句边界统一释放——消费点覆盖：打印族实参、消费族内置调用实参、拼接链
  操作数、融合链段、用户函数传参位、语句位丢弃值；三元条件 `条件 ? 串A : 串B`
  中被选中分支的串临时同样在语句边界释放；方法链 `造盒().取串()` 返回的临时对象
  及其串字段在同一点析构。释放时机对用户不可见（RAII），**不存在「连接临时活到
  函数尾」或「语句中途即释放」的第三种语义**。
- **视图边界（悬垂零容忍）**：`字符*` 借用视图的合法寿命以其**来源的拥有串**为界；
  来源为临时连接产物的视图不得活过其所在语句——活过即悬垂（[plans/001] §1.1a
  分层安全①：能证明的编译期拦，证不了的确定性失败兜底）。
- **设计约束（成文）**：**链式与落变量天然等价，无避坑方言**——`打印行(s + "甲" + "乙")`
  与 `字符串 t = s + "甲"; 打印行(t + "乙");` 在求值结果与释放语义上等价；
  语言不诱导「必须先落变量才安全/才不泄漏」的写法。用户按可读性选择写法即可。

### 示例代码

```
字符串 s = "前缀-";
// 链式写法：临时串在语句边界释放
打印行(s + "甲" + "乙");            // 前缀-甲乙
// 落变量写法：语义与上等价（设计约束·无避坑方言）
字符串 t = s + "甲";
打印行(t + "乙");                    // 前缀-甲乙

// ❌ 反例（悬垂）：借用视图活过来源临时串所在语句
// 字符* 视图 = (s + "临时").字符指针();   // 来源=连接临时（此形态编译期拒绝或
// 打印行(视图);                            // 运行期确定性失败·不得静默悬挂）
```

### 设计决策

- 消费点结算+语句边界统一释放（任务 662 六消费位收口·双侧同构）：任何消费形态
  残留即缺陷（`内存::活动分配数` 差值判据·E2E 1026 十二形态折位锁面）。
- 借用来源分级：成员/下标/解引用/参数/全局静态/透传调用=借用（保守不接管·防误
  释放共享对象）；本地标识符移出/类构造新建=拥有。该分级是「链式与落变量等价」
  的实现基石。

## 六E、类型文本串的边界（编译器内部协议）

> 任务 1642 条文（第174审计①·与双侧实现对读一致）

### 规则

- **类型文本串**：以源码文本形态承载类型信息的内部串——尖括号形态（`可选<整64>`、
  `结果<整32, 整32>`、`向量<盒子>`）与合成名形态（`可选$整64`、`结果$整32$整32`、
  `向量$盒子`）两态。
- **边界条文**：类型文本串是**解析与语义检查边界之内的内部表示**；跨出检查边界的
  类型信息以**已解析的类型 ID / 已登记的布局表**为权威。实现不得新增「把原始类型
  文本串直接返回给下游、由下游自行再解析」的出口；确需跨层携带时按驻留 ID 或
  结构化类型对象传递（正例见下）。
- **物化归一**：泛型语境中的类型文本串（含类型形参 T）在使用点经物化归一
  （实参替换+规范名）后再进入下游；模板态文本不作跨边界通行证。

### 示例（实现侧正反形态）

```
✅ 正例：接口方法签名表以「返回类型文本ID + 参数串ID（驻留 ID）」登记——
   下游（语义检查/IR 分派）按 ID 查表，不自由解析裸串；
   泛型类型文本经 resolveGenericTypeName 物化归一后才进入布局与 IR。

❌ 反例（已根治的病根形态·任务 1615/797 实录）：把 `结果$结果$整32$整32$整32`
   的裸文本直接交多个散点各自「段首砍」——嵌套 T 被砍残成裸「结果」，
   载荷字节查表 miss → 静默按 8 字节算=越界写。
```

### 设计决策

- 「修复都做了、行为都对，但出口散在各处」是本条立法动因：类型文本串的**产生、
  归一、消费**各收敛到单点（物化单点/切分单点，见六F），禁止新增裸串出口，
  使「文本串直接返回的出口」在全树保持可普查、可穷举。

## 六F、载荷切分的元数感知（编译器内部协议）

> 任务 1642 条文（第175审计③·与双侧实现对读一致）

### 定义

**元数感知**：从合成类型文本中切分载荷实参时，按**基名元数表**递归消费——
`结果`=2 个实参、`可选`/`向量`/`数组`/`手动释放`=1 个实参、`映射`=2 个实参、
用户泛型类按其声明形参个数；切分位置只认**尖括号深度为 0 的顶层逗号**（或 $ 形态
下按基名元数整段取出），嵌套实参整段完整取出、不得按字符位置盲砍。

### 规则

- 正确切分示例：`可选<可选<盒子>>` 外层载荷=`可选<盒子>`（整段）； 
  `结果<结果<整32,整32>,整32>` 的 T=`结果<整32,整32>`、E=`整32`。
- **禁止形态启发式**：以「文本宽度>0 即有载荷」「取首段/剩余段」等字符级近似替代
  元数表——对嵌套实参必砍错（`结果$结果$整32$整32$整32` 按首段砍得裸「结果」，
  三处 miss 显形；`整32[3]` 数组载荷被砍丢 `[3]`——此类形态一律按元数表+数组
  尾缀规则处理）。
- 切分失败（元数不符/括号不配对）=显式内部错误诊断，**禁止静默取默认载荷**。
- 单点归属：切分逻辑收敛单点实现（宿主 `resultTypeArgs`/`optionalTypeArg` 族、
  v2 `取实例实参们`/尖括号配对扫描），新增消费面调单点，禁复制粘贴第二份。

### 设计决策

- 元数感知是六E 边界条文的执行面：类型文本串既已收敛单点切分，切分算法的正确性
  就有唯一锚（任务 1611/1615 双单点对账·探针矩阵定期双侧跑）。
- E2E 锁面：543 形态④（嵌套 T）、715（数组载荷）、1557（显式 结果<用户泛型类实例>）。

## 七、隐式类型转换

### EBNF

```
隐式转换规则:
  字符 ↔ 整数
  字符串 -> 字符*（A2 收紧：借用->拥有反向须显式 字符串复制）
  空类型* ↔ 任意指针
  整数 -> 整64（宽化）
  浮32 -> 浮64（宽化）
  数值 -> 字符串（仅 + 拼接上下文）
  混合符号隐式转换禁止（二元运算/赋值/传参/返回面变量间须显式转换；字面量豁免）
```

### 转换规则表

| 源类型 | 目标类型 | 转换方向 | 说明 |
|--------|---------|---------|------|
| 字符 | 整数 | 双向 | 字符↔整数 |
| 字符串 | 字符* | 单向（拥有→借用自动） | 字符串→字符指针（A2 收紧：反向须显式 字符串复制） |
| 空类型* | 任意指针 | 双向 | 空指针↔任意指针 |
| 整数 | 整64 | 单向宽化 | 默认整数类型扩展 |
| 浮32 | 浮64 | 单向宽化 | 单精度扩展为双精度 |
| 数值/布尔/字符/枚举 | 字符串 | 单向（仅 `+` 拼接） | `字符串 + 数值` 隐式拼接（等价 `整数转字符串/浮点转字符串/字符转字符串`；布尔转换对应 `布尔转字符串`（`__cn_str_from_bool`，输出 `"真"/"假"`）） |

### 设计决策

- 隐式转换遵循"安全优先"原则：仅允许无损或宽化转换，禁止窄化转换（如整64→整32）隐式进行，需显式标注。
- 指针与整数之间禁止隐式转换，防止类型混淆（与C++不同，更严格）。
- **数值→字符串**转换**仅**在 `+` 拼接语境触发（左操作数为 `字符串`/`字符*`），不参与其他算术/比较上下文；多操作数左结合（`"a" + 1 + 2` 等价 `(("a" + 1) + 2)`）。
- **混合符号隐式转换禁止**（2026-09-10 方案A，Rust 对齐；二元面=第五十一轮、赋值/传参/返回面=第五十六轮，权威条文 plans/001 §3.7）：有符号（整N）与无符号（正M）**变量间**的二元运算（比较/算术/位运算）、赋值初始化/赋值、函数传参/返回均编译期拒绝，须显式 `类型名(表达式)` 构造转换——隐式宽化在混合符号下静默改变值语义。**字面量豁免**：一侧为整数字面量（含 `-1` 形态）时按另一侧类型参与（`大 > 100`、`正64 b = 5`、`读值(100)` 等惯用形态保留）。同符号混合宽度（正32 与 正64 等）维持宽化放行；字符 ↔ 整数互通不受影响。
- **整数字面量转换定级（788·2026-10-15 立法；权威条文 plans/001 §3.7a「整数字面量转换定级」条·执法锚=E2E 1004/1005 dual）**：①**无后缀非负字面量=随侧豁免标记**——参与类型随另一侧整数族操作数（`1 + 2U` 与 `2U + 1` 对称放行·对新手友好设计；负号字面量不随侧：`-1 + 2U` 维持混合符号拒绝）；②**带后缀字面量按后缀定级（严格）**——参与类型=后缀指定类型（L→整64/LL→整128/U→正32/UL→正64/ULL→正128），不随另一侧，结果宽于目标即四通道（赋值/声明初始化/返回/守卫）编译期拒绝；③**285 窄域适配拉窄放行**——一侧窄整数（整8/整16/正8/正16）+另一侧字面量（含带后缀）时字面量按窄侧参与（仅算术面 `+ - * / %`）；④**128→64 同符号窄化特例**——整128→整64、正128→正64 表达式源隐式放行（跨符号组合不在特例内）；⑤**值域门槛先行**——字面量直赋通道先查目标类型值域再论其他（超域字面量一律拒·特例不放行字面量直赋超域形态）。豁免面（①③）为语言设计选择、非查表 miss。
- **显式类型转换的位模式语义**（2026-09-10 第五十五轮 ④文档化，Rust `as` 对齐，权威条文 plans/001 §3.7）：`类型名(表达式)` 构造转换在整数族间定义为位模式变换（零运行时开销）：**升宽**——有符号源符号扩展（`正64(整32(-1))` = `2^64-1`）；无符号源零扩展（`整64(正32(4000000000))` = `4000000000`）。**同宽跨符号**=位模式重解释（`整64(正64(2^63))` = `-2^63`）。**降宽**=低位截断。窄宽（整8/整16/正8/正16）先按位宽扩展再按上述规则。
