## 一、默认类型（别名）

### EBNF

```
默认类型 = "整数" -> 整32 | "小数" -> 浮64
```

### 默认类型表

| 类型关键字 | 等价于 | 说明 |
|-----------|--------|------|
| 整数 | 整32 | 默认整数类型 |
| 小数 | 浮64 | 默认浮点类型 |

### 设计决策

- 保留中文命名习惯：`整数`/`小数` 作为常用别名，位宽类型（整32/浮64）用于精确控制。
- 别名在类型检查阶段解析为对应位宽类型，IR层统一按位宽类型处理。

## 二、位宽整数类型

### EBNF

```
位宽整数 = 有符号整数 | 无符号整数
有符号整数 = "整8" | "整16" | "整32" | "整64" | "整128"
无符号整数 = "正8" | "正16" | "正32" | "正64" | "正128"
```

### 位宽整数表

| 类型 | 大小 | 范围 | 说明 |
|------|------|------|------|
| 整8 | 1字节 | -128 ~ 127 | 8位有符号整数 |
| 整16 | 2字节 | -32768 ~ 32767 | 16位有符号整数 |
| 整32 | 4字节 | -2^31 ~ 2^31-1 | 32位有符号整数 |
| 整64 | 8字节 | -2^63 ~ 2^63-1 | 64位有符号整数 |
| 整128 | 16字节 | -2^127 ~ 2^127-1 | 128位有符号整数 |
| 正8 | 1字节 | 0 ~ 255 | 8位无符号整数 |
| 正16 | 2字节 | 0 ~ 65535 | 16位无符号整数 |
| 正32 | 4字节 | 0 ~ 2^32-1 | 32位无符号整数 |
| 正64 | 8字节 | 0 ~ 2^64-1 | 64位无符号整数 |
| 正128 | 16字节 | 0 ~ 2^128-1 | 128位无符号整数 |

### 设计决策

- **中文位宽命名**（决策12）：`整` 前缀表示有符号（signed），`正` 前缀表示无符号（unsigned），直观表达语义。
- 整128/正128的乘除取余等运算由运行时辅助函数实现（`__cn_mul_i128` 等），见运行时设计。

## 四、其他基础类型

### EBNF

```
基础类型 = "布尔" | "字符" | "字符串" | "空类型"
```

### 基础类型表

| 类型 | 大小 | 说明 |
|------|------|------|
| 布尔 | 1字节 | 真/假 |
| 字符 | 4字节 | Unicode标量值（支持中文字符） |
| 字符串 | - | 字符串类型（以\0结尾，UTF-8编码） |
| 空类型 | 0字节 | void，用于函数返回类型和空指针 |

### 示例代码

```
布尔 是否有效 = 真
字符 首字母 = 'A'
字符串 姓名 = "张三"
函数 无返回值() -> 空类型 {   // 显式空类型返回
    打印行("无返回值")
}
```

### 设计决策

- 字符串采用UTF-8编码、以`\0`结尾；字符串字面量在编译期进入只读数据段。
- **拥有型字符串**（2026-09-10 plans/019 阶段4' 方案A）：`字符串` 局部变量为拥有类型
  ——初始化落堆（字面量/拷贝经 `__cn_str_copy`）、赋值=free 旧+拥有化新、返回块 RAII
  自动释放（返回=所有权移出）、`转移()` 零拷贝衔接、裸视图用 `字符*`；拥有判定白名单
- **返回拥有契约（A2 2026-09-11 方案甲 用户批准）**：返回类型 `字符串`=拥有（调用方登记 RAII 自动
  释放——Rust `fn f() -> String` 同款）；返回类型 `字符*`=借用（调用方不释放零拷贝，`&str` 同款）。
  函数返回位借用形态（参数直传/成员/下标/解引用借出/字符*/全局静态）拒绝——须显式 字符串复制(...)
  或改返回类型 字符*。**隐式转换方向收紧**：拥有→借用（字符串→字符*）自动放行（安全方向）；
  借用→拥有（字符*→字符串 变量初始化/赋值）拒绝，须显式 字符串复制(...)——分配成本可见
  （Rust `&str -> String` 的 to_string 哲学）。函数返回类型 字符串 的字面量返回由编译器自动
  拥有化（copy 落堆——字面量驻只读段）。
  （字面量/标识符/内置分配族），其余调用形态退出 RAII；参数=借用。
- **字符串驻留（2026-08-25 用户批准；对标 rustc Symbol / LLVM StringPool）**：`驻留(字符串)` -> 整64 返回唯一整数 ID（相同内容同 ID、内容只存一份，驻留表进程级常驻）；`驻留文本(整64)` -> 字符* ID 反查（A2 2026-09-11 方案甲：返回驻留表内部指针=借用视图——持有须 字符串复制(...) 落堆）；`驻留计数()` -> 整64。Token/AST/IR/符号表的文本字段用整型 ID 引用（O(1) 比较），消除重复字符串分配——性能最优自举编译器的符号表示基石。
- **字符串内置函数字节级口径（T10 收口·495-a·2026-09-20）**：`字符串子串(字符串, 整64 起始, 整64 长度)`
  与 `字符串长度`/`字符串查找` 等**一律按 UTF-8 字节**（非码点——与「字符串长度按字节」同口径），
  越界**钳位不报错**（安全方向·实现唯一归属 `__cn_str_sub`）：`起始<0` 钳位 0；`长度<0` 计 0（返回空串）；
  `起始≥字节长` 返回空串；`长度` 超出剩余字节截断至串尾。**字节级切割可能劈开多字节序列**
  （如 `"甲乙丙"` 子串(1,3) 得半字符乱码——多字节完整性由调用方保证）。
  对照：Rust `&str::get(..)` 越界返回 None / `[..]` 越界 panic——CN 取静默钳位（无恐慌语义面，
  与整数溢出回绕 T9 同族哲学：运行期安全兜底、编译期不拦）。例：`字符串子串(s, 2, 99)`（s="abc"）=`"c"`；
  `字符串子串(s, 5, 2)`=`""`；`字符串子串(s, -1, 2)`=`"ab"`。
- **字符串下标字节语义（T48 收口·504-a·2026-09-20 用户裁决甲）**：`字符串[i]` 按 **UTF-8 字节**
  索引、结果类型 **整8**（带符号字节值——与 IR 层 i8 符号扩展装载自 A-1 起一致；原「字符」标注
  与本节「字符=Unicode 标量值」定义矛盾，属规范空白，本轮关闭）。下标须为整型；越界=运行期
  错误码 2（与数组同通道·T4 防线）。**与 `字符` 的分工**：`字符`=完整 Unicode 标量值（4 字节）；
  字节碎片经 `字符转字符串`（值 <0 或 ≤0xFF 单字节直放——U+0080~00FF 边界按单字节直放，
  T40 双来源兼容临时态本轮闭合为明文口径）重建多字节序列；码点路径（>0xFF）按 UTF-8 编码。
  例：`"内存好"`（9 字节）的 `s[0]`=-27、`s[4]`=-83；`字符转字符串(s[6])+字符转字符串(s[7])
  +字符转字符串(s[8])`=`"好"`。
- `空类型` 对应C++的 `void`，同时用于空指针类型（见复合类型-指针）。

## 五、复合类型

### EBNF

```
复合类型 = 指针类型 | 数组类型 | 结构体类型 | 枚举类型 | 函数指针类型 | 联合体类型
指针类型 = 类型, "*"
数组类型 = 类型, "[", 长度, "]"
结构体类型 = "结构体", 标识符, "{", 字段列表, "}"
枚举类型 = "枚举", 标识符, "{", 枚举成员列表, "}"
联合体类型 = "联合体", 标识符, "{", 字段列表, "}"
函数指针类型 = 返回类型, "(*", 标识符, ")", "(", 参数类型列表, ")"
```

### 复合类型表

| 类型 | 语法 | 说明 |
|------|------|------|
| 指针 | 类型* | 指向类型的指针 |
| 数组 | 类型[长度] | 固定长度数组 |
| 结构体 | 结构体 名 { ... } | 自定义结构体 |
| 枚举 | 枚举 名 { ... } | 枚举类型 |
| 联合体 | 联合体 名 { ... } | 所有字段共享同一内存区域，同一时间只有一个字段有效 |
| 函数指针 | 返回类型(*名)(参数) | 函数指针 |

### 示例代码

```
整32* 指针变量              // 指向整32的指针
整32[10] 数组变量           // 10个整32元素的数组

结构体 点 {
    浮64 x
    浮64 y
}

枚举 颜色 {
    红,
    绿,
    蓝
}

联合体 数值 {
    整32 整数部分
    浮64 浮点部分
}

整32(*回调)(整32, 整32)     // 函数指针
```

### 设计决策

- **指针+手动内存管理**（决策5）：与C/C++一致，提供完整指针运算（取地址`&`、解引用`*`、成员访问`.`——v2.1 成员访问统一，`->` 已废除）。
- **取地址语义一致化（2026-09-21 用户裁决甲·588-a）**：`&类变量`（含顶层静态类变量）产**对象地址**——类变量为指针槽模型（变量槽存句柄），取地址=解包句柄（Load 槽），与 `类名*` 类型标注一级语义对齐（C++ `&obj` / Rust `&T` 对照）；`点* p2 = &p1;` 后 `p2.x`、`p2.方法()`、`p2.x = v` 均作用于 p1 对象本身。`&结构体变量`/`&标量变量` 维持槽地址（值类型槽=存储本身）。`T&` 引用形参的实参自动取地址为编译器内部机制（形参槽存被引用左值地址），与用户级 `&` 表达式语义无关。
- **联合体**：源语言层面可用，同时编译器内部用于结果/可选类型降级（见[07-错误处理.md](07-错误处理.md)）。
- **函数指针采用C风格声明**：`整32(*回调)(整32, 整32)`，与C/C++保持一致，便于底层编程人员理解（见[04-函数与函数指针.md](04-函数与函数指针.md)）。

## 六、错误处理类型

### EBNF

```
错误处理类型 = 结果类型 | 可选类型
结果类型 = "结果", "<", 正常类型, ",", 错误类型, ">"
可选类型 = "可选", "<", 类型, ">"
```

### 错误处理类型表

| 类型 | 语法 | 说明 |
|------|------|------|
| 结果 | 结果<正常类型, 错误类型> | 正常值或错误值（错误码） |
| 可选 | 可选<类型> | 有值或无值 |

### 示例代码

```
函数 除法(整32 a, 整32 b) -> 结果<整32, 整32> {
    如果 b == 0 {
        返回 错误(1)   // 错误码1: 除零错误
    }
    返回 正常(a / b)
}

函数 查找(整32 键) -> 可选<整32> {
    如果 表.包含(键) {
        返回 某些(表[键])
    }
    返回 无
}
```

> 详细规则见 [07-错误处理.md](07-错误处理.md)。

## 六B、类型大小 内建（2026-08，A-3）

### EBNF

```
类型大小 = "类型大小", "(", 类型名, ")"
```

### 规则

- **内建编译期求值表达式**（C++ `sizeof` 运算符等价物），**不是函数**：由编译器直接求值为字节数常量（整64），不产生函数调用、不可取地址、不可作函数指针。
- 参数为类型名（基础类型/结构体/数组/指针/限定类型 `模块::类型`/泛型参数 `T`）；泛型上下文中按实例化实参类型求值。
- 典型用途：容器按元素真实大小分配（`容量 * 类型大小(T)`）。

### 示例代码

```
打印行(类型大小(整32))          // 4
打印行(类型大小(整128))         // 16
打印行(类型大小(字符串))        // 8（指针）
结构体 点 { 整32 x; 整32 y }
打印行(类型大小(点))            // 8
```

## 七、隐式类型转换

### EBNF

```
隐式转换规则:
  字符 ↔ 整数
  字符串 -> 字符*（A2 收紧：借用->拥有反向须显式 字符串复制）
  空类型* ↔ 任意指针
  整数 -> 整64（宽化）
  浮32 -> 浮64（宽化）
  数值 -> 字符串（仅 + 拼接上下文）
  混合符号隐式转换禁止（二元运算/赋值/传参/返回面变量间须显式转换；字面量豁免）
```

### 转换规则表

| 源类型 | 目标类型 | 转换方向 | 说明 |
|--------|---------|---------|------|
| 字符 | 整数 | 双向 | 字符↔整数 |
| 字符串 | 字符* | 单向（拥有→借用自动） | 字符串→字符指针（A2 收紧：反向须显式 字符串复制） |
| 空类型* | 任意指针 | 双向 | 空指针↔任意指针 |
| 整数 | 整64 | 单向宽化 | 默认整数类型扩展 |
| 浮32 | 浮64 | 单向宽化 | 单精度扩展为双精度 |
| 数值/布尔/字符/枚举 | 字符串 | 单向（仅 `+` 拼接） | `字符串 + 数值` 隐式拼接（等价 `整数转字符串/浮点转字符串/字符转字符串`；布尔转换对应 `布尔转字符串`（`__cn_str_from_bool`，输出 `"真"/"假"`）） |

### 设计决策

- 隐式转换遵循"安全优先"原则：仅允许无损或宽化转换，禁止窄化转换（如整64→整32）隐式进行，需显式标注。
- 指针与整数之间禁止隐式转换，防止类型混淆（与C++不同，更严格）。
- **数值→字符串**转换**仅**在 `+` 拼接语境触发（左操作数为 `字符串`/`字符*`），不参与其他算术/比较上下文；多操作数左结合（`"a" + 1 + 2` 等价 `(("a" + 1) + 2)`）。
- **混合符号隐式转换禁止**（2026-09-10 方案A，Rust 对齐；二元面=第五十一轮、赋值/传参/返回面=第五十六轮，权威条文 plans/001 §3.7）：有符号（整N）与无符号（正M）**变量间**的二元运算（比较/算术/位运算）、赋值初始化/赋值、函数传参/返回均编译期拒绝，须显式 `类型名(表达式)` 构造转换——隐式宽化在混合符号下静默改变值语义。**字面量豁免**：一侧为整数字面量（含 `-1` 形态）时按另一侧类型参与（`大 > 100`、`正64 b = 5`、`读值(100)` 等惯用形态保留）。同符号混合宽度（正32 与 正64 等）维持宽化放行；字符 ↔ 整数互通不受影响。
- **显式类型转换的位模式语义**（2026-09-10 第五十五轮 ④文档化，Rust `as` 对齐，权威条文 plans/001 §3.7）：`类型名(表达式)` 构造转换在整数族间定义为位模式变换（零运行时开销）：**升宽**——有符号源符号扩展（`正64(整32(-1))` = `2^64-1`）；无符号源零扩展（`整64(正32(4000000000))` = `4000000000`）。**同宽跨符号**=位模式重解释（`整64(正64(2^63))` = `-2^63`）。**降宽**=低位截断。窄宽（整8/整16/正8/正16）先按位宽扩展再按上述规则。
