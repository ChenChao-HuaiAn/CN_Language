# P7b②：v2 容器类型实例化与容器方法调用全链路（标量+字符串元素闭环）

## 背景与路线（已核实）

「IR 层 运行时错误(7)」与「解析类型 只认 标识符+*」是 **v2 编译器自身**的缺口（`CN语言编译器v2/IR生成.cn:425` 成员调用直接中止；`语法分析.cn:450` 不认泛型），非宿主缺陷（宿主链路 E2E 30/31 已通）。

**路线**：v2 生成对宿主类方法符号的直接调用（`向量$整64$追加#整64` → nameMangle `?E59091E9878F24E695B4363424E8BFBDE58AA0@@YJ@Z`），链接 `cn build` 编译 v2 组件时产出的 `target/audit2/v2p.obj`（stdlib 源码级并入、内含全部容器方法机器码）。rustc 链接预编译 std 的同款模式；③ 对拍（v2 编译 7 组件→链接）可直接沿用（79 闭环 /FORCE:MULTIPLE+符号自检同款）。

**本轮范围**：向量<整32/整64/字符串> + 映射<整64,整64> 局部变量全生命周期：构造/追加/元素/大小/删除/清空/设置/获取 + `结果<T,整32>` 接收（.正常/.值）+ RAII 析构。结构体元素（向量<Token>）、嵌套容器、容器字段/传参/返回值、`&` 引用参数、静态容器 → ②b 下轮。

宿主契约（已提取，照抄即可）：类对象=8字节指针槽；NewObject=`__cn_object_new(24)`；构造 `向量$整64$向量(this)`；this=参数位0；返回 `结果` 的方法 rcx=隐藏返回指针、this 后移 rdx；`结果<空类型,整32>`=12B（.正常@0 i32、.值@4）、`结果<整64,整32>`=16B（.值@8）；RAII=入口置零+返回前 DeleteObject（析构调用+`__cn_object_delete`，空指针 test/je 跳过）；容器方法全部直接调用无虚表。

## 实施步骤

### 1. 语法分析.cn
- `解析类型`：标识符后消费 `<实参,...>`（类型位置无歧义，直接平衡扫描；实参递归 `解析类型`），**直接合成 mangled 类型名**并驻留：`向量$整64`、`映射$整64$整64`、`结果$空类型$整32`；后缀 `*` 指针层与 `&` 引用编码进 附加（指针层 | 引用<<8，`&` 本轮仅登记不崩）。
- 变量声明检测（`解析语句` 554 行处）：前瞻「标识符 `<` 平衡闭合后是标识符」→ 声明路径（防 `a < b` 表达式误判）；构造初始化 `= 向量<整64>()` 自然进已有 `=` 分支。
- 构造调用表达式：`解析原子`/`解析后缀链` 识别 `名<实参>(` 形态 → 合成标识符节点（文本=合成名 `向量$整64`），后续 `()` 走已有调用节点。
- 方法调用链 `表.追加(x)` 语法已有（节点_成员+节点_调用），无需改。

### 2. 语义分析.cn（轻量）
- 容器变量（类型名基名 ∈ {向量,映射,链表,栈,队列,集合,结果,可选}）成员访问/方法调用不报未声明；调用返回类型查内置方法表。

### 3. IR生成.cn（核心）
- 新类型码 `T_对象=9`（8 字节指针槽）；新操作码：`IR_分配对象=60`（附加=类名ID、类型=对象大小）、`IR_结构体拷贝=61`（源地址/目标地址/类型=字节数）、`IR_删除对象=62`（对象指针寄存器、附加=类名ID）、`IR_调用参数化=63`（附加=符号ID、操作数1=实参数、操作数2=实参寄存器区起点【函数IR 新增 向量<整64> 调用参数区】、操作数3=retbuf 槽(0=标量返回)、目标=返回寄存器）——一次到位支持 4 参数位与隐藏返回指针，为③任意参数数铺路。
- `函数IR` 新增：`映射<整64,整64> 变量类型`（变量名ID→类型名ID）、`向量<整64> 调用参数区`、retbuf 用普通槽机制（`IR_分配` 2 槽，复用现有帧扫描）。
- 变量声明（容器类型）：1 槽 + 登记 变量类型 + 函数入口零初始化（Store 0）；初始化=构造调用 → `IR_分配对象`+构造调用(this)+`IR_存储`；裸声明同样 NewObject+无参构造（H7 同款）。
- 方法调用（`节点_调用` 被调=成员 且 对象变量类型是容器）：弹 this（对象槽 Load）+实参 → 内置方法签名表（类基名+方法名+实参数 → 参数类型串按 T 实例替换 + 返回形态标量/结果）→ 符号 `类$方法#参数串`；结果返回 → retbuf 槽 + `IR_调用参数化`；`结果<T,E> r = ...` 接收 → `IR_结构体拷贝` retbuf→r 槽（r=2 槽）；丢弃返回值合法。
- `r.正常`（偏移0 i32）/`r.值`（偏移4 或 8，按 T）成员访问读。
- RAII：每个 `IR_返回` 前，对本函数全部容器局部 Load+`IR_删除对象`。
- 删除 `运行时错误(7)` 兜底（改为对真正未知形态报 6 号无效参数并打印诊断）。

### 4. 代码生成.cn
- `符号修饰` 重写为宿主同款 nameMangle：`#` 切分参数串、类型编码表（整32=H 正32=I 整64=J 正64=K 浮64=N 字符串=PAX 空类型=X 布尔=_N 类/结构体=_T+hex、&=A 前缀）、`@@Y[编码]@Z`、`主→cn_main`、`__cn_` 原样；向量$字符串 元素参数类型=字符串(PAX)。
- `IR_分配对象`：`mov rcx,大小 / sub rsp,32 / call __cn_object_new / add rsp,32 / mov 目标,rax`。
- `IR_调用参数化`：实参区逐个装载 rcx/rdx/r8/r9（retbuf 为 `lea rcx,变量槽`）+ 影子空间 + call + `mov 目标,rax`。
- `IR_结构体拷贝`：`mov rdi/rsi/rcx(len), rep movsb`（v2 不用 rdi/rsi，安全）。
- `IR_删除对象`：`mov rcx,对象 / test rcx,rcx / je @N / call ~类(rcx) / mov rcx,对象 / call __cn_object_delete / @N:`。
