# 阶段 P7a：顶层常量声明全链路 + 跨模块常量引用（v2 自举第三步之①）

## 背景与范围

v2 自举重建 P1~P6 完成（P6h 多源文件，E2E 119 闭环）。按 HANDOFF「下一步」进入 P7 自举闭环第一切片：**顶层 `常量 名 = 值` 全链路支持**。这是 v2 编译自身的硬缺口——7 个 v2 组件源码共 84 处顶层常量（已验证全部为整数字面量形态，规格书 5.2：`常量 PI = 3.14` 类型推断式）。

### 5. IR生成.cn
- 模块级 `静态 映射<整64,整64> 常量表`（名ID → 值文本ID），`IR生成多文件`/`IR生成` 入口清空并收集
